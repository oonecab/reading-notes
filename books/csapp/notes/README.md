## 内容和阅读

沿原书问题组织连续叙述：具体困难、作者的处理、关键例子、公式或程序推演与边界。习题用 `details.exercise`，题干及全部小问、数据、输入代码先于 `div.answer`；数字结果给出代入，状态题给变化过程，编程题提供可执行方法及解释。教材疑点保留原条件与校注。

页面共同使用原两书的纸色、字号和组件，左目录定位大节，宽屏右栏显示两条小节阅读注解，窄屏原位展开。数学为静态 MathML，图为内嵌 SVG/状态表，代码与图表在本容器内滚动。保留原文件名和全部既有锚点。代码与计算的独立验证、原书内容审阅、浏览器阅读效果分别验收，工作记录见根 I003/P003/T003/M003。

完整程序和长代码片段遵循 [RN-001 v1.7](../../../docs/reading-notes-standard.md) 的原生折叠约定。C/Python 代码对保留既有默认状态；独立的完整汇编及性能基准收起，至少 12 行的汇编、HCL、伪代码和命令讲解片段默认展开且可收起。原题程序随题干完整呈现，运行输出保留在解释旁。折叠摘要标明语言和用途，原代码锚点与下载保持可用。

2026-10-16 的全书解释修订见 [逐项审阅记录](explanation_review.json) 与 [T018](../../../test/T018-csapp-explanations.md)：正文、419 道原书题解、36 道自测和实验说明逐项读回，补充 109 处具体推演，并展开第 5 章指针别名示例。重点是对象身份、读写顺序、公式各项的来源及条件使用。新增的例子和解释属于伴读，原题、原文及来源继续保留。审阅记录分别列出内容判断、原书抽查、执行回归与桌面／390px 阅读证据。

同日的全书图表与章节导航复核见 [图表审阅记录](visual_navigation_review.json) 与 [T019](../../../test/T019-csapp-visual-navigation.md)：逐项读回 58 幅图及其图注、363 张表，核对箭头、单位、条件和链接目标。修订覆盖硬件连接、DRAM 行列选择、异常返回、描述符共享、socket 两端及事件循环分支；总览的逐章推演表补齐第 1—12 章入口。全部图表进行浏览器布局扫描，图形逐幅目视阅读，窄屏另查局部滚动和实际点击。维护检查按原书章节清单验证导航完整性，图意和阅读效果保留独立审阅证据。此前内容、执行和页面哈希仍按各自批次解释，新修订另行绑定。

## 原文与重要原理

第一批八页保留 78 处英文原文与中文陈述，页内索引与[全书摘录索引](book_overview.html#source-reading)可以直接定位。第 2 章覆盖全部 25 条 `PRINCIPLE` 的原标题、条件、结论和原式；原书为公式编号、未给这些原理另编序号，页面沿用这一结构。经典段落放在相关机制旁，接着说明适用条件、推导与例子。印刷页与 PDF 页序、转录文本及原式记录在[原文来源清单](source_excerpts.json)。

英文引文、中文翻译或陈述、笔记解释分别标示；组合不同段落时说明摘录范围。定宽等式保留数学模型与 C11 语言规则的边界。`equation` 和 `math-block` 共用块公式样式，长式在自身容器滚动；`math-inline` 用于正文中的变量和短式，代码中的语言运算符保持原样。短值表采用自然宽度；较长的公式和图表出现横向溢出时显示滑动提示，也可以聚焦后使用方向键查看。

本轮原文与模型修订记录见根 I004/P004/T004/M004。源码读取导图连接第 4、6 章模拟器的状态、单步处理、提交/失败路径与统计。程序验证覆盖流水统一寄存器开销、Python 容器长度与失败契约、缓存写策略及关闭断言后的实际填充验证；原文复核与 Chrome DevTools MCP 阅读验收分别记录，历史执行和历史页面哈希保留其原有范围。

78 条原文、译义和条件的逐条复核依据见[原文伴读审阅](source_reading_review.json)，浏览器范围与实际交互见[阅读验收](reading_review.json)。逐章记录中的 `source_reading_revision` 绑定本轮页面，原有逐题审阅仍保留当时的页面哈希和实际范围。
