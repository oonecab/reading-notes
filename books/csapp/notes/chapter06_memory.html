第 4 章把内存访问抽象成一个固定时长的阶段；这一章拆开这个假设。寄存器由指令中的寄存器名指定；普通内存读取则给出地址，先由 SRAM 缓存查找，未命中再向下层请求，必要时访问 DRAM。寄存器不是内存地址查找中的一级缓存。若所需虚拟页尚在磁盘上，操作系统先处理缺页，把页面调入主存，然后重新执行访问；第 9 章会补全这一步。理解层次结构，要同时追踪“数据存在哪里”和“下一次访问会用到刚搬来的哪一部分”。书中的产品价格、容量与带宽是成书时的历史样例，下面用它们推导机制，不把它们当作当前硬件报价。

6.1.1 · RAM 的单元、阵列、模块与总线Random Access Memory

SRAM：反馈保持；DRAM：电荷保持

SRAM 用双稳态电路保存一位，典型单元需要六个晶体管；只要供电，反馈会把小扰动拉回原稳定状态。DRAM 用一个电容和一个访问晶体管保存电荷，密度高，但电荷泄漏要求周期性读出再写回。这里“静态”表示无需刷新，不表示断电还能保存；SRAM 与 DRAM 都是易失存储。

技术保存机制必须付出的代价本章典型用途
SRAM双稳态反馈更多晶体管、较低密度与较高成本L1/L2/L3
DRAM电容电荷刷新、行列激活时序主存与帧缓冲

图 6.2 的 Persistent 一栏描述持续供电时是否稳定，不能翻译成断电持久化。ECC 再加入校验位，例如把 64 数据位编码成 72 位，以检测并纠正指定类别的位错误；它不改变程序可用数据字的宽度。

二维 DRAM 与 RAS/CAS

d×w 芯片有 d 个超单元，每个超单元 w 位，总容量 dw 位。排成 r 行、c 列后 rc=d；地址脚先传行号，再传列号，所以所需脚数是 max(log2r,log2c)，不是二者相加。RAS 选择整行并送入内部行缓冲，CAS 再从缓冲中选一个超单元。16×8、4×4 的例子只需两根复用地址线；若一拍传完整 4 位索引则要四根。

模块宽度与改进型 DRAM

八片 8M×8 芯片并联时，同一个 (i,j) 广播给八片，每片提供一个字节，合成 64 位。容量为 8×8M×8 bit=64 MiB；增加芯片不是把一个字节读取八次。若还有多个模块，控制器先根据地址选择模块，再选择行列。

技术保留的基本单元增加的吞吐机制
FPMDRAM首次 RAS/CAS 后连续发 CAS，复用已打开的行
EDODRAM缩短相邻列访问的间隔
SDRAMDRAM以共同外部时钟安排传输
DDR SDRAMDRAM两个时钟边沿传输，并使用预取缓冲
VRAMDRAM按序输出帧缓冲，支持显示读取与更新写入并行

行缓冲的复用已是局部性的一个实例：连续读相同行中的邻居比反复切换行更容易摊销准备工作。DDR 的“每秒传输次数”与核心时钟频率也要分开，不能把双边沿简单当成所有访问延迟减半。

非易失存储与固件

ROM 是历史总称，包含不能改写的存储以及可编程类型。PROM 用一次性的编程机制；EPROM 可经紫外线整片擦除；EEPROM 可电擦写；闪存把电擦写组织成页和更大的擦除块。存储的启动程序或设备控制程序称为固件，术语描述软件的存放与部署方式，不代表程序不可能更新。

总线同时需要地址、数据和控制信息；物理线上可以复用不同阶段的信号。图 6.6 的 I/O bridge 是教学抽象，不要求每台机器真有一个独立北桥芯片。一次请求的延迟与多个请求重叠后的带宽是不同指标。

6.1.2 · 旋转磁盘：容量是几何，时间是机械运动Disk Storage

盘片、盘面、磁道、扇区与柱面

每个盘片通常有两个记录面；一个面上同心圆形成磁道，每条磁道再分扇区。所有盘面上半径相同的磁道合称一个柱面。因此 15,000 个柱面、6 个盘面就是 90,000 条磁道，不能再额外乘一次“柱面数”。分区记录允许外圈磁道含更多扇区；容量计算使用每道平均扇区数。

容量=字节扇区×平均扇区数磁道×磁道数盘面×盘面数盘片×盘片数

例：磁盘容量的单位换算

例如 512×300×20,000×2×5=30,720,000,000 字节，即 30.72 GB。磁盘标称容量使用十进制 GB=109 字节；缓存容量常用 KiB=210 字节。涉及完整扇区的文件题若只写 MB，需要把这一口径明确写在计算前。

寻道、旋转等待与传输

T转一圈=60000RPM msT平均旋转=30000RPM msT扇区传输=60000RPM×每道扇区数 ms

单个随机扇区的平均访问时间是 T寻道+T平均旋转+T扇区传输。12,000 RPM、5 ms 寻道、每道 300 扇区时为 5+2.5+0.016667=7.516667 ms。第一次定位昂贵，连续扇区随后可按旋转流过磁头；不能为每个连续字节重复收费，也不能把随机块都按一次定位收费。

逻辑块、控制器和 DMA

操作系统给磁盘逻辑块号；控制器把它映射为实际盘面、磁道、扇区并处理坏块和保留空间。CPU 向内存映射 I/O 寄存器写入命令、逻辑块号和目的主存地址；设备随后通过 DMA 把数据搬进主存，完成后以中断通知 CPU。CPU 可以在等待期间处理其他工作。DMA 省掉逐字节搬运的 CPU 指令，不等于整次 I/O 没有控制、总线占用或同步代价。

平均“半圈”需要怎样的假设

在随机扇区访问模型里，磁头到达目标磁道后，目标扇区相对于磁头的相位近似均匀：有时几乎立即遇到，有时刚错过、要等接近一整圈。等待时间在 0 到一圈时间之间均匀，平均才是一圈的一半。12,000 RPM 表示一分钟转 12,000 圈，先用 60,000 毫秒÷12,000=5 毫秒/圈 换单位，再除以 2 得 2.5 毫秒。这一步不包含寻道，也不包含数据真正流过磁头的传输时间。

6.1.3 · SSD 把机械定位换成页写与块擦除Solid State Disks

闪存读写单位是页，擦除单位是包含多页的块。已经编程的页不能简单覆盖：控制器通常把新版本写到已擦除的空闲页，更新逻辑到物理的映射，随后回收旧块；回收要搬走仍有效的页再擦除。因此一次逻辑写入可能造成多次物理读写，这就是写放大的来源。FTL 还用磨损均衡分散擦除次数。随机读取不需要磁头寻道；随机更新仍可能触发回收，不能从“无机械部件”推得读写代价相同。

书中 SSD 730 的 128 PB 耐写量、470/303MB/s 吞吐用于习题 6.5。按 365 天一年，它们对应连续写约 8.64/13.40 年；这是给定总写入预算除以给定速率的数学值，实际设备寿命还受具体介质、写放大与负载影响。

6.1.4 · 容量增长不等于访问延迟同速下降Storage Technology Trends

书中 1985—2015 数据显示：DRAM 单位容量价格下降 44,000 倍，访问延迟只改善约 10 倍。处理器可以在一次慢访问完成前发出更多工作，便需要缓存来保留高频数据，也需要带宽支持并行请求。把单核周期除以核数只是在特定并行假设下描述总吞吐，不能用来声称单个依赖链的延迟也按核数缩短。

阅读注解
单位

容量先统一到字节

位宽、超单元数与芯片数分别负责不同维度；磁盘十进制 GB 和缓存二进制 KiB 应在公式中明确。

理解

延迟与带宽可以分别改进

一条请求要等多久，与连续请求每秒能完成多少，不是同一个量。行缓冲、突发传输和 DMA 都说明了这种区别。

6.2 · 把循环展开成地址顺序Locality

来源：印刷 640—645 页 / PDF 641—646 页

原书原理 · 局部性描述访问倾向

Well-written computer programs tend to exhibit good locality. That is, they tend to reference data items that are near other recently referenced data items or that were recently referenced themselves.

中文陈述。有良好局部性的程序，倾向于很快再次访问已用过的数据，或访问刚用过数据附近的位置。前者是时间局部性，后者是空间局部性；这是访问模式的倾向，是否命中仍要结合具体缓存状态判断。

下面的向量求和用反复更新的 sum 说明时间局部性，用连续的 v[i] 说明空间局部性；二维数组的行列地址表进一步把这种倾向变成可计算的字节跨度。

原书 §6.2，印刷 640 页 / PDF 641 页。

6.2.1 · 用地址序列判断数据局部性Locality of References to Program Data

时间局部性是同一位置很快再次被使用；空间局部性是附近位置很快被使用。向量求和中 sum 每轮更新，具有时间局部性并通常留在寄存器；v[i] 每个元素只读一次，缺少逐元素重用，却以连续地址获得空间局部性。步长以元素为单位还是以字节为单位必须说明：4 字节 int 的 stride-3 是 12 字节。

访问方式int a[2][3] 的字节地址顺序相邻跨度
按行0,4,8,12,16,20通常 4 字节
按列0,12,4,16,8,20内层 12 字节

C 多维数组按最右下标最快变化的顺序存放：a[i][j][k] 的线性序号是 (i×N+j)×N+k。交换循环次序是否安全，要先检查依赖、别名与数值运算顺序；性能理由不自动授权改变程序语义。

6.2.2 · 取指也有局部性Locality of Instruction Fetches

直线指令按相邻地址获取，表现为空间局部性；循环多次执行同一小段代码，表现为时间局部性。过度展开会增大指令工作集，因此第 5 章通过展开获得的并行性也会在这里支付指令缓存容量的代价。

6.2.3 · 好的局部性是条件，映射仍会干预Summary of Locality

先写出最内层的地址增量，再找相同数据隔多少次访问重用。连续扫描通常较好，但两条连续流若始终落到同一直接映射组，仍会相互驱逐。局部性是程序访问模式；命中率还取决于块大小、容量、相联度和初始状态。

阅读注解
推导

先看最右下标

声明的布局决定线性地址，循环变量的名字没有特殊意义；a[j][k][i] 应让 i 最快变化。

边界

局部性不保证命中

同样的程序在不同映射、容量和块大小上有不同命中率，必须把参数带入计算。

6.3 · 用块传输摊销慢存储的代价The Memory Hierarchy

来源：印刷 645—650 页 / PDF 646—651 页

原书原理 · 上层保存下层数据的副本

In other words, each level in the hierarchy caches data objects from the next lower level.

中文陈述。存储层次中的较快、较小一层保存下一较慢、较大层的部分数据副本，让访问优先由较快层服务。层次之间遵循同一缓存思想，但搬运单位与管理者可以不同。

下面的层次表把寄存器、硬件缓存、主存页和文件缓冲放到各自管理方式中。寄存器由指令显式指定；这个层次思想并不意味着每条普通 load 都要按内存地址搜索寄存器。

原书 §6.3.1，印刷 647 页 / PDF 648 页。

6.3.1 · 缓存复制块并管理替换Caching in the Memory Hierarchy

层次 k 保存层次 k+1 的一部分数据副本。一次 miss 把包含目标地址的整个块向上复制；之后同一块里的其他字节也可能命中。不同相邻层次可用不同搬运单位：寄存器常按字，SRAM 缓存按几十字节，主存与磁盘之间按页或块。

层次示例保存的数据主要管理者
寄存器暂存变量和中间值编译器／指令
L1/L2/L3缓存块硬件
主存页虚拟地址空间的页MMU 与操作系统
文件缓冲文件块操作系统
浏览器缓存响应对象应用软件

冷 miss 是块首次使用时没有副本；冲突 miss 是位置限制使本可共存的块相互挤出；容量 miss 是活跃工作集超过可用行数。严谨区分后两者时，可以用相同容量的全相联 LRU 作参照：在实际缓存 miss、参照命中时归为映射冲突。非首次访问不必然是容量 miss。

6.3.2 · 小而快的层怎样服务大地址空间Summary of Memory Hierarchy Concepts

原书原理 · 一次搬块由后续访问分摊

Blocks usually contain multiple data objects. Because of spatial locality, we can expect that the cost of copying a block after a miss will be amortized by subsequent references to other objects within that block.

中文陈述。一个块通常含有多个数据对象。若后续访问及时使用同一块中的邻近对象，一次 miss 的整块搬运成本就由这些访问共同承担；收益取决于块被替换前能用到多少数据。

在 16 字节块、4 字节整数的连续扫描中，一次 miss 后的三个元素可以命中；若每次跨过整块，只取一个整数，同样的搬运量就服务更少的有用数据。

原书 §6.3.2，印刷 650 页 / PDF 651 页。

时间局部性让一次填入换来多次重用；空间局部性让一次块传输服务多个邻近对象。若命中耗时 h、miss 的额外代价为 p、miss 概率 r，每次访问先付出基础查找时间，只有 miss 再增加 p。在各次访问串行完成的模型中：

AMAT=(1−r)h+r(h+p)=h+rp

h=4 周期、r=0.05、p=100 周期得到平均 9 周期；具体访问分别付出 4 或 104 周期。这一平均值尚未计入乱序重叠和排队。

定义

块、行、组各司其职

块是传输的数据；行是保存块与标记的容器；组是一组可供同一块选择的位置。

计算

miss penalty 是额外部分

若下层延迟已含本层时间，就不能再把整段延迟当作额外罚时重复相加。

6.4 · 从地址分解推到替换和写策略Cache Memories

来源：印刷 650—669 页 / PDF 651—670 页

原书定义 · 块、行与组

A line is a container in a cache that stores a block, as well as other information such as the valid bit and the tag bits.

中文陈述。块是缓存与下层之间传输的数据单位；行是容纳一个块以及有效位、标记等信息的缓存容器；组则包含一个或多个可供映射到该组的块使用的行。

因此下面的数据容量等于组数×每组行数×块字节数，另需保存标记与状态。可配置缓存程序只模拟行的标记、有效位、脏位和替换状态，能够推导命中与流量。

原书 §6.5，Aside: Cache lines, sets, and blocks，印刷 670 页 / PDF 671 页。

6.4.1 · 地址切分是商与余数的硬件实现Generic Cache Memory Organization

记 S=2s 组、每组 E 行、每块 B=2b 字节、地址 m 位。数据容量 C=S×E×B，不包含有效位、标记、脏位和替换状态。令 q=⌊AB⌋，则块内偏移 CO=AmodB，组号 CI=qmodS，标记 CT=⌊qS⌋。对应位段为 [m−1:s+b]、[s+b−1:b]、[b−1:0]。

b=log2B,s=log2S,t=m−s−b
A=(CT×S+CI)×B+CO

E 不直接占地址位：组内哪一行保存某个块由标记比较决定。有效位为零时，即使保存着相同 tag 的旧位型也必须 miss。若一个访问跨越块边界，就要对覆盖的每个块分别查询；教材的一字节习题故意省掉了这层复杂性。

为什么地址里没有“第几路”

可把一个组想成一排只能接收某类块的空位。地址先确定这一排，组内各路再用 tag 判断有没有自己的块；它没有规定必须放左边还是右边。以 B=4,S=8,A=0x0D53=3411 为例，先除以 4 得块号 852、余数 3，再用 852÷8=106 余 4 得 tag 106（0x6A）、组 4。反算 (106×8+4)×4+3=3411，说明三个字段完整还原了地址。提高路数只增加组内候选位置，不需要再从地址切下一段“路号”。

“脏”描述的是缓存副本与下层副本不一致。例如地址 0 原为 10，写回缓存命中后把它改成 11，此时处理器再读应得到 11，下层仍可暂存 10；脏位记录这份更新尚须传下去。若直接丢弃这一行，就会丢掉程序的写入，所以淘汰前必须写回。只读过的干净行与下层一致，淘汰时便可直接丢弃。

        self.writebacks = self.read_bytes = self.write_bytes = 0

            raise ValueError('invalid reference')

static bool access_cache(struct cache *c, uint64_t address) {
    const uint64_t number = address / c->block;
    const unsigned int set = (unsigned int)(number % SETS);
    const uint64_t tag = number / SETS;
    struct line *rows = c->lines[set];
    ++c->clock;
    for (unsigned int i = 0; i < c->ways; ++i) {
        if (rows[i].valid && rows[i].tag == tag) {
            rows[i].age = c->clock; ++c->hits; return true;
        }
    }

    for (unsigned int i = 0; i < c->ways; ++i) {
        if (!rows[i].valid) { victim = i; break; }
        if (rows[i].age < rows[victim].age) victim = i;
    }

    ++c->misses; return false;
}

import re
import sys
class Cache:
    def __init__(self, ways=1, block=2):
        self.ways, self.block = ways, block
        self.sets = [[] for _ in range(4)]  # Oldest tag first.
        self.hits = self.misses = 0
    def access(self, address):
        number = address // self.block
        rows, tag = self.sets[number % 4], number // 4
        hit = tag in rows
        if hit:
            self.hits += 1
            rows.remove(tag)
        else:
            self.misses += 1
            if len(rows) == self.ways:
                rows.pop(0)
        rows.append(tag)
        return hit

def parse(s):
    if not re.fullmatch(r"[+]?[0-9]+", s):
        raise ValueError("decimal nonnegative integer required")
    value = int(s)
    if value > (1 << 64) - 1:
        raise ValueError("uint64 range exceeded")
    return value

6.22 · 固定每道位数时怎样选中心孔

原题（中文翻译）

来源：印刷 685 页 / PDF 686 页

设计旋转磁盘，使每条磁道位数相同。位数由最内磁道周长决定，可把它看作中心孔周长；加大孔能增加每道位数，却减少磁道数。盘片半径为 r，孔半径为 x·r，求使容量最大的 x。

解答

固定线密度 d 与径向磁道密度 k，单面容量近似 (2πxr·d)×((1−x)r·k)=2πdk r2x(1−x)，0≤x≤1。x(1−x)=1/4−(x−1/2)2，最大点 x=1/2。微分也得 1−2x=0、二阶导−2<0。这是固定每道位数的模型；分区记录允许外圈增加扇区后不再沿用同一目标函数。

6.45 · 实现并测量分块转置

原题（中文翻译）

来源：印刷 695—696 页 / PDF 696—697 页

把N×N的int源矩阵S拷贝并转置为D，使D[j][i]=S[i][j]。下列基线接受dst、src和dim，要求运用第5、6章方法构造尽可能快的版本。

void transpose(int *dst, int *src, int dim) {
    int i, j;
    for (i=0; i<dim; i++)
        for (j=0; j<dim; j++)
            dst[j*dim+i] = src[i*dim+j];
}

解答

在两矩阵不重叠、尺寸乘法与分配均有效的条件下，用16×16块让一小片目的行在短时间内反复使用。实际可运行版本见完整C11与Python；C教学文件用uint32_t固定每个元素4字节，下面给原int接口的同一循环。

C：分块矩阵转置
void transpose_blocked(int *restrict dst, const int *restrict src,
                       size_t n) {
    const size_t tile = 16;
    for (size_t ii=0; ii<n; ii+=tile)
        for (size_t jj=0; jj<n; jj+=tile) {
            size_t imax = n-ii < tile ? n : ii+tile;
            size_t jmax = n-jj < tile ? n : jj+tile;
            for (size_t i=ii; i<imax; ++i)
                for (size_t j=jj; j<jmax; ++j)
                    dst[j*n+i] = src[i*n+j];
        }
}

每个(i,j)属于唯一块，仍只复制一次，时间O(n2)、额外空间O(1)。imax/jmax处理n非16倍数的边缘。restrict表达源目的不重叠；若允许重叠，应选择另一种原地转置算法，不能直接调用此版本。

6.46 · 对称块配对的图无向化

原题（中文翻译）

来源：印刷 696 页 / PDF 697 页

有向图g有N个顶点，以N×N、元素0或1的邻接矩阵G表示。无向图g′在u、v之间有边，当且仅当原图u→v或v→u存在。原题规定对角线全为1，并指出无向图矩阵对称。给定基线如下，构造尽可能快的转换。

void col_convert(int *G, int dim) {
    int i, j;
    for (i=0; i<dim; i++)
        for (j=0; j<dim; j++)
            G[j*dim+i] = G[j*dim+i] || G[i*dim+j];
}
题干校注：“邻接矩阵对角总是1”不是一般图论性质，而是本题附加输入约定。转换不应凭空为原图没有的自环置1。

解答

对每对i<j，只需读取原G[i][j]与G[j][i]、作一次OR，再同时写回两处。不同无序顶点对不共享元素，因此原地执行不会污染未来所需输入。用成对16×16块限制两条转置访问流的活跃范围：

C：邻接矩阵对称化
void undirect_blocked(int *G, size_t n) {
    const size_t tile = 16;
    for (size_t ii=0; ii<n; ii+=tile)
        for (size_t jj=ii; jj<n; jj+=tile) {
            size_t imax = n-ii < tile ? n : ii+tile;
            size_t jmax = n-jj < tile ? n : jj+tile;
            for (size_t i=ii; i<imax; ++i) {
                size_t first = jj > i+1 ? jj : i+1;
                for (size_t j=first; j<jmax; ++j) {
                    int v = G[i*n+j] | G[j*n+i];
                    G[i*n+j] = v;
                    G[j*n+i] = v;
                }
            }
        }
}

输入元素限定为 0 或 1，因此按位 OR 的结果仍是 0 或 1，与逻辑 OR 的结果相同。这里的 | 会求值两个操作数：同一对只处理一次，源码层面非对角元素总读 n(n−1)、总写 n(n−1)，对角保持不动；基线对整个n2区域重复计算对称关系。块内first=max(jj,i+1)同时排除下三角和对角，尾块取min边界。完整下载版本使用uint32_t的0/1元素，按位OR与逻辑OR在该输入域等价。
