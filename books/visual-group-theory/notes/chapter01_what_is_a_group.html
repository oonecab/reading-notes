1.1 一件著名的玩具 · A famous toy

来源：印刷 3 / PDF 18

魔方的吸引力在于规则容易学，打乱以后却很难恢复。Carter 从这件玩具开始，是因为它让我们直接面对一种数学结构：每次转动是一个动作，连续转动是动作的组合，而恢复原状需要寻找撤销这种组合的方法。

先固定观察方向和魔方中心块的位置，把每个面的顺时针四分之一转看作基本动作。一个面顺时针转两次，就是半转；转三次与逆时针转一次效果相同；转四次则回到原状。这里研究的是这些转动对整个魔方配置的作用，因而需要分清当前颜色排列与改变排列的动作。

原书图 1.1—1.2 展示完整魔方及连续转动。为了先把关系算清，本笔记用两枚不同硬币 A、B 做一个更小的原创示意。状态只有“左 A 右 B”和“左 B 右 A”；动作 s 则是“交换两个位置”。

AB 是我们此刻看见的状态，s 是可在两个状态上执行的规则。把状态与规则分开，才能讨论“交换两次是什么动作”，以及“两个不同的操作序列是否其实做了同一件事”。

理解与边界

固定什么，才知道改变了什么

魔方例子固定整体朝向，硬币例子固定左、右位置，并区分 A 与 B。若把整个物体的转动也算进去，或不再分辨硬币，讨论的状态空间和可识别动作就会改变。

1.2 观察魔方 · Considering the cube

来源：印刷 4–5 / PDF 19–20

Observation 1.1

There is a predefined list of moves that never changes.

中文陈述：预先约定一份固定的基本动作清单，清单不随进行过程改变。

来源：印刷 4 / PDF 19

象棋的一步是否合法会受到棋盘局面影响；魔方某一面的转动则不会因为先前转过其他面就失去资格。这不是说魔方只有六个动作效果，而是说六种基本指令能反复用来生成更多动作。

Observation 1.2

Every move is reversible.

中文陈述：每个动作都能撤销。

来源：印刷 4 / PDF 19

硬币交换 s 的撤销动作还是 s。魔方某面顺时针转动 r 的撤销可以用三个同方向四分之一转实现。因此“撤销”不要求另发一条新指令，但必须真正恢复每一个受影响的位置。

Observation 1.3

Every move is deterministic.

中文陈述：每个动作都是确定的：给定完整起始状态和动作，结果唯一。

来源：印刷 5 / PDF 20

确定性并不要求我们擅长解魔方，也不要求结果容易心算。它只要求同一个起始配置经过同一个理想转动得到同一个结果。这里排除了手滑、机械损坏或随机投币决定转哪一面等额外因素。

Observation 1.4

Moves can be combined in any sequence.

中文陈述：动作可以按任意有限次序连接执行。

来源：印刷 5 / PDF 20

“任意”排除了做到一半突然没有资格继续的情况；“有限”说明一次复合包含有限步，群运算并不自动定义无限长操作的最终结果。已做 a 再 b，要撤销时必须先撤销 b，再撤销 a：后做的动作先拿掉，才会回到做 a 后的中间状态。

阅读注解
理解与边界

逆动作为什么倒着来

撤销 a 后 b 时，先做 b 的逆使状态退回“只做过 a”的位置，再做 a 的逆回到起点。这条中间状态链比记一个逆元公式更可靠。

1.3 研究对称 · The study of symmetry

来源：印刷 5–6 / PDF 20–21

平常说一个图形对称，往往只是在说“看起来一样”。群论把这句话变成可操作的问题：允许对对象做哪些变换，做完后又保留了哪些关系？一个正方形旋转四分之一圈后仍占据同一块区域，但四个角的位置可能交换了。不同的保持结构的变换，可以互相组合，也可以撤销。

魔方要稍作区分。转动一层通常改变颜色配置，它并不是把“已经还原的那一张颜色图”保持不动的几何对称；它是在全部合法配置之间进行可逆、确定的变换。第 1 章的四项观察把这类动作也带进研究范围。第 3 章再进一步说明怎样从具体对象提取对称群。

这样的抽象有实际收益：硬币、画作、几何图形的材质不同，动作的合成结构却可能相同。如果某条结论只使用固定动作、复合与撤销，就可以应用到所有符合这些条件的例子。第 2 章的 Cayley 图、第 4 章的乘法表，都是把这种结构显露出来的不同方式。

因此读者需要逐渐把注意力从“操作什么”移到“操作怎样相互作用”。这不会丢掉例子；恰恰相反，一个足够小、能完全列出的例子会帮助我们检查抽象语言有没有用错。

1.4 群的规则 · Rules of a group

来源：印刷 6–7 / PDF 21–22

Rule 1.5

There is a predefined list of actions that never changes.

中文陈述：预先确定一份固定的基本动作清单。

来源：印刷 6 / PDF 21

Rule 1.6

Every action is reversible.

中文陈述：每个动作都可撤销。

来源：印刷 6 / PDF 21

Rule 1.7

Every action is deterministic.

中文陈述：给定状态后，每个动作的结果都是确定的。

来源：印刷 6 / PDF 21

Rule 1.8

Any sequence of consecutive actions is also an action.

中文陈述：任意有限串接的动作，也整体视为一个动作。

来源：印刷 6 / PDF 21

作者把 move 改成 action，使语言适用于游戏以外的对象；更关键的变化在规则 1.8：它允许我们把“一连串动作”当作一个完整动作。这时要区分最初给出的生成元与生成出来的全部动作。只有生成元清单还不能告诉我们群里有多少个动作。

Definition 1.9

A group is a system or collection of actions satisfying Rules 1.5 through 1.8.

中文陈述：群（本章非正式定义）是满足规则 1.5—1.8 的动作系统或动作集合。

来源：印刷 7 / PDF 22

这是一种建立直觉的动作语言，第 4 章才给正式公理。本笔记在严谨推演时把状态放在一个固定集合里，把动作看成定义在全部状态上的可逆函数，并把在所有状态上效果相同的指令序列视为同一个动作。这个补充解释使“相同”“可逆”“复合”都有明确含义；它不把本章四条非正式规则伪装成四条相互独立的现代公理。

无限多个序列，为什么可能只有两个动作

在硬币例子里，s、sss、sssss 都交换两枚硬币；ss、ssss 则都保持位置不变。记保持全部状态不变的动作为 e。每两次相邻的 s 可以抵消，所以一个长度为 k 的串，只需看 k 是奇数还是偶数。

s2=e,s2m=e,s2m+1=ss²=e，s^(2m)=e，s^(2m+1)=s

这里 m 是非负整数。序列长度没有上界，但不同效果只有 e 与 s。更一般地，判定两个动作相同必须比较它们对所有状态的作用：例如一个正方形的中心点被许多不同旋转同时固定，单看中心点无法识别旋转。

完整推演：三幅画，两个交换，六个效果

令三幅不同的画为 A、B、C，位置固定为左、中、右。动作 a 交换左/中，动作 b 交换中/右；写 ab 时按时间从左到右执行，即先 a 后 b。若写成通常的函数记号，同一操作是 b∘ab∘a。这个约定在图、题解和程序中保持一致。

亲手试：次序会怎样改变结果

先点 a，再点 b，观察 BCA；重置后先点 b，再点 a，观察 CAB。也可以连续点两次同一个按钮，检查它怎样撤销自己。

ABC

当前指令序列：e；相同效果的代表：e。

代表字词最终排列从 ABC 出发逐步执行
eABC不操作
aBACABC → BAC
bACBABC → ACB
abBCAABC → BAC → BCA
baCABABC → ACB → CAB
abaCBAABC → BAC → BCA → CBA

这张表为什么已经完整？左边的位置有 3 种选择；选定后中间剩 2 种；最后一个位置只剩 1 种。因此不同排列总数是 3×2×1=63×2×1=6。表中找到了六个互不相同的排列，恰好达到上界，所以没有漏掉。

3!=3×2×1=63!=3×2×1=6

为什么这里能由六种排列推到六个动作？每幅画有独立标签，动作只重排固定位置。知道 ABC 被送到哪个排列，就知道原来每一个位置的内容被送到了哪里，从而唯一确定这个位置重排对其他排列的作用。这个理由专属于当前完整标记模型；一般群作用的状态数不等于群的阶。

表中 ab 得 BCA，ba 得 CAB，所以 ab 与 ba 是不同动作。两者都由同样两个生成元组成，区别只来自先后次序。相反，aba 与 bab 都把左右两幅对调、保留中间那幅，因而作为位置重排是同一个动作。

把复合与撤销走一遍

从 ABC 依次做 ab 得 BCA。逆着操作顺序再做 ba：先做 b，BCA 回到 BAC；再做 a，BAC 回到 ABC。这使用了 a、b 各自做两次都等于 e，而不是交换律。若错误地仍按 ab 的顺序撤销，BCA → CBA → CAB，反而没有回到起点。

三个动作的结合律也可直接理解：把 abc 分成“先 ab，再 c”或“先 a，再 bc”，实际执行始终是 a、b、c。括号只改变记账方式；交换 a、b 的位置才改变了发生顺序。函数复合的结合性，是动作模型里这一性质的依据。

程序怎样从生成元找到全部效果

程序用长度为 3 的排列记录状态，0、1、2 分别代表 A、B、C。队列最初只有 ABC 和空字词。每次取出一个尚未扩展的状态，依次尝试 a、b：若新状态已见过，就不再加入；若第一次出现，则保存它及到达它的字词。因为从任何已知状态出发的两个生成元方向都处理过，队列为空时便没有未发现的可达状态。

不重复加入状态的原因是：后续转移只由当前完整状态和下一条指令决定。若两个历史到达同一状态，此后接上相同字词，会继续得到相同结果。这里有限性又保证循环能停止：至多六种排列，每一种只扩展一次。a 总先于 b，因此首次发现的代表顺序稳定为 e、a、b、ab、ba、aba。

C 的数组是一个长度固定为 6 的小队列，用 head 表示下一项、count 表示已经发现的数量；新状态写入前检查容量。Python 用元组保存状态、列表记录队列，也进行线性查重。两版都只处理本例的三个不同对象；不是通用魔方求解器。

C11：固定容量队列与逐项比较
/* Three distinct pictures; words execute from left to right. */
#include <stdio.h>
#include <string.h>

enum { POSITIONS = 3, MAX_STATES = 6, WORD_CAPACITY = 7 };
typedef struct {
    int at[POSITIONS];
    char word[WORD_CAPACITY];
} State;

static void step(State *state, char action)
{
    int left = action == 'a' ? 0 : 1;
    int saved = state->at[left];
    state->at[left] = state->at[left + 1];
    state->at[left + 1] = saved;
}

static int same(const State *left, const State *right)
{
    for (int i = 0; i < POSITIONS; ++i)
        if (left->at[i] != right->at[i])
            return 0;
    return 1;
}

static void print_state(const State *state)
{
    for (int i = 0; i < POSITIONS; ++i)
        putchar("ABC"[state->at[i]]);
    putchar('\n');
}

int main(int argc, char **argv)
{
    State states[MAX_STATES] = {{{0, 1, 2}, ""}};
    if (argc > 2) {
        fputs("usage: actions [word of a and b]\n", stderr);
        return 2;
    }
    if (argc == 2) {
        for (const char *p = argv[1]; *p; ++p) {
            if (*p != 'a' && *p != 'b') {
                fputs("word must contain only a and b\n", stderr);
                return 2;
            }
        }
        for (const char *p = argv[1]; *p; ++p)
            step(&states[0], *p);
        print_state(&states[0]);
        return 0;
    }
    int count = 1;
    for (int head = 0; head < count; ++head) {
        const char actions[] = {'a', 'b'};
        for (int k = 0; k < 2; ++k) {
            State target = states[head];
            step(&target, actions[k]);
            int seen = 0;
            for (int i = 0; i < count; ++i)
                if (same(&states[i], &target))
                    seen = 1;
            if (!seen) {
                size_t length = strlen(states[head].word);
                if (count >= MAX_STATES || length + 1 >= WORD_CAPACITY) {
                    fputs("enumeration capacity exceeded\n", stderr);
                    return 1;
                }
                target.word[length] = actions[k];
                target.word[length + 1] = '\0';
                states[count++] = target;
            }
        }
    }
    for (int i = 0; i < count; ++i) {
        printf("%s ", states[i].word[0] ? states[i].word : "e");
        print_state(&states[i]);
    }
    return 0;
}
Python：同一状态模型与扩展顺序
#!/usr/bin/env python3
"""Three distinct pictures; words execute from left to right."""
import sys

IDENTITY = (0, 1, 2)


def step(state, action):
    if tuple(sorted(state)) != IDENTITY:
        raise ValueError("state must be a permutation of 0, 1, 2")
    if action not in ("a", "b"):
        raise ValueError("actions must be a or b")
    result = list(state)
    left = 0 if action == "a" else 1
    result[left], result[left + 1] = result[left + 1], result[left]
    return tuple(result)


def apply_word(word, state=IDENTITY):
    if tuple(sorted(state)) != IDENTITY:
        raise ValueError("state must be a permutation of 0, 1, 2")
    if any(action not in "ab" for action in word):
        raise ValueError("word must contain only a and b")
    for action in word:
        state = step(state, action)
    return state


def enumerate_actions():
    states, words = [IDENTITY], [""]
    head = 0
    while head < len(states):
        for action in "ab":
            target = step(states[head], action)
            if target not in states:
                states.append(target)
                words.append(words[head] + action)
        head += 1
    return list(zip(words, states))


def format_state(state):
    return "".join("ABC"[value] for value in state)


def main():
    if len(sys.argv) > 2:
        print("usage: actions.py [word of a and b]", file=sys.stderr)
        return 2
    if len(sys.argv) == 2:
        try:
            result = apply_word(sys.argv[1])
        except ValueError as error:
            print(error, file=sys.stderr)
            return 2
        print(format_state(result))
    else:
        for word, state in enumerate_actions():
            print(f"{word or 'e'} {format_state(state)}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

python3 actions.py
# e ABC
# a BAC
# b ACB
# ab BCA
# ba CAB
# aba CBA

python3 actions.py ab    # BCA
python3 actions.py ba    # CAB
python3 actions.py ''    # ABC

命令行参数只接受 a、b 的字词；空串表示不动，其他字符报错并以状态码 2 退出。C 的状态值始终在 0—2，固定数组的容量检查先于写入；Python 不需要整数近似。两版输出一致之外，还要与六个排列的独立枚举比较，并检查全部状态上的复合和非法输入。

理解与边界

从效果判断动作相同

在本例里，A、B、C 全部互异，所以 ABC 的完整去向决定位置重排。如果对象有重复标签或只观察一个点，两个不同动作可能看起来相同；那时必须扩大观察范围。

1.5.1 满足规则 · Satisfying the rules

习题 1.1 · 两枚硬币的交换

原书题意（中文转述）

把一枚 1 美分硬币与一枚 5 美分硬币并排放在桌上。只给出一个基本动作：交换这两枚硬币的位置。这个情形构成群吗？逐条检查四条规则，并解释结论。

来源：印刷 7 / PDF 22

解答与推演

构成群。规则 1.5：基本指令始终是同一个交换 s。规则 1.6：再做一次 s 就能撤销前一次。规则 1.7：每个起始排列经过 s 后只有一个结果。规则 1.8：可以连做任意有限次交换，任何一步之后仍可继续；整串的效果也算动作。

全部动作是 e 与 s；只把最初列出的单个生成元 s 当作全部动作会漏掉 e。两个效果的合成分别为 ee=e、es=s、se=s、ss=e，所以没有组合跑出这两项。原书附录印刷 261 / PDF 276 给出同样的四条核查。

习题 1.2 · 第三枚硬币保持不动

原书题意（中文转述）

在习题 1.1 的情形中，在右侧再放一枚 10 美分硬币。唯一的基本动作仍是交换 1 美分和 5 美分硬币的位置。这是群吗？

来源：印刷 7 / PDF 22

解答与推演

仍是群。动作清单、可逆性、确定性以及任意串接都与 1.1 相同；第三枚硬币被每个动作固定。全部效果仍然只有“不动”与“交换前两枚”，而非三枚硬币的所有六种重排。

如果把第三枚硬币的位置也视为可能改变的状态，本题生成的动作仍始终固定它，无法到达所有排列。群不要求从每个状态都能走到状态集合中的每一个其他状态；“动作系统是群”与“作用是传递的”是不同条件。

习题 1.3 · 五颗弹珠的边界

原书题意（中文转述）

设左口袋里有五颗弹珠。考虑两种动作：把一颗弹珠从左口袋移到右口袋，以及把一颗弹珠从右口袋移到左口袋。这是群吗？

来源：印刷 7 / PDF 22

解答与推演

不是。按题意只考虑这五颗弹珠，右侧初始为零。连续执行“左移到右”五次后，左边已空；第六次便无法执行。因此不能任意串接，规则 1.8 失败。这也正是原书附录印刷 261 / PDF 276 指出的原因。

写成状态 (左边颗数, 右边颗数)，路径是 (5,0) → (4,1) → (3,2) → (2,3) → (1,4) → (0,5)。在每一步可做的时候，反向移动确实能撤销它；问题在于它们只是有定义域限制的局部操作，无法在全部状态上统一执行。用正式函数语言说，两个方向都不是状态集上的处处有定义的双射。

习题 1.4 · 三幅画与不可逆合并

原书题意（中文转述）

卧室的三面墙各挂一幅画，你想重新安排它们；第四面墙有窗户，不能挂画。

  1. 若每面墙仍只挂一幅，有多少种安排？
  2. 现在只允许两个基本动作：交换左墙与中墙的画，或交换中墙与右墙的画。这两个动作能生成 (a) 中所有安排吗？
  3. (b) 描述的是群吗？若不是，违反哪些规则？
  4. 再加入一个动作：把右墙上的所有画移到中墙，即使中墙因此挂着多幅画。新情形是群吗？若不是，违反哪些规则？

来源：印刷 7–8 / PDF 22–23

解答与推演

(a) 六种安排

三幅画视为不同。先给左墙选画有 3 种，给中墙选剩余画有 2 种，右墙被确定，因此 3×2×1=63×2×1=6。全部为 ABC、ACB、BAC、BCA、CAB、CBA。

(b) 两个交换足够

沿前文逐步表，e、a、b、ab、ba、aba 分别得到 ABC、BAC、ACB、BCA、CAB、CBA。它们已覆盖六种，因而足够。每条字词都是实际允许的相邻交换；这里没有借用额外的“直接交换左右墙”指令。

(c) 构成群

清单固定；a、b 各自是自己的撤销；每次交换结果唯一；任意有限串接都保持每墙一幅且可继续。因此满足四条规则。撤销任意字词时，从右向左再做同一串交换即可，说明由生成元得到的复合动作也可逆。

(d) 加入合并后不成群

若状态仍只允许每墙一幅，新动作直接离开这个状态集合。若扩大状态集合，记录每幅画挂在哪面墙，合并则会丢失来源信息。例如 A|B|C 和 A|C|B 两个起始安排，都被合并为 A|{B,C}|空。看到合并结果，不能用一个固定的反向动作判断原来哪幅在右墙；合并不是一一对应，规则 1.6 失败。

这里的“找不回”指不存在对全部状态有效的统一逆动作。临时记住原来的墙位再手工搬回，需要引入额外记忆，已改变本题动作系统。

1.5.2 规则的后果 · Consequences of the rules

习题 1.5 · 任意串接会产生无限多动作吗

原书题意（中文转述）

规则 1.8 是否意味着每个群都必须含有无穷多个动作？请仔细解释理由。

来源：印刷 8 / PDF 23

解答与推演

不意味着。规则要求组合仍是一个动作，没有要求每种写法都产生一个新效果。习题 1.1 中无限多个字词 s、ss、sss……按长度奇偶，只对应 s 与 e 两个动作。

关键不在于能写多少字符串，而在于把对全部状态效果相同的字符串合并以后还剩多少类。原书附录印刷 261 / PDF 276 同样用奇偶次交换解释这一点。

习题 1.6 · 数动作，还是数生成元

原书题意（中文转述）

对习题 1.1—1.4 中确实构成群的每一种情形，求群中恰好有多少个动作。不要只数生成元，要计入按照规则 1.8 得到的所有不同动作。

来源：印刷 8 / PDF 23

解答与推演

1.1 有 2 个：e 与交换 s。1.2 也有 2 个：仍是 e 与 s，第三枚硬币固定。1.4(b)/(c) 有 6 个：六个代表各给一个不同位置重排。1.3 与 1.4(d) 不是群，不把它们列入本题计数。

1.4 中“六个排列对应六个动作”需要三幅画互不相同并观察全部位置，前文已说明。不能在任意场景下仅凭有六个可见状态就断言群有六个元素。

习题 1.7 · 为什么一定有恒等动作

原书题意（中文转述）

再次考虑习题 1.1。

  1. 题目只给了一个动作。按规则 1.8，连续做两次也是有效动作。描述这个动作。
  2. 每个群都会有这样的动作吗？请仔细解释。

来源：印刷 8 / PDF 23

解答与推演

(a)交换两次后，两枚硬币分别回到原位，因此整体效果是“不改变状态”，记为 e。e 并不是“没有动作资格”，而是动作系统中的一种合法整体效果。

(b)会。任取一个动作 g，规则 1.6 给出它的撤销动作；规则 1.8 允许先做 g 再做其撤销，并把这一串视为一个动作。对任意起始状态 x，先到 g(x)，再退回 x，所以复合在全部状态上保持不变。

g−1(g(x))=xg⁻¹(g(x))=x

这个论证不要求每个动作自己做两次都能撤销；魔方的四分之一转就不是如此。它要求的是“动作后接自己的逆”。恒等效果也唯一：若两个动作都保持每个状态不变，它们按效果相等的约定就是同一个动作。附录对应答案在印刷 261 / PDF 276。

习题 1.8 · 构造五种情形

原书题意（中文转述）

对 (a)—(e) 各构造一个群，满足对应的额外条件；所有例子仍须满足规则 1.5—1.8。可以重复使用已经遇到的群。

  1. 动作执行顺序会影响结果。
  2. 动作执行顺序不会影响结果。
  3. 恰有三个动作。
  4. 恰有四个动作。
  5. 有无穷多个动作。

来源：印刷 8 / PDF 23

解答与推演

(a)使用三幅画的全部位置重排。a 后 b 得 BCA，b 后 a 得 CAB，证明顺序有影响；清单固定、每个重排有逆、结果确定、重排复合仍是重排，已在 1.4 验证。

(b)使用两枚硬币群 {e,s}。所有组合为 ee=e、es=se=s、ss=e，所以换顺序不改变结果。

(c)把一个带标记的指针放在圆周三个等距位置之一，每次顺时针走一格。整体动作恰为走 0、1、2 格；走 3 格与走 0 格相同。各步都确定且可继续，走 1 格的逆是走 2 格，任意复合按总步数除以 3 的余数归入这三项。

(d)把同一构造改为四个等距位置，动作是走 0、1、2、3 格，步数相加后按 4 取余。逆分别为 0、3、2、1 格。这里只允许沿圆周旋转，未加入反射，所以恰好四个。

(e)在整数线上取所有整数平移 Tₖ，定义 Tk(x)=x+kTₖ(x)=x+k。T₀ 是恒等，T₋ₖ 是逆，先平移 k 再平移 l 等于平移 k+l；因此闭合且可逆、确定。不同 k 对 0 的结果不同，所以有无限多个动作。基本清单可以取“加 1”和“减 1”。

习题 1.9 · 任意给定动作数的构造

原书题意（中文转述）

能否设计一个办法，对任意给定的动作数量构造一个群？这里指定的是应用规则 1.8 后全部不同动作的数量，并非生成元数量。

来源：印刷 8 / PDF 23

解答与推演

对任意正整数 n，在标着 0、1、…、n−1 的圆环位置上放一个指针，允许它每次顺时针走一格 r。经过 k 步，只看 k 除以 n 的余数；因此候选动作是走 0、1、…、n−1 格。

先证“至多 n 个”：任意有限步数 k 都能写成 qn+t，0≤t<n；整圈 qn 不改变状态，所以与走 t 格效果相同。再证“至少 n 个”：从位置 0 出发，走 0 到 n−1 格分别到不同位置，故这 n 个动作两两不同。

复合两个动作等于把步数相加再取余，仍在候选内；走 t 格的逆是走 n−t 格（t=0 时仍为 0）；动作固定且确定。因此构成恰好 n 个动作的循环群。n=1 时只有恒等动作；若要求 0 个动作则不可能，因为群必须包含恒等动作。

1.5.3 打破规则 · Breaking the rules

原书让我们去掉规则 1.6、1.7、1.8 中的一条，保留其他规则。此处沿用本章的非正式动作语言；尤其“可以把结果恢复”与“存在一个统一的逆函数”需要分清。

习题 1.10 · 只去掉可逆性

原书题意（中文转述）

设计一种情形，它满足四条规则中的其余三条，唯独不满足规则 1.6。

来源：印刷 9 / PDF 24

解答与推演

令状态是非负整数，基本指令为“加 1”，允许任意有限次重复并包含不操作。全部动作是 Tk(x)=x+kTₖ(x)=x+k，其中 k≥0。

动作清单固定，结果唯一，先加 k 再加 l 等于加 k+l，故串接闭合。可是“加 1”没有本系统允许的逆：“减 1”不在动作集合中，而且在状态 0 上会离开状态空间。因此只缺可逆性。

原书附录印刷 262 / PDF 277 用“点燃并烧尽一根火柴”说明不可逆，同时假定火柴可无限供应。本例把状态和动作写成整数，避免让材料是否耗尽干扰对规则 1.8 的判断。

习题 1.11 · 不确定性与可逆性的边界

原书题意（中文转述）

设计一种情形，它满足四条规则中的其余三条，唯独不满足规则 1.7。

来源：印刷 9 / PDF 24

解答与推演

按本章“事后可以撤销”的非正式含义，可用随机方向的整数移动。状态是一枚棋子在无限整数线上的位置。固定指令表为“右移一格”“左移一格”“投一次硬币，正面右移一格、反面左移一格”，并允许任意有限串接。

清单不变；整数线没有端点，任何有限指令串都能继续执行。每一次实际发生的移动都可在看到方向后用相反的确定移动撤销，整个实际过程也可逆序逐步恢复。但从同一起点执行投币指令，结果可能是左右两个位置，所以规则 1.7 失败。

严谨边界：这里的撤销依赖观察实际结果，随机指令并没有一个固定的函数逆。如果把规则 1.6 严格定义为“动作是双射，且有统一的逆函数”，那么动作首先就是函数，给定输入必有唯一输出，已经蕴含确定性；这时本题不存在满足其余条件的例子。

因此本题展示的是本章直观用语的差别，不能据此宣称现代群公理中“可逆”和“确定”是两条独立公理。原书本节讨论规则独立性时仍处于非正式阶段；这条语义说明是笔记补充，正式群论将在第 4 章统一到函数或二元运算语言。

习题 1.12 · 只去掉任意串接

原书题意（中文转述）

设计一种情形，它满足四条规则中的其余三条，唯独不满足规则 1.8。

来源：印刷 9 / PDF 24

解答与推演

在整数线上，把完整的允许动作集合限定为“加 1”和“减 1”这两个单步动作，不把它们当作待扩充的生成元表。这份集合固定，两个动作确定且互为逆。但“加 1 后再加 1”的整体效果是“加 2”，不在这个集合里；“先加 1 再减 1”的恒等效果也不在其中，所以不满足规则 1.8。

若按照 1.8 自动把全部串接效果补进集合，它就扩充成整数平移群。这说明题目要否定的是原来两项集合的封闭性，而非声称加法不能连续执行。

原书附录印刷 262 / PDF 277 另给习题 1.3 的口袋模型：动作在各自可用时可逆、确定，但第五次转移后第六次无法进行。那个例子强调串接的可执行性；这里使用处处有定义的平移，直接隔离“合成效果是否仍被列入集合”。

1.5.4 数字构成的群 · Groups of numbers

习题 1.13 · 整数平移及最小生成清单

原书题意（中文转述）

选一个整数，考虑对它“加任意整数”的所有动作。这是无限动作集，例如“加 1”和“加 −17”。它是群吗？若是，能找到多小的一组生成元？

原题使用 whole number，但明确举出 add −17，故这里按包含正负数与零的整数理解。PDF 文本提取漏掉该负号，已核对印刷 9 / PDF 24。

来源：印刷 9 / PDF 24

解答与推演

是整数平移群。对每个整数 k 定义 Tk(x)=x+kTₖ(x)=x+k，状态 x 也取整数。先做 Tₖ，再做 Tₗ，结果为 x+k+l，因此等于 Tₖ₊ₗ；T₀ 保持不动，T₋ₖ 撤销 Tₖ。每个动作在全部整数上可执行、确定，故满足四条规则。

(Tl∘Tk)(x)=(x+k)+l=Tk+l(x)(T_l∘T_k)(x)=(x+k)+l=T_(k+l)(x)

按通常群论的生成元约定，最小生成元只有一条：{T₁}。“由生成元生成的子群”允许使用生成元及其逆，T₁ 的逆就是 T₋₁。任意正位移用 T₁ 的正次幂得到，负位移用逆的正次幂得到，零位移是恒等。因此一条足够；没有生成元只能得到恒等子群，不能生成所有平移，所以一条也是最少的。原书后续 §8.3（印刷 170 / PDF 185）也用一个标为 1 的生成元画整数群。

若制作一个只准正向按按钮的操作面板，则需要“加 1”和“减 1”两个按钮。只有“加 m”一个按钮时，反复按只能得到 0、m、2m……：m>0 得不到负位移，m<0 得不到正位移，m=0 只得恒等。加入相反方向的按钮以后，正负位移都能做到。这个两按钮结论说的是实际可执行指令清单，不能用它替换标准意义下“一生成元”的答案。

习题 1.14 · 偶数、有限区间与乘法

原书题意（中文转述）

修改上一题的数字或动作，分别回答是否构成群；构成时说明生成方式。

  1. 只允许偶数，会怎样？
  2. 只允许 0 到 10 的整数，会怎样？
  3. 允许所有整数，但把动作改为“乘任意整数”，会怎样？这些动作就是完整动作集，不是生成元表。
  4. 只允许数字 1 与 −1，且恰有两个动作：乘 1 或乘 −1，会怎样？

(d) 原页两次出现负号；保留 1 和 −1。(b) 题目没有规定模 11 运算。

来源：印刷 9 / PDF 24

解答与推演

(a) 偶数加法

构成群。状态取偶整数，动作是加 2k。两个动作合成为加 2(k+l)，仍为偶数平移；逆是加 −2k，恒等是加 0。标准意义下由“加 2”一个生成元产生；如果操作面板只准正向按按钮，则需要加 2 与加 −2 两条指令。

(b) 0 到 10 与通常加法

不构成群。若状态也限制在 0—10，在状态 10 上加 1 已不合法；即使只把加数限制在 0—10、状态允许任意整数，“加 10”后再“加 1”的加 11 效果仍不在动作集中，且加 1 的逆加 −1 也不在。不能自行改成模 11 加法来宣称原题成立。

(c) 整数乘法

不构成群。乘 0 把所有整数都送到 0，无法从结果恢复原数，立即违反规则 1.6。即使删掉乘 0，乘 2 也没有“乘某个整数”的逆，因为需要乘 1/2，而它不在允许动作集。乘法复合本身仍闭合：先乘 m 再乘 n 等于乘 mn；缺的是允许范围内的逆。

(d) 乘 1 与乘 −1

构成有两个动作的群。乘 1 是 e，乘 −1 是 s；s 把 1 与 −1 互换，s 做两次等于乘 (−1)(−1)=1，因此 s2=es²=e。两个动作固定、确定，合成仍是乘 ±1。只需把“乘 −1”列为生成元，重复两次就产生 e；这里正向串接和标准群生成都只需一条。
