9.1 群作用：把群元素解释成置换

拉格朗日定理只给必要条件：子群的阶必须整除群阶。A₄ 的阶为 12，却没有 6 阶子群，说明反向推理不成立。本章寻找可以反过来用的部分，并沿着原书的未知群 A（|A|=200=2³·5²）逐步增加信息。全章讨论有限群；固定点计数还要求被作用的集合有限。

Definition 9.1

原文摘录：

A group G acts on a set S if there is a homomorphism φ : G → Perm(S).

中文陈述：群作用是同态 φ:G→Perm(S)φ:G→Perm(S)。沿用本书动作次序，写 s·g=φ(g)(s)s·g=φ(g)(s)，要求 s·e=ss·e=s，(s·a)·b=s·(ab)(s·a)·b=s·(ab)。Perm(S) 的乘法是先左后右，故对应通常函数复合 φ(ab)=φ(b)∘φ(a)φ(ab)=φ(b)∘φ(a)。

来源：印刷 195 / PDF 210

作用可以丢失信息：令 V₄=⟨h,v⟩ 作用于矩形的四种配置，h 真正水平翻转，v 则固定所有配置。所有群关系仍成立，因而这是合法同态；但 e 和 v 有同一效果，核为 {e,v}。原书用于测量物体对称性的特殊构造另要求：(1) 像恰好是手工允许的全部对称动作；(2) 映射单射。一般群作用不要求这两项。

Definition 9.2

原文节选（轨道的描述句；作用前提与记号见下文）

the orbit of any s in S is the set of elements of S that G arrows can reach from s.

中文陈述：Orb(s)={s·g:g∈G}Orb(s)={s·g:g∈G}，即从 s 用作用箭头可到达的点集。它是 S 的子集；不同轨道不相交并覆盖 S。

来源：印刷 197 / PDF 212

这里的 orbit 是群作用在状态集合上的轨道。§5.1.3 元素的 orbit 则是反复使用同一个元素得到的循环子群；把该循环子群作用在群自身、从单位元出发时，两种说法相合。

Definition 9.3

原文节选（稳定子的描述句；稳定点定义见下文）

The stabilizer of an element s in S is the set of group elements g that don't move s.

中文陈述：Stab(s)={g∈G:s·g=s}Stab(s)={g∈G:s·g=s} 是 G 的子群。若 Stab(s)=GStab(s)=G，称 s 为稳定点（全体作用的固定点）。

来源：印刷 197 / PDF 212

定义 9.2–9.3 · 轨道分割与稳定子子群的说明

若两个轨道相交，设 s·a=t·b，则 t=s·ab⁻¹，彼此可达，所以两轨道相同。稳定子含 e；若 a,b 稳定 s，则 (s·a)·b=s，而由 s·a=s 再作用 a⁻¹ 得 s·a⁻¹=s。稳定子因此有单位元、封闭与逆元。注意“某个生成元没动这个点”不足以称稳定；所有生成元都不动才够。

Theorem 9.4

原文摘录：

The size of an element’s orbit times the size of its stabilizer is the size of the group.

中文陈述：有限群的任意作用满足 |Orb(s)|·|Stab(s)|=|G||Orb(s)|·|Stab(s)|=|G|。更本质的陈述是轨道与稳定子的陪集一一对应。

来源：印刷 198 / PDF 213

Theorem 9.4 · 证明与说明

设 H=Stab(s)。按本页右作用约定，映射 Hg↦s·g 使用右陪集：若 g′=hg，h∈H，则 s·g′=(s·h)·g=s·g，故良定义；反过来 s·g=s·k，右作用 k⁻¹ 得 s·gk⁻¹=s，即 gk⁻¹∈H，故 Hg=Hk。它显然满射，所以是双射。每个陪集有 |H| 个元素，陪集数恰为轨道大小，乘起来就是 |G|。

原书校注。印刷 199 页在从左到右执行的约定下用了左陪集 gH；还把“在 s 上取值相同”写成整个置换 φ(gh)=φ(g)。一般不能这样等同。若使用标准左作用 g·s，则 gH↦g·s 正确，但复合必须按左作用规则理解。下文 Sylow 证明明确采用左乘/左共轭的左作用；观察固定点和轨道的结果与换为逆元后的右作用完全一致。

例如 S₃ 共轭作用于它的子群：{e}、⟨r⟩、S₃ 都固定；三个反射子群成一个 3 点轨道，每个的稳定子是自己的正规化子，阶 2。因此 1·6=6、3·2=6。原图 9.3 只列真子群，若声称“全部子群”，应另补 S₃ 这个固定点。

阅读注解
理解与边界

轨道与稳定子属于不同集合

Orb(s) 在状态集合 S 中；Stab(s) 在群 G 中。作用的核是所有点稳定子的交集，不是任意一个稳定子。一个点被固定，也不意味着对应群元素在整个作用中不可见。

9.2 从固定点计数到 Cauchy 定理

Theorem 9.5

原文节选（同余结论；素数阶作用的条件见下文）

the order of S and the number of stable elements in S are congruent mod p.

中文陈述：若 |G|=p 为素数，且 G 作用于有限集 S，则 |S|≡|SG|(modp)|S|≡|Sᴳ| (mod p)，其中 SGSᴳ 为所有稳定点。

来源：印刷 200 / PDF 215

Theorem 9.5 · 证明与说明

轨道—稳定子定理让每个轨道的大小整除 p，所以只能是 1 或 p。把所有单点轨道留下，其他轨道每次删去 p 个点；删完后剩余点数与原点数模 p 相同。这个证明依靠的是轨道分割，既不要求作用忠实，也不要求 S 是群。

Theorem 9.6

原文摘录：

If p is a prime number that divides |G|, then G has an element g of order p, and therefore a subgroup ⟨g⟩ of order p.

中文陈述：若素数 p 整除有限群 G 的阶，则 G 中存在阶恰为 p 的元素，因而有 p 阶循环子群。

来源：印刷 200 / PDF 215

Theorem 9.6 · 证明与说明

要找到 g≠e 且 gᵖ=e，先把问题放大：令 X={(g₁,…,gₚ):g₁⋯gₚ=e}。前 p−1 项可任取，最后一项必须是前面乘积的逆元，因此 |X|=|G|ᵖ⁻¹。让 Cₚ 循环右移坐标：T(g₁,…,gₚ)=(gₚ,g₁,…,gₚ₋₁)。它保留 X，因为 gₚg₁⋯gₚ₋₁=gₚ(g₁⋯gₚ)gₚ⁻¹=e；左移是它的逆，Tᵖ=id。

X={(g1,…,gp):g1⋯gp=e},|X|=|G|p−1X={(g₁,…,gₚ):g₁⋯gₚ=e}，|X|=|G|^(p−1)

T 固定一个元组，当且仅当各坐标全相同。因此固定点恰为 (g,…,g)，其中 gᵖ=e。固定点数模 p 等于 |G|ᵖ⁻¹，故为 p 的倍数；它至少为 1，因为有 (e,…,e)，所以实际上至少为 p≥2。取一个非单位元 g；|g| 整除 p，又不为 1，故 |g|=p。这里“至少为 1”与“p 的倍数”合用，才排除了只存在单位元的可能。

对 |A|=200，先得到 2 阶与 5 阶元素，却尚不能说有 4、8、25 阶元素。子群阶与元素阶必须区分。

9.2.1 分类所有 6 阶群

原书 9.2.1 从 a²=e、b³=e 画出 e,b,b² 与 a,ab,ab² 两列。⟨b⟩ 的指数为 2，因此正规；共轭 a 把 b 送到 b 或 b⁻¹，这是 Aut(C₃) 的全部可能。若 aba⁻¹=b，则交换，C₂×C₃≅C₆；若 aba−1=b−1aba⁻¹=b⁻¹，则关系为 ba=ab²，得到 S₃≅D₃。两种乘法都实际存在，而且“交换/不交换”保证不同构。

阅读注解
理解与边界

为什么选乘积为单位元的元组

若直接数 gᵖ=e，很难看出总数。扩充到自由选择前 p−1 个坐标的 X 后，总数变得可算；循环作用又把所求对象恰好变成固定点。

9.3 p 群与正规化子的计数

Definition 9.7

原文摘录：

A p-group is a group whose order is a power of a prime p.

中文陈述：阶为 pnpⁿ（n≥0，p 为素数）的有限群称 p 群；它作为 G 的子群时称 p 子群。平凡群对每个 p 都是 p 群。

来源：印刷 206 / PDF 221

Theorem 9.8

原文摘录：

If a p-group G acts on a set S, then the order of S and the number of stable elements in S are congruent mod p.

中文陈述：有限 p 群作用于有限集合 S 时，|S|≡|SG|(modp)|S|≡|Sᴳ| (mod p)。

来源：印刷 206 / PDF 221

Theorem 9.8 · 证明与说明

轨道大小整除 pnpⁿ，所以只能取 1,p,…,pnpⁿ。非单点轨道不必一样大，却都被 p 整除；删去它们后仍得到同一同余。对非平凡 p 群应用于共轭作用，固定点是中心 Z(G)，所以 p∣|Z(G)|；中心含单位元，因此至少有 p 个元素。这条推论将在阶 p² 分类和 9.22 使用。

Theorem 9.9

原文摘录：

If H is a p-subgroup of G, then [N_G(H) : H] ≡ [G : H] (mod p).

中文陈述：若 H 是有限群 G 的 p 子群，则 [NG(H):H]≡[G:H](modp)[N_G(H):H]≡[G:H] (mod p)。

来源：印刷 206 / PDF 221

Theorem 9.9 · 证明与说明

让 H 以左作用 h·(gH)=hgH 作用在左陪集集 G/HG/H 上。换代表 g→gh₀ 不改变结果；h⁻¹ 是逆操作，故确是置换。一个陪集 gH 被所有 h∈H 固定，当且仅当对每个 h 有 g⁻¹hg∈H，即 g⁻¹Hg⊆H。两个有限子群阶相同，包含变成相等，所以 g∈NG(H)N_G(H)。稳定点恰有 [NG(H)N_G(H):H] 个，而全部点有 [G:H][G:H] 个，应用 9.8 即得结论。

阅读注解
理解与边界

正规化子为什么出现

H 在 G 中可能不正规，但在 NG(H)N_G(H) 中一定正规。9.9 让我们知道 NG(H)N_G(H)/H 的阶还含多少 p 因子，下一步才有合法的商群可用。

9.4 Sylow 三定理及小阶群分类

9.4.1 第一 Sylow 定理：存在并逐层放大

Theorem 9.10

原文节选（子群包含结论；存在性与阶的条件见下文）

every p-subgroup with fewer than pⁿ elements is inside one of the larger p-subgroups.

中文陈述：设 |G|=pnm|G|=pⁿm，p∤mp∤m。G 有阶为 pⁱ 的子群，0≤i≤n；任意阶 pⁱ、i<n 的 p 子群都包含在某个阶 pi+1pⁱ⁺¹ 子群中。

来源：印刷 208 / PDF 223

Theorem 9.10 · 证明与说明

给定 |H|=pⁱ，i<n，有 [G:H][G:H]=pⁿ⁻ⁱm 被 p 整除。9.9 推出 [NG(H)N_G(H):H] 也被 p 整除。令 q:NG(H)N_G(H)→NG(H)N_G(H)/H；商群非空，其阶为正的 p 倍数，故 Cauchy 定理在商群中给出 p 阶循环子群 L=⟨aH⟩。取逆像 H′=q⁻¹(L)，这是真正的子群：同态逆像保乘法和逆元。

H′ 是 p 个互不相交的 H 陪集的并，每个有 pⁱ 个元素，因此 |H′|=p·pⁱ=pi+1pⁱ⁺¹，而且包含 H。从 {e} 开始重复就得到所有大小；从任意已有 p 子群开始重复，就得到包含它的最大 p 子群。q⁻¹ 在这里是集合逆像，并非逆函数；整个构造也不是内共轭，它可能改变群阶。

9.4.2 分类所有 8 阶群

3 个阿贝尔群先由第 8 章得到：C₈、C₄×C₂、C₂³。非阿贝尔群不能所有非单位元都是 2 阶，因为 (xy)²=e 会推出 xy=yx；若存在 8 阶元又会成为循环群。因此必有 4 阶元 a。⟨a⟩ 指数为 2，正规。取 b∉⟨a⟩，共轭 b 在 C₄ 上必须是非平凡自同构，故 bab−1=a−1bab⁻¹=a⁻¹。

b²∈⟨a⟩，写 b²=aᵏ。b 与自己的平方交换，而共轭 b 将 aᵏ 变成 a⁻ᵏ，所以 2k≡0 mod4，k=0 或 2。k=0 得 b²=e，即 D₄；k=2 得 b²=a²，即本书 Q₄（通常记 Q₈）。正规形式 aⁱbʲ（0≤i<4，j=0,1）把乘法完全确定。两群分别有 5 个、1 个二阶元，所以不同构。

9.4.3 第二 Sylow 定理：彼此共轭

Definition 9.11

原文摘录：

We call H a Sylow p-subgroup of G if it is a p-subgroup whose order is the highest power of p that divides |G|.

中文陈述：阶为 |G| 中最高 p 次幂 pnpⁿ 的子群称 Sylow p 子群。

来源：印刷 213 / PDF 228

Theorem 9.12

原文摘录：

Any two Sylow p-subgroups are conjugates.

中文陈述：G 的任意两个 Sylow p 子群互为共轭。更一般地，任意 p 子群可共轭进任意指定的 Sylow p 子群。

来源：印刷 213 / PDF 228

Theorem 9.12 · 证明与说明

令 P 为 Sylow p 子群，K 为任意 p 子群，让 K 左乘作用于 G/P。点数 m=[G:P] 不被 p 整除，9.8 保证固定点数也不被 p 整除，故至少有一个固定陪集 gP。其固定条件是 g⁻¹Kg⊆P。若 K 也是 Sylow 子群，两侧大小同为 pnpⁿ，故相等。这同时解释了“大小决定存在”和“共轭决定关系”如何接在一起。

Sylow 子群正规 ⇔ 共轭只有自己 ⇔ 同一素数对应的 Sylow 子群只有一个。注意：小的 p 子群不一定彼此同构，例如 D₄ 的 4 阶子群既有 C₄ 又有 V₄；第二定理的同构结论针对最大的 p 子群。

9.4.4 第三 Sylow 定理：数目与正规性

Theorem 9.13

原文摘录：

The number n of Sylow p-subgroups of G obeys the following two restrictions. n divides |G|; n ≡ 1 (mod p).

中文陈述：Sylow p 子群的个数 npnₚ 满足 np∣|G|nₚ∣|G| 且 np≡1(modp)nₚ≡1 (mod p)。事实上 np=[G:NG(P)]nₚ=[G:N_G(P)]，因 P⊆NG(P)P⊆N_G(P)，还有更强的 np∣mnₚ∣m，其中 |G|=pnm|G|=pⁿm、p∤mp∤m。

来源：印刷 215 / PDF 230

Theorem 9.13 · 证明与说明

让 G 共轭作用于全部 Sylow p 子群。由第二定理，这是一个轨道；P 的稳定子是 NG(P)N_G(P)，轨道—稳定子便给指数公式。再只让 P 共轭作用于同一集合。若 Q 是这个作用的固定点，则 P⊆N_G(Q)。P、Q 都是 N_G(Q) 的 Sylow p 子群，第二定理说它们在该正规化子中共轭；而 Q 在其中正规，只能共轭成自己，所以 P=Q。固定点恰有一个，9.8 给 npnₚ≡1。

9.4.5 分类所有 15 阶群

对 15 阶群，n₃∣5 且 ≡1 mod3，故 n3=1n₃=1；n₅∣3 且 ≡1 mod5，故 n₅=1。两个正规子群交于 {e}；交换子既在 3 阶子群又在 5 阶子群，所以为 e，二者逐元素交换。乘积包含 15 个元素，故 G≅C₃×C₅≅C₁₅。

理解与边界

每一步都留下可检查的接口

第一定理把 p 子群嵌入最大者，第二定理让最大者构成一个共轭轨道，第三定理把这个轨道的点数限制为一个整除条件和一个同余条件。数目为 1 才能直接推出正规。

习题 9.1 · 200 阶群：知道什么

题目（中文转述）：

关于 200 阶群 A，分别列举两个 Sylow 定理回答了的问题、两个没有回答的问题。

解答与推导

习题 9.2 · 六个对象的全部置换

题目（中文转述）：

若 S 含 6 个元素，Perm(S) 有多少元素？

来源：印刷 217 / PDF 232

解答与推导

6!=6·5·4·3·2·1=720。第一个对象的像有 6 种选择，第二个不能重复已用目标所以剩 5 种，依次到最后只剩 1 种；这一计数枚举每个双射恰好一次。

习题 9.3 · 轨道与稳定子

题目（中文转述）：

  1. G 作用于 S，s∈S。Orb(s)、Stab(s) 中哪些是群？
  2. 两个集合如何联系？
  3. Orb(s) 的最小大小是多少？
  4. Orb(s) 的最大大小是多少？
  5. 中间的每个大小都能出现吗？

来源：印刷 217—218 / PDF 232—233

解答与推导

(a) Stab(s) 是 G 的子群，证明见 9.1；Orb(s) 只是 S 的子集，没有自然给定的群运算。若稳定子正规，轨道可通过 G/HG/H 另外获得群结构，但这不是一般情形。

(b) |Orb(s)|=[G:Stab(s)]；有限时两者大小的乘积等于 |G|。右作用用右陪集，左作用用左陪集。

(c) 至少为 1；全体 G 固定 s 时达到。

(d) 对给定有限 G、S，上界为 min(|G|,|S|)，但这个上界未必能达到；精确可达大小是 G 的子群指数中不超过 |S| 的那些。若允许选择 S，正则作用 S=G 达到 |G|。

(e) 不一定。轨道大小必须是某个子群指数。例如 C₅ 的轨道只能为 1 或 5。反过来任意指数 [G:H][G:H] 都可由陪集作用实现，多余点可设为固定点。

习题 9.16 · 循环移动真的给置换

  1. 在 Cauchy 证明的 X={(g₁,…,gₚ):g₁⋯gₚ=e} 中，证明每个循环右移 Tⁿ 都把 X 中的点送回 X。

所以共两类。非阿贝尔者记 C₇⋊C₃，作用 b:a↦a²；正规形式 (i,j)=aⁱbʲ，乘法 (i,j)(k,ℓ)=(i+2ʲk mod7,j+ℓ mod3)。该公式实际构造了 21 个不同元素，说明关系可实现而非只有必要条件。

习题 9.28 · 完整分类 12 阶群

题目（中文转述）：

（挑战）分类全部 12 阶群。

来源：印刷 220 / PDF 235

解答与推导

答案恰为五类：C₁₂、C6×C2C₆×C₂、D₆、A₄、C3⋊C4C₃⋊C₄（C₄ 生成元在 C₃ 上取逆，亦称 Dic₃）。下面证明没有漏项，而不是仅列出已知例子。

1. Sylow 数分支与四个 Sylow 3 子群的情形

先看 n₃。 n3∣4n₃∣4 且 ≡1 mod3，所以为 1 或 4。若 n3=4n₃=4，让 G 共轭作用于四个 Sylow 3 子群，得到左作用同态 G→S4G→S₄。核包含在每个正规化子中，而每个正规化子阶为 12/4=3。若核阶为 3，它就等于某个 Sylow 3 子群并正规，与 n3=4n₃=4 矛盾；故核平凡，G 嵌入 S₄，像阶 12、指数 2。S₄ 的指数 2 子群只能是 A₄：商映射到 C₂ 对所有共轭换位取同一个值，换位生成 S₄，非平凡商必须把它们都送到非单位元，核就是偶置换。因此此分支只有 A₄。

2. 唯一 Sylow 3 子群与四种半直积

再看 n3=1n₃=1。 P≅C3P≅C₃ 正规。取 Sylow 2 子群 Q，阶 4，故 Q≅C₄ 或 V₄。P∩Q={e}P∩Q={e} 且 |PQ|=12|PQ|=12，所以 G=P⋊QG=P⋊Q。所有选择都归结为 Q→Aut(C3)≅C2Q→Aut(C₃)≅C₂ 的同态。若 Q=C₄，作用为平凡或生成元取逆，分别给 C₁₂ 与 Dic₃；若 Q=V₄，平凡作用给 C3×V4≅C6×C2C₃×V₄≅C₆×C₂，非平凡作用的三个二阶核被 Aut(V₄) 互换，故只给一个同构类，等于 S3×C2≅D6S₃×C₂≅D₆。

3. 用元素阶和二阶元数量区分同构类

最后区分五类：两个阿贝尔群的最大元素阶为 12 与 6。三个非阿贝尔群的二阶元素数分别为 D₆ 的 7、A₄ 的 3、Dic₃ 的 1。Dic₃ 可写 a3=b4=ea³=b⁴=e、bab−1=a−1bab⁻¹=a⁻¹；其偶数 b 层是 C₃×C₂，唯一二阶元 b²；奇数层元素平方均为 b²，故阶 4。这也解释它为何不能与 D₆ 混为一谈。

分类题要同时保证穷尽与不重复

只写出几个群不能完成分类。9.28 先用 n₃ 分支证明任何 12 阶群都会落入清单，再证明这些结构实际存在，最后用不变量区分它们。

程序：列出 Sₙ 的 Sylow 子群

下面的 sylow 程序把 Sₙ 的 Sylow p 子群显式列出来，范围固定为 2≤n≤5、p≤n 为素数。置换用 0 起算的像数组表示，并按本书先左后右复合。先构造一个最大 p 子群，再将它在所有 n! 个置换下共轭、去重；每个子群同时打印它在置换清单中的编号。

p=2、n≥4 时，种子用 (1234) 与 (13) 生成 D₄，阶 8，等于 4! 与 5! 中最高的 2 幂；其他允许情形用一个 p 循环。这是对小 n 的已证明构造，不是任意有限群的通用 Sylow 搜索器。闭包队列保持“已发现元素都由生成元构成”的不变量；共轭是集合整体搬动，去重比较完整成员集合。

以 n=4,p=2 为例，24 个置换共轭种子，得到 3 个不同的 8 阶子群；每个正规化子阶 8，因此 3×8=24，且 3≡1 mod2。自然四点作用的每点稳定子阶为 6，另外验算 4×6=24。p=3 时得到 4 个 3 阶子群，正是 9.23(a)。

C 使用固定上限 120 个置换、120 个子群、每个子群至多 120 个成员的整数数组；去重辅助数组只记 0/1，输入范围先校验；n≤5 保证乘法表与阶计算不会整数溢出。Python 采用同一范围，超出、非素数或非十进制参数返回退出码 2。记 N=n!、h 为种子阶、k 为 Sylow 子群数。Python 用字典定位置换，预建表为 O(N²n)；C 为便于阅读使用线性 lookup，预建表上界 O(N³n)。Python 构造并排序全部共轭、再数正规化子需 O(kNh log h)，C 的布尔辅助数组和线性比较给 O(kN(N+h)) 上界；这是小例子算法，不能把 n=5 的成功解释为大群同样便宜。

#!/usr/bin/env python3
"""Explicit Sylow subgroups in S_n, only for 2 <= n <= 5."""
import itertools
import sys


def compose(a, b):
    """Execute a first, then b, as in the book."""
    return tuple(b[x] for x in a)


def model(n, p):
    if n not in range(2, 6) or p not in (2, 3, 5) or p > n:
        raise ValueError("2 <= n <= 5; p must be a prime <= n")
    perms = list(itertools.permutations(range(n)))
    index = {x: i for i, x in enumerate(perms)}
    table = [[index[compose(a, b)] for b in perms] for a in perms]
    inv = [row.index(0) for row in table]
    cycle = list(range(n))
    length = 4 if p == 2 and n >= 4 else p
    for i in range(length):
        cycle[i] = (i + 1) % length
    gens = [index[tuple(cycle)]]
    if length == 4:
        flip = list(range(n))
        flip[0], flip[2] = flip[2], flip[0]
        gens.append(index[tuple(flip)])
    seed = {0}
    queue = [0]
    for a in queue:
        for b in gens:
            x = table[a][b]
            if x not in seed:
                seed.add(x)
                queue.append(x)
    subgroups = sorted({tuple(sorted(table[table[g][h]][inv[g]] for h in seed))
                        for g in range(len(perms))})
    normalizers = []
    for h in subgroups:
        normalizers.append(sum(tuple(sorted(table[table[g][x]][inv[g]] for x in h)) == h
                               for g in range(len(perms))))
    return perms, subgroups, normalizers


def output(n, p):
    perms, groups, normalizers = model(n, p)
    lines = [f"S{n} order={len(perms)} p={p} sylow_order={len(groups[0])}"]
    for i, x in enumerate(perms):
        lines.append(f"perm {i}: " + ",".join(str(y + 1) for y in x))
    for h, norm in zip(groups, normalizers):
        lines.append("H={" + ",".join(map(str, h)) + f"}} normalizer={norm}")
    lines.append(f"sylow_count={len(groups)}")
    lines.append(f"point_orbit={n} point_stabilizer={sum(x[0] == 0 for x in perms)}")
    return "\n".join(lines) + "\n"


def main(args):
    try:
        if not args:
            n, p = 4, 2
        elif len(args) == 2 and all(len(x) == 1 and x in "2345" for x in args):
            n, p = map(int, args)
        else:
            raise ValueError("usage: sylow [n p]")
        result = output(n, p)
    except ValueError as error:
        print(error, file=sys.stderr)
        return 2
    print(result, end="")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))

C11

/* Explicit small symmetric groups; composition executes the left action first. */
#include <stdio.h>
#include <string.h>

#define MAX 120
static int n, count;
static int perms[MAX][5], table[MAX][MAX], inverse[MAX];
static int groups[MAX][MAX], sizes[MAX], group_count;

static void enumerate(int depth, int *a, int *used) {
    if (depth == n) {
        for (int i = 0; i < n; ++i) perms[count][i] = a[i];
        ++count;
        return;
    }
    for (int i = 0; i < n; ++i) if (!used[i]) {
        used[i] = 1; a[depth] = i;
        enumerate(depth + 1, a, used);
        used[i] = 0;
    }
}

static int lookup(const int *a) {
    for (int i = 0; i < count; ++i) {
        int equal = 1;
        for (int j = 0; j < n; ++j) if (perms[i][j] != a[j]) equal = 0;
        if (equal) return i;
    }
    return -1;
}

static int compare(const int *a, const int *b, int size) {
    for (int i = 0; i < size; ++i) {
        if (a[i] < b[i]) return -1;
        if (a[i] > b[i]) return 1;
    }
    return 0;
}

static void conjugate(const int *h, int size, int g, int *out) {
    int seen[MAX] = {0}, k = 0;
    for (int i = 0; i < size; ++i) seen[table[table[g][h[i]]][inverse[g]]] = 1;
    for (int i = 0; i < count; ++i) if (seen[i]) out[k++] = i;
}

int main(int argc, char **argv) {
    int p = 2; n = 4;
    if (argc == 3 && strlen(argv[1]) == 1 && strlen(argv[2]) == 1) {
        n = argv[1][0] - '0'; p = argv[2][0] - '0';
    } else if (argc != 1) n = 0;
    if (n < 2 || n > 5 || (p != 2 && p != 3 && p != 5) || p > n) {
        fputs("usage: sylow [n p], 2 <= n <= 5; p prime <= n\n", stderr);
        return 2;
    }
    int a[5] = {0}, used[5] = {0}; enumerate(0, a, used);
    for (int i = 0; i < count; ++i) for (int j = 0; j < count; ++j) {
        for (int k = 0; k < n; ++k) a[k] = perms[j][perms[i][k]];
        int result = lookup(a);
        if (result < 0) return 1;
        table[i][j] = result;
        if (result == 0) inverse[i] = j;
    }
    int length = p == 2 && n >= 4 ? 4 : p;
    for (int i = 0; i < n; ++i) a[i] = i < length ? (i + 1) % length : i;
    int gens[2] = {lookup(a), 0}, ng = 1;
    if (length == 4) {
        for (int i = 0; i < n; ++i) a[i] = i;
        a[0] = 2; a[2] = 0; gens[ng++] = lookup(a);
    }
    int seen[MAX] = {0}, seed[MAX] = {0}, size = 1; seen[0] = 1;
    for (int head = 0; head < size; ++head) for (int j = 0; j < ng; ++j) {
        int x = table[seed[head]][gens[j]];
        if (!seen[x]) { seen[x] = 1; seed[size++] = x; }
    }
    for (int g = 0; g < count; ++g) {
        int h[MAX]; conjugate(seed, size, g, h);
        int found = 0;
        for (int i = 0; i < group_count; ++i) if (compare(groups[i], h, size) == 0) found = 1;
        if (!found) {
            int at = group_count;
            while (at > 0 && compare(h, groups[at - 1], size) < 0) {
                memcpy(groups[at], groups[at - 1], sizeof groups[at]);
                sizes[at] = sizes[at - 1]; --at;
            }
            memcpy(groups[at], h, (size_t)size * sizeof h[0]);
            sizes[at] = size; ++group_count;
        }
    }
    printf("S%d order=%d p=%d sylow_order=%d\n", n, count, p, size);
    for (int i = 0; i < count; ++i) {
        printf("perm %d: ", i);
        for (int j = 0; j < n; ++j) printf("%s%d", j ? "," : "", perms[i][j] + 1);
        putchar('\n');
    }
    for (int i = 0; i < group_count; ++i) {
        int norm = 0;
        for (int g = 0; g < count; ++g) {
            int h[MAX]; conjugate(groups[i], sizes[i], g, h);
            if (compare(groups[i], h, size) == 0) ++norm;
        }
        printf("H={");
        for (int j = 0; j < size; ++j) printf("%s%d", j ? "," : "", groups[i][j]);
        printf("} normalizer=%d\n", norm);
    }
    printf("sylow_count=%d\n", group_count);
    int stab = 0;
    for (int i = 0; i < count; ++i) if (perms[i][0] == 0) ++stab;
    printf("point_orbit=%d point_stabilizer=%d\n", n, stab);
    return 0;
}
