8.1 嵌入与商映射

上一章的子群是“在群内找出一份完整结构”，商群是“把同类元素压成一点”。本章用一个公式把它们统一：φ(ab)=φ(a)φ(b)φ(ab)=φ(a)φ(b)。这个等式允许压缩，却要求每一次乘法在压缩前后给出同一个结果。读图时要同时追踪节点和路径：一个生成元的箭头可以变成多步路径，也可以缩成自环。

G ──φ──→ H；Ker φ = {g∈G : φ(g)=e_H}；Im φ = {φ(g) : g∈G}G ──φ──→ H；Ker φ = {g∈G : φ(g)=e_H}；Im φ = {φ(g) : g∈G}

Definition 8.1

原文节选（定义引导句；保乘法条件见下文）

A homomorphism is a function between two groups that mimics the structure of its domain in its codomain.

中文陈述：同态是群之间保乘法的函数：对所有 a,b∈G，φ(ab)=φ(a)φ(b)φ(ab)=φ(a)φ(b)。图上 a 经 b 到 ab，必须对应 φ(a) 经 φ(b) 到 φ(ab)；表中乘法格也必须相应保持。

来源：印刷 159 / PDF 174

“函数”先要求每个输入有且只有一个输出；“同态”再要求乘法相容。由 φ(e)=φ(e)φ(e) 在目标群消去一个 φ(e)，得到 φ(e)=e；由 φ(g)φ(g⁻¹)=φ(e)=e 得到 φ(g⁻¹)=φ(g)⁻¹。这两步不能把“群中所有函数”都误当成同态。

同态由生成元的像唯一决定，但任意指定像不一定能延拓。例如 C₃=⟨1 : 3·1=0⟩，指定 1↦k∈C₆ 时必须有 3k=0 mod 6，所以 k 只能为 0、2、4。若指定 1↦1，绕原来的三圈回到 0，像却停在 3，同一点的两条表达得到不同结果，映射就没有良定义。

8.1.1 嵌入与同构

单射同态称嵌入；单射意味着只改变表示，没有合并不同元素。双射同态称同构，其逆也保乘法。C₃→S₃ 的 x↦rˣ 与 C₃→C₆ 的 x↦2x 都是嵌入，像分别是 ⟨r⟩ 与 {0,2,4}；它们都没有覆盖整个目标群。C₄→{1,i,−1,−i} 的 x↦iˣ 才是同构。群的运算不必同名：前者的加法对应后者的乘法，因为 i^(x+y)=iˣiʸ。

判定单射只需检查核：φ(a)=φ(b) ⇔ φ(a⁻¹b)=e ⇔ a⁻¹b∈Ker φ。因此 Ker φ={e} 等价于单射；核永远至少含单位元，不能说“核为空”。

8.1.2 商映射、核与纤维

设 K=Ker φ。一个输出 h 的所有原像称一个纤维。选定某个 g 使 φ(g)=h，则 φ(x)=h ⇔ φ(g⁻¹x)=e ⇔ x∈gK。没有被命中的 h 的纤维是空集，以下结论针对 h∈Im φ。

Observation 8.2

Every collection of domain elements that maps to the same codomain element has the same structure in the domain.

中文陈述：非空纤维都有同一种平移后的结构；有限群情形每个纤维恰有 |K| 个元素。

来源：印刷 164 / PDF 179

Observation 8.3

The collections of domain elements mentioned in Observation 8.2 are actually a subgroup and its left cosets.

中文陈述：这些非空纤维正是核 K 及其左陪集 gK。K 是子群，因为 e∈K 且 x,y∈K 时 φ(xy−1)=eφ(xy⁻¹)=e。

来源：印刷 165 / PDF 180

Observation 8.4

The left cosets mentioned in Observation 8.3 are also right cosets, and thus the subgroup is normal.

中文陈述：K 的左陪集同时也是右陪集；核是正规子群。对 k∈K，φ(gkg−1)=φ(g)eφ(g)−1=eφ(gkg⁻¹)=φ(g)eφ(g)⁻¹=e，因此 gKg−1=KgKg⁻¹=K。

来源：印刷 166 / PDF 181

原书把发生合并的同态称为 quotient map，强调“压缩到像”的过程。标准术语通常把商映射保留给满射 G→G/K；若原同态的目标比像更大，应明确区分 G→Im φ 的满射部分和 Im φ↪H 的包含部分。

阅读注解
理解与边界

同态的纤维为何等大

若 φ(x)=φ(g)，则 g⁻¹x 在核中，故 x 属于 g Ker φ；反向也成立。每条非空纤维都是核的一个陪集。

8.2 同态基本定理：先折叠，再改名

Theorem 8.5

If φ : G → H is a homomorphism, then Im(φ) ≅ G/Ker(φ).

中文陈述：若 φ:G→H 为同态，则 G/Kerφ≅ImφG/Ker φ ≅ Im φ。具体同构为 gKerφ↦φ(g)g Ker φ ↦ φ(g)。

来源：印刷 167 / PDF 182

证明与说明

证明需要分别解决四件事，不能只比较元素个数。记 K=Ker φ，定义 F(gK)=φ(g)。①良定义：gK=g′K 意味着 g⁻¹g′∈K，故 φ(g)=φ(g′)。②保乘法：F((gK)(hK))=F(ghK)=φ(gh)=φ(g)φ(h)。③单射：F(gK)=F(hK) 反推 g⁻¹h∈K，故两陪集相同。④满到像：Im φ 中每个元素按定义就是某个 φ(g)。正规性已经由 Observation 8.4 保证，所以 (gK)(hK)=ghK 本身合法。

例：核、陪集与像

例如 φ:C₁₂→C₈，φ(x)=2x mod 8。核为 {0,4,8}；四个陪集分别是 {0,4,8}、{1,5,9}、{2,6,10}、{3,7,11}，映到 0、2、4、6。商群是 C₄，像是 C₈ 中的偶数子群，也是 C₄，而目标仍是 C₈。有限情形由等大的纤维数元素得 |G|=|Ker φ|·|Im φ|。无限情形仍有同构，不能用“两个无限基数相等”替代上述单射证明。

阅读注解
理解与边界

像与目标群

G/Ker φ 同构的是 Im φ。若 φ 不满射，不能把 H 放到同构式右边。C₁₂→C₈ 的 x↦2x 只有四个像。

8.3 模运算来自整数的商群

把整数加法群 Z 中的 nZ={…,-2n,-n,0,n,2n,…} 折叠为零，其他框就是余数类 k+nZ。每个整数用除法算法写成 qn+r，0≤r<n；这里 q 可以为负，所以 −9=−1·12+3 的最小非负余数是 3。

a ≡ b (mod n) ⇔ a−b ∈ nZ ⇔ n | (a−b)a ≡ b (mod n) ⇔ a−b ∈ nZ ⇔ n | (a−b)

定义 π:Z→Cₙ，π(a)=a mod n。因为 a=qn+r、b=sn+t，有 a+b=(q+s)n+(r+t)，因此先取余再相加与先相加再取余同类。核正是 nZ，像为全部 Cₙ，同态基本定理给 Z/nZ≅Cₙ。换代表元 a→a+kn、b→b+ℓn，只把和增加 (k+ℓ)n，这就是商加法良定义的具体理由。

8.4 互素与循环直积

Definition 8.6

Two integers a and b are relatively prime when their least common multiple is their product ab.

中文陈述：本节取正整数 n,m。“互素”表示 lcm(n,m)=nmlcm(n,m)=nm，等价于 gcd(n,m)=1gcd(n,m)=1。

在 Cₙ×Cₘ 中走 (1,1) 一步，会让两个坐标都前进 1。走 k 步回到 (0,0) 当且仅当 n|k 且 m|k，第一次返回就在 lcm(n,m)。若 g=gcd(n,m)，把 n=gn′、m=gm′ 分开公共质因子，得到 lcm(n,m)=gn′m′=nm/g。

8.5 有限阿贝尔群的基本定理

Theorem 8.8

Every finite abelian group A is isomorphic to a direct product of cyclic groups.

中文陈述：每个有限阿贝尔群都同构于有限个循环群的直积。把这些循环因子进一步按互素因子拆开，可以全部取为素数幂阶循环群。

来源：印刷 175 / PDF 190

“有限”“阿贝尔”分别在哪里使用？有限让元素阶、群阶与递降归纳有终点；交换让幂映射是同态、各子群正规、分解因子彼此交换。Q₄ 虽然有限却不能是循环群直积，因为任何这样的直积都交换。Z 虽然交换，却需要无限循环因子。

证明路线与完整解答入口

证明路线分两层。第一层按质数拆开：每个元素都能唯一分解为一个 p 幂阶部分和一个阶与 p 互素的部分，Bezout 等式负责把它们真正写出来。第二层在有限阿贝尔 p 群里选最长循环 C，连续商去与 C 不相交的 p 阶小子群，保持 C 不被压短；到只剩 C 后再沿商映射逆像返回，得到补因子 H。习题 8.45—8.47 把每一个步骤补全，8.48 将它们合并成证明。

例：200 阶有限阿贝尔群

例如 200=2³·5²。2³ 可以按 3、2+1、1+1+1 分配为 C₈、C₄×C₂、C₂³；5² 可以按 2、1+1 分配为 C₂₅、C₅²；两侧独立组合，得到六类，见 8.44(f)。这一计数还要说明候选不重复：元素阶分布、各 p 次幂为单位元的解数都是同构不变量。

反向提升为什么取整个原像

8.6 用同态控制半直积的改接线

直积每一层使用同样的生成元箭头。半直积允许按层改接线，但改接线必须保乘法，即来自自同构；而不同层的改接线还必须服从层群的乘法。记 α:H→Aut(G)α:H→Aut(G)，采用 (g,h)=g·h 的正规形式，并规定 αhα_h(x)=hxh⁻¹。

Definition 8.9

原文节选（仅步骤 1；三步构造见下文）

Begin with the Cayley diagram for H.

中文陈述：给定 α:H→Aut(G)α:H→Aut(G) 的同态，先画 H；将每个 h 节点换成按 αhα_h 重接线的 G；再用 H 的箭头连接各层相应节点，得到 G⋊αHG⋊αH 的 Cayley 图。

来源：印刷 179 / PDF 194

把两段正规形式相乘，先把中间的 h 和 g′ 交换位置：h g′=(h g′h⁻¹)h=αhα_h(g′)h。因此乘法必须是：

(g,h)(g′,h′) = (g α_h(g′), hh′)(g,h)(g′,h′) = (g α_h(g′), hh′)

结合律不是图画出来后自动成立的。三元乘积的第一坐标，左括号给 g αhα_h(g′) α_hh′(g″)，右括号给 g αhα_h(g′) (αhα_h∘αhα_h′)(g″)。它们相等正是 α_hh′=αhα_h∘αhα_h′。这里自同构按通常函数复合书写；本书动作的时间顺序仍是先执行左边群元素，再执行右边群元素，不能把两种复合符号混写。

恒等作用给直积；C₂ 对 Cₙ 的反向作用给 Dₙ；C₃ 循环置换 V₄ 的三个非单位元给 A₄。正规子群与商群只说明某个群是一次扩张，并不保证扩张能拆为半直积：例如 C₈ 中唯一二阶子群 H 的商是 C₄，而 C₂⋊C₄ 只有平凡作用，得 C₂×C₄，得不到 C₈。

原书校注。习题 8.29、8.30、8.38—8.39 的一些半直积因子次序与所给作用映射不一致。本页始终按 Definition 8.9：α:H→Aut(G) 对应 G⋊αH；每题保留原映射，再明确参与作用的两因子。

理解与边界

自同构还需组成同态

给每层任选一个自同构还不够。层 h 后接层 k 的改接线必须等于层 hk 的改接线；这正是 α:H→Aut(G)α:H→Aut(G) 的保乘法条件。

习题 8.2 · 同态判断

题目（中文转述）：

  1. 任意 H、G 之间都有同态 H→G。
  2. 任意 H、G 之间都有嵌入 H→G。
  3. 每个同态都是嵌入或商映射。
  4. 嵌入是核为空的同态。
  5. A≅B 时，存在 A→B 的同构，也存在 B→A 的同构。

来源：印刷 180 / PDF 195

解答与推导

(a) 真，把所有元素映到 G 的单位元。

(b) 假，C₂ 不能嵌入 C₃：非单位元的像必须同时满足平方为 e 和三次方为 e，只能是 e。

(c) 按原书把非单射同态称“商映射”的约定为真。若采用商映射必须满射到给定目标的标准约定，则不成立，例如 C₁₀→C₆ 的 x↦3x 既不单射也不满射；它分解成商到像再包含。

(d) 假。正确是 Ker φ={e}。单位元总映到单位元。

(e) 真。若 i 双射保乘法，写 x=i(a)、y=i(b)，则 i⁻¹(xy)=i⁻¹(i(ab))=ab=i⁻¹(x)i⁻¹(y)。

习题 8.45 · 先按质数拆开

题目（中文转述）：

  1. 有限阿贝尔 A 中，p 整除 |A|。令 Gₚ 为所有 p 幂阶元素（含 e），S 为阶不被 p 整除的元素；证明都是子群。
  2. 求 Gₚ∩S。
  3. 若 |g|=pᵏm、p∤mp∤m，且 apᵏ=bm+1，如何推出 g∈GₚS？
  4. A 与 Gₚ、S 有什么关系？
  5. 对其他质数重复，说明得到怎样的分解；允许用定理 9.6 的 Cauchy 结论。

来源：印刷 190 / PDF 205

解答与推导

(a) e 在两集合中。在交换群中 (xy⁻¹)^L=x^L y^(−L)，L 取两元素阶的最小公倍数就等于 e。两 p 幂阶的最小公倍数仍是 p 幂；两与 p 互素的阶的最小公倍数也与 p 互素。逆元与原元素同阶，所以子群判别条件成立。

(b) 仅 e。其阶既是 p 幂又与 p 互素，只能为 1。

(c) 把 g^(apᵏ)=g^(bm+1) 移项得 g=(gᵐ)^(−b)(g^(pᵏ))ᵃ。第一个因子阶整除 pᵏ，第二个阶整除 m；因此分别在 Gₚ、S。Bezout 等式的系数 a,b 指明了分解，不只是声称“可以拆”。

(d) A=GₚS 且交集平凡，交换群中两子群正规，于是乘积映射给 A≅Gₚ×S，见 8.43。每个 g 的分解唯一：两种表示相除会让 Gₚ 与 S 出现共同的非单位元。

(e) 在 S 上按另一个质数重复。Gₚ 的阶只能含质数 p，否则 Cauchy 给它一个其他质数阶元素，与定义矛盾；S 的阶不含 p，否则 Cauchy 给它一个 p 阶元素。结合 |A|=|Gₚ||S|，Gₚ 的阶正是 |A| 中完整的 p 幂。依次得到 A≅∏ₚGₚ，|A|=∏ₚp^eₚ 时 |Gₚ|=p^eₚ。这里只引用本题明确允许的 Cauchy 结论，不预先使用待证分类定理。

习题 8.46 · 唯一 p 阶子群迫使循环

题目（中文转述）：

  1. 有限阿贝尔 p 群 G，唯一 p 阶子群为 H。设 φ(g)=gᵖ；若 Im φ 循环，证明 G 循环。
  2. 不断对上一像取 p 次幂，哪些非平凡像包含 H？
  3. 每个像有多少 p 阶子群？
  4. 画像的递降链，说明末尾是什么。
  5. 组合以上步骤证明原结论。

来源：印刷 190 / PDF 205

解答与推导

(a) Ker φ=H：非单位解 gᵖ=e 都有阶 p，只能在唯一的 H 内，反之 H 中所有元素都满足。若 |G|=pᴺ，则 |Im φ|=p^(N−1)。像若由 aᵖ 生成，aᵖ 的阶 p^(N−1) 强迫 a 的阶 pᴺ（N=1 时 G 本来是 p 阶循环群），因此 ⟨a⟩=G。

(b) 每一个非平凡像都包含 H。任取其中非单位元素 x，若阶 pᵏ，则 x^(p^(k−1)) 有阶 p，生成的子群只能是 H。最终平凡像不包含非平凡的 H。

(c) 非平凡像恰有一个，即 H；平凡像没有 p 阶子群。

(d) G=G₀→G₁→…→G_(N−1)→G_N={e}，每步 x↦xᵖ，非平凡阶段的核都是 H，阶依次 pᴺ,p^(N−1),…,p,1。末尾非平凡群 G_(N−1) 阶 p，故循环；若 N≥2，倒数第三个阶 p²。

(e) 从最后的 Cₚ 开始往回用 (a)：后一像循环 ⇒ 前一群循环。有限链最终回到 G，所以 G 循环。不能仅凭“阶依次变小”断言循环，逆推依赖核恰有 p 个元素以及 (a) 的生成元阶计算。

习题 8.47 · 最长循环的补因子

题目（中文转述）：

  1. 有限阿贝尔 p 群 G 非循环，取最长循环子群 C。8.46 告诉我们什么？
  2. C 中有几个 p 阶子群？
  3. 为什么能选 p 阶 K 不在 C 内？C∩K 有多少元素？
  4. C 与 K 的乘积如何分解？
  5. 商映射 q:G→G/K 把 CK 映到什么？
  6. 为什么 G/K 仍含与 C 一样长的循环？
  7. 持续商去这样的 Kᵢ，群阶下降；何时结束、最终 Gₙ 是什么？
  8. 反向证明每层 Gᵢ≅Cᵢ×Hᵢ，并推出原群可分成循环因子。

来源：印刷 191 / PDF 206

解答与推导

(a) 8.46 的逆否命题：G 至少有两个 p 阶子群。非平凡 p 群至少有一个，可由任意元素取幂得到。

(b) 恰一个，若 C=⟨c⟩ 阶 pᵐ，它是 ⟨cpm−1⟩。

(c) 选与 C 内唯一 p 阶子群不同的 K。K 阶为素数，任何非单位交点都会生成整个 K，从而 K≤C，矛盾。故交集只有 e。

(d) C、K 正规且交集平凡，CK≅C×K，由 (c,k)↦ck 给出。

(e) q(CK)=CK/K，且 q(CK)=q(C)。q|C 的核 C∩K 平凡，故 CK/K≅C。

(f) C₂=q(C) 有与 C 相同的阶。它仍是最长循环：商中任何元素阶整除其原像的阶，不会超过原群最长元素阶；而这一个最长阶确实保留下来。

(g) 只要 Gᵢ≠Cᵢ，因 Cᵢ 已有最长阶，Gᵢ 不能是循环群，就仍可选 Kᵢ。每步 |Gi+1|=|Gᵢ|/p，|Cᵢ| 固定，因此有限步后恰有 Gₙ=Cₙ。

(h) 终点取 Hₙ={e}。若 Gi+1=Ci+1Hi+1 且交集平凡，令 Hᵢ=qᵢ⁻¹(Hi+1)。任意 c∈Cᵢ∩Hᵢ 的像在 Ci+1∩Hi+1={e}，而 qᵢ|Cᵢ 单射，故 c=e。对任意 g∈Gᵢ，把 qᵢ(g) 写成 qᵢ(c)h′，则 c⁻¹g∈qᵢ⁻¹(Hi+1)=Hᵢ，故 Gᵢ=CᵢHᵢ。交换性加 8.43 得 Gᵢ≅Cᵢ×Hᵢ。逆推到第一层得到 G=C×H；H 阶更小，对 H 重复即可终止于循环直积。

原书校注。原提示写 Hₙ=Kₙ，但终点 Gₙ=Cₙ 已停止选 K。正确逆推基点是 Hₙ={e}，随后取每个商映射的完整原像，而不是只取原先的 Kᵢ。

习题 8.48 · 合并有限阿贝尔群证明

题目（中文转述）：

概括 8.45—8.47 如何证明任何有限阿贝尔群都是循环群直积。

来源：印刷 191 / PDF 206

解答与推导

先用互素阶的 Bezout 分解把 A 拆为各质数 p 的主分量 Gₚ。再在每个 Gₚ 取最大阶元素生成的循环 C；若已覆盖全群就结束，否则利用“非循环 ⇒ 至少两个 p 阶子群”选一个不碰 C 的 K，商去它并保持 C 的长度。有限下降到仅剩 C 后，以 {e} 为终点补因子，沿商映射逆像返回得到 Gₚ=C×H。对较小的 H 再做同样步骤，群阶严格下降确保终止。最后合并各 p 的循环因子，便得 A 的循环直积分解。

习题 8.49 · 证明比陈述多了什么

题目（中文转述）：

上述证明对循环因子的阶 n₁,…,nₘ 还保证什么？

来源：印刷 191 / PDF 206

解答与推导

每个非平凡循环因子的阶都是某个素数的正整数次幂，因为 8.45 先拆成 p 群，之后只在各 p 群内取子群。不同因子可以使用同一个素数。原定理只说是循环群直积，允许任意阶；这里给的是更细的“初等因子”形式。互素因子又可以按 8.7 合并，得到外形不同但同构的表示。

习题 8.50 · 有限生成的无限阿贝尔群

题目（中文转述）：

无限阿贝尔 G 由有限个 g₁,…,gₙ 生成，部分生成元阶无限；猜测其循环直积分解，无须证明。

来源：印刷 192 / PDF 207

解答与推导

应为 G≅Zʳ×C_(p₁^e₁)×…×C_(pₛ^eₛ)，r≥1，s≥0，只有有限个因子。Z 是无限循环群，有限部分按有限阿贝尔分类分解；也可合并成整除链形式。

r 是独立的无限循环方向数，不是给定列表中无限阶生成元的个数。例如 Z 由 2、3 两个无限阶元素生成，但 3·2−2·3=0 给出依赖，仍只有 r=1。有限生成条件不可省：Q 的加法群不能由有限个有理数生成，因有限个分母只能产生某个固定分母的整数倍，达不到任意新的分母。

程序：枚举循环群间的全部同态

输入 m、n，枚举 Cₘ→Cₙ 的所有同态。不要枚举 nᵐ 个任意函数：生成元 1 的像 k 决定 φ(x)=kx mod n，只需试 n 个 k。关系 m·1=0 要求 mk≡0 mod n；反过来此条件保证换代表 x→x+m 后像不变，也保证加法相容，所以筛选既不漏也不多。

程序逐个列出像数组、核、像以及每个纤维。默认 m=12,n=8，合法 k 为 0、2、4、6，共 gcd(12,8)=4 个。以 k=2 为例，三个核元素 {0,4,8} 的每个平移恰构成一个纤维，四个纤维映到 0、2、4、6。输出把 8.5 的抽象同构化为可逐项核对的数据。

Python 的 maps 是生成器，每次产出一个完整映射。C 用长度 12 的固定数组：used 去重像，kernel 收集值为 0 的输入，fiber 按输出 y 再扫描输入，保证输出顺序一致。1≤m,n≤12 的界限同时约束数组与算术；C 中乘积最多 132，普通 int 足够。有效 k 的数量 d=gcd(m,n)，总工作量约 O(n+d·mn)，空间 O(m+n)。

两份程序默认输出必须相同；更关键的核验是对小群穷举所有保加法函数，以及逐对检查每个输出映射的 φ(a+b)=φ(a)+φ(b)，并验证纤维确为核陪集。这些检查验证数学行为，不以两个相同算法相互同意代替正确性。

#!/usr/bin/env python3
"""List every homomorphism C_m -> C_n, with kernel, image and quotient fibers."""
import sys


def maps(m, n):
    # The image k of 1 must respect the relation m*1 = 0.
    for k in range(n):
        if m * k % n == 0:
            values = [x * k % n for x in range(m)]
            kernel = [x for x, y in enumerate(values) if y == 0]
            image = sorted(set(values))
            fibers = [(y, [x for x, value in enumerate(values) if value == y])
                      for y in image]
            yield k, values, kernel, image, fibers


def show(xs):
    return '{' + ','.join(map(str, xs)) + '}'


def main(argv):
    if len(argv) not in (0, 2):
        raise ValueError('usage: homomorphisms.py [m n], 1 <= m,n <= 12')
    if any(len(s) > 2 or not s.isascii() or not s.isdecimal() for s in argv):
        raise ValueError('m and n must be decimal integers')
    m, n = map(int, argv) if argv else (12, 8)
    if not (1 <= m <= 12 and 1 <= n <= 12):
        raise ValueError('m and n must lie between 1 and 12')
    print(f'C{m} -> C{n}')
    count = 0
    for k, values, kernel, image, fibers in maps(m, n):
        count += 1
        print(f'k={k} values={show(values)}')
        print(f'kernel={show(kernel)} image={show(image)} '
              f'injective={"yes" if len(kernel) == 1 else "no"} '
              f'surjective={"yes" if len(image) == n else "no"}')
        for y, fiber in fibers:
            print(f'fiber {show(fiber)} -> {y}')
    print(f'homomorphisms={count}')

/* Every homomorphism C_m -> C_n is determined by the image of 1. */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int parse(const char *s) {
    size_t length = strlen(s);
    if (!length || length > 2) return -1;
    int value = 0;
    for (size_t i = 0; i < length; ++i) {
        if (s[i] < '0' || s[i] > '9') return -1;
        value = value * 10 + (s[i] - '0');
    }
    return value >= 1 && value <= 12 ? value : -1;
}

static void show(const int *items, int count) {
    putchar('{');
    for (int i = 0; i < count; ++i) printf("%s%d", i ? "," : "", items[i]);
    putchar('}');
}

int main(int argc, char **argv) {
    int m = 12, n = 8;
    if (argc == 3) { m = parse(argv[1]); n = parse(argv[2]); }
    if ((argc != 1 && argc != 3) || m < 1 || n < 1) {
        fputs("usage: homomorphisms [m n], 1 <= m,n <= 12\n", stderr);
        return 2;
    }
    printf("C%d -> C%d\n", m, n);
    int count = 0;
    for (int k = 0; k < n; ++k) {
        if (m * k % n != 0) continue; /* m*1=0 must remain true. */
        int values[12], kernel[12], image[12], used[12] = {0};
        int nk = 0, ni = 0;
        for (int x = 0; x < m; ++x) {
            values[x] = x * k % n;
            used[values[x]] = 1;
            if (values[x] == 0) kernel[nk++] = x;
        }
        for (int y = 0; y < n; ++y) if (used[y]) image[ni++] = y;
        ++count;
        printf("k=%d values=", k); show(values, m); putchar('\n');

            int fiber[12], nf = 0;
            for (int x = 0; x < m; ++x) if (values[x] == image[j]) fiber[nf++] = x;
            printf("fiber "); show(fiber, nf); printf(" -> %d\n", image[j]);
        }
    }
    printf("homomorphisms=%d\n", count);
    return 0;
}
