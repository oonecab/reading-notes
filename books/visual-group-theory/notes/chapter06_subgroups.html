6.1 群的乘法为什么要求图处处一致

上一章可以从每张群乘法表提取置换。反过来，把任意彩色状态图都叫作 Cayley 图会出错：节点若代表整个群元素，同一条关系不能在某些节点成立、在另一些节点失败。

Definition 6.1

I call a diagram regular if it repeats every one of its internal patterns throughout the whole diagram, in the sense discussed above.

中文陈述：Cayley 图的 regularity 指每一种标色路径关系在所有起点都一致。

来源：印刷 98 / PDF 113

精确地说，若两个生成元字词 u,vu,v 从一个节点得到同一终点，它们从任何节点都应得到同一终点。因为 xu=xvxu=xv 可左消 xx，得 u=vu=v，再左乘任意 yy 得 yu=yvyu=yv。这是群的结合律与消去律在图上的投影，不是通常图论中“各顶点度数相同”的 regular graph。

6.1.1 完善非正式定义

确定性要求每点每色只有一个后继；可逆性要求每点每色只有一个前驱；连通性要求生成元及其逆能到全部节点。即使三项都有，也可能缺少上述关系一致性，习题 6.1 左图就是反例。这样的图仍可描述某个置换群的状态作用，只是不能把每个状态直接认作一个群元素。

理解与边界

把闭合字词搬到别处

群的 Cayley 图要求同一个字词在每个起点具有一致的代数效果。只在某个顶点出现的闭路，可能揭示图不满足 regularity。

6.2 子群：在原运算下仍然是群的部分

Definition 6.2

When one group is completely contained in another, the inner group is called a subgroup of the outer one.

中文陈述：HH 是 GG 的子群，指 H⊆GH⊆G 并且沿用 GG 的运算后，HH 本身也是群。

来源：印刷 99 / PDF 114

本书把 H<GH<G 也用于 H=GH=G 的情况；本文正文采用 H≤GH≤G，真子群会明确写 H≠GH≠G。不能只凭某几个节点围成漂亮形状判断：HH 必须包含 ee，对乘法和逆元封闭。结合律由 GG 继承，无需重新证明。常用的等价判据是 HH 非空且对任意 a,b∈Ha,b∈H 都有 ab−1∈Hab⁻¹∈H。令 a=ba=b 得 e∈He∈H；令 a=ea=e 得 b−1∈Hb⁻¹∈H；再把 bb 换为 b−1b⁻¹ 得乘法封闭。

例如 S3S₃ 中 H={e,r,r2}H={e,r,r²} 是循环子群；{e,f}{e,f} 也是子群。{r,r2}{r,r²} 缺 ee，{e,r}{e,r} 缺 r2r²，均失败。有限非空子集只查乘法封闭就能补出逆元，因为每个元素的正幂最终回到 ee；无限集合不能省略逆元检查，非负整数在加法下封闭却不是 ℤℤ 的子群。

理解与边界

有限条件用在哪里

有限且非空的乘法封闭子集里，aa 的正幂必然重复；消去相同因子后得到单位元及逆元。无限集合不能直接使用这个重复论证。

6.5 Lagrange 定理：先分块，再数块

Theorem 6.7

If H is a subgroup of G, then each element of G belongs to exactly one left coset of H.

中文陈述：左陪集把 GG 分成互不相交的块，每个元素恰属于一个左陪集。

来源：印刷 106 / PDF 121

Theorem 6.7 · 证明与说明

覆盖已由 g∈gHg∈gH 给出。若 x∈aH∩bHx∈aH∩bH，由 Observation 6.6 得 aH=xH=bHaH=xH=bH。所以两个陪集要么完全相同，要么完全不交；这里不存在“只交一半”的情况。

Theorem 6.8

If H<GH < G, then the order |H| of the subgroup divides the order |G| of the larger group.

中文陈述：若 GG 有限、H≤GH≤G，则 |H||H| 整除 |G||G|。

来源：印刷 107 / PDF 122

Theorem 6.8 · 证明与说明

每个块都与 HH 等大：映射 h↦ghh↦gh 满射到 gHg H，且 gh1=gh2gh₁=gh₂ 可消去 gg，所以单射。设不同左陪集共有 kk 个，上一结论保证它们互斥又穷尽，因此 |G|=k|H||G|=k|H|。系数 kk 不是额外假设，而是不同陪集的个数。

Definition 6.9

If H<GH < G then the index of H in G, written [G : H], is how many times |H| goes into |G|.

中文陈述：指数 [G:H][G:H] 是 HH 的左陪集数；有限时等于 |G||H||G|/|H|。

来源：印刷 107 / PDF 122

[G:H]=|G||H|[G:H]=|G|/|H|

HH 自身也是一个陪集，必须计入。无限群仍可按陪集个数定义指数，例如 [ℤ:2ℤ]=2[ℤ:2ℤ]=2；不能把它解释成 ∞/∞∞/∞。有限情形下，任何真子群阶至多 |G|/2|G|/2，元素阶也整除 |G||G|。但“dd 整除 |G||G|”不保证存在 dd 阶子群，习题 6.31 的 A4A₄ 会给出明确反例。

#!/usr/bin/env python3
"""Chapter 6: all subgroups and both coset partitions of D_n, 1 <= n <= 6."""
import sys


def multiply(a, b, n):
    i, j = a % n, a // n
    k, ell = b % n, b // n
    return (i + (-1 if j else 1) * k) % n + n * ((j + ell) % 2)


def members(mask, size):
    return [a for a in range(size) if mask & (1 << a)]


def cosets(subgroup, n, right=False):
    result = set()
    for g in range(2 * n):
        image = [multiply(h, g, n) if right else multiply(g, h, n)
                 for h in subgroup]
        result.add(sum(1 << x for x in image))
    return sorted(result)


def set_text(mask, size):
    return '{' + ','.join(map(str, members(mask, size))) + '}'


def main(args):
    if len(args) > 1 or (args and (not args[0].isascii() or not args[0].isdecimal())):
        raise ValueError('expected an integer n in 1..6')
    n = int(args[0]) if args else 4
    if not 1 <= n <= 6:
        raise ValueError('n must be in 1..6 (subset enumeration is exponential)')
    size = 2 * n
    print(f'D{n}: index i+n*j means r^i f^j; identity=0')
    count = 0
    for mask in range(1, 1 << size, 2):  # only sets containing identity 0
        subgroup = members(mask, size)
        if any(not mask & (1 << multiply(a, b, n)) for a in subgroup for b in subgroup):
            continue
        # For a nonempty FINITE subset, product closure implies inverse closure.
        left, right = cosets(subgroup, n), cosets(subgroup, n, True)
        count += 1
        print('H=' + set_text(mask, size), f'order={len(subgroup)}',
              f'index={size // len(subgroup)}', 'normal=' + ('yes' if left == right else 'no'))
        print('L', '|'.join(set_text(x, size) for x in left))
        print('R', '|'.join(set_text(x, size) for x in right))
    print('subgroups=' + str(count))


if __name__ == '__main__':
    try:
        main(sys.argv[1:])
    except ValueError as error:
        print('error:', error, file=sys.stderr)
