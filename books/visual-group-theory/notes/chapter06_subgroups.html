6.1 群的乘法为什么要求图处处一致

上一章可以从每张群乘法表提取置换。反过来，把任意彩色状态图都叫作 Cayley 图会出错：节点若代表整个群元素，同一条关系不能在某些节点成立、在另一些节点失败。

Definition 6.1

I call a diagram regular if it repeats every one of its internal patterns throughout the whole diagram, in the sense discussed above.

中文陈述：Cayley 图的 regularity 指每一种标色路径关系在所有起点都一致。

来源：印刷 98 / PDF 113

精确地说，若两个生成元字词 u,v 从一个节点得到同一终点，它们从任何节点都应得到同一终点。因为 xu=xvxu=xv 可左消 x，得 u=v，再左乘任意 y 得 yu=yvyu=yv。这是群的结合律与消去律在图上的投影，不是通常图论中“各顶点度数相同”的 regular graph。

6.1.1 完善非正式定义

确定性要求每点每色只有一个后继；可逆性要求每点每色只有一个前驱；连通性要求生成元及其逆能到全部节点。即使三项都有，也可能缺少上述关系一致性，习题 6.1 左图就是反例。这样的图仍可描述某个置换群的状态作用，只是不能把每个状态直接认作一个群元素。

阅读注解
理解与边界

把闭合字词搬到别处

群的 Cayley 图要求同一个字词在每个起点具有一致的代数效果。只在某个顶点出现的闭路，可能揭示图不满足 regularity。

6.2 子群：在原运算下仍然是群的部分

Definition 6.2

When one group is completely contained in another, the inner group is called a subgroup of the outer one.

中文陈述：H 是 G 的子群，指 H⊆GH⊆G 并且沿用 G 的运算后，H 本身也是群。

来源：印刷 99 / PDF 114

本书把 H<G 也用于 H=G 的情况；本文正文采用 H≤GH≤G，真子群会明确写 H≠GH≠G。不能只凭某几个节点围成漂亮形状判断：H 必须包含 e，对乘法和逆元封闭。结合律由 G 继承，无需重新证明。常用的等价判据是 H 非空且对任意 a,b∈H 都有 ab−1∈Hab⁻¹∈H。令 a=b 得 e∈He∈H；令 a=e 得 b−1∈Hb⁻¹∈H；再把 b 换为 b⁻¹ 得乘法封闭。

例如 S₃ 中 H={e,r,r²} 是循环子群；{e,f} 也是子群。{r,r²} 缺 e，{e,r} 缺 r²，均失败。有限非空子集只查乘法封闭就能补出逆元，因为每个元素的正幂最终回到 e；无限集合不能省略逆元检查，非负整数在加法下封闭却不是 ℤ 的子群。

阅读注解
理解与边界

有限条件用在哪里

有限且非空的乘法封闭子集里，a 的正幂必然重复；消去相同因子后得到单位元及逆元。无限集合不能直接使用这个重复论证。

6.3 让子群在图表中显现

H 是否存在与选了什么生成元无关，但图上是否显眼取决于生成元。C₆ 只画 +1 时是六环；补画 +2 后可看见 H={0,2,4} 及另一份 {1,3,5}。将 H 的元素放在一起，再将每个副本分别放在一起，就得到陪集布局。

同样的顺序用于乘法表的行与列，左上角便是 H 的整张表。其他块不一定是同一组元素，也不一定自身为子群；它们来自平移后的节点集合。第 7 章会进一步问：何时能够把整个块压成一个新群元素。

阅读注解
理解与边界

子群格中的线表示覆盖

向上连线表示包含，且中间没有另一个已列出的子群。同一层的节点之间通常不可比较；子群格的分支保留这些差别。

6.4 左右陪集：同一个子群的两种平移

Observation 6.3

Every subgroup has cosets, and they cover every node of the group’s Cayley diagram.

中文陈述：每个群元素都位于某个子群 H 的副本中；对左、右陪集都成立。

来源：印刷 102 / PDF 117

Observation 6.3 · 证明与说明

因为 e∈He∈H，任意 g 都属于 gH，也属于 Hg。这给出覆盖，但还没证明不同副本是否重叠。

Observation 6.4

The copy of H based at a is named aH.

中文陈述：从 a 出发沿 H 内所有路径到达的节点集合是 aH={ah:h∈H}aH={ah:h∈H}。

来源：印刷 102 / PDF 117

这里 aH 是左陪集：固定乘在左边的 a，变化的是右侧 h。图上从 a 出发沿 H 的生成元走，正好枚举 ah。右陪集 Ha={ha:h∈H} 则是从 H 中每个点各走同一个 a 路径的全部终点。

Observation 6.5

Each coset can have more than one name.

中文陈述：同一个左陪集可以用其中任意一个元素作为代表元。

来源：印刷 103 / PDF 118

Observation 6.6

If b is in aH, then aH = bH.

中文陈述：若 b∈aHb∈aH，则 bH=aHbH=aH。

来源：印刷 103 / PDF 118

Observation 6.6 · 证明与说明

写 b=ah₀。对每个 h∈H，bh=a(h₀h)∈aH，所以 bH⊆aH；反过来 a=bh₀⁻¹，使 ah=b(h₀⁻¹h)∈bH，所以 aH⊆bH。两个包含关系一起才得到相等。

S₃ 中左右陪集实际不同
代表 g左陪集 g⟨f⟩右陪集 ⟨f⟩g
e{e,f}{e,f}
r{r,rf}{r,r²f}
r²{r²,r²f}{r²,rf}

定义 H 正规，记 H◁GH◁G，意思是对所有 g 都有 gH=HggH=Hg。并不要求每个 gh=hg；只要求两个集合相同。在 S₃ 中 ⟨r⟩ 正规，而 ⟨f⟩ 不正规。第 7 章将证明正规性正是陪集能形成商群的条件。

阅读注解
理解与边界

左陪集的左指谁

aH 中固定的 a 写在左边；在右 Cayley 图里实际从 a 出发走 H 的路径。名称与箭头的阅读方向要分别理解。

6.5 Lagrange 定理：先分块，再数块

Theorem 6.7

If H is a subgroup of G, then each element of G belongs to exactly one left coset of H.

中文陈述：左陪集把 G 分成互不相交的块，每个元素恰属于一个左陪集。

来源：印刷 106 / PDF 121

Theorem 6.7 · 证明与说明

覆盖已由 g∈gH 给出。若 x∈aH∩bH，由 Observation 6.6 得 aH=xH=bH。所以两个陪集要么完全相同，要么完全不交；这里不存在“只交一半”的情况。

Theorem 6.8

If H < G, then the order |H| of the subgroup divides the order |G| of the larger group.

中文陈述：若 G 有限、H≤GH≤G，则 |H| 整除 |G|。

来源：印刷 107 / PDF 122

Theorem 6.8 · 证明与说明

每个块都与 H 等大：映射 h↦gh 满射到 gH，且 gh₁=gh₂ 可消去 g，所以单射。设不同左陪集共有 k 个，上一结论保证它们互斥又穷尽，因此 |G|=k|H|。系数 k 不是额外假设，而是不同陪集的个数。

Definition 6.9

If H < G then the index of H in G, written [G : H], is how many times |H| goes into |G|.

中文陈述：指数 [G:H][G:H] 是 H 的左陪集数；有限时等于 |G||H||G|/|H|。

来源：印刷 107 / PDF 122

[G:H]=|G||H|[G:H]=|G|/|H|

H 自身也是一个陪集，必须计入。无限群仍可按陪集个数定义指数，例如 [ℤ:2ℤ]=2；不能把它解释成 ∞/∞。有限情形下，任何真子群阶至多 |G|/2，元素阶也整除 |G|。但“d 整除 |G|”不保证存在 d 阶子群，习题 6.31 的 A₄ 会给出明确反例。

阅读注解
理解与边界

计数前先证明分割

|G|=k|H| 的依据是每块等大、两两不交且覆盖全部。缺任何一条都不能用这个乘法计数。

6.6.1 基础

习题 6.1 · 三张图的不同失败点

题目（中文转述）：

判断原题左、中、右三图哪张是 Cayley 图，哪张只缺 regularity。以下按原图重绘，L/R 表示左右列，0/1/2 表示从上到下的行。

来源：印刷 108 / PDF 123

解答与推导

右图是 C₃×C₂≅C₆：蓝边各列循环三步，红边在两列互换，两者交换。左图确定、可逆、连通，但不 regular：蓝³ 从 L0 回 L0，而从 R0 到 R1；同一个闭路关系在两处不同。中图底行没有蓝色出边，也没有顶行蓝色入边，连可逆动作的基本条件也不满足。

习题 6.2 · 八个着色集合

题目（中文转述）：

依次判断原图标出的八个集合是否是子群：V₄ 中 {N,B}、{R,RB}（N=e）；C₄ 中 {0,1}、{0,2}；D₄ 中四个反射、{e,rf,r²,r³f}；C₃ 中 {0}；C₂³ 中 {000,010,101,111}。

来源：印刷 108—109 / PDF 123—124

解答与推导

逐项检查单位元、封闭性和逆元
原题集合结论直接依据
{N,B}是，C₂B²=N
{R,RB}否不含 N
{0,1}⊂C₄否1+1=2 不在集合
{0,2}⊂C₄是，C₂2+2=0
四个反射否缺 e，任意反射平方为 e
{e,rf,r²,r³f}是，V₄由 r²、rf 生成，两个二阶元素交换
{0}⊂C₃是，平凡群0+0=0
{000,010,101,111}是，V₄由 010、101 逐位模 2 相加生成

集合条件已把原图的着色完整转录；图形重排不会改变这些结论。

题目（中文转述）：

  2. 给 V₄ 作图。
  3. 给 C₅ 作图。
  4. 给 S₃ 作图。

来源：印刷 109 / PDF 124

解答与推导

习题 6.6 · Dₙ 的左右陪集

题目（中文转述）：

  1. rᵐ⟨f⟩ 含什么？
  2. ⟨f⟩rᵐ 含什么？
  3. 在典型 Cayley 图上各是什么样？

来源：印刷 109 / PDF 124

解答与推导

(a) {rᵐ,rᵐf}，就是一个径向配对。

(b) {rᵐ,frᵐ}={rᵐ,r⁻ᵐf}。

(c) 左陪集是 f 边直接相连的外、内两点；右陪集是从 e、f 同走 m 个 r 步的终点，内外圈方向相反。两集合相同当且仅当 2m≡0 mod n。

习题 6.7 · 加一个生成元会怎样

题目（中文转述）：

  1. ⟨e⟩ 是什么？
  2. a∈⟨b,c⟩ 时，⟨a,b,c⟩ 是什么？
  3. a 不在 ⟨b,c⟩ 且后者指数为 2，加入 a 得什么？
  4. a 不在一个 28 阶子群 ⟨b,c⟩ 中，加入 a 后的阶能说什么？

来源：印刷 110 / PDF 125

解答与推导

(a) {e}。

(b) 还是 ⟨b,c⟩，因为新增的 a 已能由 b,c 及其逆写出。

(c) 整个 G。新子群 K 严格包含 H=⟨b,c⟩；指数乘法或两陪集分块说明没有中间子群。也可直接写 G=H∪aH，二者已包含在 K。

(d) 若新子群有限，其阶为大于 28 的 28 的倍数，至少 56；也可能无限。不能仅凭题意断言恰为 56。

习题 6.8 · 循环群中给定阶的子群

题目（中文转述）：

m|n 时，描述 Cₙ 的所有 m 阶子群。

来源：印刷 110 / PDF 125

解答与推导

恰好一个，H=⟨n/m⟩={0,n/m,2n/m,…,(m−1)n/m}。存在性由阶公式 |a|=n/gcd(n,a) 得到。唯一性可将 Cₙ 视为 ℤ/nℤ：任意子群的原像是 ℤ 的一个子群 dℤ，且包含 nℤ，所以 d|n；像的阶是 n/d。指定阶 m 强制 d=n/m。也可用子群最小正代表作带余除法得到同样结论。

习题 6.9 · 一个交换生成子群的指数

题目（中文转述）：

a=(1 2)∈Sₙ，其余点固定，求 [Sₙ:⟨a⟩]。

来源：印刷 110 / PDF 125

解答与推导

n≥2，a²=e 且 a≠e，故 ⟨a⟩ 阶 2，指数为 n!/2。这里 2 来自子群的两个元素，不来自“交换了两个位置”这一口头描述本身。

习题 6.10 · 五个阶数断言

题目（中文转述）：

  1. 18 阶群不能有 9 阶子群。
  2. 22 阶群不能有 12 阶子群。
  3. 12 阶群不能有 22 阶子群。

习题 6.15 · 把代表元替换证明补全

题目（中文转述）：

习题 6.16 · 右陪集也能分块

题目（中文转述）：

  1. 为什么每个元素在某个右陪集中？
  2. 把 6.15 改成右陪集版本需要怎样改？
  3. 怎样改定理 6.7 的证明？
  4. 为什么 |Hg|=|H|？
  5. 怎样改 Lagrange 定理的证明？

来源：印刷 111 / PDF 126

解答与推导

(a) g=eg∈Hg。

(b) 若 b∈Ha，写 b=h₀a。于是 Hb=Hh₀a=Ha；逐项证明为 hb=(hh₀)a，反向用 a=h₀⁻¹b。H 的乘数在左边，不能把原来的右乘路径机械地照抄。若画常规右 Cayley 图，可用反向映射 x↦x⁻¹ 转换左右版本。

(c) 若 x∈Ha∩Hb，则 Hx=Ha 且 Hx=Hb，所以两右陪集相同；配合 (a) 得到分割。

(d) h↦hg 是满射，hg=h′g 右消 g 得 h=h′，故为双射。图中是从每个 h 走 g 路径的一一对应。

(e) G 被右陪集分成同样大小的块，|G|=右陪集数·|H|。因此有限时左右陪集数相同，都是 |G||H||G|/|H|；一般也可用 gH↦Hg⁻¹ 给左右陪集集合的双射。

习题 6.17 · ℤ 的子群及零的边界

习题 6.19 · 同一子群放在不同母群中

阶的整除是筛选条件

Lagrange 定理能排除不整除群阶的候选。要证明某个阶的子群确实存在，仍需构造元素集合并验证封闭与逆元。

程序：穷尽 Dₙ 的子群与左右陪集

程序把 rifjrⁱfʲ 编号为 i+n·j。默认 D₄ 的 e,r,r²,r³,f,rf,r²f,r³f 对应 0…7；例如 H={0,4} 就是 ⟨f⟩。它的左陪集含 {1,5}，右陪集含 {1,7}，所以 normal=no；H={0,1,2,3} 两套陪集一致，normal=yes。

用整数的第 k 位表示元素 k 是否在集合中。枚举 mask 时只取奇数，因为第 0 位必须为 1；对集合内每一对 a,b 检查乘积位是否也存在。这里母群已由 Dₙ 公式保证为群，而且子集有限，故非空乘法封闭足以推出逆元封闭。随后固定 g 分别算 {gh} 与 {hg}，去重并按掩码排序，比较的是整套集合，不是代表元名字。

默认输出应列出 10 个子群；对 H 每行打印阶、指数与左右陪集。C 的 unsigned 位操作在 2n≤12 下安全；C、Python 均限制 1≤n≤6，因为集合枚举有 2²ⁿ 个候选。这个范围限制是算法成本说明，不是群论成立范围。全部子群清单由独立生成闭包方法及具体群模型再核对。

#!/usr/bin/env python3
"""Chapter 6: all subgroups and both coset partitions of D_n, 1 <= n <= 6."""
import sys


def multiply(a, b, n):
    i, j = a % n, a // n
    k, ell = b % n, b // n
    return (i + (-1 if j else 1) * k) % n + n * ((j + ell) % 2)


def members(mask, size):
    return [a for a in range(size) if mask & (1 << a)]


def cosets(subgroup, n, right=False):
    result = set()
    for g in range(2 * n):
        image = [multiply(h, g, n) if right else multiply(g, h, n)
                 for h in subgroup]
        result.add(sum(1 << x for x in image))
    return sorted(result)


def set_text(mask, size):
    return '{' + ','.join(map(str, members(mask, size))) + '}'


def main(args):
    if len(args) > 1 or (args and (not args[0].isascii() or not args[0].isdecimal())):
        raise ValueError('expected an integer n in 1..6')
    n = int(args[0]) if args else 4
    if not 1 <= n <= 6:
        raise ValueError('n must be in 1..6 (subset enumeration is exponential)')
    size = 2 * n
    print(f'D{n}: index i+n*j means r^i f^j; identity=0')
    count = 0
    for mask in range(1, 1 << size, 2):  # only sets containing identity 0
        subgroup = members(mask, size)
        if any(not mask & (1 << multiply(a, b, n)) for a in subgroup for b in subgroup):
            continue
        # For a nonempty FINITE subset, product closure implies inverse closure.
        left, right = cosets(subgroup, n), cosets(subgroup, n, True)
        count += 1
        print('H=' + set_text(mask, size), f'order={len(subgroup)}',
              f'index={size // len(subgroup)}', 'normal=' + ('yes' if left == right else 'no'))
        print('L', '|'.join(set_text(x, size) for x in left))
        print('R', '|'.join(set_text(x, size) for x in right))
    print('subgroups=' + str(count))


if __name__ == '__main__':
    try:
        main(sys.argv[1:])
    except ValueError as error:
        print('error:', error, file=sys.stderr)
        sys.exit(2)

/* Chapter 6. Exhaustive subsets of D_n, bounded to 2n <= 12. */
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
#define MAX_SIZE 12

static int multiply(int a, int b, int n) {
    int k = a % n + (a / n ? -1 : 1) * (b % n);
    k = (k % n + n) % n;
    return k + n * ((a / n + b / n) % 2);
}
static int count_bits(unsigned mask) {
    int count = 0;
    while (mask) { count += (int)(mask & 1u); mask >>= 1; }
    return count;
}
static void print_set(unsigned mask, int size) {
    int first = 1;
    printf("{");
    for (int i = 0; i < size; ++i) if (mask & (1u << i)) {
        printf("%s%d", first ? "" : ",", i); first = 0;
    }
    printf("}");
}
static int cosets(unsigned mask, int n, int right, unsigned result[MAX_SIZE]) {
    int count = 0;
    for (int g = 0; g < 2*n; ++g) {
        unsigned image = 0;
        for (int h = 0; h < 2*n; ++h) if (mask & (1u << h))
            image |= 1u << (right ? multiply(h,g,n) : multiply(g,h,n));
        int i = 0;
        while (i < count && result[i] < image) ++i;
        if (i < count && result[i] == image) continue;
        for (int j = count; j > i; --j) result[j] = result[j-1];
        result[i] = image; ++count;
    }
    return count;
}
int main(int argc, char **argv) {
    int n = 4;
    if (argc > 2) { fprintf(stderr,"error: expected n in 1..6\n"); return 2; }
    if (argc == 2) {
        const char *s = argv[1]; n = 0;
        if (!*s) { fprintf(stderr,"error: empty n\n"); return 2; }
        for (; *s; ++s) {
            if (!isdigit((unsigned char)*s) || n > 6) {
                fprintf(stderr,"error: expected n in 1..6\n"); return 2;
            }
            n = 10*n + *s - '0';
        }
    }
    if (n < 1 || n > 6) { fprintf(stderr,"error: n must be in 1..6\n"); return 2; }
    int size = 2*n, count = 0;
    printf("D%d: index i+n*j means r^i f^j; identity=0\n", n);
    for (unsigned mask = 1; mask < (1u << size); mask += 2) {
        int closed = 1;
        for (int a = 0; a < size && closed; ++a) if (mask & (1u << a))
            for (int b = 0; b < size; ++b) if (mask & (1u << b))
                if (!(mask & (1u << multiply(a,b,n)))) { closed = 0; break; }
        if (!closed) continue;
        /* A nonempty finite product-closed subset of a group contains inverses. */
        unsigned left[MAX_SIZE], right[MAX_SIZE];
        int lc = cosets(mask,n,0,left), rc = cosets(mask,n,1,right), normal = lc == rc;
        for (int k = 0; k < lc && normal; ++k) normal = left[k] == right[k];
        int order = count_bits(mask); ++count;
        printf("H="); print_set(mask,size);
        printf(" order=%d index=%d normal=%s\n", order,size/order,normal ? "yes" : "no");
        printf("L ");
        for (int k = 0; k < lc; ++k) { if (k) printf("|"); print_set(left[k],size); }
        printf("\nR ");
        for (int k = 0; k < rc; ++k) { if (k) printf("|"); print_set(right[k],size); }
        printf("\n");
    }
    printf("subgroups=%d\n",count);
    return 0;
}
