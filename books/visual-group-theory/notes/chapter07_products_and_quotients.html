7.1 直积：两个坐标彼此独立

7.1.1 把每个节点换成一张小图

Definition 7.1

原文节选（仅步骤 1；三步构造见下文）

Begin with the Cayley diagram for A.

中文陈述：构造 A×BA×B：在 A 图的每个节点放一份 B，再按 A 的边连接这些副本的对应节点。

来源：印刷 118 / PDF 133

从 A 的每个节点 a 长出一份完整 B，副本中的 b 记成 (a,b)。沿 B 边只改变第二坐标；沿原 A 边只改变第一坐标。若 |A|=n、|B|=m，共 nm 个节点。两份图的颜色要分开，以免把本来独立的动作混为同一生成元。

7.1.2 有序对与多个因素

Definition 7.2

A subgroup H < G is called normal if each left coset of H is also a right coset of H (and vice versa).

中文陈述：H≤GH≤G 正规，指它的左陪集也都是右陪集，反之亦然。等价地，对每个 g∈G 有 gH=HggH=Hg。记 H◁GH◁G。

来源：印刷 121 / PDF 136

在 C₄×C₂ 中，两行与四列分别是两个自然因素的陪集；左右平移得到相同的分块，所以它们正规。一般两个因素的正规性见 7.12。A×BA×B 的元素是有序对 (a,b)，运算逐坐标进行。

有序意味着 (a,b) 与 (b,a) 是不同的表达；A×BA×B 和 B×A 同构但通常不是同一个集合。三个因素可写 (a,b,c)，每个动作只动一个坐标。C₂³ 的图是立方体；C₂⁴ 再给每个立方体顶点增加第四个开关，共 16 个节点。第三、第四坐标用平铺副本表示时，仍要画出副本之间的连线。

7.1.3 为什么直积能简化大群

例如 D₄×C₇ 有 56 个元素。要描述 (r²,5)，只需在八节点 D₄ 图标 r²，并在七节点 C₇ 图标 5；组合时两个坐标各自运算即可，无需把全部 56 节点挤在一张纸上。有效的简化来自乘法独立，不是只从节点数分解 56=8·7 就猜直积。D₄ 的八节点虽能排成 4×2，却有翻面造成的反向，故不是 C₄×C₂。

7.1.4 表格构造与代数定义

Definition 7.3

原文节选（仅步骤 1；三步构造见下文）

Begin with a multiplication table for A.

中文陈述：从 A 的表开始，把每格放大为一张 B 表；格子的两个标签组成有序对。

来源：印刷 126 / PDF 141

(a,b)(a′,b′)=(aa′,bb′)。(a,b)(a′,b′)=(aa′,bb′)。

两个运算分别发生在 A 与 B。C₄×C₂ 中 (2,1)(3,1)=(2+3 mod4,1+1 mod2)=(1,0)；第一个 1 来自 5 的模 4 余数，第二个 0 来自 2 的模 2 余数。单位元是 (eA,eB)，逆元是 (a⁻¹,b⁻¹)，结合律逐坐标继承。

(a,e)(e,b)=(a,b)=(e,b)(a,e)。(a,e)(e,b)=(a,b)=(e,b)(a,e)。

跨因素元素总交换，因素内部则未必交换。A×BA×B 阿贝尔当且仅当 A、B 都阿贝尔。把 A 认作 A×{e}、B 认作 {e}×B 后，两者都是正规子群，相交只有单位元，乘起来覆盖整个群。

7.2 半直积预览：副本可以被自同构扭转

Definition 7.4

原文节选（仅条件 (c)；完整约束见下文）

The algebraic relationships among group elements must be the same in both diagrams.

中文陈述：rewiring 固定节点位置，可以重接箭头，但必须保留元素之间全部乘法关系。

来源：印刷 129 / PDF 144

例如 C₃ 中把生成箭头 r 换成 r²，相当于反转环方向；因为 r↦r² 是双射且保乘法，群没有改变。C₄ 中却不能任意把节点 1、2 对调：1 的阶是 4，2 的阶是 2，会破坏乘法。V₄ 的三个非单位元可任意置换，得到六种自同构，构成 S₃。第 8 章将把 rewiring 正式称为 automorphism。

从一个群 G 与它的自同构群 Aut(G) 出发，把每个自同构对应的重接图当成一个副本，再连接对应节点，得到 G⋊Aut(G)。更一般的 G⋊H 需要给出 H 如何作用于 G；只写两个因素而不写作用，并不能唯一指定半直积。

本书的时间约定一直是字词 ab 先 a 后 b。涉及“函数的函数”时，本笔记显式使用通常的复合符号：F∘G 表示先 G 后 F；因此时间上的 ab 对应 b∘ab∘a。半直积坐标式中的左作用 αh 满足 αhk=αh∘αk；这条式子写清了函数顺序，不把普通复合符号与动作字词混用。

阅读注解
理解与边界

半直积必须指定作用

第二坐标 h 通过自同构 αₕ 改变第一坐标。相乘时先把 g′ 改为 αₕ(g′)，再与 g 相乘；αₕₖ=αₕ∘αₖ 保证连续改接线一致。

Theorem 7.6

If H < G, then a quotient group G/H can be constructed just when H ◁ G.

中文陈述：陪集运算 (aH)(bH)=abH(aH)(bH)=abH 能成为商群运算，当且仅当 H◁GH◁G。

来源：印刷 137 / PDF 152

证明与说明

先证充分性。若 a′=ah₁、b′=bh₂ 是另外两个代表元，则 a′b′=ah₁bh₂=ab(b⁻¹h₁b)h₂。正规性保证 b⁻¹h₁b∈H，故 a′b′H=abH；因此结果与代表元无关。随后结合律由 G 继承，单位是 H，aH 的逆是 a⁻¹H。

再证必要性。假设把右乘 g 的所有箭头折叠后都不含歧义。从 H 中的 e、h 出发，终点 g、hg 必须同属 gH，故 hg∈gH，对全部 h 得 Hg⊆gH。再对 g⁻¹ 使用同样结论并乘回去，得反向包含，所以 gH=HggH=Hg。图上“同色出口一致”与正规性恰好等价。

7.4 正规化子：在哪个最大子群中 H 会正规

定义 NG(H)N_G(H)={g∈G:gH=HggH=Hg}={g:gHg⁻¹=H}。H 中的元素当然在里面；若全部 G 都在里面，H 就正规。NG(H)N_G(H) 衡量的是哪些元素保持 H 这个集合，而不是每个 h 都逐点固定。

Theorem 7.7

For any H < G, NG(H) < G as well.

中文陈述：NG(H)N_G(H) 自身是 G 的子群，且 H◁NG(H)H◁N_G(H)。

来源：印刷 141 / PDF 156

证明与说明

单位元显然保持 H。若 a、b 都保持 H，则 (ab)H(ab)⁻¹=a(bHb⁻¹)a⁻¹=aHa⁻¹=H；若 aHa⁻¹=H，左右乘 a⁻¹、a 得 a⁻¹Ha=H，所以逆元也保持 H。这证明子群判据，且没有使用有限性。按定义，H 在这个子群中正规；任何使 H 正规的中间子群，其元素都必须在 NG(H)N_G(H) 中，所以它最大。

H ≤ N_G(H) ≤ G；若 H◁K≤G，则 K≤N_G(H)。H ≤ N_G(H) ≤ G；若 H◁K≤G，则 K≤N_G(H)。

例：计算反射子群的正规化子

D₆ 中，rᵏfr⁻ᵏ=r²ᵏf。要保持 {e,f}，需 2k≡0 mod6，即 k=0 或 3；加上相应反射，N_D₆(⟨f⟩)={e,r³,f,r³f}≅V₄。因此 H 在整个 D₆ 中不正规，却在这个四阶子群中正规。

原书校注。印刷 140 页把 A₄ 中 V₄ 的正规化子误写为 N_V₄(A₄)。母群应写在下标处，正确是 N_A₄(V₄)=A₄。

7.5 共轭：把同一个动作搬到另一个位置

共轭 ghg⁻¹ 按时间解释为先换环境 g，再做 h，再恢复环境 g⁻¹。代数上它是群的自同构，因为 (gxg⁻¹)(gyg⁻¹)=gxyg⁻¹。共轭保留阶；它会把一个旋转轴或交换位置搬到别处，却保留相同的动作结构。

正四面体中 a,b,c,d 是绕四个顶点的同方向 120° 转动；改变顶点所处位置能把它们互相共轭。按前文 A₄ 标签，cac⁻¹=b。反方向的四个转动构成另一类，在 A₄ 内不能把空间取向反转来连接这两类。

习题 7.3 · 六个直积判断

题目（中文转述）：

  1. |A×BA×B|=|A||B|。
  2. C₃×C₄ 与 C₄×C₃ 的元素集合相同。
  3. 任意 A×BA×B 都阿贝尔。
  4. C₂×C₂ 与 C₄ 结构相同。
  5. 任意 A 都是 A×BA×B 的正规子群。
  6. Dₙ 与 C₂×Cₙ 总同构。

来源：印刷 147 / PDF 162

(c) 假：S₃×C₂ 含不交换的 (r,e)、(f,e)。

(e) 认作自然副本 A×{e} 后为真；字面上的不同集合须先说明这个嵌入。

(f) 假：n≥3 时左边非交换、右边交换；n=1,2 才是例外。

习题 7.8 · 交换性如何传递

题目（中文转述）：

  1. A、B 都阿贝尔，A×BA×B 呢？
  2. 用图说明。
  3. 用代数说明。
  4. A 非阿贝尔时 A×BA×B 呢？
  5. 用图说明。
  6. 用代数说明。

来源：印刷 148—149 / PDF 163—164

解答与推导

(a) 也阿贝尔。

(b) 同一个因素内部的两路径可交换，跨因素的两路径又因独立而可交换，故全部生成元两两交换。

(c) (a,b)(a′,b′)=(aa′,bb′)=(a′a,b′b)=(a′,b′)(a,b)。

(d) 必非阿贝尔。

(e) 固定 B 坐标，任一 A 副本都保留原来不交换的两条路径；放大不会使不同终点合并。

(f) 取 aa′≠a′a，则 (a,e)(a′,e)≠(a′,e)(a,e)。

习题 7.9 · Q₄ 中有商却没有直积分解

题目（中文转述）：

  1. 按 ⟨i⟩ 整理 Q₄；它正规吗？
  2. 若 Q₄=⟨i⟩×A，A 必为几阶？
  3. A 有哪些候选？
  4. 这种直积存在吗？

来源：印刷 149 / PDF 164

解答与推导

(a) H={1,i,−1,−i}，另一左陪集 {j,k,−j,−k}。指数为 2，所以正规。

(b) 8/4=2。

(c) {m}，交换群中所有共轭都是自己。

(d) 绕三条对面中心轴的 ±90°，共六个转动。共轭可搬轴，也可改变取定的轴向，所以包括正反两个角度。

(e) 绕同样三轴的半转，共三个。180° 与 −180° 是同一个动作，不能重复计数。

(f) 全部换位 (ij)，1≤i<j≤n，共 n(n−1)/2 个。

(g) 全部 k 循环，2≤k≤n 时个数为 n!/[k(n−k)!]：选出 k 点、排成循环，同一循环的 k 个起点要除掉。k=1 是恒等，只有一个；此时不能套上面的选点计数。

习题 7.32 · 一个长循环加一个交换生成 Sₙ

题目（中文转述）：

  1. 令 c=(1 2 … n)、t=(12)，求 ctc⁻¹ 与 cᵏtc⁻ᵏ。
  2. 这些共轭给出什么集合？
  3. 用交换 (23) 共轭 t 得什么？如何产生任意换位？
  4. 据此 ⟨c,t⟩ 已含哪些元素？
  5. 先 t 再 (23) 得什么？如何产生任意循环？
  6. 结合不相交循环分解，确定 ⟨c,t⟩。

来源：印刷 153—154 / PDF 168—169

解答与推导

(a) 按本书时间顺序，ctc⁻¹ 交换 c⁻¹(1)、c⁻¹(2)，即 (n 1)。一般 cᵏtc⁻ᵏ=(1−k,2−k)，下标循环取 1…n。若改用通常右到左的置换乘积，表面公式会反向，不能混用。

(b) 圆周相邻换位 (12),(23),…,(n−1 n),(n1)。

(c) (23)(12)(23)=(13)。一般若已有 (ab)、(bc)，则 (bc)(ab)(bc)=(ac)；沿相邻点链逐步延长，可产生任意 (ij)。

(d) 全部换位都在 ⟨c,t⟩ 中。

(e) 先 (12) 后 (23) 得 (132)。时间约定下，(a₁ a₂ … aₖ)=(a₁ a₂)(a₁ a₃)…(a₁ aₖ)。逐点看，a₁ 在第一步变 a₂ 并保持，aᵢ（2≤i<k）先在第 i−1 步变 a₁，再在第 i 步变 aᵢ₊₁，aₖ 在最后一步变 a₁。例 k=3，(12)(13)=(123)。所有这些换位已在群内。

(f) 每个置换分成不相交循环，每个循环又是换位之积，所以 ⟨c,t⟩=Sₙ（n≥2）。

  2. 计算若干偶数 n 并归纳。

习题 7.34 · 哪些类方程可能存在

题目（中文转述）：

  1. 1+2=3。
  2. 1+1+1+1+1=5。
  3. 1+2+3=6。
  4. 1+3+3=7。
  5. 1+3+4=8。

来源：印刷 154 / PDF 169

解答与推导

(a) 不可能：三阶群循环，每个类均大小 1。

(b) 只有 C₅，素数阶群循环。

习题 7.35 · 共轭子群最少能交多少

题目（中文转述）：

gHg⁻¹ 与 H 最少有多少共同元素？给出最小例子并解释。

来源：印刷 154 / PDF 169

解答与推导

至少一个，因为共同包含 e。取 S₃、H=⟨f⟩、g=r，则 gHg⁻¹={e,r²f}，交集恰 {e}。若要求 H 非平凡且共轭后不同，这是最小母群：阶小于 6 的群都阿贝尔，所有子群共轭不变。若允许 H={e} 的退化例子，则平凡群已经达到交集大小 1。

习题 7.36 · 共轭是等价关系

题目（中文转述）：

  1. 证明自反。
  2. 证明对称。
  3. 证明传递。

来源：印刷 154 / PDF 169

解答与推导

(a) g=ege⁻¹，所以 g 共轭于自身。

(b) 若 g₁=hg₂h⁻¹，则 g₂=h⁻¹g₁h=(h⁻¹)g₁(h⁻¹)⁻¹。

(c) 若 g₁=ag₂a⁻¹ 且 g₂=bg₃b⁻¹，代入得 g₁=(ab)g₃(ab)⁻¹。用到了 (ab)−1=b−1a−1(ab)⁻¹=b⁻¹a⁻¹。因此所有元素可分成互不相交的共轭类。

"""Chapter 7: C_n semidirect C_m, with t*r*t^-1 = r^u."""
import math
import sys


def multiply(a, b, n, m, u):
    i, j = a % n, a // n
    k, ell = b % n, b // n
    return (i + pow(u, j, n) * k) % n + n * ((j + ell) % m)


def element_order(a, n, m, u):
    x = 0
    for k in range(1, n * m + 1):
        x = multiply(x, a, n, m, u)
        if x == 0:
            return k
    raise ValueError('invalid group parameters')


def main(args):
    if not args:
        args = ['4', '2', '3']
    if len(args) != 3 or any(not s.isascii() or not s.isdecimal() for s in args):

/* Chapter 7. C_n semidirect C_m; t*r*t^-1=r^u. */
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
static int number(const char *s, int *out) {
    int n = 0;
    if (!*s) return 0;
    for (; *s; ++s) {
        if (!isdigit((unsigned char)*s) || n > 24) return 0;
        n = 10*n + *s - '0';
    }
    *out = n; return 1;
}
static int gcd(int a, int b) {
    while (b) { int r = a%b; a=b; b=r; }
    return a;
}
static int modpow(int u, int j, int n) {
    int v = 1;
    for (int k=0; k<j; ++k) v = v*u%n;
    return v;
}
static int multiply(int a, int b, int n, int m, int u) {
    int i=a%n, j=a/n, k=b%n, ell=b/n;
    return (i+modpow(u,j,n)*k)%n + n*((j+ell)%m);
}
static int element_order(int a, int n, int m, int u) {
    int x=0;
    for (int k=1; k<=n*m; ++k) {
        x=multiply(x,a,n,m,u);
        if (!x) return k;
    }
    return 0;
}
int main(int argc, char **argv) {
    int n=4,m=2,u=3;
    if (argc != 1 && (argc != 4 || !number(argv[1],&n) ||
                     !number(argv[2],&m) || !number(argv[3],&u))) {
        fprintf(stderr,"error: expected n m u\n"); return 2;
    }
    if (n<2 || n>12 || m<1 || m>6 || n*m>24 || u<0 || u>=n ||
        gcd(u,n)!=1 || modpow(u,m,n)!=1) {
        fprintf(stderr,"error: require bounded n,m and unit u with u^m=1 mod n\n"); return 2;
    }
    int size=n*m;
    printf("n=%d m=%d u=%d; id=i+n*j represents r^i t^j\n",n,m,u);
    for (int a=0; a<size; ++a)
        printf("%d (%d,%d) order=%d quotient=%d\n",a,a%n,a/n,element_order(a,n,m,u),a/n);
    printf("TABLE\n");
    for (int a=0; a<size; ++a) {
        for (int b=0; b<size; ++b) printf("%s%d",b?" ":"",multiply(a,b,n,m,u));
        printf("\n");
    }
    printf("QUOTIENT C%d\n",m);
    for (int j=0; j<m; ++j) {
        printf("%d: ",j);
        for (int i=0; i<n; ++i) printf("%s%d",i?",":"",i+n*j);
        printf("\n");
    }
    return 0;
}
