3.1 赋值与局部状态

PDF 324

连续两次取款都传入 25，为什么答案可以不同？让过程记住余额 100，第一次扣到 75，第二次扣到 50。取款额单独不能决定结果，还要知道调用前的余额。

阅读注解
理解与补充

把两次取款的记录并排看：相同输入只有在相同状态下才保证同一结果。可把余额显式作为参数传入，比较两种接口究竟把历史存在哪里。

3.1.1 局部状态变量

PDF 325

两个账户以 100 开户。只对第一个取 40，两个余额成为 60、100；再对第一个取 70，应返回余额不足并保留 60。构造时建立绑定，取款时修改已有绑定。

阅读注解
理解与补充

给两个计数器送入完全相同的增量并不能证明它们彼此独立。只修改其中一个，再读取另一个，才会让复制数值和共享位置的差别显现出来。

3.1.2 引入赋值的好处

PDF 333

把随机数状态封装在发生器中，面积估计器只需要索取样本。固定两个单位正方形样本为角点和中心，映射到边长 2 的正方形后只命中一次，面积估计为 2。重复这一组固定样本可以核对算法，却不能提高统计精度。

阅读注解
理解与补充

用相同种子生成相同序列，可以区分抽样变化和算法错误。固定样本适合验证命中计数及面积缩放，不能用来证明估计量已足够接近真实面积。

3.1.3 引入赋值的代价

PDF 339

把同一账户绑定到第二个名字，与另开一个相同余额的账户有可观察的区别。前一种情形经第二个名字存入 5，第一个名字也会读到增加的余额；后一种情形不会。这个实验检验对象身份，只比较初始余额无法作出判断。

阅读注解
理解与补充

若把同一个带副作用的调用在表达式里用它的值替换两次，第二次读取时的状态可能已不同。比较习题 3.8 的两种计算次序即可观察到区别。

3.2 求值环境模型

PDF 348

同一个名字怎样取得两个值？让全局环境绑定 x 为 10，在局部框架把 x 绑定为 5。查找从局部框架开始，第一次命中就停止，离开这个框架后全局 x 仍为 10。

An environment is a sequence of frames.

PDF 349
阅读注解
理解与补充

画图时把“下一步返回给谁”和“这个自由变量在哪里找”分别追踪。递归调用可能返回上一层，但其过程对象的环境指针仍可直接指向全局环境。

查找先从最内层框架开始。两个分支都能到达同一外围框架，却不能直接查找彼此的局部名字。

3.2.1 求值规则

PDF 350

把平方过程应用于 5。先取得过程对象和实参值，再建新框架，把参数绑定为 5，外围指向定义过程时保存的环境。两个乘数在那里都读到 5，结果为 25。从调用者而非定义处查找自由变量会在同名遮蔽时得到错误结果。

阅读注解
理解与补充

求值过程表达式先得到带定义环境的对象，应用才新建参数框。若误把调用点环境设为外围，在调用者碰巧有同名局部绑定时便会读错值。

过程对象有一条边指向函数体，另一条边指向定义环境。全局名字指向整个对象。

沿实参绑定找到 5，再沿过程体的两次变量引用取得同一个 5，返回 25。

3.2.2 简单过程的应用

PDF 355

递归阶乘在参数从 6 降到 1 的过程中保留五个待做的乘法。每次调用各有自己的参数绑定，却都以全局环境为外围。动态返回顺序不能用来代替词法查找路径。习题 3.9 列出每一个框架。

阅读注解
理解与补充

把迭代阶乘的乘积和计数写在同一行，再逐行检查乘入的是哪个因子。帧里暂存的数值会变，但已经处理的那些因子只应各出现一次。

几个全局过程的代码各异，词法环境却都指回同一个全局框架。

沿每个调用框的外围指针看，它们直接连接定义环境；执行顺序不能代替这些箭头。

3.2.3 储存局部状态的框架

PDF 358

构造两个余额均为 100 的取款过程，只对第一个取 50。调用帧里的金额为 50，余额沿环境指针查到第一个构造帧，改写为 50；第二个构造帧仍为 100。调用返回后金额绑定可以消失，闭包仍引用余额绑定。

阅读注解
理解与补充

对象的生命期不能简单按创建它的过程是否已返回来判断。只要全局名字还能通过闭包到达余额框，该框的局部绑定就仍可以被读写。

此时仅有构造过程，余额要等到调用后才有自己的存储位置。

第一个取款闭包的环境边落在余额 100 的帧上；返回闭包让该帧继续可达。

取款形参在新帧中，改写的余额在它的外围；两个名字归属不同的框。

调用结束后短命的金额帧消失，沿闭包仍能找到已扣减的余额。

第二次开户重新分配余额帧，两个 100 在写入时可以区分。

3.2.4 内部定义

PDF 365

局部定义的存款与取款过程捕获同一个构造帧。开户 50，存 40 后取 60，结果依次是 90 和 30。另开一个 100 的账户会新建构造帧；两帧能引用相同的全局加法过程，却各有自己的余额。

阅读注解
理解与补充

内部过程的定义对每次构造调用重新生效。可共享的是代码体，检验独立性的办法是给两个账户不同的交易历史，再读出各自余额。

看内部过程的环境边，它们共享这一次开平方调用的局部变量，另一次调用会有另一帧。

3.3 用可变数据建模

PDF 369

两次观察之间究竟改了哪一条边？让两个变量引用同一个盒子，将盒中 1 写成 7；由另一名字读取也得到 7。再造一个内容为 7 的盒子，单独改它不会传播到第一盒。必须区分值相等和存储位置相同。

阅读注解
理解与补充

区分外部根与内部边非常重要。改写尾边可以使一段结构从一个根不可达，但另一个变量仍可能保存它；失去一条边不能推出结点已经消失。

3.3.1 可变表结构

PDF 370

怎样只走一遍便反转链？输入三个盒子 A→B→C。保存 B，把 A 的尾改为空；保存 C，把 B 的尾改指 A；最后让 C 指向 B。由 C 读到三个元素，由旧头 A 只能读到一个。该算法的输入须是有限无环尾链。

阅读注解
理解与补充

画反转的每一步时，先标出旧尾部的入口，再画改写后的边。若颠倒这两个动作，程序会丢失尚未处理的结点，最终无法恢复完整序列。

先沿尾边读外层表，再进入首槽所指的子表。内外层不是同一条链。

比较改写前后的首槽，新边指向第二个表；已有变量仍指原来的外盒。

新建盒子自己的两条边分别指向旧结构。分配新头不会复制两个后缀。

替换尾槽后，从旧头出发转入另一条尾链。原尾是否仍可达取决于其他根。

两个槽的箭头汇入同一个结点。经任一路写首槽，另一路都会观察到变化。

两条外边落点不同，虽然打印内容相同，左侧写入不会穿过右侧的边。

3.3.2 队列的表示

PDF 381

如何让插入、删除都不遍历整条链？空队列插入 a 时首尾指同一结点；再插 b 时只修改旧尾和尾指针。删去 a 后首尾同指 b，删去 b 后首指针为空。逐次读取首元素得到 a、b，符合先进先出。查询空队首应报错；题给实现只依据首指针判空。

阅读注解
理解与补充

检查空、单元素和多元素三种状态。单元素时首尾引用的应是同一个盒子，打印队列若同时遍历两个指针，就会错误地把最后一个元素算两遍。

队列一端加入、另一端离开；比较每次操作前后谁是最早仍在队中的元素。

首指针给出遍历入口，尾指针只缓存最后一个盒子；尾端没有额外一份数据。

旧尾的空边接到新结点之后，还要把尾指针移过去。首指针保持原位。

删除只把首指针向后移一步。未被删的结点无须向前复制。

3.3.4 数字电路模拟器

PDF 397

为什么输出事件必须记住安排时的输入？初始与门输入为 0、1，同一时刻先升第一线再降第二线，得到两次采样 1、0。两项事件在同一未来时刻按入列次序执行，最后输出 0，与稳定输入的真值表相符。颠倒同刻事件会让过时的 1 留在输出端。

阅读注解
理解与补充

只追踪最终稳定值可能掩盖同刻事件逆序的错误。把事件入队时采样的位和出队写入的位分别记下来，反向排列时就能看到陈旧值覆盖新值。

沿输入线看动作怎样计算输出；门的延迟属于写输出的事件，不属于读取输入。

输入 1、0 时，或门得 1，与门进位为 0，反相后允许和位为 1。

第一个半加器先合并两位，第二个再合并中间和，两个局部进位由或门合并。

从低位向高位沿进位线读，每个后续级依赖上一级，不能把所有级的延迟只算一次。

3.3.5 约束的传播

PDF 414

温度关系能否不用两套程序就双向计算？输入摄氏 25，通过乘 9、除 5、加 32 得到华氏 77。先撤回原信息，再从华氏端输入 212，依次减 32、乘 5、除 9 得摄氏 100。两组值均满足同一等式。未撤回既有值便写入矛盾值应报告冲突。

阅读注解
理解与补充

传播要知道是谁提供了当前值。若甲推得一个值，乙随后撤回自己的输入，不能无条件擦掉甲仍支持的事实；只有对应信息源可使连接器失值。

从摄氏端走到乘法器再到加法器，也可由华氏端反走。连接器只保存值和信息来源。

3.4 并发：时间与顺序

PDF 429

多个正确过程如何合成错误余额？余额 100，两笔提款各为 10、20。若都读到 100，再写 90、80，最后只扣了 20。按任一串行次序执行都应得到 70。确定性交错用于展示反例，不能代表所有硬件行为。

阅读注解
理解与补充

串行化的范围取决于需要保持的性质。一个账户上的加减各自正确，并不自动保证两个账户在交换之后仍持有原来的那两个数值。

3.4.1 并发系统中时间的性质

PDF 431

为何只比较最后一条写指令不够？让两个计算共享初值 10：平方两次读 10 得到 100，若递增随后读 100 则写 101；若递增在平方写回前读 10 并先写 11，最终会被旧的 100 覆盖。必须说明每一次读是否属于同一原子操作。

阅读注解
理解与补充

在时间线上标出所有读取，再标写回。若直接把乘法当作一次不可分割动作，就漏掉两次读取之间另一进程写入导致的混合乘积。

    (set-mcdr! (mcdr a) b)
    (set-mcar! (mcdr b) a))

    (define first (forward sentinel))
    (define last (back sentinel))
    (case op
      [(empty?) (eq? first sentinel)]
      [(front-insert! rear-insert!)
       (define right (if (eq? op 'front-insert!) first sentinel))

(define (make-logic-network and-delay or-delay not-delay)
  (define clock 0)
  (define events '())
  (define (later delay action)
    ;; Stable sort keeps previously inserted events first when times tie.
    (set! events (sort (append events (list (cons (+ clock delay) action))) < #:key car)))
  (define (wire)
    (define bit 0)
    (define actions '())
    (lambda (message . args)
      (case message
        [(read) bit]
        [(write)
         (unless (= bit (car args))
           (set! bit (car args))
           (for-each (lambda (act) (act)) actions))]
        [(attach) (set! actions (cons (car args) actions)) ((car args))])))
  (define (gate f delay ins out)
    (define (act)
      (define next (apply f (map (lambda (w) (w 'read)) ins)))
      (later delay (lambda () (out 'write next))))
    (for-each (lambda (w) (w 'attach act)) ins))
  (define (and! a b out) (gate bitwise-and and-delay (list a b) out))
  (define (or! a b out) (gate bitwise-ior or-delay (list a b) out))
  (define (not! a out) (gate (lambda (x) (- 1 x)) not-delay (list a) out))
  (define (or-via-not! a b out)
    (define x (wire)) (define y (wire)) (define z (wire))
    (not! a x) (not! b y) (and! x y z) (not! z out))
  (define (half! a b sum carry)
    (define d (wire)) (define e (wire))
    (or! a b d) (and! a b carry) (not! carry e) (and! d e sum))
  (define (full! a b cin sum cout)
    (define mid (wire)) (define c1 (wire)) (define c2 (wire))
    (half! b cin mid c1) (half! a mid sum c2) (or! c1 c2 cout))
  (define (ripple! as bs ss carry)
    ;; Wires are listed least significant first.
    (unless (= (length as) (length bs) (length ss)) (error 'ripple! "unequal widths"))
    (let loop ([as as] [bs bs] [ss ss] [cin (wire)])
      (unless (null? as)
        (define cout (if (null? (cdr as)) carry (wire)))
        (full! (car as) (car bs) cin (car ss) cout)
        (loop (cdr as) (cdr bs) (cdr ss) cout))))
  (define (propagate)
    (unless (null? events)
      (define event (car events))
      (set! events (cdr events)) (set! clock (car event))
      ((cdr event)) (propagate)))
  (values wire or! or-via-not! ripple! propagate))

  • 对于 (scale-stream S 3) 和 (scale-stream S 5) 也是如此。
  • 这些就是 S 的全部元素。

(define (merge s1 s2)
  (cond ((stream-null? s1) s2)
        ((stream-null? s2) s1)
        (else
         (let ((s1car (stream-car s1))
               (s2car (stream-car s2)))
           (cond ((< s1car s2car)
                  (cons-stream 
                   s1car 
                   (merge (stream-cdr s1) 
                          s2)))
                 ((> s1car s2car)
                  (cons-stream 
                   s2car 
                   (merge s1 
                          (stream-cdr s2))))
                 (else
                  (cons-stream 
                   s1car
                   (merge 
                    (stream-cdr s1)
                    (stream-cdr s2)))))))))

       (if (null? front) (set! front node) (set-mcdr! rear node))
       (set! rear node)]
      [(delete!)
       (when (null? front) (error 'queue "empty queue"))
       (begin0 (mcar front)
         (set! front (mcdr front))
         (when (null? front) (set! rear '())))]
      [(items) (let loop ([p front])
                 (if (null? p) '() (cons (mcar p) (loop (mcdr p)))))]
      [else (error 'queue "unknown message")])))

(define (make-path-table same-key?)
  (struct branch (children value present?) #:mutable)
  (define root (branch '() #f #f))
  (define (find path insert?)
    (for/fold ([node root]) ([key path] #:break (not node))
      (define found (assoc key (branch-children node) same-key?))
      (cond [found (cdr found)]
            [insert?
             (define child (branch '() #f #f))
             (set-branch-children! node (cons (cons key child) (branch-children node)))
             child]
            [else #f])))
  (lambda (message keys . args)
    (case message
      [(put!)
       (define node (find keys #t))
       (set-branch-value! node (car args))
       (set-branch-present?! node #t)]
      [(get)
       (define node (find keys #f))
       (unless (and node (branch-present? node)) (error 'table "no value"))
       (branch-value node)]
      [else (error 'table "unknown message")])))

;; One time segment of the AND gate agenda. Sample at input change time.
(define (schedule-and inputs)
  (define agenda (make-fifo))
  (for ([sample inputs])
    (define bit (bitwise-and (car sample) (cadr sample)))
    (agenda 'insert! (lambda () bit)))
  (let fire ()
    (if (agenda 'empty?) '()
        (cons ((agenda 'delete!)) (fire)))))

;; Deterministic read/write interleavings; no hardware scheduling assumptions.
;; Each process reads x once per factor, then writes the product.
(define (transitions factors)
  (define (search value states)
    (if (andmap not states) (set value)
        (for/fold ([results (set)]) ([s states] [index (in-naturals)] #:when s)
          (define reads (car s))
          (define product (cdr s))
          (define reading? (positive? reads))
          (set-union results
                     (search (if reading? value product)
                             (list-set states index
                                       (and reading? (cons (sub1 reads) (* value product)))))))))
  (search 10 (map (lambda (n) (cons n 1)) factors)))

;; Node = (value . (previous . next)); the sentinel closes both ends.
(define (make-deque)
  (define sentinel (mcons #f (mcons #f #f)))
  (define (back n) (mcar (mcdr n)))
  (define (forward n) (mcdr (mcdr n)))
  (define (link! a b)
    (set-mcdr! (mcdr a) b)
    (set-mcar! (mcdr b) a))
  (link! sentinel sentinel)
  (lambda (op . args)
    (define first (forward sentinel))
    (define last (back sentinel))
    (case op
      [(empty?) (eq? first sentinel)]
      [(front-insert! rear-insert!)
       (define right (if (eq? op 'front-insert!) first sentinel))
       (define node (mcons (car args) (mcons #f #f)))
       (link! (back right) node)
       (link! node right)]
      [(front rear front-delete! rear-delete!)
       (when (eq? first sentinel) (error 'deque "empty deque"))
       (define n (if (memq op '(front front-delete!)) first last))
       (when (memq op '(front-delete! rear-delete!)) (link! (back n) (forward n)))
       (mcar n)]
      [else (error 'deque "unknown request")])))

;; The connectors supply the textbook messages has?, get, set!, forget!, connect!.
(define (make-squarer a b)
  (define (update)
    (cond [(b 'has?)
           (when (< (b 'get) 0) (error 'squarer "negative square"))
           (a 'set! (sqrt (b 'get)) self)]
          [(a 'has?) (b 'set! (sqr (a 'get)) self)]))
  (define (self message)
    (case message
      [(new) (update)]
      [(lost) (a 'forget! self) (b 'forget! self) (update)]))
  (a 'connect! self)
  (b 'connect! self)
  self)

;; Counting semaphore using Racket's atomic semaphore for the guard and wakeup.
(define (semaphore-counter n)
  (unless (exact-positive-integer? n) (error 'semaphore-counter "expected positive capacity"))
  (define guard (make-semaphore 1))
  (define wake (make-semaphore 0))
  (define free n)
  (define (acquire)
    (define ok? (call-with-semaphore guard (lambda ()
                  (and (> free 0) (begin (set! free (sub1 free)) #t)))))
    (unless ok? (semaphore-wait wake) (acquire)))
  (lambda (message)
    (case message
      [(acquire) (acquire)]
      [(release)
       (call-with-semaphore guard
         (lambda ()
           (when (= free n) (error 'semaphore-counter "unmatched release"))
           (set! free (add1 free))
           (semaphore-post wake)))]
      [else (error 'semaphore-counter "unknown request")])))

;; Textbook-style wire and agenda interface, injected so the gates can be tested
;; on simulated time. An agenda event captures the sampled bit before scheduling.
(provide make-logic-network make-connector averager c-constant c-product c-sum
         c-difference c-quotient)
(define (make-logic-network and-delay or-delay not-delay)
  (define clock 0)
  (define events '())
  (define (later delay action)
    ;; Stable sort keeps previously inserted events first when times tie.
    (set! events (sort (append events (list (cons (+ clock delay) action))) < #:key car)))
  (define (wire)
    (define bit 0)
    (define actions '())
    (lambda (message . args)
      (case message
        [(read) bit]
        [(write)
         (unless (= bit (car args))
           (set! bit (car args))
           (for-each (lambda (act) (act)) actions))]
        [(attach) (set! actions (cons (car args) actions)) ((car args))])))
  (define (gate f delay ins out)
    (define (act)
      (define next (apply f (map (lambda (w) (w 'read)) ins)))
      (later delay (lambda () (out 'write next))))
    (for-each (lambda (w) (w 'attach act)) ins))
  (define (and! a b out) (gate bitwise-and and-delay (list a b) out))
  (define (or! a b out) (gate bitwise-ior or-delay (list a b) out))
  (define (not! a out) (gate (lambda (x) (- 1 x)) not-delay (list a) out))
  (define (or-via-not! a b out)
    (define x (wire)) (define y (wire)) (define z (wire))
    (not! a x) (not! b y) (and! x y z) (not! z out))
  (define (half! a b sum carry)
    (define d (wire)) (define e (wire))
    (or! a b d) (and! a b carry) (not! carry e) (and! d e sum))
  (define (full! a b cin sum cout)
    (define mid (wire)) (define c1 (wire)) (define c2 (wire))
    (half! b cin mid c1) (half! a mid sum c2) (or! c1 c2 cout))
  (define (ripple! as bs ss carry)
    ;; Wires are listed least significant first.
    (unless (= (length as) (length bs) (length ss)) (error 'ripple! "unequal widths"))
    (let loop ([as as] [bs bs] [ss ss] [cin (wire)])
      (unless (null? as)
        (define cout (if (null? (cdr as)) carry (wire)))
        (full! (car as) (car bs) cin (car ss) cout)
        (loop (cdr as) (cdr bs) (cdr ss) cout))))
  (define (propagate)
    (unless (null? events)
      (define event (car events))
      (set! events (cdr events)) (set! clock (car event))
      ((cdr event)) (propagate)))
  (values wire or! or-via-not! ripple! propagate))

(define (make-connector)
  (define source #f) (define value #f) (define constraints '())
  (define (notify except message)
    (for ([c constraints] #:unless (eq? c except)) (c message)))
  (lambda (message . args)
    (case message
      [(has?) (and source #t)] [(get) value]
      [(set!)
       (match-define (list x who) args)
       (cond [(not source) (set! value x) (set! source who) (notify who 'new)]
             [(not (= x value)) (error 'connector "conflicting values")])]
      [(forget!)
       (when (eq? source (car args)) (set! source #f) (set! value #f) (notify (car args) 'lost))]
      [(connect!)
       (unless (memq (car args) constraints)
         (set! constraints (cons (car args) constraints))
         (when source ((car args) 'new)))])))

(define (relation op reverse-op a b c product?)
  (define (infer)
    (cond [(and product? (or (and (a 'has?) (zero? (a 'get)))
                             (and (b 'has?) (zero? (b 'get))))) (c 'set! 0 self)]
          [(and (a 'has?) (b 'has?)) (c 'set! (op (a 'get) (b 'get)) self)]
          [(and (a 'has?) (c 'has?)) (b 'set! (reverse-op (c 'get) (a 'get)) self)]
          [(and (b 'has?) (c 'has?)) (a 'set! (reverse-op (c 'get) (b 'get)) self)]))
  (define (self message)
    (when (eq? message 'lost)
      (for ([x (list a b c)]) (x 'forget! self)))
    (infer))
  (for ([x (list a b c)]) (x 'connect! self)))
