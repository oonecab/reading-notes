从关系到方法，从方法到可操作的对象

原书 p.1 / PDF 29 起。

数学可以用“平方后等于给定数”定义平方根；程序还必须交代怎样产生候选、怎样改进、何时停止。原书把这种“怎样做”的知识写成过程，然后反过来研究：一个短小的过程描述，究竟会展开成怎样的时间和空间消耗？

本章三次改变观察尺度。§1.1 解释表达式如何组合、名字如何绑定，使用求根建立过程抽象；§1.2 比较递归、迭代、树形展开和增长阶；§1.3 把“求和”“找不动点”“改造函数”本身变成可传递、可返回的过程。最后获得的不是更多语法，而是一组能够组合的方法。

阅读注解
理解与补充

先问这一层承诺什么

阅读时交替写三句话：这个过程的输入与结果是什么；它怎样推进；我为何相信结果和停止条件。相同的数学答案可以由不同的计算过程产生，接口相同也不等于成本相同。

1.1 程序设计的基本元素

原书 p.6 / PDF 34 起。

一种语言应提供基本表达式、组合手段和抽象手段。Scheme 的前缀组合把操作符和操作数写在同一对括号中；过程定义又把已有组合命名，使下一层程序可以把它当作一个部件。数据与过程在本章先分别作为被操作的东西和操作方法，后面将逐步看见两者都能成为组合材料。

阅读注解
理解与补充

括号统一，求值规则仍有边界

普通过程调用、定义与条件式的表面形式相似，却不能共享同一个“先求所有子式的值”的规则。每读到新形式，都要先确定它是否是特殊形式。

1.1.1 表达式：把计算写成树

原书 p.7 / PDF 35 起。

数值是最简单的表达式；(+ 137 349) 是组合式，第一项是操作符，其余项是操作数。前缀形式允许任意多个参数，也不依赖通常的乘除优先级；嵌套括号明确给出子表达式的结构。解释器的读入、求值、打印循环提供即时反馈，缩进则把树的层次交给人看。

(+ (* 3 (+ (* 2 4) (+ 3 5)))
   (+ (- 10 7) 6))
;; => 57
阅读注解
理解与补充

从最内层开始读

先辨认最外层做什么，再求出它需要的子结果。不要把一长串括号当作从左往右的字符操作；缩进与换行不改变语法树，缺少或多出括号却会改变树。

1.1.2 命名与环境

原书 p.10 / PDF 38 起。

(define size 2) 把名字和一个值关联起来。环境保存这些关联，因此后续组合能用名字指代先前建立的值。通过逐步定义圆周率、半径、周长，一个复杂计算可以由一系列有意义的名字组织起来。定义不是通常意义上的数值表达式，其打印反馈依实现而异。

阅读注解
理解与补充

名字不是文本替换宏

环境告诉求值器一个名字指向什么；过程定义的形式参数又会在应用时引入局部绑定。本章先用代换帮助理解纯过程，第 3 章引入赋值后必须使用更完整的环境模型。

1.1.3 组合式的求值

原书 p.12 / PDF 40 起。

普通组合式先求各子表达式的值，再把操作符所得的过程应用到操作数所得的参数。对子式重复应用同一规则，就得到沿语法树向上的求值。数值的值是自身，基本过程的名字指向对应运算，其他名字由环境给值。define 则按专门规则处理名字与定义式，不能先把待定义的名字当成普通参数求值。

阅读注解
理解与补充

不要凭结果假定操作数的顺序

本章的无副作用算式通常不暴露操作数先后；Scheme 的一般论述也没有在这里保证逐个从左到右。本文在 Racket 中执行的具体实验依其规则进行，后文讨论其他求值模型时单独说明。

1.1.4 复合过程

原书 p.15 / PDF 43 起。

定义 square 后，调用者只需知道它返回参数的平方；再用它定义平方和，便能继续组合。形式参数是过程定义中的局部名字，应用时由实际参数值提供本次计算的输入。过程体的写法可以替换，只要对外承诺保持，客户就可以停留在同一抽象层。

(define (square x) (* x x))
(define (sum-of-squares x y) (+ (square x) (square y)))
(define (f a) (sum-of-squares (+ a 1) (* a 2)))
(f 5) ; => 136

理解与补充

把定义读成一句契约

square 的定义给出实现，名字给出复用入口；两者共同形成抽象。只看名字不能保证行为正确，仍要核对定义或已有证据。过程也可以作为值出现在操作符位置，习题 1.4 已埋下伏笔。

1.1.5 过程应用的代换模型

原书 p.18 / PDF 46 起。

对纯复合过程，可以把应用理解为：用实际参数值替换过程体中相应形式参数，再求值。例如先求 (+ a 1) 与 (* a 2)，再展开平方和。这种“先求参数、再应用”的方式称应用序。正则序则先展开外层过程，直到需要基本操作时才求其参数；重复出现的子式可能被重复计算。

对本章适用的纯、终止表达式，两种规则常给出相同结果；这不足以说明它们总能同时终止。(test 0 (p)) 将在习题 1.5 中区分它们。代换模型是解释工具，避免把同名局部变量错误地捕获也需要关注绑定范围。

阅读注解
理解与补充

正则序不自动记忆结果

按需展开一个表达式，与把第一次所得的值存下来供以后复用，是两件事。习题 1.20 的 18 次求余依赖没有这种记忆；带记忆的惰性计算将在第 4 章另讲。

1.1.6 条件表达式与谓词

原书 p.22 / PDF 50 起。

cond 按顺序检查谓词，选第一个为真的子句求值；else 是最后的兜底。if 先判断谓词，再只求两个分支之一。and 与 or 也会短路，not 取反。由此可以定义绝对值和分段函数，而不会执行未选中的危险计算。

(define (abs-value x)
  (cond ((< x 0) (- x))
        (else x)))
阅读注解
理解与补充

真假与分支的契约

Scheme 以 #f 为假，其他值为真；谓词通常主动返回布尔值。短路还允许先验证分母不为零，再做除法。把 if 包在一个普通 new-if 过程中会丢失“未选分支不求值”的性质。

1.1.7 例子：牛顿法求平方根

原书 p.28 / PDF 56 起。

“平方等于输入”是说明式定义；牛顿迭代把它改成生成答案的方法。对正数和正猜测，用猜测与输入除以猜测的平均数改进，再检查是否足够好。原书把 good-enough?、improve 和 sqrt-iter 分开，因而能分别讨论停止、进展和控制。

ynext=(y+x/y)/2。例如输入 2，从 1 开始依次得到 1.5、约 1.416667、约 1.414216。原书以平方残差小于 0.001 停止，这只是演示选择；它不承诺所有尺度上相同的有效数字。习题 1.7 将改用相邻猜测的相对变化，并显式处理零和非法输入。

原始平方根与停止测试 · PDF 58、PDF 59

此处是原书的绝对残差版本，供1.6—1.8和1.46引用；依赖前面的square、average。其零值、尺度与浮点局限在1.7另行修改，不能把此版本当作改进版。

教材输入 · 原始平方根与停止测试
(define (sqrt-iter guess x)
  (if (good-enough? guess x)
      guess
      (sqrt-iter (improve guess x) x)))

(define (improve guess x)
  (average guess (/ x guess)))

(define (good-enough? guess x)
  (< (abs (- (square guess) x)) 0.001))

(define (sqrt x)
  (sqrt-iter 1.0 x))
阅读注解
理解与补充

近似值为什么不继续变化

浮点数只能取有限多个可表示值；即使目标误差尚未达到，下一次改进也可能舍入回自身。停止条件、相对误差、残差和最大迭代次数各管不同问题，不能把其中一项当成普遍收敛证明。

1.1.8 过程作为黑箱抽象

原书 p.33 / PDF 61 起。

求根的调用者不必同时阅读所有辅助过程。过程参数的名字可一致地改名而不改变行为，这称约束变量的改名；自由变量则来自外围绑定。把辅助过程放进 sqrt 内部，再让它们共享外部参数 x，便得到块结构和词法作用域：名字的含义由程序文本中的定义位置决定。

(define (sqrt-local x)
  (define (good? y) (< (abs (- (* y y) x)) 0.001))
  (define (improve y) (/ (+ y (/ x y)) 2))
  (define (iter y) (if (good? y) y (iter (improve y))))
  (iter 1.0))

这里的内部辅助过程依赖同一次调用的 x，却不把它暴露为全局名字。上述代码忠实演示原书的停止规则；实际边界改进另见习题 1.7。过程抽象使我们能够更换实现，也要求我们明确客户可依赖的输入范围与近似精度。

阅读注解
理解与补充

同名不表示同一绑定

外层或别处也可以有名为 x 的变量。分析某次出现时，从它在文本中的位置寻找最近有效绑定；不要沿运行时调用者的局部变量猜测。返回的过程仍能使用定义时的自由变量，这会在 §1.3.4 再次出现。

1.2 过程与它们产生的计算

原书 p.40 / PDF 68 起。

过程定义是静态描述，计算过程是描述随输入展开的活动。比较算法时既看结果，也看基本步骤数与必须保留的信息。以下空间指尚未完成的计算所需状态或控制信息，增长阶先按原书的基本操作单位计数；精确大整数的位成本另行说明。

阅读注解
理解与补充

把输入规模与成本单位写出来

指数、金额、整数大小各自是不同的规模变量。声称“对数时间”前先说相对于哪个变量，以及乘法、求余是否按常数成本计数；这决定结论的适用范围。

1.2.1 线性递归与迭代

原书 p.41 / PDF 69 起。

阶乘的直接定义先计算较小的阶乘，再补做乘法。展开时积压乘法，返回时逐层收缩，因此是线性递归过程。另一版本只保存当前乘积、计数器与上界，转移到下一状态时没有待做运算，因此是线性迭代过程。二者步骤数都随输入线性增长，控制空间分别线性与常量。

(define (factorial-iter n)
  (define (iter product counter)
    (if (> counter n) product
        (iter (* counter product) (+ counter 1))))
  (iter 1 1))

迭代版本仍在语法上调用自己。Scheme 的尾调用语义使这种状态转移无需保留一层等待返回的调用；换到不保证尾调用的实现，应重新检查实际空间。源程序出现递归调用，不足以判定它产生递归过程。

阅读注解
理解与补充

状态是否足以恢复下一步

若只给当前乘积、计数器和上界，就能完整继续迭代；若仍有一串乘法等待子结果，则这些待做操作也是状态。用这个检查比数函数名出现几次更可靠。

1.2.2 树形递归与换零钱

原书 p.47 / PDF 75 起。

朴素 Fibonacci 把一次调用拆成两个较小调用，重复计算同一子问题。树的节点数按黄金比例指数增长，最大深度仍线性。利用相邻两项构造状态转移，可得到线性步数、常量个状态变量的版本。换零钱的递归则按“是否使用一种面额”分解：不用该面额，或使用一枚后继续处理剩余金额。

记金额为 a、可用面额数为 k，则 C(a,k)=C(a,k−1)+C(a−dk,k)。金额为零有一种空选法；负金额或无可用面额而金额仍正时为零。这个分解避免按硬币排列重复计数。习题 1.14 给出 11 美分的全部调用关系。

Fibonacci 的递归定义 · PDF 76

下标为非负整数，起始值为0和1，后续项为前两项之和。黄金比例是φ=(1+5)/2；1.13将从该递推证明闭式。

教材输入 · Fibonacci 的递归定义
(define (fib n)
  (cond ((= n 0) 0)
        ((= n 1) 1)
        (else (+ (fib (- n 1))
                 (fib (- n 2))))))

Fibonacci 的状态迭代 · PDF 78

这是替代上一个fib定义的另一版本，不把两个同名定义并列装进一个模块。初态(a,b)=(1,0)，每步同时更新为(a+b,a)。

教材输入 · Fibonacci 的状态迭代
(define (fib n)
  (fib-iter 1 0 n))

(define (fib-iter a b count)
  (if (= count 0)
      b
      (fib-iter (+ a b) a (- count 1))))

count-change 的完整输入 · PDF 80

固定五种面额，amount为整数、kinds-of-coins在0—5内；金额为零先于无面额分支判断。习题1.14的全部调用树以这一定义为准。

教材输入 · count-change 的完整输入
(define (count-change amount)
  (cc amount 5))

(define (cc amount kinds-of-coins)
  (cond ((= amount 0) 1)
        ((or (< amount 0)
             (= kinds-of-coins 0))
         0)
        (else
         (+ (cc amount (- kinds-of-coins 1))
            (cc (- amount (first-denomination
                           kinds-of-coins))
                kinds-of-coins)))))

(define (first-denomination kinds-of-coins)
  (cond ((= kinds-of-coins 1) 1)
        ((= kinds-of-coins 2) 5)
        ((= kinds-of-coins 3) 10)
        ((= kinds-of-coins 4) 25)
        ((= kinds-of-coins 5) 50)))
阅读注解
理解与补充

树适合说明分解，也会暴露重复

重复节点不代表不同的答案，而是相同子问题被重新计算。把结果记忆下来会改变运行成本，也引入存储结构；本章先从原始树分析，不能把后来的动态规划成本写回原算法。

1.2.3 增长阶

原书 p.54 / PDF 82 起。

若存在正常数，使资源函数在足够大的输入上被同一个比较函数的常数倍从上下夹住，就写成 R(n)=Θ(f(n))。它忽略常数和低阶项，保留输入增大时的主要趋势。线性递归阶乘的时间和空间均为 Θ(n)，尾迭代的控制空间为 Θ(1)；朴素 Fibonacci 时间为 Θ(φn)、栈深为 Θ(n)。

这是粗粒度模型。返回一个巨大整数本身就需要越来越多位；“常量空间”通常指常量个寄存器或状态变量，而不是输出位数恒定。实测还会受到解释器、编译、缓存与计时分辨率影响。

阅读注解
理解与补充

上界不等于紧确阶

一个线性算法也满足二次上界，但不能据此称它为 Θ(n2)。若只证明不超过某个量，用 O；上下两侧都能成立才使用 Θ。本章的计时表用来观察模型，不能反过来替代证明。

1.2.4 求幂：用不变量压缩步骤

原书 p.57 / PDF 85 起。

逐次乘法的次数与指数线性相关；偶数指数可以先算半指数，再平方。每次把指数减半，使计算深度与乘法次数降为对数。递归版本在返回时平方；迭代版本多保存一个累计乘积，用不变量 abn=BN 表明每一步保持原目标。奇数步把一个底数并入累计值，偶数步则平方底数并折半指数。

相同思想可以作用到乘法和线性变换。§1.2.4 的脚注还把乘法次数精确关联到指数的二进制长度和其中 1 的数量；数量级分析只保留对数增长。

递归 fast-expt · PDF 86

这里的指数为非负整数。square只求一次半指数结果；1.16把同一目标改为迭代，1.25比较完整求幂与逐步取模。

教材输入 · 递归 fast-expt
(define (fast-expt b n)
  (cond ((= n 0)
         1)
        ((even? n)
         (square (fast-expt b (/ n 2))))
        (else
         (* b (fast-expt b (- n 1))))))
阅读注解
理解与补充

平方结果必须复用

(square (fast-expt b (/ n 2))) 只计算一次半指数；把它写成两个同样的递归调用，会重新展开两棵树。习题 1.26 让这个差别在模幂中变得明显。

1.2.5 最大公约数

原书 p.62 / PDF 90 起。

若 r=amodb，则 gcd(a,b)=gcd(b,r)，因为两对数有完全相同的公因子。不断把两数替换为较小数及余数，到第二项为零时，第一项即为答案。206 与 40 依次变成 (40,6)、(6,4)、(4,2)、(2,0)，共求余四次。

1.2.6 素数测试与概率证据

原书 p.65 / PDF 93 起。

        (else else-clause)))

习题 1.7 · 相对停止条件

原题（中文翻译）

原书 p.33 / PDF 61。

解答与推导

输入 10−12 的平方根应为 10−6，原测试却约在猜测 0.03125 时就接受，因为其平方已经小于 0.001；相对误差极大。实测输入 1013 时，原测试在 2000 步内仍不能接受，因浮点平方残差无法满足小于 0.001；猜测停滞也不会自动使它通过。另一些大数恰好可表示为所需平方，仍可能正常结束，所以问题是这一阈值缺少统一保证。

原书 p.73 / PDF 101。

Louis Reasoner 的 1.24 程序似乎比 prime? 还慢。Eva 看到他把 expmod 的平方写成了两个递归调用的显式乘法，如下。Eva 说这把 Θ(logn) 过程变成了 Θ(n) 过程。解释她为何正确。

(define (expmod base exp m)
  (cond ((= exp 0) 1)
        ((even? exp)
         (remainder
          (* (expmod base (/ exp 2) m)
             (expmod base (/ exp 2) m))

习题 1.28 · Miller–Rabin 与校注

原题（中文翻译）

原书 p.73 / PDF 101–102。

Miller–Rabin 检验是不会被 Carmichael 数欺骗的 Fermat 变体。若 n 是素数，正整数 a<n 满足 an−1≡1（模 n）。随机取 a，用 expmod 计算这个幂；每次平方时检查是否发现模 n 的 1 的非平凡平方根，即不等于 1 或 n−1、平方却与 1 同余的数；发现它可证明 n 不是素数。原题进一步声称：对奇合数 n，至少一半 a<n 的上述幂计算会揭示这样的平方根，因此不会被欺骗。修改 expmod，使发现这种根时发出信号；再据此写类似 fast-prime? 的 Miller–Rabin 检验，在已知素数和合数上测试。提示：可让 expmod 返回 0 发信号。

解答与推导

平方前保留 x，令 r=x2modn；若 r=1 且 x 既非 1 又非 n−1，返回哨兵 0，并让外层模运算继续传播 0。最终只有结果为 1 才接受，这也会拒绝未出现非平凡平方根、但最终余数已经不为 1 的底数。素数情况下，域中 (x−1)(x+1)=0 只能给出 ±1，因此哨兵不会误拒素数。

原题校注：“至少一半底数会揭示非平凡平方根”不能逐字当作一般定理。9 的模平方根中，平方等于 1 的只有 1、8，没有非平凡者；底数 2 却给出 28mod9=4，由最终余数条件识别。正确的概率论述应针对完整的合数见证条件。本文保留原题措辞并用这个反例说明缺口，不把返回 0 当成唯一失败条件。

一次通过也不代表必为素数：2047 在底数 2 上通过，底数 3 上失败。回归检查 2–299 的所有合法底数、六个 Carmichael 数和该强伪素数；固定底数集合对任意整数没有额外确定性保证。

miller-rabin? 接收明示的底数列表，便于复现；miller-rabin/random? 按正整数轮数抽样，并允许传入随机源。概率解释依赖均匀、独立选底；固定返回某个底数的测试用来核对见证逻辑，本身不提供随机误差界。默认随机接口使用与本章 Fermat 实验相同的宿主取值范围。

习题 1.32 · 一般累积与方向

原题（中文翻译）

原书 p.81 / PDF 109–110。

(a) 证明 sum 和 product 都是更一般的 accumulate 的特例。accumulate 按下面的接口组合一系列项：term、a、next、b 意义同前；combiner 是组合当前项和累积结果的二元过程，null-value 是没有项时的值。实现 accumulate，再用它定义 sum 和 product。（b）若实现产生递归过程，补写迭代版本；若产生迭代过程，补写递归版本。

原题（中文翻译）

原书 p.96 / PDF 124。

习题 1.46 · 把改进控制再抽象

原题（中文翻译）
