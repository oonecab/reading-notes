| 题号涉及的接口 | 实现与边界 |
| --- | --- |
| 2.1 make-rat/numer/denom | 整数输入、分母非零；约为互素整数且分母正，零为0/1。枚举1640组带符号输入核对值及不变量。 |
| 2.2 点/线段/中点/print-point | 点坐标为精确有理数，中点取两端平均；打印格式按原给定过程核对。 |
| 2.3 两种矩形 | 原点/边长/角度与原点/两条垂直边向量两种表示；周长、面积只调用宽高选择器。边长必须正，向量必须非零且正交。非平方有理数的开方可能由Racket给出近似值，不宣称所有几何结果精确。 |
| 2.4 过程序对 | procedure-cons/car/cdr避免覆盖宿主名称；选择器保留对象身份。 |
| 2.5 素数指数序对 | 非负整数指数；正整数编码只允许素因子2、3。256组往返及非法因子/零/负数测试。 |
| 2.6 Church数 | 直接给出零、一、二、后继与函数复合加法；用非数字列表构造检查作用次数。 |
| 2.7–2.11 区间四则 | 教学适配把端点排序并限定为精确有理数；相减取下界减另一上界、上界减另一下界。乘法按端点符号分九类；45个整数端点区间两两组合，共2025组，以四角极值独立核对。除数区间包含零（包括端点）即拒绝。 |
| 2.12–2.13 中心/百分比 | 百分数输入1表示1%；宽度为abs(center)*p/100，p非负。中心为零时相对误差未定义，percent报错。正中心小容差乘积按精确式核对，不把近似加法当精确等式。 |
| 2.14–2.16 依赖性实验 | A中心100、容差1%，B中心200、容差1%。实际记录A/A、A/B、par1及par2的精确端点、中心、百分比；这不是一般表达式范围求解器。 |

区间代码故意拒绝浮点端点：普通浮点四则没有自动向外舍入，不能直接声称结果始终包含精确实数值。这个接口限制属于教学执行适配，不改变原书给定程序。负中心百分比按绝对中心定义；零中心不人为指定有限百分比。
