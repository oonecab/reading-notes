这一章还没有给集合分配概率。它先建立一个可以承受可数运算的描述系统，再规定函数怎样把一个空间中的描述拉回另一个空间。沿着原书五节，我们会反复使用同一个想法：把复杂对象拆成可操作的简单对象，证明运算保留我们需要的结构。

§1 集合及其运算

固定非空空间 X，补集 Ac=X⧵A 总是相对于这个 X。并表示“至少一个条件成立”，交表示“条件同时成立”，差 A⧵B 表示“属于 A 且不属于 B”，对称差 A△B 表示“两个条件恰有一个成立”。指示函数 IA 把集合成员关系变为 0 和 1：在 A 上取 1，在外面取 0。

IA∩B=IAIB,IA∪B=IA+IB−IAIB

第一式是“两个开关都开”的乘积；第二式先数两次，再减去交集里多算的一次。这也说明：只有不交时，两个集合的并才能直接用指示函数相加。补集交换“或”与“且”，于是得到 De Morgan 法则。

(⋃tAt)c=⋂tAtc,(⋂tAt)c=⋃tAtc

单调集合列的极限很直观：An↑ 时每个点只会加入，不会退出，极限就是并；An↓ 时每个点只会退出，不会重新加入，极限就是交。非单调时，应分别问一个点“是否从某时起一直出现”和“是否出现无穷多次”。

lim infnAn=⋃m=1∞⋂n≥mAn,lim supnAn=⋂m=1∞⋃n≥mAn

左式先固定起点 m，要求后面每次都属于，再允许存在某个起点；右式要求无论把起点移到多后面，都还能至少出现一次。因此 lim infAn⊆lim supAn，相等时才称集合列有极限。量词的先后次序正是两种极限的差别。

例如 A2n−1=(0,1]、A2n=(1,2]：每个点至多属于两块中的一块，却会在那一块重复出现，所以 lim supAn=(0,2]；没有点从某时起每次出现，所以 lim infAn=∅。反之，两两不交的集合列里每个点最多出现一次，上、下极限都为空。

原书：印刷 1—3 / PDF 13—15

阅读注解
理解与条件

不要把可数偷换成任意

集合恒等式可以涉及任意指标集，但 σ 域只承诺可数并、可数交。后面用有理数表达阈值集合，目的就是把可能不可数的条件变成可数运算。

§2 集合系

为什么要这么多集合系？我们通常先在区间或其他简单集合上定义大小，但一般事件会由它们做交、并、补和极限得到。每一种集合系都记录一组允许的运算；生成与扩张定理负责把简单对象送到更大的体系。

集合系必须保留的运算这项要求的作用
π 系非空；A,B∈P⇒A∩B∈P适合验证交集条件和测度唯一性
半环π 系；包含关系下的差可拆为有限个两两不交的成员区间的差可能不是一个区间，但可有限分片
环非空；有限并与差封闭把有限分片收成一个成员
域（代数）含 X，有限交与补封闭允许做有限逻辑运算
单调系非降并与非增交封闭只处理单调极限
λ 系含 X，真差封闭、非降并封闭适合在有限总量下相减
σ 域（σ 代数）含 X，补与可数并封闭用作可测集合的全体
σ 环非空；差与可数并封闭不一定包含全空间

§2 例 1 · 半直线构成 π 系

类型：定义性短说明

PR={(−∞,a]:a∈R}。两条半直线的交是 (−∞,min(a,b)]，仍在集合系中。它本身不必含 X，也不必对补封闭。

原书：印刷 3 / PDF 15

§2 例 2 · 半开区间怎样切开

类型：定义性短说明

QR={(a,b]:a,b∈R}，允许 a≥b 时为空。两个区间的交仍属这一类；例如 (0,5]⧵(2,3]=(0,2]∪(3,5]。左开右闭的端点约定让切割位置只计入一边，差至多分成两段。开、闭或另一方向的半开区间都是 π 系，但成为半环还须检查差。

原书：印刷 4 / PDF 16

§2 例 3 · 有限空间的单点

类型：定义性短说明

原书在有限空间 X={x1,…,xn} 上，将仅含全部单点集的族写成 π 系和半环。

原书校注

扫描印刷 4 页的族中未列空集。若 n≥2，两个不同单点的交为空，故原族不是 π 系；即使 n=1，成员减自身也要求空集。应使用 {∅,{x1},…,{xn}}。这是补齐原例的缺项，不能在显示原题时悄悄加入。

原书：印刷 4 / PDF 16

§2 例 4 · 有限个半开区间的并形成环

类型：定义性短说明

RR 为有限个 (a,b] 的并所组成的集合系。把两个表示中的所有端点排序，用相邻端点切成共同的小段；并集保留至少出现一次的小段，差集保留只在前一个集合出现的小段，因此仍是有限个半开区间的并。

原书：印刷 4 / PDF 16

§2 例 5 · 有限空间的所有子集

类型：定义性短说明

P(X) 对并、交和差都封闭，所以是环；它还包含 X 并对任意并封闭，因此也是 σ 域。注意“成员有限”与“集合系成员个数有限”是不同的两个概念。

原书：印刷 4 / PDF 16

命题 1.2.1 · 有限运算的包含关系

仅页码定位，无逐句摘录。

域必是环，环必是半环，半环必是 π 系。

原书：印刷 5 / PDF 17

证明与理解

域中先用 De Morgan 得有限并，再写 A⧵B=A∩Bc 得差。环中 A∩B=A⧵(A⧵B)，所以有交；当 B 包含于 A 时，差本身就是一个环成员，已是所需的一个分片。半环是 π 系则直接来自定义。

命题 1.2.2·σ 域、λ 系与单调系

仅页码定位，无逐句摘录。

σ 域是 λ 系；λ 系是单调系。

原书：印刷 6 / PDF 18

证明与理解

σ 域中真差可写成与补集的交，非降并属于可数并。λ 系包含补集 Ac=X⧵A；若 An↓A，则 Anc↑Ac，先取非降并再取补即得到 A，故下降极限也保留。

命题 1.2.3 · 域加单调封闭就够了

仅页码定位，无逐句摘录。

一个同时是域和单调系的集合系必是 σ 域。

原书：印刷 6 / PDF 18

证明与理解

给定任意成员列 An，先取有限并 Bn=⋃k≤nAk。域保证每个 Bn 仍是成员，且 Bn↑⋃nAn；单调封闭便补上可数并。补集和全空间早已由域提供。

命题 1.2.4·π 系与 λ 系的交会

仅页码定位，无逐句摘录。

一个同时是 π 系和 λ 系的集合系必是 σ 域。

原书：印刷 7 / PDF 19

证明与理解

λ 系给 X 和补，π 系给有限交，所以它是域；命题 1.2.2 又给单调封闭，再用命题 1.2.3。

于是可测空间定义为 (X,F)，其中 F 是 X 上的 σ 域。可测性是相对于这个集合系而言的；同一个子集在较细的集合系里可测，在较粗的集合系里可能不可测。

原书：印刷 3—7 / PDF 15—19

把“分辨能力”算一遍

设 X={0,1,2,3}，只允许观察“是否属于 A={0,1}”。观察只能把空间分成 A 和 Ac={2,3} 两块，不能区分 0 与 1；因此生成的 σ 域只有 ∅,A,Ac,X。这两个无法再分的非空块称为原子。加入 B={0,2} 后，四种是否属于 A、B 的组合恰好区分四个点，才得到全部 16 个子集。

程序的位掩码 3 表示 {0,1}，12 表示 {2,3}。它从全空间这个原子出发，遇到一个生成元就把每个原子切成“在生成元内”和“在生成元外”两份，丢弃空片；所有原子的并构成生成的 σ 域。循环不变量是：已处理的每个生成元都由当前原子拼成。

"""Finite sigma fields and cover outer measures; at most eight labelled points."""
import json
import re
import sys


def space(n):
    if not isinstance(n, int) or not 1 <= n <= 8:
        raise ValueError('n must be an integer from 1 to 8')
    return (1 << n) - 1


def sigma_field(n, generators):
    full = space(n)
    if any(not isinstance(g, int) or not 0 <= g <= full for g in generators):
        raise ValueError('generator is outside the finite space')
    atoms = [full]
    for generator in generators:
        atoms = [part for atom in atoms
                 for part in (atom & generator, atom & (full ^ generator)) if part]
    atoms.sort()
    family = [0]
    for atom in atoms:
        family += [member | atom for member in family]
    return {'atoms': atoms, 'sets': sorted(family)}


def outer_measure(n, offers):
    full = space(n)
    if len(offers) > 256:
        raise ValueError("at most 256 cover options")
    for mask, cost in offers:
        if not isinstance(mask, int) or not 0 <= mask <= full:
            raise ValueError('cover is outside the finite space')
        if not isinstance(cost, int) or not 0 <= cost <= 1000000:
            raise ValueError('cost must be an integer from 0 to 1000000')
    infinity = float('inf')
    costs = [infinity] * (full + 1)
    costs[0] = 0
    # Union can only add bits, so nontrivial transitions increase the mask.
    for covered in range(full + 1):
        for mask, cost in offers:
            target = covered | mask
            costs[target] = min(costs[target], costs[covered] + cost)
    tau = [min(costs[covered] for covered in range(full + 1)
               if covered & target == target) for target in range(full + 1)]
    measurable = [a for a in range(full + 1)
                  if all(tau[d] == tau[d & a] + tau[d & (full ^ a)]
                         for d in range(full + 1))]
    return {'outer': [None if x == infinity else x for x in tau],
            'measurable': measurable}


def integer(token):
    if not re.fullmatch(r'-?[0-9]+', token):
        raise ValueError('expected ASCII integer without whitespace or plus')
    return int(token)


def main(argv):
    if len(argv) < 2:
        raise ValueError('usage: sigma n [mask ...] | outer n [mask:cost ...]')
    mode, n = argv[0], integer(argv[1])
    if mode == 'sigma':
        result = sigma_field(n, [integer(x) for x in argv[2:]])
    elif mode == 'outer':
        offers = []
        for item in argv[2:]:
            parts = item.split(':')
            if len(parts) != 2 or len(parts[0]) >= 32:
                raise ValueError('expected mask:cost')
            offers.append(tuple(map(integer, parts)))
        result = outer_measure(n, offers)
    else:
        raise ValueError('mode must be sigma or outer')
    print(json.dumps(result, separators=(',', ':')))


if __name__ == '__main__':
    try:
        main(sys.argv[1:])
    except ValueError as error:
        print(str(error), file=sys.stderr)
        sys.exit(2)

/* Finite model: bits 0..n-1 name points; null in JSON denotes infinity. */
#include <errno.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define CAP 256
#define INF (LLONG_MAX / 4)

static int number(const char *s, int maximum, int *out) {
    const char *digits = *s == '-' ? s + 1 : s;
    if (!*digits) return 0;
    for (const char *p = digits; *p; ++p)
        if (*p < '0' || *p > '9') return 0;
    char *end = NULL;
    errno = 0;
    long value = strtol(s, &end, 10);
    if (errno || end == s || *end || value < 0 || value > maximum) return 0;
    *out = (int)value;
    return 1;
}
static int fail(void) {
    fputs("invalid input: sigma n [mask ...] | outer n [mask:cost ...]\n", stderr);
    return 2;
}
static int compare(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);
}
static void array(const int *values, int count) {
    putchar('[');
    for (int i = 0; i < count; ++i) printf("%s%d", i ? "," : "", values[i]);
    putchar(']');
}
int main(int argc, char **argv) {
    int n;
    if (argc < 3 || !number(argv[2], 8, &n) || n < 1) return fail();
    int full = (1 << n) - 1;
    if (strcmp(argv[1], "sigma") == 0) {
        int atoms[CAP] = {full}, count = 1;
        for (int k = 3; k < argc; ++k) {
            int mask, next[CAP], used = 0;
            if (!number(argv[k], full, &mask)) return fail();
            for (int j = 0; j < count; ++j) {
                int a = atoms[j] & mask, b = atoms[j] & (full ^ mask);
                if (a) next[used++] = a;
                if (b) next[used++] = b;
            }
            memcpy(atoms, next, (size_t)used * sizeof(int));
            count = used;
        }
        qsort(atoms, (size_t)count, sizeof(int), compare);
        int sets[CAP] = {0}, size = 1;
        for (int i = 0; i < count; ++i) {
            for (int j = 0; j < size; ++j) sets[size + j] = sets[j] | atoms[i];
            size *= 2;
        }
        qsort(sets, (size_t)size, sizeof(int), compare);
        fputs("{\"atoms\":", stdout); array(atoms, count);
        fputs(",\"sets\":", stdout); array(sets, size); puts("}");
    } else if (strcmp(argv[1], "outer") == 0) {
        int masks[CAP], weights[CAP], count = argc - 3;
        if (count > CAP) return fail();
        for (int i = 0; i < count; ++i) {
            const char *item = argv[i + 3], *colon = strchr(item, ':');
            char left[32];
            if (!colon || (size_t)(colon - item) >= sizeof left) return fail();
            memcpy(left, item, (size_t)(colon - item)); left[colon - item] = '\0';
            if (!number(left, full, &masks[i]) || !number(colon + 1, 1000000, &weights[i])) return fail();
        }
        long long cost[CAP], tau[CAP];
        for (int i = 0; i <= full; ++i) cost[i] = INF;
        cost[0] = 0;
        for (int s = 0; s <= full; ++s) {
            if (cost[s] == INF) continue;
            for (int i = 0; i < count; ++i) {
                int target = s | masks[i];
                long long candidate = cost[s] + weights[i];
                if (candidate < cost[target]) cost[target] = candidate;
            }
        }
        for (int a = 0; a <= full; ++a) {
            tau[a] = INF;
            for (int s = 0; s <= full; ++s)
                if ((s & a) == a && cost[s] < tau[a]) tau[a] = cost[s];
        }
        int measurable[CAP], size = 0;
        for (int a = 0; a <= full; ++a) {
            int ok = 1;
            for (int d = 0; d <= full; ++d) {
                long long l = tau[d & a], r = tau[d & (full ^ a)];
                long long sum = (l == INF || r == INF) ? INF : l + r;
                if (tau[d] != sum) { ok = 0; break; }
            }
            if (ok) measurable[size++] = a;
        }
        fputs("{\"outer\":[", stdout);
        for (int a = 0; a <= full; ++a) {
            if (a) putchar(',');
            if (tau[a] == INF) fputs("null", stdout); else printf("%lld", tau[a]);
        }
        fputs("],\"measurable\":", stdout); array(measurable, size); puts("}");
    } else return fail();
    return 0;
}

§3σ 域的生成

“生成”不意味着一次并、一次补就能写出全部成员。它用最小性规定最终对象：包含给定材料且满足指定封闭规则的集合系中，取最小的一个。证明时常用双向包含，不必逐个列出成员。

定义 1.3.1 · 生成集合系

原文摘录（数学符号按正文统一排版）：

由集合系 C 生成的环（或单调系，或 λ 系，或 σ 域），也就是包含 C 的最小的环（或单调系，或 λ 系，或 σ 域）。

摘录范围：生成集合系的定义；C 对应原书花体集合系符号。 印刷 7 / PDF 19。

由 E 生成的环、单调系、λ 系或 σ 域，是包含 E 的相应类别中最小的集合系，分别记为 r(E),m(E),λ(E),σ(E)。

原书：印刷 7 / PDF 19

命题 1.3.1 · 生成对象存在

仅页码定位，无逐句摘录。

任意集合系生成的上述四种集合系都存在。

原书：印刷 8 / PDF 20

证明与理解

所有子集组成的 P(X) 是一个候选者，所以候选者族非空。取所有候选者的交：它包含 E；若若干集合属于这个交，它们就属于每个候选者，在每个候选者里作允许的运算后仍属于每个，因而属于交。这个交满足封闭性且包含于任一候选者，正是最小对象。

定理 1.3.2 · 半环生成的环

仅页码定位，无逐句摘录。

若 Q 是半环，则 r(Q) 恰好由有限个两两不交的 Q 成员的并组成。

原书：印刷 8 / PDF 20

证明与理解

记右侧集合系为 R。任何含 Q 的环都对有限并封闭，所以包含 R。反过来要证 R 是环：若 A、B 都已分成不交的小片，对 A 的每片依次减去 B 的每片；半环的差可有限分解，每次仍只产生有限片，最终得到 A∖B 的不交表示。再写 A∪B=B∪(A⧵B)，两部分不交，故 R 对差与并封闭。最小性给出两边相等。

定理 1.3.3 · 集合单调类定理

原文摘录（数学符号按正文统一排版）：

如果 A 是域，则 σ(A)=m(A)。

摘录范围：单调类定理完整结论；A 对应原书花体域符号。 印刷 9 / PDF 21。

若 A 是域，则 m(A)=σ(A)由域 A 生成的单调系 m(A) 等于由 A 生成的 sigma 域。。

原书：印刷 9 / PDF 21

证明与理解

令 M 为生成的单调系。因为 σ 域是单调系，先有 M⊆σ(A)。关键是证明 M 也是域。固定 A∈A，令 DA={B∈M:A∪B,A⧵B∈M}；并随单调列同向变化，差随单调列反向变化，M 对两种极限都封闭，所以 DA 是包含 A 的单调系，必含 M。

现在固定任意 B∈M，对变量 A 定义同样的集合系 EB={A∈M:A∪B,A⧵B∈M}。上一段保证它包含原来的域，它又对单调极限封闭，故包含 M。这两次固定变量把运算从原域推广到 M 的任意两个成员。M 因而是环，含 X 所以是域；再由命题 1.2.3 得它是 σ 域，反向包含成立。

推论 1.3.4 · 用单调系推广集合性质

仅页码定位，无逐句摘录。

若域 A 包含于单调系 M，则 σ(A)⊆M。

原书：印刷 9 / PDF 21

证明与理解

最小性给 m(A)⊆M，再把生成的单调系换成生成的 σ 域。应用时应先把“满足待证性质的全部集合”定义成 M，再逐条核查上升和下降两种封闭性。

定理 1.3.5·π–λ 定理

仅页码定位，无逐句摘录。

若 P 是 π 系，则 λ(P)=σ(P)。

原书：印刷 9 / PDF 21

证明与理解

令 L 为生成的 λ 系，显然 L⊆σ(P)。要反向，只需证明 L 对交封闭。先固定 A∈P，令 LA={B∈L:A∩B∈L}。它含 X；真差的交可写为两个嵌套交集的差；上升并也与交交换，故是 λ 系。π 封闭保证它含 P，所以含 L。

再固定任意 B∈L，令 LB={A∈L:A∩B∈L}。它同样是 λ 系，第一轮结论保证它含 P，所以也含 L。于是 L 同时为 π 系和 λ 系，由命题 1.2.4 是 σ 域。两次推广的顺序不可省略：第一轮只证明一个因子来自原生成族。

"""Exact dyadic lower approximation for a nonnegative rational input."""
import json
import re
import sys


def approximate(p, q, level):
    if not 0 <= p <= 1000000 or not 1 <= q <= 1000000 or not 1 <= level <= 20:
        raise ValueError('require 0<=p<=1000000, 1<=q<=1000000, 1<=level<=20')
    scale = 1 << level
    grid = min(level * scale, p * scale // q)
    return {'grid': grid, 'scale': scale}


def integer(token):
    if not re.fullmatch(r'[0-9]+', token):
        raise ValueError('expected unsigned ASCII integer')
    return int(token)


if __name__ == '__main__':
    try:
        if len(sys.argv) != 4:
            raise ValueError('usage: simple_approx.py numerator denominator level')
        print(json.dumps(approximate(*map(integer, sys.argv[1:])), separators=(',', ':')))
    except ValueError as error:
        print(str(error), file=sys.stderr)
        sys.exit(2)

定理 1.5.4 · 只依赖观测值的函数

仅页码定位，无逐句摘录。

原书：印刷 18 / PDF 30

证明与理解

若 h 是简单函数，每个值对应的原像 Ai 都可写成 g−1Ci。Ci 在整个 Y 中未必不交，但可依次减去前面的 C，得到不交的 Bi=Ci⧵⋃j<iCj；因为 Ai 已不交，它们的原像仍为 Ai。令 f=∑iaiIBi，未覆盖的 Y 点取 0，就有 h=f∘g。

一般 h 取简单逼近 hn，对每个 n 造 fn。令 f 在 fn 极限存在的集合上取其极限，其余点取 0；这个收敛集合可由上、下极限相等描述，故可测。在 g(X) 上极限一定存在且等于 h，所以复合关系成立。若 h 有限，只保留有限极限；若 |h|≤M，再把 f 截在 [−M,M]。反方向是复合可测定理。直观上，这说 h 只使用 g 已提供的信息。

这也展示“典型方法”：先证明指示函数，再证明非负简单函数，再利用非降逼近处理非负可测函数，最后处理正负部。每次从一层到下一层，都要检查待证性质能否通过相应运算保留，不能只报出这四个步骤的名称。

给定可测空间 (X,F)、(Y,G) 和映射 f:X→Y，A1,…,An 为 X 的有限可测分割。定义 fi(x)=f(x)（x∈Ai）。证明 f 可测当且仅当每个 fi:(Ai,Ai∩F)→(Y,G) 可测。

原书：印刷 22 / PDF 34

解答

若 f 可测，则对 B∈G，fi−1B=Ai∩f−1B 是迹可测集，故限制可测。反向，每个 fi−1B 可写成 Ai∩Ci，Ci∈F；又 Ai 本来可测，所以它也是 X 上可测集。于是 f−1B=⋃i=1nfi−1B∈F，得到 f 可测。

Y 是任意可测空间，不能假设其元素可以相加；使用原像并集证明便不需要这种额外结构。

习题 1 · 24　收敛发生的点构成可测集

原书题目（保留条件与小问，符号统一排版）

设 fn 是 (X,F) 上可测函数列，证明 {limnfn 存在}∈F；对任一可测函数 f，再证明 {limnfn=f}∈F。

原书：印刷 22 / PDF 34

解答

令 u=liminf fn、v=limsup fn。它们由定理 1.5.2 可测。广义实数列极限存在当且仅当 u=v，故收敛集为 {u=v}，由比较集合的可测性得结论；允许共同极限为正负无穷。

收敛到给定 f 的集合为 {u=f}∩{v=f}，同样可测。若问题另要求有限极限，只需再交 {−∞<u<∞}；本题没有把“存在”限制为有限存在。

习题 1 · 25　次序统计量的可测性

原书题目（保留条件与小问，符号统一排版）

设 f1,…,fn 是 (X,F) 上随机变量。对每个 x，把 f1(x),…,fn(x) 从小到大排列成 f(1)(x)≤⋯≤f(n)(x)，相等值顺序任意。证明每个 f(k) 仍是随机变量。

原书：印刷 22 / PDF 34

解答

{f(k)≤a}=⋃J⊆{1,…,n}|J|=k ⋂j∈J{fj≤a}

第 k 小的值不超过 a，当且仅当至少 k 个原值不超过 a。选择这 k 个指标就得到右侧；有限个指标子集只产生有限并交，故可测。所有原值都有限，排序后的值仍有限。相等值的先后不会改变第 k 个数值，所以不会影响可测性。
