# 全六章伴读与学习路线

版本、章名、节名与页序以 [source_manifest.json](notes/source_manifest.json)为唯一清单。原书六章路线是可测结构 → 测度 → 积分 → 符号测度与密度 → 乘积空间 → 独立序列极限定理。作者前言以基础五章为主，星号部分和第六章按概率论方向补读；笔记保留星号含义。

2026-10-17 首批范围为伴读总览、丛书序言与作者前言、第一章和第二章。全目录与各章首末页已核对；前两章及附录对应提示细读。先建立独立 75 项编号内容和 57 题清单，再写第一章样章，并在桌面与手机验收后继续第二章。

第一章重点解释集合闭包与生成的最小性、π–λ 与单调类的证明步骤、可测性阈值检验和简单函数逼近；全部 25 题保留题干及推理。第二章重点解释覆盖外测度、Caratheodory 分割、扩张的存在与唯一性、完全化以及不同收敛的量词；全部 32 题保留有限性、全空间覆盖等条件的用法。详见[校注登记](notes/source_issues.json)。

第三、四章批次沿“积分与收敛定理 → Lp 与一致可积 → Hahn/Jordan → R–N 与 Lebesgue 分解 → 条件期望及正则版本”展开。新增 72 项原书编号内容、30+28 道习题；先对扫描页独立登记，再按条件、证明步骤、极端情形读回。第五、六章在 I034 批次继续展开：先逐页目视 PDF 141—228 与附录提示 242—251，登记 89 项编号内容和 55 题，再围绕核积分、无穷乘积、截断、特征函数和极限定理写出论证。

计算模型只在有解释收益处设置：有限点空间可显示生成原子与可测集之间的关系，覆盖代价能展示外测度与测度的差别，精确有理数能说明简单函数如何从下方逼近。代码、静态结构、来源读回和真实阅读证据各自记录，不用程序结果代替一般证明。

第三、四章共用四点加权例子，先逐项算出积分与二阶矩，再从信息分块求条件期望，最后定位底测度零点上的奇异质量。源码的逐点计算使用层集积分、所有子集极值和全部信息事件积分作独立基准；无限维结论仍依赖正文证明。当前执行与历史首批证据分别保留在 review/ 与 review/history/。

第五章有限模型从初始概率和转移核算出联合质量，再核验边缘、独立性和函数期望。第六章同一程序将独立路径逐层卷积为二项质量，计算标准化特征函数；精确的分布质量、数学极限证明和浮点显示分开。第六章习题中的原式问题直接在原题后解释并修正。
