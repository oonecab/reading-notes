# Repository agent guidelines

本仓库用于阅读 Weiss《Data Structures and Algorithm Analysis in C》（第二版，中国改编版）并结合 C 代码学习。

## 阅读与核对

- 以仓库根目录中的 PDF 为章节内容依据；不要把不同版次或网络资料的章节内容混为一谈。
- 分清原书叙述、自己的解释与补充实现。代码示例可以重写，但要标明与书中约定的区别。
- 复杂度必须注明前提，例如“已知前驱位置的删除 O(1)”不等于“按值删除 O(1)”。
- 遇到扫描/OCR 错误时，以页面上下文判断，不将损坏文字当成准确原句。

## 笔记交付

- 章节正文维护于 `src/content/books/weiss/` 的受控 HTML，一章一份；`notes/` 是独立 Python 检查使用的展开镜像，构建输出仍为单文件 HTML。
- 创建或修改笔记前遵循 `notes/README.md` 的内容组织、版式和引用规则。
- 全书总览与各章使用同一套内嵌 CSS、页头、目录、相邻章节导航及页尾；新增章节以现有页面和 `notes/README.md` 的固定参数为基准。
- 目录在桌面位于正文左侧并固定跟随；窄屏使用上方折叠目录。保留原分节锚点，当前阅读分节提供明确标识，具体宽度和交互见 `notes/README.md`。
- 通用环境与程序使用说明集中维护在 `book_overview.html#program-guide`；各章页头提供入口。总览提供复现方法与结果解释，程序核对摘要保存在维护记录；章节正文保留教学解释、习题所需测试方法及实测数据。
- 一章的笔记以原书论证与具体图例为线索，连贯讲述问题、作者的处理方式及其中细节；在叙述中自然覆盖代码不变量、边界条件、复杂度和应用。
- 精选少量英文短摘句，配准确的中文翻译及所在小节；主要内容应为原创分析和讲解，避免连续复制原书大段文字。
- 不随意生成额外资源文件；如确需额外文件，先在 `notes/README.md` 说明用途与命名方式。

## 习题、程序与验收

- 习题区统一使用“习题解答 · 起止题号”，各题按本版题号连续排列；题目之间不插入主题分类标题，也不设置分组索引。单题内部可按解答需要设置小标题。
- 每题展开后先展示原题的完整中文翻译，再展示解答。保留全部子问题、条件、公式、输入与提示，注明本版原题号、印刷页及 PDF 页码；题目所需的原图、表格与程序片段随题干呈现。题干校注和上下文补充单独标明，具体结构遵循 `notes/README.md`。
- 编程习题、正文教学程序与实验驱动同时给出 C11 和 Python 3 解法，采用相同算法、输入约定、平局规则与复杂度；语言自身的整数、分配或异常差异在相邻文字中说明。
- 每对实现使用 `div.code-pair`，内部依次放 C、Python 的 `details.code-version`；C 默认展开，Python 可展开。程序块设置唯一锚点和 `data-language`。原有题号、锚点与链接要保留。
- 共享类型与辅助函数在本章给出完整定义，引用时链接到对应的双语代码。纯数学证明、手工推演和结构设计按题意写清，不为凑语言数量添加无意义程序。
- 有具体输入且正文已有实现的习题可补双语调用驱动，复用共享算法并输出对应结果；新增算法实现与当前解答保持一致。各题驱动的组合与运行入口仍集中在全书总览。
- 习题交付须有确定的答案、推导或可执行方法。高阶结果应写明使用的定理、适用条件和完成关键推导的步骤；发现题干与原论文结论不一致时，给出准确差异、可核验结论及其完整解法。
- 实验题提供两种语言的复现驱动，并在题内记录实际输入、种子、计时范围和结果。环境、编译与运行命令、代码组合方法统一放在 `book_overview.html` 开头的程序说明中；具体入口与特殊依赖按章展开。数值样本与一般证明分别表述；递归失效阈值须注明栈大小等关键条件。
- 从最终 HTML 提取程序验证：C 使用严格 C11 警告检查，指针和内存操作使用 AddressSanitizer／UndefinedBehaviorSanitizer；Python 实际运行。对可比输入使用独立参考结果检查两版输出及数据结构不变量。
- 有副作用的算法操作独立执行，实验与自测不得依赖断言开启才运行；共享依赖及程序组合入口集中维护在总览和 `notes/tools/check_notes.py`，不另存一套算法正文。
- 交付前检查全题号覆盖、全部本地链接、唯一锚点、双语代码及依赖，并在桌面和窄屏浏览器核对目录、展开交互、MathML、表格和 SVG。正式笔记只保留教学内容、确定的结论与具体的验证证据。

Astro 维护、镜像同步与冻结基线规则见 [构建维护说明](../../docs/astro-authoring.md)。

本书的当前阅读契约以 RN-001 v1.11 为准：完整中文题干和来源、逐节注解、共同版心、代码等宽与原生折叠、命名明确的索引、直达登记 PDF 的原文入口。逐页义务在根目录 `docs/reader-contract.json`，原书发布身份在 `docs/reader-sources.json`；历史批次记录保留当时的范围，当前复查执行 `python3 tools/project.py check` 及完整浏览器矩阵。
