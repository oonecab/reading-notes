一、从单次代价转向整个序列

第二章通常先固定一个输入，再问某次操作最坏需要多少步。本章回到第四、五章已经实现的结构，问的是：如果操作可以由对手任意选择，一共做 M 次，最坏总账是多少？AVL 树把每次访问都限制在 O(logN)，而伸展树允许某次访问 Θ(N)，通过重排阻止昂贵形态持续造成同样的损失。这个序列保证不依赖“输入恰好随机”。

因此，摊还代价与平均情形使用不同的量词。平均情形先规定概率分布，再取期望；摊还分析对每一个合法操作序列都给出总界。若结构已经带着很多节点进入分析，还必须把初始状态包含进总账。对任意初始伸展树，通常写 O(MlogN+NlogN)；从空结构开始的构造序列，初始势能为零，结论才可以直接只看各步摊还和。

设第 i 步真实代价为 ci，操作前后的结构为 Di−1、Di，给每个状态指定势能 Φ(D)。定义摊还代价并相加：

c^i=ci+Φ(Di)−Φ(Di−1)
∑i=1Mci=∑i=1Mc^i+Φ(D0)−Φ(DM)

只要最后势能不低于初始势能，摊还和就是实际总代价的上界。最常用的安排是初始势能为零、其余状态非负。势能不是额外等待时间，也不需要程序在每一步计算；它把“现在留下了多少未来可能要处理的结构”转成可抵消的数字。实际实现中的指针读写若对应多个基本步骤，可以给势能乘一个固定常数，复杂度结论不变。

二、11.1：猫的往返，为什么时间更容易求

原书让两只小猫相距 100 码，各以每分钟 10 码相向而行；猫妈妈以每分钟 100 码不断在它们之间往返，转向不损失速度。逐段算妈妈的路程会得到一个无穷等比级数，但两只小猫的相对速度直接给出相遇时间 100/(10+10)=5 分钟，所以妈妈总共跑 100×5=500 码。

作者在这里引出“增加一个变量”的分析方式。每一段往返距离不好分别跟踪，时间却能连接所有往返；后面的结构变化也很碎，势能则把它们连成能消去中间项的一串等式。计算技巧的核心是找到能覆盖整个过程的状态量。

“an extra variable, known as the potential”

“一个额外变量，称为势能。”——§11.1，印刷页 430／PDF 447。它承担连接局部操作与全局总代价的作用。

三、11.2：二项队列，把连接看成进位

二项树 Br 有 2r 个节点，根有 r 个孩子。队列每阶最多保留一棵树，所以根链表描述的是节点数的二进制表示。图 11.2 中 H1 有 B1、B2，大小 6；H2 有 B0、B1、B2，大小 7。合并时从低阶开始，同阶的两棵树连接成下一阶，三棵则留一棵、连接两棵。图 11.3 的结果是大小 13 的 B0+B2+B3，对应 11012。

插入一个新节点相当于二进制加一。按照原书的成本口径，创建单节点树算一单位，每次同阶连接再算一单位。若一共连接 c−1 次，树的数量先加一、再减去 c−1，所以 ΔT=2−c。选 Φ=T 后，每次插入的摊还代价恰好为 2：

c+ΔΦ=c+(2−c)=2

DeleteMin 仍须找到最小根，把它的孩子反转成按秩递增的根链表，再合并回去。势能 T 足以证明插入摊还常数，但一般合并的常数摊还证明还需要补上最大秩这一项，见 习题 11.14。下面的实现用按秩排列的根链表，一旦另一条链和进位都空了，就直接挂接剩余后缀；这个实现细节会影响合并的界。

节点的孩子按秩递减保存，合并只比较根的键，键相同时比较编号。Insert 分配节点；DeleteMin 返回键和编号并释放被删的根，剩余树继续归队列所有。空队列返回失败／None。共享分配与比较约定见 共享定义。

typedef struct BNode BNode;
struct BNode { int64_t key; size_t id, rank; BNode *child, *next; };
typedef struct { BNode *roots; size_t n; uint64_t links, stages; } BQueue;

BNode *bq_link(BNode *a, BNode *b, BQueue *h) {
    assert(a->rank == b->rank);
    if (key_before(b->key, b->id, a->key, a->id)) { BNode *t = a; a = b; b = t; }
    b->next = a->child; a->child = b; ++a->rank; ++h->links;
    return a;
}
/* Consume b. An unopposed root-list suffix is attached in one step. */
void bq_meld(BQueue *a, BQueue *b) {
    assert(a != b && a->n <= SIZE_MAX - b->n);
    BNode *x = a->roots, *y = b->roots, *carry = NULL, *out = NULL;
    BNode **tail = &out;
    while (x || y || carry) {
        if (!carry && (!x || !y)) { *tail = x ? x : y; break; }
        size_t r = SIZE_MAX;
        if (x && x->rank < r) r = x->rank;
        if (y && y->rank < r) r = y->rank;
        if (carry && carry->rank < r) r = carry->rank;
        BNode *v[3]; size_t k = 0;
        if (x && x->rank == r) { v[k++] = x; x = x->next; }
        if (y && y->rank == r) { v[k++] = y; y = y->next; }
        if (carry && carry->rank == r) { v[k++] = carry; carry = NULL; }
        for (size_t i = 0; i < k; ++i) v[i]->next = NULL;
        ++a->stages;
        if (k & 1) { *tail = v[0]; tail = &v[0]->next; }
        if (k >= 2) carry = bq_link(v[k - 2], v[k - 1], a);
    }
    a->roots = out; a->n += b->n; b->roots = NULL; b->n = 0;
}
void bq_insert(BQueue *h, int64_t key, size_t id) {
    BNode *x = checked_array(1, sizeof *x); x->key = key; x->id = id;
    BQueue one = {x, 1, 0, 0}; bq_meld(h, &one);
}
bool bq_pop(BQueue *h, int64_t *key, size_t *id) {
    if (!h->roots) return false;
    BNode **best = &h->roots;
    for (BNode **p = &h->roots; *p; p = &(*p)->next)
        if (key_before((*p)->key, (*p)->id, (*best)->key, (*best)->id)) best = p;
    BNode *z = *best; *best = z->next;
    BNode *rev = NULL;
    for (BNode *p = z->child; p;) { BNode *next = p->next; p->next = rev; rev = p; p = next; }
    assert(z->rank < sizeof(size_t) * CHAR_BIT);
    size_t children = ((size_t)1 << z->rank) - 1;
    h->n -= children + 1; BQueue sub = {rev, children, 0, 0}; bq_meld(h, &sub);
    *key = z->key; *id = z->id; free(z); return true;
}
size_t bq_trees(const BQueue *h) {
    size_t n = 0; for (BNode *x = h->roots; x; x = x->next) ++n; return n;
}
size_t bq_potential(const BQueue *h) {
    size_t t = 0, r = 0;
    for (BNode *x = h->roots; x; x = x->next) { ++t; r = x->rank; }
    return t + r;
}

class BNode:
    def __init__(self, key, item):
        self.key, self.id, self.rank = key, item, 0
        self.child = self.next = None

class BQueue:
    def __init__(self):
        self.roots = None
        self.n = self.links = self.stages = 0
    def link(self, a, b):
        assert a.rank == b.rank
        if key_before(b.key, b.id, a.key, a.id):
            a, b = b, a
        b.next, a.child = a.child, b
        a.rank += 1
        self.links += 1
        return a
    def meld(self, other):
        if self is other:
            raise ValueError("self meld")
        x, y, carry, out, tail = self.roots, other.roots, None, None, None
        while x is not None or y is not None or carry is not None:
            if carry is None and (x is None or y is None):
                rest = x if x is not None else y
                if tail is None: out = rest
                else: tail.next = rest
                break
            r = min(z.rank for z in (x, y, carry) if z is not None)
            v = []
            if x is not None and x.rank == r:
                v.append(x); x = x.next
            if y is not None and y.rank == r:
                v.append(y); y = y.next
            if carry is not None and carry.rank == r:
                v.append(carry); carry = None
            for z in v: z.next = None
            self.stages += 1
            if len(v) & 1:
                if tail is None: out = v[0]
                else: tail.next = v[0]
                tail = v[0]
            if len(v) >= 2:
                carry = self.link(v[-2], v[-1])
        self.roots = out
        self.n += other.n
        other.roots, other.n = None, 0
    def insert(self, key, item):
        one = BQueue(); one.roots, one.n = BNode(key, item), 1
        self.meld(one)
    def pop(self):
        if self.roots is None: return None
        best, bp, prev, x = self.roots, None, None, self.roots
        while x is not None:
            if key_before(x.key, x.id, best.key, best.id): best, bp = x, prev
            prev, x = x, x.next
        if bp is None: self.roots = best.next
        else: bp.next = best.next
        rev, x = None, best.child
        while x is not None:
            nxt, x.next = x.next, rev
            rev, x = x, nxt
        sub = BQueue(); sub.roots, sub.n = rev, (1 << best.rank) - 1
        self.n -= sub.n + 1
        self.meld(sub)
        best.child = best.next = None
        return best.key, best.id
    def trees(self):
        t, x = 0, self.roots
        while x is not None: t += 1; x = x.next
        return t
    def potential(self):
        t, r, x = 0, 0, self.roots
        while x is not None: t += 1; r = x.rank; x = x.next
        return t + r

四、11.3：斜堆，长路径用重节点支付

左式堆保存空路径长，主动限制右路径。斜堆把这份平衡信息省掉：比较两个根，沿较小根的右子树继续合并，并交换访问节点的左右孩子。单次路径可能很长，但长路径上的某些形态会在交换后消失，因此可以为它们安排势能。

令 s(x) 包括节点自身。依本版定义，若 s(xright)≥s(x)/2，就称 x 是重节点，否则是轻节点；空右子树对应轻节点。沿右路径经过一个轻节点后，规模小于原来的一半，所以任一路径最多有 O(logN) 个轻节点。原书图 11.7 的重节点为 15、3、6、12、7；“重”描述右子树比例，不表示键大或深度大。

取势能为重节点数。设合并实际访问的两条右路径共包含 h 个重节点、l 个轻节点。重节点交换后，旧左子树成为新右子树；它在旧树中就小于一半，而合并只会增加总规模，因此这些节点变轻。轻节点可能变重，数量至多 l；终止处的未扫描后缀只引入常数项。于是：

c≤h+l+O(1),ΔΦ≤l−h+O(1)
c^≤2l+O(1)=O(logN)

一根长右链可以有很多重节点，所以不能把这项结论改成单次最坏 O(logN)。习题 11.3 构造了可由合法插入生成的长右路径。一次昂贵合并会把那段路径翻到左边，并消耗相应势能；如果接下来又出现昂贵操作，必须先有其他操作把势能重新积累起来。

下面沿右路径迭代完成合并，避免让线性最坏路径变成线性递归栈。已访问前缀沿新左链连接，原左孩子成为新右孩子；每次接入都同步设置 parent。DecreaseKey 在破坏堆序时切下整个子树并重新合并，节点句柄必须属于当前堆且尚未被删。剪切后的祖先尺寸仅用于证明，程序不计算它们；习题 11.5 说明为什么仍能获得对数摊还界。

typedef struct SNode SNode;
struct SNode { int64_t key; size_t id; SNode *left, *right, *parent; };
typedef struct { SNode *root; uint64_t visits; } Skew;

SNode *sk_merge(Skew *h, SNode *a, SNode *b) {
    SNode *out = NULL, *last = NULL; SNode **slot = &out;
    while (a && b) {
        if (key_before(b->key, b->id, a->key, a->id)) { SNode *t = a; a = b; b = t; }
        SNode *next = a->right;
        a->right = a->left; if (a->right) a->right->parent = a;
        a->left = NULL; a->parent = last;
        *slot = a; last = a; slot = &a->left; a = next; ++h->visits;
    }
    *slot = a ? a : b; if (*slot) (*slot)->parent = last;
    return out;
}
void sk_insert(Skew *h, SNode *x, int64_t key, size_t id) {
    *x = (SNode){key, id, NULL, NULL, NULL}; h->root = sk_merge(h, h->root, x);
}
SNode *sk_pop(Skew *h) {
    SNode *x = h->root; if (!x) return NULL;
    SNode *a = x->left, *b = x->right;
    if (a) a->parent = NULL; if (b) b->parent = NULL;
    h->root = sk_merge(h, a, b);
    x->left = x->right = x->parent = NULL; return x;
}
bool sk_decrease(Skew *h, SNode *x, int64_t key) {
    if (key > x->key) return false;
    x->key = key; SNode *p = x->parent;
    if (!p || !key_before(x->key, x->id, p->key, p->id)) return true;
    if (p->left == x) p->left = NULL; else { assert(p->right == x); p->right = NULL; }
    x->parent = NULL; h->root = sk_merge(h, h->root, x); return true;
}

class Skew:
    def __init__(self):
        self.root = None
        self.visits = 0
    def merge(self, a, b):
        out = last = None
        while a is not None and b is not None:
            if key_before(b.key, b.id, a.key, a.id): a, b = b, a
            nxt, a.right = a.right, a.left
            if a.right is not None: a.right.parent = a
            a.left, a.parent = None, last
            if last is None: out = a
            else: last.left = a
            last, a = a, nxt
            self.visits += 1
        rest = a if a is not None else b
        if last is None: out = rest
        else: last.left = rest
        if rest is not None: rest.parent = last
        return out
    def insert(self, x):
        x.left = x.right = x.parent = None
        self.root = self.merge(self.root, x)
    def pop(self):
        x = self.root
        if x is None: return None
        a, b = x.left, x.right
        if a is not None: a.parent = None
        if b is not None: b.parent = None
        self.root = self.merge(a, b)
        x.left = x.right = x.parent = None
        return x
    def decrease(self, x, key):
        if key > x.key: return False
        x.key = key; p = x.parent
        if p is None or not key_before(x.key, x.id, p.key, p.id): return True
        if p.left is x: p.left = None
        else:
            assert p.right is x
            p.right = None
        x.parent = None
        self.root = self.merge(self.root, x)
        return True

推导

轻节点限制长度，重节点支付工作

沿右路径经过轻节点后，剩余子树规模至少缩小一半，所以这样的节点只能出现对数多个。重节点可能很多，但本次交换会使被访问的重节点变轻，释放对应势能。把两类节点分别计数，才能解释长路径为何仍有对数摊还代价。

五、11.4：延迟连接，再用标记控制剪切

这一节的动机来自第九章 Dijkstra：每个顶点最多从优先队列取出一次，而成功松弛可能很多次。使用带位置表的二叉堆，插入、取最小值、降键都可能沿对数高度移动，总界为 O((E+V)logV)。若降键摊还只需常数，队列的总工作就有机会降到 O(E+VlogV)。Fibonacci 堆把主要整理工作推迟到 DeleteMin。

原书先说明左式堆可以借 parent 指针剪下待降键子树，但维护空路径长仍可能要沿祖先走。这里应在父节点的空路径长不再变化时立即停止；只有实际发生秩变化的那段路径需要继续处理，其旧秩逐层增加，所以更新次数才是对数级。单纯沿高树形向根一直检查，无法由这段论证直接得到该界。

从懒惰二项队列到 Fibonacci 堆

懒惰二项队列在 Insert、Merge 时只拼接根链表，暂时允许同阶树并存。DeleteMin 才把根按秩放入桶，遇到相同秩就连接。原书图 11.15 中根为 5、6、3、4、7；删除 3 后，把孩子 9 与以 15 为根、含 21 的子树放回根集合，再按秩整理。根列表采用带尾指针的链或双向环，拼接才能真正是 O(1)。

允许 DecreaseKey 后，剪掉孩子会使树不再是严格二项树，秩目录的范围也不能机械照搬 ⌊log2N⌋。Fibonacci 堆使用多叉最小堆树，parent、child 和左右兄弟指针组成环；根节点不标记，非根节点在“自上次成为某个节点的孩子以后第一次失去孩子”时标记，第二次失去孩子时必须把自身剪成根，再向父节点级联。

为什么秩仍然是对数级

证明：Fibonacci 堆的秩界

按仍然存活的孩子被连接到当前父节点的先后顺序，从最早到最晚编号 c1,…,cr。当 ci 接入时，前面的 i−1 个现存孩子已经在父节点下，因此它当时的秩至少为 i−1；作为孩子期间最多损失一个孩子，否则早已被剪走，所以现在秩至少为 i−2。

正文校注：引理 11.1 的 “ith youngest child” 与随后按连接先后讨论的证明顺序不一致（PDF 462）；这里统一按最早连接的现存孩子起编号。改变编号方向后，原书的 i−2 论证才按上述顺序成立。

令 Sr 是秩 r 允许的最小子树大小，则 S0=1、S1=2。根和第一个至少含一节点的孩子贡献 2，其余孩子给出：

Sr≥2+∑j=0r−2Sj(r≥2)

取该递推的最小值便得到 1、2、3、5、8、13……。按本书 F0=F1=1 的约定，它是 Fr+1；因此 s(x)≥Fr+1，秩 r 至多 O(logN)。具体地，令 φ=(1+5)/2，这些数至少以 φr 增长，故 r≤logφN。这正是结构名称的来源；堆里没有运行 Fibonacci 数列程序。

势能为什么给每个标记两单位

取 Φ=T+2m，其中 T 是根数，m 是标记数。Insert 添加一个根，Merge 拼接两个根集合，二者的实际工作及势能变化都为常数。DeleteMin 若原有 T 棵树、最小根有 r 个孩子，真实整理成本为 O(T+r+logN)，整理后最多 O(logN) 个根且标记数不增加，故 ΔΦ≤O(logN)−T，两者相加只剩 O(logN)。

对降键，设第一刀以外有 C 次级联。第一刀加一棵树；每次级联把一个标记节点变成未标记根，势能净减一；末端最多产生一个新标记，势能加二。因此：

c=C+1,ΔΦ≤1−C+2=3−C,c^≤4

系数 2 同时支付了剪切的动作和增加一棵根树的势能。单次降键仍可能级联很多刀，DeleteMin 也可能扫描很多根；常数和对数都是摊还结论。FindMin 只读取 min 指针，是最坏常数。

指针实现与 Dijkstra 中的实际接口

下面的节点由调用者保存，Insert 接受一个尚未在堆中的节点，调用者继续持有该节点作为稳定位置；本章函数直接使用该位置降键。pop 返回节点并令 alive 为假，旧句柄可检测到失效；C 不释放调用者的节点。Merge 消费第二个堆，其节点句柄转而属于第一个堆。最小键平局按编号决定，DecreaseKey 只接受不增大的键。

consolidate 先逐个脱离根环，再按 degree 连接，避免在一边改环时依赖原环遍历的终点。秩桶仅清空 O(logN) 个槽；C 的局部上限依据 size_t 位宽分配，实际使用长度为 3+2⌊log2N⌋，足够覆盖 Fibonacci 秩界，Python 使用相同长度。剪切之前保存父指针、从旧环移除，再作为未标记根接入。

bool fib_less(Fib *h, const FNode *a, const FNode *b) {
    ++h->comparisons; return key_before(a->key, a->id, b->key, b->id);
}
void fib_unlink(FNode *x) {
    x->left->right = x->right; x->right->left = x->left;
    x->left = x->right = x;
}
void fib_ring_add(FNode *head, FNode *x) {
    x->left = head->left; x->right = head;
    head->left->right = x; head->left = x;
}
void fib_add_root(Fib *h, FNode *x) {
    x->parent = NULL; x->mark = false;
    if (!h->min) { x->left = x->right = x; h->min = x; }
    else { fib_ring_add(h->min, x); if (fib_less(h, x, h->min)) h->min = x; }
}
void fib_insert(Fib *h, FNode *x, int64_t key, size_t id) {
    assert(!x->alive && h->n != SIZE_MAX);
    *x = (FNode){key, id, 0, false, true, NULL, NULL, x, x};
    fib_add_root(h, x); ++h->n;
}
void fib_meld(Fib *a, Fib *b) {
    assert(a != b && a->n <= SIZE_MAX - b->n);
    if (!b->min) return;
    if (!a->min) a->min = b->min;
    else {
        FNode *al = a->min->left, *bl = b->min->left;
        al->right = b->min; b->min->left = al;
        bl->right = a->min; a->min->left = bl;
        if (fib_less(a, b->min, a->min)) a->min = b->min;
    }
    a->n += b->n; b->n = 0; b->min = NULL;
}
FNode *fib_link(Fib *h, FNode *a, FNode *b) {
    if (fib_less(h, b, a)) { FNode *t = a; a = b; b = t; }
    b->parent = a; b->mark = false;
    if (!a->child) { a->child = b; b->left = b->right = b; }
    else fib_ring_add(a->child, b);
    ++a->degree; ++h->links; return a;
}
void fib_consolidate(Fib *h) {
    enum { MAX_RANKS = 2 * sizeof(size_t) * CHAR_BIT + 3 };
    FNode *a[MAX_RANKS]; size_t limit = 3;
    for (size_t n = h->n; n > 1; n >>= 1) limit += 2;
    assert(limit <= MAX_RANKS); memset(a, 0, limit * sizeof *a);
    while (h->min) {
        FNode *x = h->min;
        h->min = x->right == x ? NULL : x->right;
        fib_unlink(x); size_t r = x->degree;
        assert(r < limit);
        while (a[r]) {
            FNode *y = a[r]; a[r] = NULL; x = fib_link(h, x, y);
            r = x->degree; assert(r < limit);
        }
        a[r] = x;
    }
    for (size_t r = 0; r < limit; ++r) if (a[r]) fib_add_root(h, a[r]);
}
FNode *fib_pop(Fib *h) {
    FNode *z = h->min; if (!z) return NULL;
    while (z->child) {
        FNode *x = z->child;
        z->child = x->right == x ? NULL : x->right;
        fib_unlink(x); --z->degree; fib_add_root(h, x);
    }
    h->min = z->right == z ? NULL : z->right;
    fib_unlink(z); --h->n;
    if (h->min) fib_consolidate(h);
    z->alive = false; z->parent = z->child = NULL; z->mark = false;
    return z;
}
void fib_cut(Fib *h, FNode *x, FNode *p) {
    if (p->child == x) p->child = x->right == x ? NULL : x->right;
    fib_unlink(x); --p->degree; fib_add_root(h, x); ++h->cuts;
}
bool fib_decrease(Fib *h, FNode *x, int64_t key) {
    if (!x->alive || key > x->key) return false;
    x->key = key; FNode *p = x->parent;
    if (p && fib_less(h, x, p)) {
        fib_cut(h, x, p);
        while (p->parent) {
            FNode *g = p->parent;
            if (!p->mark) { p->mark = true; break; }
            fib_cut(h, p, g); p = g;
        }
    }
    if (h->min && fib_less(h, x, h->min)) h->min = x;
    return true;
}

class Fib:
    def __init__(self):
        self.min = None
        self.n = self.comparisons = self.links = self.cuts = 0
    def less(self, a, b):
        self.comparisons += 1
        return key_before(a.key, a.id, b.key, b.id)
    @staticmethod
    def unlink(x):
        x.left.right, x.right.left = x.right, x.left
        x.left = x.right = x
    @staticmethod
    def ring_add(head, x):
        x.left, x.right = head.left, head
        head.left.right, head.left = x, x
    def add_root(self, x):
        x.parent, x.mark = None, False
        if self.min is None:
            x.left = x.right = x
            self.min = x
        else:
            self.ring_add(self.min, x)
            if self.less(x, self.min): self.min = x
    def insert(self, x, key, item):
        if x.alive: raise ValueError("node already in a heap")
        x.key, x.id, x.degree = key, item, 0
        x.mark, x.alive = False, True
        x.parent = x.child = None
        x.left = x.right = x
        self.add_root(x); self.n += 1
    def meld(self, other):
        if self is other: raise ValueError("self meld")
        if other.min is None: return
        if self.min is None: self.min = other.min
        else:
            al, bl = self.min.left, other.min.left
            al.right, other.min.left = other.min, al
            bl.right, self.min.left = self.min, bl
            if self.less(other.min, self.min): self.min = other.min
        self.n += other.n
        other.n, other.min = 0, None
    def link(self, a, b):
        if self.less(b, a): a, b = b, a
        b.parent, b.mark = a, False
        if a.child is None:
            a.child = b; b.left = b.right = b
        else: self.ring_add(a.child, b)
        a.degree += 1; self.links += 1
        return a
    def consolidate(self):
        limit = 3 + 2 * max(0, self.n.bit_length() - 1)
        a = [None] * limit
        while self.min is not None:
            x = self.min
            self.min = None if x.right is x else x.right
            self.unlink(x); r = x.degree
            while a[r] is not None:
                y, a[r] = a[r], None
                x = self.link(x, y); r = x.degree
            a[r] = x
        for x in a:
            if x is not None: self.add_root(x)
    def pop(self):
        z = self.min
        if z is None: return None
        while z.child is not None:
            x = z.child
            z.child = None if x.right is x else x.right
            self.unlink(x); z.degree -= 1; self.add_root(x)
        self.min = None if z.right is z else z.right
        self.unlink(z); self.n -= 1
        if self.min is not None: self.consolidate()
        z.alive, z.mark = False, False
        z.parent = z.child = None
        z.left = z.right = None
        return z
    def cut(self, x, p):
        if p.child is x: p.child = None if x.right is x else x.right
        self.unlink(x); p.degree -= 1; self.add_root(x); self.cuts += 1
    def decrease(self, x, key):
        if not x.alive or key > x.key: return False
        x.key = key; p = x.parent
        if p is not None and self.less(x, p):
            self.cut(x, p)
            while p.parent is not None:
                g = p.parent
                if not p.mark:
                    p.mark = True; break
                self.cut(p, g); p = g
        if self.min is not None and self.less(x, self.min): self.min = x
        return True

RunStats dijkstra(const Graph *g, bool use_fib, size_t source, int64_t *dist) {
    assert(source < g->n);
    bool *seen = checked_array(g->n, sizeof *seen), *done = checked_array(g->n, sizeof *done);
    for (size_t i = 0; i < g->n; ++i) dist[i] = DIST_INF;
    dist[source] = 0; seen[source] = true;
    Fib f = {0}; Binary b = {0}; FNode *nodes = NULL;
    if (use_fib) { nodes = checked_array(g->n, sizeof *nodes); fib_insert(&f, &nodes[source], 0, source); }
    else { b = binary_new(g->n, dist); binary_insert(&b, source); }
    RunStats st = {0};
    while (use_fib ? f.n > 0 : b.n > 0) {
        size_t u = use_fib ? fib_pop(&f)->id : binary_pop(&b); done[u] = true;
        for (size_t j = g->off[u]; j < g->off[u + 1]; ++j) {
            ++st.scans; size_t v = g->to[j]; if (done[v]) continue;
            int64_t candidate = dist[u] + g->weight[j];
            if (candidate >= dist[v]) continue;
            dist[v] = candidate;
            if (!seen[v]) {
                seen[v] = true;
                if (use_fib) fib_insert(&f, &nodes[v], candidate, v); else binary_insert(&b, v);
            } else {
                ++st.decreases;
                if (use_fib) { if (!fib_decrease(&f, &nodes[v], candidate)) abort(); }
                else binary_decrease(&b, v);
            }
        }
    }
    st.comparisons = use_fib ? f.comparisons : b.comparisons;
    st.links = f.links; st.cuts = f.cuts;
    if (use_fib) free(nodes); else binary_free(&b);
    free(seen); free(done); return st;
}

    def __init__(self, n, edges):
        self.n, self.m = n, len(edges)
        self.off, self.to, self.weight = [0] * (n + 1), [0] * self.m, [0] * self.m
        for u, v, w in edges:
            if not (0 <= u < n and 0 <= v < n and 0 <= w <= 1000000000):
                raise ValueError("invalid edge")
            self.off[u + 1] += 1
        for u in range(1, n + 1): self.off[u] += self.off[u - 1]
        cursor = self.off[:-1].copy()
        for u, v, w in edges:
            j = cursor[u]; cursor[u] += 1
            self.to[j], self.weight[j] = v, w
    @staticmethod
    def random(n, factor, seed):
        rng, edges = Rng32(seed), []
        for i in range(n * factor):
            if i < n: u, v = i, (i + 1) % n
            else:
                u, v = rng.next() % n, rng.next() % n
                if u == v: v = (v + 1) % n
            edges.append((u, v, 1 + rng.next() % 1000))
        return Graph(n, edges)

def dijkstra(g, use_fib, source, dist):
    assert 0 <= source < g.n
    seen, done = [False] * g.n, [False] * g.n
    for i in range(g.n): dist[i] = DIST_INF
    dist[source], seen[source] = 0, True
    nodes = [FNode() for _ in range(g.n)] if use_fib else None
    heap = Fib() if use_fib else Binary(g.n, dist)
    if use_fib: heap.insert(nodes[source], 0, source)
    else: heap.insert(source)
    decreases = scans = 0
    while heap.n:
        x = heap.pop(); u = x.id if use_fib else x
        done[u] = True
        for j in range(g.off[u], g.off[u + 1]):
            scans += 1; v = g.to[j]
            if done[v]: continue
            candidate = dist[u] + g.weight[j]
            if candidate >= dist[v]: continue
            dist[v] = candidate
            if not seen[v]:
                seen[v] = True
                if use_fib: heap.insert(nodes[v], candidate, v)
                else: heap.insert(v)
            else:
                decreases += 1
                if use_fib:
                    ok = heap.decrease(nodes[v], candidate)
                    assert ok
                else: heap.decrease(v)
    return (heap.comparisons, heap.links if use_fib else 0,
            heap.cuts if use_fib else 0, decreases, scans)

六、11.5：伸展树的访问引理

伸展操作只有 zig、zig-zag、zig-zig 三种基本形态，但高度没有 AVL 的局部保证。把全部节点深度相加看似能描述“不平衡程度”，却可能因一次旋转上升 Θ(N)，不能稳定支付路径工作。原书转而用每个节点子树规模的对数：

s(x)=1+s(xleft)+s(xright),R(x)=log2s(x),Φ=∑xR(x)
证明：访问引理的局部势能与求和

一次单旋只改变参与旋转的两个节点的子树大小，双旋只改变 x,p,g 的大小。其余节点虽可能换深度，但子树集合不变，这让势能变化能够局部计算。这里的“秩”是对数子树大小，并不等于 AVL 高度、二项树孩子数或并查集的秩。

关键不等式来自算术—几何均值：若 a,b>0 且 a+b≤c，则 ab≤c2/4，于是：

log2a+log2b≤2log2c−2

一次 zig-zag 的旋转成本为 2，消去 x,p,g 的秩变化后，有 2+Rf(p)+Rf(g)−Ri(x)−Ri(p)。因为旋转后的 p,g 子树不相交且包含在新 x 子树中，上式的前两项可用引理压成 2Rf(x)−2，再用 Ri(p)≥Ri(x)，得到至多 2(Rf(x)−Ri(x))，当然也不超过三倍。zig-zig 的两个不相交子树选法不同，完整推导在 习题 11.8。

各次双旋的界都只含 x 的前后秩差，因此一串双旋中间的秩会相消。最后至多一次 zig 多出一个单位，旋转数 q 满足访问引理：

q+ΔΦ≤3(log2N−log2sbefore(x))+1

成本口径校注：定理 11.5 的双旋推导计的是旋转数，而前一段将一次访问写成“1 加旋转数”（PDF 464–466）。若这一个单位也单独计入，统一的上界应在右边再加 1，即 3(log2N−log2sbefore(x))+2。例如根 6 的左孩子为 1，1 的右子树含 2、3、4、5，访问 1 只做一次 zig，势能不变，真实的“1 加旋转数”为 2；右边只加 1 的版本在此为 1+3log2(6/5)<2。渐近界仍为 O(logN)。

        if p.left is x:
            p.left, x.right = x.right, p
            if p.left is not None: p.left.parent = p
        else:
            p.right, x.left = x.left, p
            if p.right is not None: p.right.parent = p
        p.parent, x.parent = x, g

        elif g.left is p: g.left = x
        else: g.right = x
        pull(p); pull(x); self.rotations += 1

            elif (g.left is p) == (p.left is x):

        while x is not None:
            last = x
            if key == x.key: break

        if last is not None: self.splay(last)
        return x is not None

子树规模让旋转的势能局部化

旋转可能改变很多节点的深度，但多数节点所包含的子树集合保持原样，只有参与旋转的少数节点需要重算规模。用子树规模的对数定义势能，就能局部估计一次旋转，再让连续双旋中目标节点的前后秩差相消，连接到整次访问。

11.1 · 连续插入什么时候严格少于 2M

原题（中文翻译）

向一个二项队列连续插入 M 次，什么时候耗时少于 2M 个时间单位？

本版习题 11.1；印刷页 452／PDF 第 469 页。

解答

仍以一次插入的基本动作加每次连接各一单位计时。设初始大小为 n，开始和结束的树数分别为 T0、TM。逐步相加 ci+ΔTi=2，得到：

∑i=1Mci=2M+popcount(n)−popcount(n+M)

因此充要条件是 popcount(n+M)>popcount(n)。从空队列出发且 M>0 时一定成立，因为终态至少有一棵树。若初始大小为 7、只插入一次，树数从 3 降到 1，真实成本为 4，大于 2M=2；此时支付成本的包括初始势能。M=0 时总成本和 2M 都为零，不满足严格小于。

11.2 · 插入与删除成对时，常数摊还如何成立

原题（中文翻译）

假设已经建立一个含 N=2k−1 个元素的二项队列。交替执行 M 对 Insert 和 DeleteMin。显然，每个操作花费 O(logN) 时间。为什么这不与插入的 O(1) 摊还界矛盾？

本版习题 11.2；印刷页 452／PDF 第 469 页。

解答

先给出题意中反复触发最长进位的具体序列：原队列含 B0 到 Bk−1，每次插入一个比现有所有键都小的键。Insert 连做 k 次连接，成本 k+1，把 k 棵树变成一棵 Bk。紧接着 DeleteMin 删掉刚插入的根，释放它的 k 个孩子，重新得到原来的 k 阶根集合。于是每对确实可以反复做 Θ(k) 工作。

操作实际关键工作树数变化摊还账
Insertk+1从 k 到 1，ΔΦ=1−kk+1+(1−k)=2
DeleteMin拆出 k 个孩子并恢复根链，Θ(k)从 1 到 k，ΔΦ=k−1Θ(k)，负责重新积累势能

插入的常数摊还界并没有宣称删除也为常数。每次删除付出了实际整理代价，同时又补回下一次插入需要消耗的势能，因此整串 M 对操作总账仍是 Θ(MlogN)。题干中“每个操作”指可以构造出这样的最坏序列，并非任意插入键都会形成同样的删除恢复。

解答

取任意 k≥2，从空斜堆交替插入：

k, k+1, k−1, k+2, k−2, k+3,…, 1, 2k

归纳可得，做完前 i 对插入后，右路径为 k−i+1,k−i+2,…,k，第 j 个右路径节点的左孩子是此前配对插入的较大键。下一对先插入更小的根，把旧树挂到其左边；再插入大于所有路径键的新键，根的交换把旧树转到右边，新大键成为左孩子，因此路径再增长一节点。

最终根为 1，右路径是 1,2,…,k，左孩子依次为 2k,2k−1,…,k+1。另建只含 2k+1 的斜堆，调用标准 Merge：单节点堆的根始终更大，因此每步都沿第一棵树的右边走，共访问 k 个节点。参与合并的总节点数为 N=2k+1，成本为 Θ(N)。若改为 DeleteMin，则内部合并访问 k−1 个节点，也为线性。

这就是 Sleator–Tarjan 原论文 §2 的交错插入构造，本文将其再接一次显式 Merge。参见 Self-adjusting Heaps，SIAM J. Comput. 15(1986)，第 57–59 页。标准迭代合并 会产生上述访问数。

11.4 · 常数摊还合并的表示与方向

原题（中文翻译）

说明如何用一次自顶向下的遍历合并两个斜堆，并把 Merge 的代价降低到 O(1) 摊还时间。

本版习题 11.4；印刷页 452／PDF 第 469 页。

解答

题干校注：本版明确写 “top-down”（PDF 469），但它所引用的 Sleator–Tarjan 论文给出常数摊还合并的是 §3 的 bottom-up 斜堆；§2 的标准 top-down 版得到 O(logN) 摊还合并。本题以下按论文的常数摊还版本给出表示、操作和完整计账。正文的双语 skew 程序采用标准自顶向下版。

为每条从根或左孩子起始的右路径保存末端入口，并允许沿右路径逆向访问。论文的 ring 表示在 left、right 之外增加 up：右孩子的 up 指向父节点，根和左孩子的 up 指向从自身出发的右路径最末节点。这样从堆的根可直接到右路径底端，沿 up 可向上走；不能在每次 Merge 开始时重新扫描到底端，否则增加的扫描不会由下面的常数账覆盖。

Merge 从两条路径的底端开始，比较当前键，取较大者接到已合并路径的上端；交换参与节点的左右孩子，最低节点保留原孩子。继续向上，直到某条输入路径的根 r 已经接入。把 r 挂成另一条尚未耗尽路径的最低剩余节点的右孩子，并保留那条未走的上部路径。每步通过已保存的父／末端入口调整环，工作为常数；这是一趟从底向上的合并。键值相同时使用唯一编号排序，可使论文假设的比较键互异成立。

把根开始的右路径称主路径，把根的左孩子开始的右路径称副路径。令 H 为全树的右重孩子数，Lmaj、Lmin 为主、副路径上的右轻孩子数（不计起始根）。采用论文的势能：

Φ=H+2Lmaj+2Lmin

设本次真正访问的合并路径有 t 个节点。路径上除 r 以外，原重孩子转成左孩子，其势能至少降一；原轻孩子在主路径上值两单位，转成左孩子后，新增右兄弟最多贡献一单位，也至少降一。未走的另一条主路径只会增大相应子树；轻变重时势能从 2 变 1，不能增加。r 新进入主路径最多增加两单位，原副路径顶端改变身份最多再增加两单位，其余不增加。故：

ΔΦ≤−(t−1)+4,t+ΔΦ≤5

这证明 Merge 摊还 O(1)。Insert 是与单节点堆合并，也为摊还 O(1)；DeleteMin 删根后，新暴露的两条副路径各只有 O(logN) 个轻节点，势能增加 O(logN)，再接一次常数摊还合并，故仍为 O(logN)。从空堆开始势能为零，任意初始 N 个节点的堆则最多带入 O(N) 初势能。完整来源为 Sleator–Tarjan，§3、Theorem 2，第 60–63 页。

11.5 · 斜堆的 DecreaseKey

原题（中文翻译）

扩展斜堆，使其支持 O(logN) 摊还时间的 DecreaseKey 操作。

本版习题 11.5；印刷页 452／PDF 第 469 页。

解答

每个节点增加 parent 指针，并由调用者持有节点位置。降低键后，如果它仍满足与父节点的堆序，就结束；否则从父节点的 left 或 right 槽断开整个子树，将其作为单独斜堆与原堆合并。剪切本身只需常数次指针修改，合并已有 O(logN) 摊还界。完整 C／Python 实现见 sk_decrease／decrease。

还要证明剪切不会在祖先上凭空增加线性势能。剪去右子树的一段，只可能让该祖先从重变轻；新增重节点只能出现在受影响路径从左孩子经过的祖先上。若这些节点从下向上为 u1,u2,…，在剪切后的结构中，每个新增重节点的未受影响右子树至少与受影响左子树一样大，而后者包含下面的新增重节点子树。所以相邻这类节点的剩余子树大小至少翻倍，它们至多 O(logN) 个。

因而拆分的势能上升至多 O(logN)，加上重新 Merge 的 O(logN) 摊还代价，整个降键也是 O(logN)。这个证明不用实际向上更新尺寸，也不用维持左式堆的空路径长。句柄定位按已知位置计 O(1)，按键查找一个节点的成本要另算。

11.7 · 从四个节点指针减为三个

原题（中文翻译）

Fibonacci 堆的标准实现每个节点需要四个指针：parent、child 和两个兄弟指针。说明如何减少指针数量，同时运行时间至多增加一个常数因子。

本版习题 11.7；印刷页 452／PDF 第 469 页。

解答

可以保留 parent、child、link 三个指针，把不需要的指针槽用来存另一个邻接关系。每个节点另有 degree，它本来就需要保存。孩子用有起点的双向链组织；child 在 degree 大于零时指向第一个孩子，degree 为零时保存本节点的 nextSibling。link 在非首孩子上保存 previousSibling，在首孩子上保存它父节点的 nextSibling。

节点情形child 字段link 字段
有孩子首孩子若自己是首孩子，存父节点的下一兄弟；否则存自己的前一兄弟
无孩子自己的下一兄弟同上；根链的首节点没有普通前驱，用堆头记录边界

由此，读取任意节点 x 的下一兄弟只需：degree 为零时读 x.child；否则读 x.child.link。读取前一兄弟时，先通过 parent.child 判断是否为首孩子；不是首孩子就直接读 x.link。父节点仍由 parent 直接访问，所以级联剪切的每一级也保持常数工作。根链使用一个堆头，保存首根和尾根，根节点的 parent 为 NULL；堆头的边界信息只需常数个指针。

插入一个新首孩子前先保存父节点的 nextSibling。让新孩子的 link 保存这个值，让它的 nextSibling 指向原首孩子；原首孩子若存在，就把其 link 改为新孩子。更新 parent.child 和 degree 即可。若原来没有孩子，父节点 child 原本保存的 nextSibling 转移到新首孩子的 link。

剪掉非首孩子时，用 previousSibling 和 nextSibling 的读取规则接回链，改后继的 link；剪掉首孩子时，新的首孩子 link 继承旧首孩子保存的父节点 nextSibling。若删掉最后一个孩子，父节点的 child 改为刚保存的 nextSibling，degree 变零。设置一个节点的 nextSibling 也只是写 child，或写首孩子的 link。遍历、剪切、链拼接和同阶连接都增加固定次数的解码和赋值，势能证明保持不变。

这是带类型判别的指针槽复用，不需要沿兄弟链寻找父节点。其通用复用思想见 Kaplan、Tarjan、Zwick，Fibonacci Heaps Revisited，§4 第 5 页；本答案补齐叶子节点与首孩子更换时的字段约定。正文保留四指针版本，便于核对环关系。

11.8 · zig-zig 的三倍秩差界

原题（中文翻译）

证明一次 zig-zig 伸展的摊还时间至多为 3(Rf(X)−Ri(X))。

沿用本节的秩、势能与旋转计费约定：s(x) 是以节点 x 为根的子树节点数，R(x)=log2s(x)；下标 i、f 分别表示本次双旋之前与之后。势能为 Φ=∑xR(x)，一次基本旋转记一个实际时间单位，摊还代价等于实际代价加 ΔΦ。

本版习题 11.8；印刷页 452／PDF 第 469 页。

解答

取左右对称情形中的一种：x 是 p 的左孩子，p 是 g 的左孩子。双旋后 x 获得原 g 的整棵子树，所以 Rf(x)=Ri(g)；其余节点的秩不变。按两次单旋计实际成本 2，摊还成本为：

c^=2+Rf(p)+Rf(g)−Ri(x)−Ri(p)

利用 Rf(p)≤Rf(x)、Ri(p)≥Ri(x)，可得 c^≤2+Rf(x)+Rf(g)−2Ri(x)。原 x 子树与新 g 子树互不相交，且都包含在新 x 的子树中，所以 si(x)+sf(g)≤sf(x)。对这两个不相交规模应用引理 11.4：

Ri(x)+Rf(g)≤2Rf(x)−2

即 Rf(g)≤2Rf(x)−2−Ri(x)，代回前式：

c^≤2+Rf(x)+2Rf(x)−2−Ri(x)−2Ri(x)=3(Rf(x)−Ri(x))

右—右的对称情形完全同理。本题只分析双旋，入口的一次访问单位没有包含在成本 2 里；一整次访问的常数口径在正文校注中统一。

11.9 · 加权访问引理与频率界

原题（中文翻译）

改变势能函数可以证明伸展操作的不同界。给树的每个节点 i 指定权重函数 W(i)，令 S(i) 为以 i 为根的子树内所有节点（包括自身）的权重和。全部节点的 W(i)=1 时，就是证明伸展界所用的函数。设树有 N 个节点，共进行 M 次访问。证明：

  1. 总访问时间为 O(M+(M+N)logN)。
  2. 若 qi 为元素 i 被访问的次数，且每个 i 的 qi>0，则总访问时间为 O(M+∑i=1Nqilog(M/qi))。

本版习题 11.9；印刷页 452／PDF 第 469 页。

解答

固定所有权重为正，取 R(i)=log2S(i)、Φ=∑iR(i)。双旋用到的两个子树仍不相交，权重和仍满足同一个算术—几何均值不等式，所以加权访问引理为：

c^i≤3log2WtotalSbefore(i)+2≤3log2WtotalW(i)+2

(a) 单位权重

置 W(i)=1，每步摊还至多 3log2N+2。任意初始树的势能满足 0≤Φ0≤Nlog2N，最后势能非负，因此 ∑ci≤M(3log2N+2)+Nlog2N，即题目所给的 O(M+(M+N)logN)。空树没有合法成功访问；N=1 时只剩 O(M)。

(b) 按访问频率加权

在分析中事后取 W(i)=qi，程序无需预知它们。因为每个元素至少被访问一次，qi≥1 且 ∑iqi=M。摊还和至多 2M+3∑iqilog2(M/qi)。再控制首尾势能：每个初始子树权重至多 M，每个末态子树至少含本节点的 qi，因此：

Φ0−ΦM≤∑ilog2(M/qi)≤∑iqilog2(M/qi)

把两部分相加，实际总时间至多 2M+4∑iqilog2(M/qi)，得到所求界。最后一步用到 qi≥1 和每个对数非负，这也解释了题干为何要求所有 qi>0。

该频率界是静态最优性的核心：与固定的一棵最佳静态查找树在同一访问频率下比较，只差常数因子。它没有证明与任意随访问而重排的最佳动态树同样快。本版参考文献段把两个小问的解释混在一起，以上按公式所实际证明的结论区分；来源参见 Sleator–Tarjan，Self-Adjusting Binary Search Trees。

11.10 · 任意键范围的伸展树合并

原题（中文翻译）

  1. 说明如何实现伸展树的 Merge，使从 N 棵单节点树开始的任意 N−1 次合并总共耗时 O(Nlog2N)。
  2. 将总界改进为 O(NlogN)。

本版习题 11.10；印刷页 452／PDF 第 469 页。

解答

Merge 在本题表示两个有序集合的并集；输入键值范围可以交错，因此需要真正的集合合并。以下操作消费输入树，相同键合并为一个节点；若有重复初始键，另保存 mass，表示该集合吸收过的单节点输入数，用来进行大小计账。

(a) 小集合逐项插入大集合

每次枚举 mass 较小集合的键，将它们逐个按普通伸展树插入到较大集合；小树枚举后消费。某个初始元素每次属于小集合，其所属集合的 mass 至少翻倍，因此最多被搬动 ⌊log2N⌋ 次，总搬动量 O(NlogN)。在所有仍存活的树上使用势能 ∑log2s(x)，每次伸展插入摊还 O(logN)，枚举及销毁小树只降低其势能。从单节点森林开始势能为零，最后非负，故总成本为 O(Nlog2N)。

(b) 中位拆分的批量合并

正文 sset_meld／meld 使用以下构造。对较小 mass 的输入树作线性中序遍历，取得有序节点数组，并解除旧左右、父链接。取数组中位键 x，在大树中伸展查找 x，把大树分成键小于、等于、大于 x 的三部分。递归用数组的前半、后半分别合并小于、大于部分，最后将结果挂为 x 的左右孩子。若大树已有 x，删去其同键节点。空数组时直接返回该段大树。

中位划分使递归深度为 O(logm)，其中 m 是小输入的实际节点数；与键范围是否交错无关。中序枚举、解除旧树成本 O(m)，并删除非负的旧树势能。每次查找拆分在其当前 b 个节点的大树上，按访问引理摊还 O(1+log(b+1))；拆开边或移走同键根只会降低势能。最后把数组节点接成根，使势能新增 log2(b+msegment)，可与该次拆分的界一起计入。

在中位递归第 j 层，至多有 2j 个互不相交的大树片段，总节点数至多 n；数组片段也总共至多 m。对数的凹性给出这一层 O(2j[1+log2((n+m)/2j)]) 的账。把 j=0 至 ⌊log2m⌋ 的各层相加，换元为离底层的层数，利用 ∑d≥02−d、∑d≥0d2−d 收敛，得到：

C^meld=O(m+mlog2(1+n/m))

下面完成所有合并的总账。设两输入 mass 为 A≤B。实际节点数 m≤A、n≤B，函数 a[1+log2(1+b/a)] 对两参数单调，因此该次成本可用 O(A[1+log2((A+B)/A)]) 上界。把对数项平均分给小 mass 集合中的每个初始元素，它本次得到的费用就是所属集合增长的对数：

log2((A+B)/A)=log2(A+B)−log2A

每个元素被收费的这些增长嵌在从 1 到最多 N 的单调 mass 历程中，相加不超过 log2N。非对数的 A 项也能并入，因为 B≥A 时对数至少为 1。于是所有合并的摊还和为 O(NlogN)；初始森林势能为零、最后势能非负，实际总时间同界。重复键被消费后仍作为概念上的初始元素保留在 mass 中，所以计账仍成立。

算法需要 O(m) 临时数组与栈；C／Python 均逐个重新计算父指针和 size。这里给出完整批量构造及势能总账，与文献中的最优合并结论相符；该结论的原始出处为 Port–Moffat，A Fast Algorithm for Melding Splay Trees，WADS 1989，第 450–459 页。

11.11 · 半满再散列的正式势能分析

原题（中文翻译）

第七章介绍过再散列：表超过半满时，构造一个容量为原来两倍的新表，将旧表的所有元素再散列进去。给出带势能函数的正式摊还分析，说明插入的摊还成本仍为 O(1)。

本版习题 11.11；印刷页 452／PDF 第 469 页。

解答

令 n 为元素数、m 为偶数容量，且没有删除。使用：

Φ(n,m)=max(0,2n−m/2)

不扩容的一次插入使势能最多增加 2，若其正常插入成本有常数界，摊还成本也为常数。触发扩容时，旧状态为 n=m/2、势能 m/2；插入一项并将容量增为 2m 后，势能为 2(m/2+1)−m=2。要搬迁 m/2 个旧元素，加上新项及固定开销，若每元素重插按一单位计：

c≤m/2+O(1),ΔΦ=2−m/2,c^=O(1)

初始化新数组有 O(m) 个槽，也可一并计入，把势能乘足够大的固定常数即可。初始空表势能为零，所以任意 M 次插入的这些数组与搬迁工作总计 O(M)（初始容量初始化另计）。

散列探测本身的界仍需要相应前提：在均匀散列等能保证装载因子不超过 1/2 时每次探测期望常数的模型下，得到期望摊还 O(1) 插入；上述扩容账是确定的。若所有键都冲突、重插时逐项长距离探测，搬迁不能无条件按每元素常数计，本题不能消去这部分探测成本。

11.12 · 2–3 树为什么只能总共线性分裂

原题（中文翻译）

证明：若不允许删除，那么向一棵初始含 N 个节点的 2–3 树连续插入 M 次，产生的节点分裂总数为 O(M+N)。

本版习题 11.12；印刷页 452／PDF 第 469 页。

解答

以含两个键的满节点，即 3-node，的数量作势能。一次插入若某节点不分裂而从一个键变成两个键，势能增加 1；若一个满节点暂时收到第三个键，就分裂成两个各含一个键的节点，并把中间键上送，原来的一个满节点消失。

设某次插入连做 k 次分裂。每次分裂贡献 −1 势能，传播最后停止的位置至多新增一个满节点；分裂根产生的新根仅一个键，不增加这项势能。因此 ΔΦ≤1−k，也就是 k+ΔΦ≤1。连续相加：

∑i=1Mki≤M+Φ0−ΦM≤M+N

最后一步来自初始满节点数最多 N、势能非负。证明只计节点分裂；每次按键寻找插入叶子的路径成本仍要另外计算。禁止删除使被分裂掉的满节点不能通过借键、合并反复低成本恢复，正是这里的条件。

原题（中文翻译）

带堆序的双端队列由一列元素构成，支持以下操作：

操作要求
Push(X,D)在 D 的前端插入 X。
Pop(D)移走前端元素并返回它。
Inject(X,D)在 D 的后端插入 X。
Eject(D)移走后端元素并返回它。
FindMin(D)返回 D 中最小元素，相同键可任意打破平局。

  2. 描述如何以每个操作 O(1) 最坏时间支持上述操作。

本版习题 11.13；印刷页 453／PDF 第 470 页。

解答

(a) 两个带最小值摘要的栈

用 front 栈的栈顶作为前端、rear 栈的栈顶作为后端。每个栈项同时存“加入本项后整个栈的最小值”。Push、Inject 分别压栈，FindMin 比较两栈顶摘要；从非空栈删除直接弹出。所需一端为空而另一端有 n 项时，把逻辑序列收集后平分，两栈各获得约 n/2 项，重算栈内最小值，再删除目标端；n=1 时直接处理唯一项。

取 Φ=K||front|−|rear||。普通端点操作使差值至多变化 1；重分前势能为 Kn，重分再删除后差值至多 2，势能下降至少 K(n−2)。选择 K 覆盖每项搬移及最小值计算的固定成本，就把 O(n) 重分消成常数摊还。底层动态数组几何扩容另使用其标准线性搬迁总账；两份势能相加仍得到 O(1) 摊还。FindMin 最坏 O(1)，空间 O(n) 摊还容量，空结构返回失败／None。

typedef struct { int64_t key, minimum; } MEntry;
typedef struct { MEntry *a; size_t n, capacity; } MStack;
typedef struct { MStack front, rear; uint64_t moves; } MinDeque;
void ms_push(MStack *s, int64_t key) {
    if (s->n == s->capacity) {
        size_t cap = s->capacity ? s->capacity * 2 : 4;
        if (cap < s->capacity || cap > SIZE_MAX / sizeof *s->a) { fputs("size overflow\n", stderr); exit(1); }
        MEntry *a = checked_array(cap, sizeof *a);
        if (s->n) memcpy(a, s->a, s->n * sizeof *a);
        free(s->a); s->a = a; s->capacity = cap;
    }
    int64_t minimum = s->n && s->a[s->n - 1].minimum < key ? s->a[s->n - 1].minimum : key;
    s->a[s->n++] = (MEntry){key, minimum};
}
void md_rebuild(MinDeque *d) {
    size_t n = d->front.n + d->rear.n; int64_t *a = checked_array(n, sizeof *a); size_t k = 0;
    for (size_t i = d->front.n; i > 0; --i) a[k++] = d->front.a[i - 1].key;
    for (size_t i = 0; i < d->rear.n; ++i) a[k++] = d->rear.a[i].key;
    d->front.n = d->rear.n = 0; size_t mid = (n + 1) / 2;
    for (size_t i = mid; i > 0; --i) ms_push(&d->front, a[i - 1]);
    for (size_t i = mid; i < n; ++i) ms_push(&d->rear, a[i]);
    d->moves += n; free(a);
}
void md_push(MinDeque *d, int64_t x) { ms_push(&d->front, x); }
void md_inject(MinDeque *d, int64_t x) { ms_push(&d->rear, x); }
bool md_pop(MinDeque *d, bool rear, int64_t *key) {
    if (!d->front.n && !d->rear.n) return false;
    MStack *s = rear ? &d->rear : &d->front;
    if (!s->n) md_rebuild(d);
    if (!s->n) s = rear ? &d->front : &d->rear; /* The one-item deque. */
    *key = s->a[--s->n].key; return true;
}
bool md_min(const MinDeque *d, int64_t *key) {
    if (!d->front.n && !d->rear.n) return false;
    if (!d->front.n) *key = d->rear.a[d->rear.n - 1].minimum;
    else if (!d->rear.n) *key = d->front.a[d->front.n - 1].minimum;
    else {
        int64_t a = d->front.a[d->front.n - 1].minimum, b = d->rear.a[d->rear.n - 1].minimum;
        *key = a < b ? a : b;
    }
    return true;
}
void md_free(MinDeque *d) { free(d->front.a); free(d->rear.a); *d = (MinDeque){0}; }

class MinDeque:
    def __init__(self):
        self.front, self.rear, self.moves = [], [], 0
    @staticmethod
    def push_stack(s, key):
        s.append((key, min(key, s[-1][1]) if s else key))
    def rebuild(self):
        a = [x[0] for x in reversed(self.front)] + [x[0] for x in self.rear]
        mid = (len(a) + 1) // 2
        self.front.clear(); self.rear.clear()
        for i in range(mid - 1, -1, -1): self.push_stack(self.front, a[i])
        for i in range(mid, len(a)): self.push_stack(self.rear, a[i])
        self.moves += len(a)
    def push(self, x): self.push_stack(self.front, x)
    def inject(self, x): self.push_stack(self.rear, x)
    def pop(self, rear=False):
        if not self.front and not self.rear: return None
        s = self.rear if rear else self.front
        if not s: self.rebuild()
        if not s: s = self.front if rear else self.rear
        return s.pop()[0]
    def minimum(self):
        if not self.front: return self.rear[-1][1] if self.rear else None
        if not self.rear: return self.front[-1][1]
        return min(self.front[-1][1], self.rear[-1][1])

(b) 以有界局部修复取得最坏常数

采用 Gajewska–Tarjan 的 heap-ordered deque 结果；它的五种接口与题意一致，键比较与指针动作按常数计，空间线性。原始论文为 Deques with Heap Order，IPL 22(1986)，197–200。下面用可直接阅读的 Boyapati–Rangan，On O(1) Concatenation of Deques With Heap Order，§3 Algorithm 5、Lemmas 2–4、Theorem 2（1995） 指定一套具体的结构与修复调度；本题不需要它额外提供的 Concatenate。

叶子按从左到右的队列顺序组织成等高多叉树；通常内部节点含 2…4 个孩子。最左、最右路径称外路径，外路径底端直接定位队列两端，保存最低失衡节点栈，使下一修复位置可在常数时间找到。内部区域保存向上的最小项摘要，根和外路径上的摘要向两端传递；这是该定理使用的堆序组织。

每次端点插入或删除只做：修改一个端点叶子；修复该端外路径的最低失衡节点一次；若修复影响根，则同时修复另一外孩子与根这些常数个节点，并设置两条摘要修复前沿；最后每条前沿向下推进一层。结构修复包括 5 孩子节点分裂、1 孩子节点与兄弟借取或合并；分裂、合并把相应外节点恢复到 3 孩子的中性状态，借取则恢复到 2…4 个孩子的合法范围。允许尚未轮到修复的外节点暂时有 1…5 个孩子。小到根直接容纳全部叶子的情况直接处理常数项。

关键的最坏界来自“不会在下一次机会前再次越界”：某节点分裂或合并后有 3 个孩子，要再次对父节点产生插入／删除，至少经历两个本级更新；其间至少有一次本级保持在 2…4 孩子内，可以把修复机会传给父节点。由叶层向上归纳，所有外节点在相邻两次改变其孩子数的事件之间都获得一次修复机会，所以度数一直留在 1…5，且一次用户操作只处理常数个节点。最低失衡节点栈用局部变化同步维护，定位本身也不扫描整条路径。

摘要另有两条修复前沿。Algorithm 5 每次分别推进一层，树高为 h 时在 h 次操作内完成传播；Lemma 4 给出根在完成传播前不会再次引入重叠传播任务的间隔保证。因此同时只有这两个受控的摘要边界，Theorem 2 的 FindMin 直接利用该堆序摘要，在 O(1) 最坏时间返回最小项。这个已证明的查询保证与有界结构修复结合，完成五个操作的最坏常数界；这里引用的是具体 Algorithm 5 和 Theorem 2，不能把 (a) 的整批重分成本按平均数当成该结论。

11.14 · 二项队列的 Merge 也能摊还常数

原题（中文翻译）

证明二项队列事实上支持 O(1) 摊还时间的合并。将一个二项队列的势能定义为树的数量加最大树的秩。

本版习题 11.14；印刷页 453／PDF 第 470 页。

解答

采用按秩递增的根链表，且合并时只处理两输入或进位存在竞争的前缀；若另一输入与进位都空了，直接挂接剩余后缀。正文 bq_meld／meld 正是这个实现。设两输入的树数为 T1,T2，最大秩为 R1,R2，空队列约定最大秩 0。令本次连接数为 L、结果为 T3,R3。

T3=T1+T2−L

两输入总大小小于 2max(R1,R2)+2，所以 R3≤max(R1,R2)+1，从而：

ΔΦ=−L+R3−R1−R2≤−L+1−min(R1,R2)

把一次“处理一个秩，至多连接一次”算一单位。较小最大秩范围内至多处理 min(R1,R2)+1 阶；它的输入耗尽以后，继续向高阶处理的每一步要么产生一连接、让进位继续，要么一次输出进位后直接挂接后缀。因此秩阶段数至多 L+min(R1,R2)+2，再加边界固定成本：

c≤L+min(R1,R2)+O(1),c+ΔΦ=O(1)

固定数量的指针读写只改变成本单位，按同一比例缩放势能即可。这个证明在所有存活队列上把势能相加；若从空队列开始，初始为零，最后非负，整串合并的总成本由常数摊还和上界。任意初始森林则要加上其已有势能。

若实现对每次 Merge 都扫描一张固定全宽秩数组，即使另一输入为空也不停止，它还多付出了这项证明没有计入的扫描。采用上述链表和后缀挂接才能与题目的常数摊还操作界相对应。
