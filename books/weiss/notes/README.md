# 章节笔记规范

## 组织

- 一章一份笔记：`chapterXX_<topic>.html`。辅助性说明集中在本文件；仓库范围的代理规范见根目录 `agent.md`。
- 全书架构笔记为 `book_overview.html`，开头集中“阅读与程序使用说明”，随后记录本版教材的整体主线、价值分析与章节依赖图；章节细节仍放在各章笔记中。
- 完成章节后，在总览的章节表、拓扑图节点及关系表中链接相应笔记；章节页头提供返回全书地图的入口，并链接已有的相邻章节。
- 当前选用 HTML，是为了在同一文件中保留图示、代码、表格与清晰的导航。若日后以 Obsidian 双链为主要阅读方式，再讨论迁移 Markdown；不要同时维护两个内容副本。
- 不引入外部字体、图片、CSS 或脚本，单文件即可离线阅读。
- 程序提取与核对工具为 `tools/check_notes.py`：只读取正式 HTML，检查题号、锚点、目录和双语结构，并按内置依赖清单提取程序、组合实验入口；可选核对实验的确定性计数。输出写到命令指定的目录，程序正文仍以 HTML 为唯一来源；工具的使用方法集中在全书总览。

## 内容

- 采用伴读式叙述：沿原书论证顺序解释作者先提出什么困难、图或代码如何回应、接下来为何引出新结构。正文以连贯讲解为主，表格和清单只作辅助。
- 每章笔记附按本版题号排列的完整习题解答，每题使用一个 `details.exercise`；标题统一为“题号 · 任务”。计算题给推导与结果，证明题写明假设、关键推理和边界，编程题给算法、实现、边界与复杂度，实验题给复现程序和实测结果。
- 每题展开后，固定先展示“原题（中文翻译）”，再展示“解答”。题干对照本版 PDF 完整翻译，保留各小问的字母与顺序、全部条件、公式、输入数据、实验规模和原书提示，并标明题号、印刷页及 PDF 页码。题目的简短摘要继续用于定位。
- 中文题干使用 `div.exercise-question`，包含 `p.question-title.rn-exercise-label`、题干正文及来源；在随后 `div.answer` 的开头使用 `p.answer-title.rn-exercise-label` 标记解答。题干的 `data-original-exercise` 与 `data-source-pdf-pages` 分别记录原题号和 PDF 页码，便于检查覆盖。达到 20 题的章节在习题区顶部提供连续题号索引，题目仍按原顺序展示。
- 原题给出的程序片段按原貌放在 `pre.question-code`，内部代码标记 `data-source="textbook"`；这些题目材料与双语教学实现分别呈现。题目依赖的输入图、表格及数据随题干展示，用内联 SVG 或语义表格复现并标明原图号；共有输入也可以链接到本章的明确锚点。
- 印刷错误、约定差异及必要的上下文说明单独标为“题干校注”或“原书上下文”。原题中的表达与解答采用的修正分别写清，完整推导仍放在解答部分。
- 在关键转折处精选有辨识度的短句，附准确译文、小节位置，并结合上下文细读；不要把改写文字放入原文引号。
- 用小规模实例、语义表格或内联 SVG 推演具体状态，指出指针更新顺序、边界条件、复杂度前提、空间与时间的交换。
- 对原书应用场景讲清数据如何组织、作者为什么选它、何处仍有代价或局限。
- 代码使用独立编写的完整教学实现，明确内存所有权、空结构、失效位置、整数范围及失败行为。共享定义在本章给出一次，引用处提供精确的双语锚点；外部库和 POSIX 等平台依赖注明名称及运行条件。
- 高阶习题写出具体构造及复杂度推导。采用已发表定理时给出来源、适用前提和它在解答中承担的步骤；题干与所引论文有差异时直接解释差异，并完成可核验版本的解法。

## 双语程序

- 正文程序、编程习题和实验驱动均提供 C11 与 Python 3 实现。两版使用相同算法、数据约定、重复值与平局规则；需要不同错误接口或整数表示时明确说明对应关系。
- 每对实现放在 `div.code-pair` 中，内部依次是两份 `details.code-version`，语言属性分别为 `data-language="c"` 与 `data-language="python"`，摘要为“C（C11）”和“Python 3”。C 带 `open`，Python 默认收起，读者可以同时展开。
- 每个 `<pre><code>` 设置唯一 ID、`data-language` 和 `language-c`／`language-python` 类。保留旧代码 ID；新增对应语言采用描述性的 ID，通常以 `-python` 或 `-c` 结尾。
- 共享实现必须涵盖题目要求的操作。纯证明、数值推导、结构设计可用文字与图完成；如果给出程序，则两种语言同时给出。
- 已有正文实现的具体输入题，题内可补一对小驱动：构造原题输入、调用共享函数、打印题目需要的结果，并链接准确的依赖锚点。算法正文保持一份；递归过程可通过共享实现的可选观察回调记录。补充实现沿用现有解答的算法及平局规则，纯证明仍以推导完成。
- 固定容量、预分配、动态扩容、递归栈深和大整数的成本应与宣称的时间界一致。不要让某一种语言的便捷库悄悄改变算法或复杂度。
- 插入、删除、查找、输出及计时所需调用必须独立执行，不能只放在 `assert` 的表达式里。断言用于内部不变量；实验驱动和自测用显式检查验证必须执行的工作，Python 优化模式或 C 的 `NDEBUG` 不得改变实际操作序列。
- 通用语言版本、机器与解释器环境、编译和运行命令、程序组合顺序及特殊平台依赖，统一维护在 `book_overview.html#program-guide`；按章展开具体入口与附加选项。章节页头提供一个“程序说明”入口，正文围绕算法与解答展开。
- 实验题在结果附近保留输入规模、生成规则与种子、重复次数、计时范围、统计方式和单位；通用环境与执行步骤引用全局说明。影响结论的独特条件（如固定栈大小、递归限制、整数范围）仍随结论说明。
- 程序核对的范围摘要保存在维护记录。总览的折叠区说明复现方法和结果解释，章节保留习题要求的测试方法、不变量及实际实验数据。

## 实验图表

- benchmark 与统计结果在原表附近补充内联 SVG 图；保留原始表格，并从图注链接回对应数据。图中的点、条形与热图格子均取已记录数值，原书历史测量与本机实测标明来源；缺失项保持缺失。
- 规模增长采用折线图，分类比较采用从零开始的条形图，参数矩阵采用热图。跨度较大时可使用明确标注的对数折线或点图；归一化指标写清分母与单位。C、Python 及不同计时口径分别呈现，输入与计数规则沿用原表。
- 图表沿用纸色、强调绿及辅助色 `#b17c3c`、`#57788e`、`#997278`、`#71864c`、`#3e8580`；曲线同时用不同点形辨识。图中保留轴、单位、图例及可读标题，多指标使用原生视图控件；窄屏按单列排布，密集热图在局部横向滚动，单文件可离线查看。
- 总览的“实验图索引”链接到各章图表。交付时逐项核对图数据与原表单元格、对数刻度及缺失值处理，确认原题、解答、代码和原表内容一致，再检查桌面与窄屏显示、视图切换及来源跳转。

## 固定版式与导航

- 保持简洁的书页风格：浅底色、适度留白、单一强调色和明确层级；用语义化 HTML 组织内容，表格与图示服务于当前论证。
- 全书总览和章节页嵌入完全相同的 CSS。当前固定参数：纸色 `#fffefa`，正文 `#252b29`，辅助文字 `#58615d`，边线 `#d9dfda`，强调绿 `#285a4e`，浅底 `#f4f6f2`；使用系统中文字体。
- 正文 `17px`、行高 `1.9`，主栏最大宽 `860px`，桌面内边距 `48px 24px 90px`；`640px` 以下为 `30px 18px 60px`。桌面一级／二级／三级标题为 `2.2rem`／`1.55rem`／`1.16rem`，窄屏一级／二级标题为 `1.75rem`／`1.3rem`。
- `1100px` 及以上使用左侧目录与正文双栏：外层最大宽 `1200px`、左右内边距 `24px`，目录宽 `240px`，栏间距 `32px`。目录距视口顶部 `32px` 固定跟随，并在自身范围内滚动；当前分节以强调色和 `aria-current="location"` 标识。
- `1100px` 以下目录置于正文上方，采用原生 `details` 收起展开；展开后的长目录在内部滚动，选中分节后收起，跳转位置留出目录栏高度。关闭脚本仍可展开并使用全部链接。打印时隐藏目录，正文恢复单栏。
- 页头顺序统一为版本与章号、章节名称、伴读主线、来源页码、全书地图及已有相邻章入口。总览为全书入口，保持章节表、可点击拓扑节点和关系表同步。
- 全书总览和各章使用同一左侧目录结构，由现有分节链接组成，正文中不重复目录。目录中的习题链接也使用完整起止题号。习题区标题统一为“习题解答 · 起止题号”，各题按题号连续排列，不插入主题分类标题，不设置分组索引。单题内部的小标题按解答需要设置，语言切换使用原生展开控件。
- 页尾保留必要的版次／来源说明，统一放“返回页首、全书地图、已有相邻章”导航。已完成笔记的正式内容采用确定的答案与说明。
- 宽表格、代码、MathML 和 SVG 只在各自容器内横向滚动；整页在窄屏不得溢出。中文状态与箭头关系使用表格、结构节点或 SVG 对齐，`<pre>` 只放程序。
- 数学表达式统一采用静态 MathML，变量、复杂度、上下标、分式、求和及取整使用相应结构；显示公式居中，长公式局部横向滚动。行内公式保留足够的上下留白，展开全部习题后仍不得裁掉求和或分式。程序代码中的运算符保留语言原貌，SVG 图中上下标用 `tspan` 的 `baseline-shift` 排版。

## 验证

- 从最终 HTML 抽取代码实际运行，核对它与测试版本的内容一致。C 采用 `clang -std=c11 -Wall -Wextra -Werror -pedantic`；有内存与指针操作的功能测试加 `-fsanitize=address,undefined`。Python 使用 Python 3 实跑。
- 测试选择能独立判断答案的参考方法：排序／集合／线性扫描、穷举小输入或数据结构不变量；核对两种语言的可比输出。编译成功不能替代功能验证，运行样本不能替代数学证明。
- 实验记录输入规模、随机生成规则与种子、计时范围及统计方式；语言版本与编译选项统一写在总览的程序说明中。性能表写实际数据；递归崩溃探测在独立子进程中执行，并注明影响阈值的限制条件。
- 静态检查所有本版题号、唯一 ID、内链、双语对、共享依赖和资源引用；桌面及 `390px` 窄屏检查目录导航、习题与语言展开、公式、图表的局部滚动。程序核对摘要与显示检查结果在维护记录中保存，用于交付验收。
- 逐题核对中文题干与本版扫描页：题号和页码正确，各小问及所需输入齐全；题干在解答之前，原题程序与教学代码可区分。只补题干或调整样式时，核对已有解答、代码与锚点的内容一致，并对新增公式和输入图进行渲染检查。
- MathML 除标签合法性外，还核对 `data-tex` 中分组花括号及转义分隔符是否完整，查看正文是否遗留转换标记；上下标、分式与求和以实际渲染结果验收。

正文和教学代码维护入口为 `src/content/books/weiss/`，本目录十三份 HTML 为兼容镜像；程序提取仍由原 Python 检查器从镜像独立进行。共享 CSS/JS 构建内联，流程见 仓库的 `docs/astro-authoring.md`。章节 frontmatter 的范围合并原章首正文页与全部题干页属性，印刷页加 17 对应 PDF 页序，参考文献范围仍保留在章首。
