一、§6.1：先明确可以使用哪些信息

第五章的堆只维护“下一项”，本章要求把全部元素排成顺序。作者先统一接口：输入是数组和合法长度，所有排序都使用从 0 开始的下标；示例用整数，但比较规则可以来自记录的某个字段。若只允许比较与赋值，我们面对的是比较排序。后面桶排序把整数键直接变成下标，已经使用了额外信息，复杂度下界必须跟着模型一起看。

排序结果要同时满足两件事：键非递减，且输出仍是原输入的一个排列。只检查“已排序”会漏掉元素丢失、重复写入等错误。若键相等还要保持原始先后，这第三项性质叫稳定性；它取决于比较和移动的细节。正文默认升序，重复值按出现次数保留。

以下程序使用同一比较计数器。C 数组由调用者拥有，长度与可读写空间必须一致；长度为 0 时允许空指针，其他情况下必须是有效数组。普通排序接受整个 int 键域，比较不做减法，因此极值相减不会溢出。Python 对应操作原地修改列表；整数任意精度，但本章两版可比测试使用 32 位有符号键。比较与索引视为常数时间，超大整数需要另外计入位数成本。

#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct { uint64_t comparisons; } Stats;

int key_cmp(int x, int y, Stats *s) {
    if (s) ++s->comparisons;
    return (x > y) - (x < y);
}

void key_swap(int *x, int *y) {
    int t = *x; *x = *y; *y = t;
}

uint32_t next_u32(uint32_t *state) {
    /* state must be nonzero; all arithmetic is unsigned. */
    uint32_t x = *state;
    x ^= x << 13; x ^= x >> 17; x ^= x << 5;
    *state = x;
    return x;
}

        stats.comparisons += 1

    a[i], a[j] = a[j], a[i]


def next_u32(state):
    # A one-element list holds the same nonzero uint32 state as C.
    x = state[0]
    x ^= (x << 13) & 0xFFFFFFFF
    x ^= x >> 17
    x ^= (x << 5) & 0xFFFFFFFF
    state[0] = x & 0xFFFFFFFF
    return state[0]

二、§6.2–6.3：把“几乎有序”变成可以计数的量

插入排序从第二个元素开始。处理位置 P 前，左侧前缀已经有序；把新键暂存为 value，所有严格大于它的前驱向右移动，最后填入空穴。这与上一章上滤的空穴写法相通：先保存待放元素，再移动别人，避免反复交换。循环中只跨过较大键，相等键不会被越过，因此这一写法稳定。

void insertion_sort(int *a, size_t n, Stats *s) {
    for (size_t i = 1; i < n; ++i) {
        int value = a[i];
        size_t j = i;
        while (j > 0 && key_cmp(a[j - 1], value, s) > 0) {
            a[j] = a[j - 1];
            --j;
        }
        a[j] = value;
    }
}

本实现依赖共同定义。外层每轮保存一个键，内层在 j > 0 后才访问 a[j-1]。空数组和单元素数组自然返回，工作空间为 O(1)。

§6.3 用逆序对解释上述差异：下标 i<j，却有 Ai>Aj。相邻的一对失序元素交换后，恰好消去一个逆序对；插入排序的一次右移就是这种交换的隐式形式。因此输入有 I 个逆序对时，时间是 Θ(N+I)。图 6.1 的 9 次右移，对应最初的 9 个逆序对。

0≤I≤N(N−1)2,𝔼[I]=N(N−1)4

平均式要求 N 个不同键的所有排列等可能。任取一对键，两种先后各占一半，所以每对以概率 1/2 构成逆序。于是插入排序最坏及该模型的平均时间都是 Θ(N2)，已排序输入是 Θ(N)。这个下界也约束所有只靠相邻交换消除失序的算法。常见选择排序会交换远处元素，不能仅凭这一相邻交换论证把它纳入同一类；它的二次比较界需要单独计数。

三、§6.4：先让远处的元素交流，再缩小间隔

希尔排序对每个间隔 h，分别对下标同余的 h 条链做插入排序，得到 Ai≤Ai+h 的 h 有序数组。间隔必须最终到 1，才覆盖全部相邻关系。关键性质是：后做另一种间隔的排序，不会破坏已有的 h 有序性；6.7给出证明。这让前面各轮的工作可以累积。

/* Descending positive gaps; include 1 to sort every possible input. */
void shell_sort(int *a, size_t n, const size_t *gaps, size_t count,
                Stats *s) {
    for (size_t k = 0; k < count; ++k) {
        size_t h = gaps[k];
        if (h == 0 || h >= n) continue;
        for (size_t i = h; i < n; ++i) {
            int value = a[i];
            size_t j = i;
            while (j >= h && key_cmp(a[j - h], value, s) > 0) {
                a[j] = a[j - h];
                j -= h;
            }
            a[j] = value;
        }
    }
}

/* family: 0 Shell, 1 Hibbard, 2 Knuth, 3 Gonnet, 4 Sedgewick.
   The experiment restricts n <= 1,000,000. */
size_t make_gaps(size_t n, int family, size_t out[GAP_LIMIT]) {
    size_t used = 0;
    if (n < 2) return 0;
    if (family == 0 || family == 3) {
        size_t h = family == 0 ? n / 2 : n * 5 / 11;
        if (h == 0) h = 1;
        while (h > 0) {
            out[used++] = h;
            h = family == 0 ? h / 2 : h * 5 / 11;
        }
        if (out[used - 1] != 1) out[used++] = 1;
        return used;
    }
    if (family == 1 || family == 2) {
        size_t h = 1;
        while (h < n) {
            out[used++] = h;
            size_t ratio = family == 1 ? 2 : 3;
            if (h > (SIZE_MAX - 1) / ratio) break;
            h = ratio * h + 1;
        }
    } else {
        /* Union of 9*4^i-9*2^i+1 (i>=0),
           and 4^i-3*2^i+1 (i>=2). */
        for (size_t p = 1; p <= 2048; p *= 2) {
            size_t h = 9 * p * p - 9 * p + 1;
            if (h < n) out[used++] = h;
            if (p >= 4) {
                h = p * p - 3 * p + 1;
                if (h < n) out[used++] = h;
            }
        }
    }
    /* Few gap values: insertion-sort descending and remove duplicates. */
    for (size_t i = 1; i < used; ++i) {
        size_t value = out[i], j = i;
        while (j > 0 && out[j - 1] < value) {
            out[j] = out[j - 1]; --j;
        }
        out[j] = value;
    }
    size_t unique = 0;
    for (size_t i = 0; i < used; ++i)
        if (unique == 0 || out[i] != out[unique - 1])
            out[unique++] = out[i];
    return unique;
}

排序例程依赖共同定义；给定间隔数组的空间归调用者，正间隔按递减顺序提供，必须包含 1。间隔 0 或不小于 N 的值被跳过。make_gaps 是本章实验的辅助程序，明确限制 0≤N≤106、族号 0–4，最多 128 个间隔槽位，Sedgewick 两个公式取并集、去重后倒序；它并非无限键域的通用间隔生成器。

3.1　原始增量的失败来自分组之间长期没有联系

原始序列从 ⌊N/2⌋ 开始反复减半。取 N 为 2 的幂，则最后一轮之前的间隔全部为偶数。让大键占一类奇偶位置、小键占另一类，早期各轮只能在各自类里调整；最后的普通插入排序仍要消去 Θ(N2) 个逆序。另一方面，一轮 h 排序的最坏代价为 O(N2/h)，各轮倒数构成几何和，因此总上界也是 O(N2)。

3.2　Hibbard 的上界：大间隔和小间隔分别估计

Hibbard 使用 hk=2k−1，即 1、3、7、15……。当前 h 排序前，已经完成 a=2h+1 与 b=4h+3 两轮；两数互素。若距离能写成 ua+vb，其中 u、v 非负，沿这些已知有序边前进，就能断定较早的键不大于较后的键。

这里用到二元 Frobenius 结论：互素 a、b 的所有整数 d≥(a−1)(b−1) 都能这样表示。证明可以选 v∈{0,…,a−1} 使 vb≡d(moda)；此时 d−vb 是 a 的倍数且大于 −a，故非负。对 Hibbard，阈值为 8h2+4h，一条 h 链中最多剩下 O(h) 个可能挡路的前驱，所以小间隔一轮只需 O(Nh)。

∑h≤NO(Nh)+∑h>NO(N2/h)=O(N3/2)

两端都按几何级数求和，不应把每轮的最大代价再乘 logN。6.8 构造了一族前半段大间隔几乎无事可做的 0–1 输入，补上 Ω(N3/2)，所以最坏界为 Θ(N3/2)。原书提到的 Hibbard 平均 N5/4、Sedgewick 平均 N7/6 是该版的经验猜测，不作为定理使用；Sedgewick 所述序列的最坏上界是 O(N4/3)。实际比较见 6.36。

四、§6.5：把输出放在堆刚腾出来的位置

上一章用最小堆连续 DeleteMin，可以依次得到升序，但另存输出会占第二个数组。作者改用最大堆：每次根与有效堆末尾交换，最大元就进入最终位置，堆长度减一；剩余前缀下滤恢复堆序。整个数组逐步分成“未输出的最大堆”和“已排序的后缀”。两区的长度共为 N，空间因此可以重复利用。

本章下标从 0 起，孩子为 2i+1、2i+2，父亲为 ⌊(i−1)/2⌋。自底向上建堆只处理实际内部节点；无符号下标倒序使用 i > 0 后访问 i-1，避免减到负数。下滤先选较大孩子，相等时固定选左边；右孩子存在后才读取。

C（C11）
/* Max-heap on [0,n); choose the left child on a tie. */
void heap_down(int *a, size_t root, size_t n, Stats *s) {
    int value = a[root];
    while (root < n / 2) {
        size_t child = 2 * root + 1;
        if (child + 1 < n && key_cmp(a[child], a[child + 1], s) < 0)
            ++child;
        if (key_cmp(value, a[child], s) >= 0) break;
        a[root] = a[child]; root = child;
    }
    a[root] = value;
}

/* Exercise 6.41: descend to a leaf first, then rise within this path. */
void heap_down_floyd(int *a, size_t root, size_t n, Stats *s) {
    size_t start = root;
    int value = a[root];
    while (root < n / 2) {
        size_t child = 2 * root + 1;
        if (child + 1 < n && key_cmp(a[child], a[child + 1], s) < 0)
            ++child;
        a[root] = a[child]; root = child;
    }
    while (root > start) {
        size_t parent = (root - 1) / 2;
        if (key_cmp(a[parent], value, s) >= 0) break;
        a[root] = a[parent]; root = parent;
    }
    a[root] = value;
}

void heap_sort(int *a, size_t n, bool floyd, Stats *s) {
    if (n < 2) return;
    /* Both experiments use the same ordinary bottom-up build. */
    for (size_t i = n / 2; i > 0; --i) heap_down(a, i - 1, n, s);
    for (size_t end = n; end > 1; --end) {
        key_swap(&a[0], &a[end - 1]);
        if (floyd) heap_down_floyd(a, 0, end - 1, s);
        else heap_down(a, 0, end - 1, s);
    }
}

def heap_sort(a, floyd=False, stats=None):
    n = len(a)
    for i in range(n // 2 - 1, -1, -1):
        heap_down(a, i, n, stats)
    for end in range(n, 1, -1):
        key_swap(a, 0, end - 1)
        (heap_down_floyd if floyd else heap_down)(a, 0, end - 1, stats)

这对实现依赖共同定义。floyd=false 是图 6.8 的普通空穴下滤；true 只在输出阶段使用习题 6.41 的“先降到叶，再上滤”，两者建堆相同。普通版本比较待放键与较大孩子，以便提前停止；Floyd 版本先省去这些比较，再付少量上滤代价，是否更快由实测决定。

建堆最坏 Θ(N)，输出阶段最坏 Θ(NlogN)，总工作空间 O(1)。原书还分析均匀随机、不同键输入的平均比较数 2Nlog2N−O(NloglogN)；这是该版本的理论结果，不是由本章几次计时拟合出来的。远距离根末交换会改变相等记录的顺序，因此堆排序通常不稳定。

五、§6.6：先取得两份有序输入，合并就只需向前走

归并把困难拆成两个较小排序问题，再线性地接起来。合并时只比较两个尚未输出的首元素，取较小者；一侧耗尽后，另一侧直接复制。图 6.10 在相等时选左边，保证原本在左半段的同键记录仍在右半段之前。合并长度合计为 n 时，键比较最多 n−1 次；最后一次比较至少让一侧耗尽。

图例的 [1,13,24,26] 与 [2,15,27,38] 合并顺序为 1、2、13、15、24、26，随后直接复制 27、38。每次指针前移都输出一个元素，所以总搬动仍是线性，两个输入首元素之外的部分无需重复搜索。

T(N)=2T(N/2)+N,T(1)=1⟹T(N)=Nlog2N+N(N=2k)

一层全部子问题的合并长度共为 N，递归共 log2N 层。原书还演示除以 N 后让递推式望远镜消去；一般 N 使用向上、向下取整，数量级保持 Θ(NlogN)。精确最坏比较数另见 6.16。

/* 0 success; -1 allocation/size error. Failure leaves a unchanged. */
int merge_sort(int *a, size_t n, Stats *s) {
    if (n < 2) return 0;
    if (n > SIZE_MAX / sizeof *a) return -1;
    int *tmp = malloc(n * sizeof *tmp);
    if (!tmp) return -1;
    for (size_t width = 1; width < n;) {
        size_t lo = 0;
        while (lo < n) {
            size_t mid = lo + (n - lo < width ? n - lo : width);
            size_t hi = mid + (n - mid < width ? n - mid : width);
            size_t i = lo, j = mid, k = lo;
            while (i < mid && j < hi)
                tmp[k++] = key_cmp(a[i], a[j], s) <= 0 ? a[i++] : a[j++];
            while (i < mid) tmp[k++] = a[i++];
            while (j < hi) tmp[k++] = a[j++];
            lo = hi;
        }
        for (size_t i = 0; i < n; ++i) a[i] = tmp[i];
        if (width >= n - width) break;
        width *= 2;
    }
    free(tmp);
    return 0;
}

void merge_recursive_range(int *a, int *tmp, size_t lo, size_t hi, Stats *s) {

六、§6.7：划分质量与扫描规则共同决定效率

快速排序先选主元，把其余元素分到较小侧和较大侧，再分别排序；主元已经落到最终位置，所以不用归并。节省临时数组的代价是：两边可能很不平衡。原书提醒，已排序数据在实际输入中很常见，直接用首元素作主元会稳定地得到 0 与 N−1 的划分。

6.1　三数中值还承担哨兵与端点整理

图 6.13 先将左端、中央、右端三键原地排好，再把中值藏在 right-1。左端不大于主元，给向左扫描提供哨兵；隐藏的主元自己给向右扫描提供哨兵。其后 i 先加一、j 先减一，遇到相等键就停止；交换后下一轮继续移动，防止相同键让循环卡住。最终把主元放到 i，然后只处理它两侧。

/* Inclusive range; callers ensure left < right and length >= 4. */
size_t book_partition(int *a, size_t left, size_t right, Stats *s) {
    size_t center = left + (right - left) / 2;
    if (key_cmp(a[left], a[center], s) > 0) key_swap(&a[left], &a[center]);
    if (key_cmp(a[left], a[right], s) > 0) key_swap(&a[left], &a[right]);
    if (key_cmp(a[center], a[right], s) > 0) key_swap(&a[center], &a[right]);
    key_swap(&a[center], &a[right - 1]);
    int pivot = a[right - 1];
    size_t i = left, j = right - 1;
    for (;;) {
        do { ++i; } while (key_cmp(a[i], pivot, s) < 0);
        do { --j; } while (key_cmp(a[j], pivot, s) > 0);
        if (i >= j) break;
        key_swap(&a[i], &a[j]);
    }
    key_swap(&a[i], &a[right - 1]);
    return i;
}

6.2　递推式里必须写出随机假设

T(N)=T(i)+T(N−i−1)+cN

6.3　选择问题只保留含目标的一边

第 k 小元素不要求两侧都排好。一次划分后，若主元下标就是目标，直接返回；否则只进入含目标的一侧。下面接口把秩统一成从 0 开始，重复键仍各占一个秩。它原地重排输入，若调用者还需要原序，应先复制。

/* k is zero-based; false for invalid k/out. a is rearranged on success. */
bool quick_select(int *a, size_t n, size_t k, int *out, Stats *s) {
    if (!a || !out || k >= n) return false;
    size_t left = 0, right = n - 1;
    while (right - left + 1 > 3) {
        size_t p = book_partition(a, left, right, s);
        if (k == p) { *out = a[p]; return true; }
        if (k < p) right = p - 1;
        else left = p + 1;
    }
    insertion_sort(a + left, right - left + 1, s);
    *out = a[k];
    return true;
}

七、§6.8：排序的是位置，最后才移动大记录

整数交换很便宜，姓名、地址、薪资等组成的大记录则可能复制很多字节。原书引入间接排序：先建立索引表 T，T[i] 记录第 i 小键原先的位置；比较时读记录的键，交换时只动索引或指针。排序后可以一直按 T 访问，也可以再真正重排记录。

本版增加了表排序和置换环的解释。键为 [75,19,59,3,61,8,36,10,25,18]，排好索引为 [3,5,7,9,1,8,6,2,4,0]。这份“新位置 → 旧位置”映射分成四个环：

环应保存／移动的记录次数
0 → 3 → 9 → 0暂存 A0；A3→0，A9→3，暂存→94
1 → 5 → 8 → 4 → 1暂存 A1，再依次取 5、8、4 的记录填空穴5
2 → 7 → 2暂存 A2；A7→2，暂存→73
6 → 6位置已经正确0

每处理一个位置，就把它的 T 项改回自身下标，作为完成标记；一次只保留一份临时大记录。一个非平凡 k 环需要 k+1 次记录搬动，总计 O(N)，最坏不超过 ⌊3N/2⌋ 次。这里例子为 12 次。环方向取决于 T 的定义，不能把“旧位置 → 新位置”的算法直接套在这张表上。

若一条记录占 R 字节，直接比较排序的搬动成本可能达到 O(RNlogN)；间接排序加最终置换，把大记录搬动降到 O(RN)，另付索引排序成本及 Θ(N) 个索引空间。键比较本身如果要扫描长字符串，仍需单独计费。Python 列表本来就保存对象引用，列表交换不会复制对象全部内容；C 的结构体赋值则按值复制，这一语言差异应与算法区分。

八、§6.9：任何比较排序都要区分 N! 种可能

作者用决策树把某个实现的分析提升为整个模型的下界。取 N 个不同键，最初有 N! 种可能顺序；每次比较最多把它们分成两个分支，正确结束的叶子必须已经确定唯一相对顺序。深度 d 的二叉树至多有 2d 个叶子，因此：

d≥⌈log2(N!)⌉=Ω(NlogN)

这并不宣称每一个输入都需要这么多比较，而是至少有一个输入使任何正确比较排序走这么深。均匀随机排列的平均下界也成立，6.40 用叶深与 Kraft 不等式完成证明。堆排序、归并排序的最坏时间在数量级上达到模型的最优。

找到某个键的查找树只要区分 N 个命中位置与未命中的情形，所以下界为对数，见 6.27；排序要区分的是全体排列，两者不能混用。额外知道整数键域，或只需合并两份已有序输入，都会减少待区分的状态，需要重新建立下界。

九、§6.10：用键的结构换取更少的比较

范围 1 至 M 的整数键可以直接计数：建立 M 个桶，扫描输入累计频次，再依次展开。清空桶、计数、输出分别是 Θ(M)、Θ(N)、Θ(M+N)，合计 Θ(M+N)。若 M 远大于 N，空间与初始化会压过收益；只有 M 同阶于 N 时，才可以直接写成线性。

基数排序把过大的键域拆成若干位。图 6.18–6.20 用三位十进制数演示，从个位到百位，每轮稳定地按当前位分桶；进入同一桶的记录必须保留此前低位排序结果。

/* Sort nine decimal digits in three stable base-1000 passes.
   id is numeric; leading zeros are preserved by display formatting. */
int radix_students(Student *a, size_t n) {
    for (size_t i = 0; i < n; ++i)
        if (a[i].id > UINT32_C(999999999)) return -1;
    if (n < 2) return 0;
    if (n > SIZE_MAX / sizeof *a) return -1;
    Student *tmp = malloc(n * sizeof *tmp);
    if (!tmp) return -1;
    for (uint32_t divisor = 1; divisor <= UINT32_C(1000000);
         divisor *= UINT32_C(1000)) {
        size_t next[1000] = {0};
        for (size_t i = 0; i < n; ++i)
            ++next[(a[i].id / divisor) % 1000];
        size_t start = 0;
        for (size_t b = 0; b < 1000; ++b) {
            size_t count = next[b]; next[b] = start; start += count;

        for (size_t i = 0; i < n; ++i) {
            size_t b = (a[i].id / divisor) % 1000;
            tmp[next[b]++] = a[i];
        }
        for (size_t i = 0; i < n; ++i) a[i] = tmp[i];
    }
    free(tmp);
    return 0;

十、§6.11：当访问代价变了，排序的组织方式也要变

内部排序默认可以常数时间跳到任何数组下标。磁带只能顺序前进或回卷，磁盘也要付读块代价；快速排序的少量原地交换并不自动转化成少量外存访问。原书用磁带模型说明：先用内存排好一批长度 M 的初始归并段，再顺序合并，往往比在外存模拟随机索引更合适。现代设备的具体代价应实测，但“按块顺序扫描”这个算法设计条件仍清楚。

R=⌈N/M⌉,merge passes=⌈logkR⌉

k 路合并用最小堆保存每个输入段的首项：输出最小者，只推进该来源，再补一个候选。每项付 O(logk) 比较，整个合并是顺序 I/O。常规轮换需要 2k 条磁带；内存还要容纳 k 个输入块、输出块与候选堆，因此不能把用于初始排序的全部 M 槽位同时许诺给合并缓冲。这个小例子用三路只需两轮合并。

原书“1000 万条、每条 128 字节、4 MB 内存 → 320 段”采用十进制 4×106 字节；若约定 4 MiB，即 4194304 字节，则每批 32768 条、初始 306 段。两者两路合并仍需 9 轮，五路需 4 轮。实际程序应先扣除缓冲与管理空间再计算 M。

10.2　多相合并用段数安排角色轮换

只有三条磁带做两路合并时，把 34 段分成 21、13，比 17、17 更容易连续轮换。每次从两条非空磁带取一段合并到空磁带，直到较短一侧耗尽；刚耗尽的磁带下一阶段成为输出。原书的 Fibonacci 段数轨迹为：

长度 M 的最小堆取出一个键之后，可以立刻再读一个键。若它不小于刚输出的键，仍能参加当前段；否则冻结在空出的存储中，留待下一段。活跃堆耗尽，就把冻结项重新建堆。活跃项和冻结项合计不超过 M，冻结项不参加当前 DeleteMin。相等键可接在当前段后，若要求稳定，还需附加原始序号。

size_t choose_pivot(const int *a, size_t n, int choice,
                    uint32_t *rng, Stats *s) {
    if (choice == 0) return 0;
    if (choice == 1) return n / 2;
    if (choice == 2) return next_u32(rng) % n;
    size_t index[5], count;
    if (choice == 4 && n >= 5) {
        index[0] = 0; index[1] = n / 4; index[2] = n / 2;
        index[3] = n * 3 / 4; index[4] = n - 1; count = 5;
    } else if (n >= 3) {
        index[0] = 0; index[1] = (n - 1) / 2; index[2] = n - 1; count = 3;
    } else return n / 2;
    for (size_t i = 1; i < count; ++i) {
        size_t value = index[i], j = i;
        while (j > 0 && key_cmp(a[index[j - 1]], a[value], s) > 0) {

        index[j] = value;

}

void optimized_quick_engine(int *a, size_t n, int choice, size_t cutoff,
                            uint32_t *rng, Stats *s, bool preserve_samples) {
    /* Smaller side recurses; larger side iterates: O(log n) stack. */
    while (n > 1) {
        if (n <= cutoff) { insertion_sort(a, n, s); return; }
        size_t i;
        if (choice == 3 && n >= 4 && preserve_samples) {
            i = book_partition(a, 0, n - 1, s);
        } else {
        size_t pivot_index = choose_pivot(a, n, choice, rng, s);
        key_swap(&a[pivot_index], &a[n - 1]);
        int pivot = a[n - 1];
        i = 0;
        size_t j = n - 1; /* j is the exclusive scan boundary. */
        while (i < j) {
            while (i < j && key_cmp(a[i], pivot, s) < 0) ++i;
            while (i < j && key_cmp(a[j - 1], pivot, s) > 0) --j;
            if (i < j) {
                key_swap(&a[i], &a[j - 1]); ++i; --j;
            }
        }
        key_swap(&a[i], &a[n - 1]);
        }
        size_t right = n - i - 1;
        if (i < right) {
            optimized_quick_engine(a, i, choice, cutoff, rng, s, preserve_samples);
            a += i + 1; n = right;
        } else {
            optimized_quick_engine(a + i + 1, right, choice, cutoff, rng, s, preserve_samples);
            n = i;
        }
    }
}

def optimized_quick(a, choice=3, cutoff=10, rng=None, stats=None,
                    preserve_samples=True):
    if choice not in range(5) or cutoff < 0:
        raise ValueError("invalid pivot/cutoff")
    if rng is None:
        rng = [0x9E3779B9]

    def sort(lo, n):
        while n > 1:
            if n <= cutoff:
                for pos in range(lo + 1, lo + n):
                    value, j = a[pos], pos
                    while j > lo and key_cmp(a[j - 1], value, stats) > 0:
                        a[j] = a[j - 1]
                        j -= 1
                    a[j] = value
                return
            if choice == 3 and n >= 4 and preserve_samples:
                i = book_partition(a, lo, lo + n - 1, stats)
            else:
                p = choose_pivot(a, lo, n, choice, rng, stats)
                key_swap(a, p, lo + n - 1)
                pivot = a[lo + n - 1]
                i, j = lo, lo + n - 1
                while i < j:
                    while i < j and key_cmp(a[i], pivot, stats) < 0:
                        i += 1
                    while i < j and key_cmp(a[j - 1], pivot, stats) > 0:
                        j -= 1
                    if i < j:
                        key_swap(a, i, j - 1)
                        i += 1
                        j -= 1
                key_swap(a, i, lo + n - 1)
            left, right = i - lo, lo + n - i - 1
            if left < right:
                sort(lo, left)
                lo, n = i + 1, right
            else:
                sort(i + 1, right)
                n = left

    sort(0, len(a))

6.2 · 所有键相等时，插入排序花多少时间？

原题（中文翻译）

如果所有键都相等，插入排序的运行时间是多少？

原书习题 6.2 · 印刷页 228 · PDF 第 245 页。

解答

使用严格大于判断时，每轮内层第一次键比较就停止。N≥1 时恰有 N−1 次键比较、没有右移，仍进行 N−1 次暂存与写回，所以时间 Θ(N)，空间 O(1)。若改成“大于等于”，相等键也被逐项右移，时间会变成 Θ(N2) 并丢失稳定性；结论依赖实际条件。

6.3 · 交换相距 k 的失序元素，消去多少逆序对？

原题（中文翻译）

假设交换原来失序的元素 A[i] 与 A[i+k]。证明至少消去 1 个、至多消去 2k−1 个逆序对。

原书习题 6.3 · 印刷页 228 · PDF 第 245 页。

解答

设左端 x、右端 y 满足 x>y，相距 k。两端自身的逆序对必消去 1 个。区间外的元素与这两个位置的逆序总贡献保持不变；区间内每个 z，只会影响 (x,z)、(z,y) 这两对。若 z<y 或 z>x，贡献不变；若 y<z<x，贡献减少 2；若 z 等于任一端，贡献减少 1。

ΔI=1+2#{z:y<z<x}+#{z:z=x or z=y}

区间内只有 k−1 项，因此 1≤ΔI≤2k−1。无区间内键介于两端时取得下界；全部严格介于两端时取得上界。重复键的端点等值情形也已包含。

原题（中文翻译）

  2. 证明：对于任意 N，都存在一个含三个增量的序列，使希尔排序运行时间为 O(N5/3)。
  3. 证明：对于任意 N，都存在一个含六个增量的序列，使希尔排序运行时间为 O(N3/2)。

原书习题 6.5 · 印刷页 229 · PDF 第 246 页。

解答

a　{2,1} 的最坏时间

2 排序只是两次长度约 N/2 的插入排序，最坏已经 Θ(N2)，最后一轮也不超过二次，因此总最坏 Θ(N2)。例如两条同余链各自逆序就达到下界；即使两链已排好，让大键、小键分别占两类位置，最后一轮仍二次。已排序输入则是线性，不能把“最坏”漏掉。

b　三轮：q+1、q、1

取 q=⌈N1/3⌉。前两轮各需 O(N2/q)；q 与 q+1 互素，最终 1 排序前，距离不小于 q(q−1) 的元素已经由两种有序性确定顺序。每项最多跨过 O(q2) 项，所以最后一轮 O(Nq2)：

O(N2/q+Nq2)=O(N5/3)

c　六轮：b²、ab、a²、b、a、1

取 a=⌈N1/4⌉≥2、b=a+1。前三个增量均为 Θ(a2)，每轮最坏 O(N2/a2)=O(N3/2)。到 b 排序时，b 同余链早已分别 a 有序和 b 有序，因为已经做过 ab、b²；两者互素，用 Frobenius 界，每项最多跨过 O(ab)=O(a2) 个链内元素，所以该轮 O(Na2)。

a 排序同理使用先前 a²、ab 两轮；b 排序不会破坏它们的有序性，依据 6.7。最后 1 排序使用 a、b，仍为 O(Nab)=O(N3/2)。六轮的和保持同阶。很小的 N 可直接插入排序，或省略不小于 N 的无效间隔；有限个小规模不影响统一上界。这个构造完整给出了题目要求的存在性，而不要求这些间隔在实际机器上最优。

6.6 · 固定整数 c 的幂增量：最坏与平均界

原题（中文翻译）

  1. 证明：对于任意整数 c，使用形如 1,c,c2,…,ct 的增量时，希尔排序的运行时间为 Ω(N2)。
  2. 证明：使用这些增量时，平均运行时间为 Θ(N3/2)。

原书习题 6.6 · 印刷页 229 · PDF 第 246 页。

解答

有效递增的正间隔族要求固定整数 c≥2，并执行所有小于 N 的 c 的幂及最后的 1。题干“任意整数 c”应在这个域内理解；c=1 只是重复普通插入排序，其随机平均为二次，不能套用 b 的结论，0 或负数也不构成合法正增量。

a　最坏为 Θ(N²)

取 N 为 c 的幂。所有非 1 间隔都是 c 的倍数，早期排序不会让记录离开它的模 c 类。把一类位置全放小键，另一类全放大键，各类内部先升序，其间至少有 Θ((N/c)2)=Θ(N2) 个逆序一直留到最后 1 排序。各轮 O(N2/h) 的几何和又给出二次上界。

b　均匀随机、不同键时为 Θ(N³ᐟ²)

先证明一个随机交错引理：把长 L 的随机不同键按固定 c 个同余位置分组，组内分别升序再交错放回，其期望逆序对数为 Θ(L3/2)。c 为常数，各组长度相差至多 1，只需分析任意两组，因为全部跨组对可以按组对相加。

两等长组 A、B 各 m 项。按全局键序记录来源标签，把第 r 个 A 的全局位置记作 p(r)，它在交错结果中的位置是 2r−1。把两个标签序列变成同一序列所需的相邻 A/B 交换数，恰好是 ∑r|p(r)−(2r−1)|；这也就是跨组逆序数。令 D(t) 为前 t 个全局键的 A 数减 B 数，则在一个 A 位置，上式项为 |1−D(t)|。

Pr(K=k)=(mk)(mt−k)(2mt),D(t)=2K−t

在中间一半的 t 范围，超几何变量 D 的方差是 Θ(m)。用 Stirling 式对 k=t/2+Θ(m) 的固定宽窗口估计，得到正的常数概率使 |D| 落在两个常数倍 m 之间，故期望绝对值下界为 Ω(m)；Cauchy–Schwarz 与方差给出 O(m) 上界。条件在当前标签为 A 时，只改变一个有界单位及相邻参数，不改变数量级。对 Θ(m) 个位置相加得到引理；不等长至多 1 及固定 c 的其他组对同样成立。

现在考虑 h 排序的一轮。此前 ch 排序已把每条 h 链中的 c 个子链分别排好；更早的增量都是 ch 的倍数，所以各子链保留的键集合正是原随机排列的均匀随机分组。h 条长度约 N/h 的链，期望工作总计：

O(h(N/h)3/2)=O(N3/2/h),∑h=1,c,c2,…N3/2h=O(N3/2)

最上层链很短，仍满足该上界；各轮基本扫描成本 O(NlogN) 已被包含。最后 h=1 的交错引理同时给出 Ω(N3/2)，上下界相合。因此题目中的 Θ 成立，不能只证明最坏二次后再凭经验写出平均指数。

6.7 · k 有序之后做 h 排序，为什么仍然 k 有序？

原题（中文翻译）

证明：一个已经 k 有序的文件，再进行 h 排序之后，仍然 k 有序。

原书习题 6.7 · 印刷页 229 · PDF 第 246 页。

解答

先证明 0–1 键。设原数组满足 Ai≤Ai+k，h 排序只是把每条模 h 链上的 0 全放到前面。记第 r 条链的 0 数为 Z(r)。对于位置 i=r+th，把 i+k=r′+(t+d)h，其中 0≤r,r′<h、d≥0。

原来第 r′ 链中每个下标不小于 k 的 0，向左平移 k 后，都对应第 r 链上的 0；否则会违反 k 有序。第 r′ 链中可因落到负下标而失去的项最多 d 个，因此 Z(r)≥Z(r′)−d。若 h 排序后 i+k 仍为 0，则 t+d<Z(r′)，进而 t<Z(r)，所以 i 也为 0。这排除了新的 k 距离 1→0。

一般键若在 h 排序后出现 Bi>Bi+k，选一个介于两者之间的阈值，把大于阈值的键映成 1，其他映成 0。每条链排序与这种单调阈值映射可交换，原数组的 k 有序性仍成立，而输出产生 1→0，矛盾。因此结论对重复键也成立。

6.8 · Hibbard 最坏 Ω(N³ᐟ²)：把原书提示做成具体构造

原题（中文翻译）

证明：使用 Hibbard 建议的增量序列时，希尔排序的最坏运行时间为 Ω(N3/2)。

提示：考虑全部元素都是 0 或 1 的特殊情况。如果下标 i 能表示为 ht,ht−1,…,h⌊t/2⌋+1 的线性组合，则令 InputData[i]=1，否则为 0。

题干校注：构造中使用非负整数系数的线性组合；生成元范围与具体构造在解答中展开。

原书习题 6.8 · 印刷页 229 · PDF 第 246 页。

解答

取充分大的 2 的幂 b（例如 b≥1024），令 N0=b2/4，下标从 0 开始。把所有 Hibbard 增量不小于 b−1 而小于 N0 的数作为生成元，即 b−1,2b−1,4b−1,…。下标 i 能写成这些数的非负整数线性组合时，令 A[i]=1，否则为 0；0 是空和，所以 A[0]=1。

这就是提示中的大增量 Frobenius 模式。若 A[i]=1，则任何仍在范围内的 i+h 也能表示，故 A[i+h]=1。所有这些大间隔轮本来就已 h 有序，完全不改变 0–1 数组。接下来首次能做实质工作的是 g=b/2−1。

构造 Ω(b²) 个 1，并为每个指出 Ω(b) 个同链后续 0

b8≤u≤3b16,b32≤v≤b16,i=ub−v

u 的二进制分解由至多 log2b 个 2 的幂组成。把某个大于 1 的幂拆成两个相同的一半，可以让项数逐个增加，直到任意 v 满足“二进制 1 数 ≤ v ≤ u”。上面选取的 v 都满足这个条件。每个幂项 q 变成生成元 qb−1，v 项之和就是 ub−v；所需最大幂不超过 u，属于已列出的生成元范围。所以这些不同 i 全是 1，共 Ω(b2) 个。

z=i+(2s+1)g=(u+s)b+b2−v−2s−1,0≤s<b64

这些 z 都小于 N0，余数在 0 与 b/2 之间。若 z 是生成元之和，设用了 w 项，则每个生成元模 b 都等于 −1，必须有 w≡b/2+v+2s+1(modb)，因此 w≥b/2。但每项至少 b−1，总下标小于 N0，又要求 w<N0/(b−1)<b/2，矛盾。故这些 z 全是 0。

每个上述 1 与其后 Ω(b) 个 z，在同一条 g 链中构成逆序；各对按 i、s 唯一计数，合计 Ω(b3)。该 g 排序是链内插入排序，每次链内右移消去恰好一个这种逆序，因此仅这一轮就需要 Ω(b3)=Ω(N03/2) 工作。

一般 N 选择最大的 b 使 b2/4≤N，则 N0>N/4，在上述模式后补 1。大间隔仍不会改变前缀，已有逆序对保留，故下界扩展到所有足够大的 N。结合正文上界，最坏为 Θ(N3/2)。这里给出的是构造证明；有限规模的可达性复算只核对构造，不能替代一般论证。

解答

针对原书平衡递归分半，N≥1，记 d=⌈log2N⌉。每次合并 a 与 b 项，最多 a+b−1 次；让两段按全局键序充分交错，可以递归构造输入使每个内部节点同时取到这个上限。

C(N)=C(⌈N/2⌉)+C(⌊N/2⌋)+N−1,C(1)=0

递归树的叶深只可能是 d−1 或 d。设较浅叶数 u、较深叶数 v，由叶数 N 及满二叉分裂的 Kraft 等式得到 u=2d−N、v=2N−2d。每个叶子在其全部祖先合并中各贡献一次长度计数，内部节点数为 N−1：

C(N)=(d−1)u+dv−(N−1)=Nd−2d+1

N=1 时 d=0，式子也为 0；N=8 时为 17，N=5 时为 8。迭代的固定宽度合并树在不规则 N 时不同，不能拿它的比较数冒充本题的平衡递归公式。

原题（中文翻译）

  2. 若修改划分策略，使 i、j 在遇到与主元相等的键时都不停下，需要怎样修改代码才能保证算法正确？全部键相等时，运行时间是多少？

原书习题 6.20 · 印刷页 230 · PDF 第 247 页。

解答

a　两侧都在相等时停下

正文代码每次停止后交换，下一轮再移动指针。全相等键会在中间交叉，子问题近乎均分，时间 Θ(NlogN)。这些值相同的交换有助于平衡，而不是可以无条件删掉的冗余。

b　两侧都越过相等键

哨兵本身也等于主元，不能再靠它自动停止。给 i 增加“尚未到隐藏主元位置”的边界，给 j 增加“尚未到左端”的边界；先验证下标，再读键。扫描交叉后，把主元放到 i（可能就在原隐藏位置），并排除这个位置递归。全相等时 i 到 right−1、j 到 left，一边只有常数项、另一边为 N−O(1)，时间 Θ(N2)。

c　只有 i 在相等时停下

j 仍需左端边界，因为等值左哨兵不再制止它。主元正确落位并排除后，全相等时 i 停在 left+1、j 到 left，仍是 1 与 N−2 的倾斜，时间 Θ(N2)。若换成没有端点保留的划分，数字可能是 0 与 N−1，但同一二次结论成立。所有版本都必须保证每轮指针进展、每次递归严格缩短区间。

6.21 · 取中间位置的键，能排除二次输入吗？

原书习题 6.21 · 印刷页 230 · PDF 第 247 页。

6.22 · 20 元素最坏排列：构造并证明比较数达到上限

针对本页与图 6.14 一致的三点整理、cutoff=3、每次键关系判断计一次，以下排列达到 127 次键比较：

C（C11）
/* Force each median-of-three pivot to be the second smallest remaining.
   Tokens track original positions while the partition's swaps are simulated. */
void bad_twenty(int out[20]) {
    size_t token[20];
    for (size_t i = 0; i < 20; ++i) { token[i] = i; out[i] = 0; }
    out[token[19]] = 20;
    int next = 1;
    for (size_t left = 0; 20 - left > 3; left += 2) {
        size_t center = left + (19 - left) / 2;
        out[token[left]] = next++;
        out[token[center]] = next++;
        size_t tmp = token[center]; token[center] = token[18]; token[18] = tmp;
        tmp = token[left + 1]; token[left + 1] = token[18]; token[18] = tmp;
    }
    /* The final two-element subarray requires one comparison. */
    if (out[token[18]] == 0) out[token[18]] = next++;
    if (out[token[19]] == 0) out[token[19]] = next++;
}
Python 3
def bad_twenty():
    token = list(range(20))
    out = [0] * 20
    out[token[19]] = 20
    next_key = 1
    for left in range(0, 18, 2):
        center = left + (19 - left) // 2
        out[token[left]] = next_key
        out[token[center]] = next_key + 1
        next_key += 2
        token[center], token[18] = token[18], token[center]
        token[left + 1], token[18] = token[18], token[left + 1]
    if out[token[18]] == 0:
        out[token[18]] = next_key
        next_key += 1
    if out[token[19]] == 0:
        out[token[19]] = next_key
    return out

生成器只使用本块定义，输出的 C 数组／Python 列表含 1–20 各一次。验证时再调用正文快速排序与Stats，得到升序输出和 127。它用位置标记反向追踪交换，最后赋值仍构成固定初始输入。

更强的“尽可能坏”可用上界证明。长度 n≥4 的不同键划分做三次采样比较；两扫描的比较总数为 n−1，故本轮最多 n+2 次。三点中值至少各留一项在主元两侧，所以定义 W(n) 为最坏比较数，有：

W(0)=W(1)=0,W(2)=1,W(3)=3,W(n)≤n+2+max1≤k≤n−2{W(k)+W(n−1−k)}

从这些初值逐项计算上界，n=4 至 20 依次为 7,10,15,19,25,30,37,43,51,58,67,75,85,94,105,115,127。本构造实际取到 22+20+⋯+6+1=127，因此在该比较计数约定下确实达到上限；无需穷举 20! 个排列。交换或分支时间是另一成本，不能仅凭此把本机运行时间也说成所有排列的最大。

6.27 · 有序表查找为什么至少要对数比较？

原题（中文翻译）

原书习题 6.27 · 印刷页 230 · PDF 第 247 页。

解答

比较 X 与某个已有序键，非相等分支把可能位置分成左右两部分。只看未命中输入，X 可以落在 N+1 个间隙；同一比较路径对应一个连续可能区间，一个正确未命中叶子不能跨过尚未排除的键。两分支树高度 q 至多区分 2q 个间隙，故最坏 q≥⌈log2(N+1)⌉=Ω(logN)。

也可以归纳：q 次 X 与表项的三路比较，等号分支最多确认一个键，左右各最多确认 2q−1−1 个，所以总共最多 2q−1 个命中位置。比较表项彼此不会增加信息，因为它们已知有序。二分查找达到此数量级；下界限制比较模型，不能排除已知整数域的直接索引。

Cmin≥⌈log2(2NN)⌉,log2(2NN)=2N−12log2(πN)+O(1/N)

b：还可以证明更强的精确最坏下界 2N−1。安排全局键序严格交替 A1<B1<A2<B2……。每一对相邻全局键来自不同输入表；若某一对从未直接比较，交换它们既保持两份输入内部有序，也保持所有其他比较结果，算法却应输出不同顺序，矛盾。因此 2N−1 个相邻跨表对都必须比较。标准双指针合并恰好达到这个最坏数，故最优。

原书习题 6.30 · 印刷页 231 · PDF 第 248 页。

解答

双语完整实现见bucket_sort。先清空 M 个计数槽，再扫描 N 项，每项加到键−1 的槽。写回时外层遍历全部 M 桶，内层写出各桶频次；全部频次之和为 N，所以嵌套循环并不是 MN 次。

6.31 · 两种键 false、true：线性、常数空间

原题（中文翻译）

假设一个 N 元素数组只含 true 和 false 两种不同的键。给出 O(N) 算法，重排数组，使所有 false 元素都在 true 元素之前。只能使用常数额外空间。

原书习题 6.31 · 印刷页 231 · PDF 第 248 页。

解答

用 0 表示 false、1 表示 true。区间 [0,left) 都是 0，[right,n) 都是 1，中间尚未分类。当前为 0 就推进 left；为 1 就与 right−1 交换并缩小 right，新的 left 项尚未检查，不能同时推进。每一步未分类长度减一，故 Θ(N) 时间、O(1) 工作空间。

C（C11）
/* Return false without modifying a if a key is outside the contract. */
bool binary_partition(int *a, size_t n) {
    for (size_t i = 0; i < n; ++i)
        if (a[i] != 0 && a[i] != 1) return false;
    size_t left = 0, right = n;
    while (left < right) {
        if (a[left] == 0) ++left;
        else { --right; key_swap(&a[left], &a[right]); }
    }
    return true;
}

/* false=0, maybe=1, true=2; [lo,scan) contains only maybe. */
bool ternary_partition(int *a, size_t n) {
    for (size_t i = 0; i < n; ++i)
        if (a[i] < 0 || a[i] > 2) return false;
    size_t lo = 0, scan = 0, hi = n;
    while (scan < hi) {
        if (a[scan] == 0) { key_swap(&a[lo], &a[scan]); ++lo; ++scan; }
        else if (a[scan] == 1) ++scan;
        else { --hi; key_swap(&a[scan], &a[hi]); }
    }
    return true;
}

def ternary_partition(a):
    if any(x not in (0, 1, 2) for x in a):
        raise ValueError("keys must be 0, 1, or 2")
    lo = scan = 0
    hi = len(a)
    while scan < hi:

            key_swap(a, lo, scan)
            lo += 1
            scan += 1
        elif a[scan] == 1:
            scan += 1
        else:
            hi -= 1
            key_swap(a, scan, hi)

6.34 · 四个不同键，最少五次比较

原题（中文翻译）

  1. 证明：任何基于比较的算法，对 4 个元素排序都需要 5 次比较。
  2. 给出只需 5 次比较就能对 4 个元素排序的算法。

原书习题 6.34 · 印刷页 231 · PDF 第 248 页。

解答

a：4!=24 种顺序，四次二分比较至多 16 个叶子，所以最坏至少 ⌈log224⌉=5。b：依次比较交换 (0,1)、(2,3)、(0,2)、(1,3)、(1,2)，下面两版固定五次。

C（C11）
void compare_exchange(int *a, size_t i, size_t j, Stats *s) {
    if (key_cmp(a[i], a[j], s) > 0) key_swap(&a[i], &a[j]);
}

void sort_four(int a[4], Stats *s) {
    compare_exchange(a, 0, 1, s); compare_exchange(a, 2, 3, s);
    compare_exchange(a, 0, 2, s); compare_exchange(a, 1, 3, s);
    compare_exchange(a, 1, 2, s);
}

/* Insert x into the first bound entries of a chain of length *length.
   The known larger partner, if present, stays after this search interval. */
void bounded_insert(int *chain, size_t *length, size_t bound,
                    int x, Stats *s) {
    size_t lo = 0, hi = bound;
    while (lo < hi) {
        size_t mid = lo + (hi - lo) / 2;
        if (key_cmp(x, chain[mid], s) < 0) hi = mid;
        else lo = mid + 1;
    }
    for (size_t i = *length; i > lo; --i) chain[i] = chain[i - 1];
    chain[lo] = x; ++*length;
}

void sort_five(int a[5], Stats *s) {
    int small1 = a[0], big1 = a[1], small2 = a[2], big2 = a[3];
    if (key_cmp(small1, big1, s) > 0) key_swap(&small1, &big1);
    if (key_cmp(small2, big2, s) > 0) key_swap(&small2, &big2);
    if (key_cmp(big1, big2, s) > 0) {
        key_swap(&small1, &small2); key_swap(&big1, &big2);
    }
    int chain[5] = {small1, big1, big2, 0, 0};
    size_t length = 3;
    bounded_insert(chain, &length, 3, a[4], s);
    /* big2 is the final item, or the penultimate item if a[4] > big2.
       An equality also works: search at most the three predecessors. */
    bounded_insert(chain, &length, 3, small2, s);
    for (size_t i = 0; i < 5; ++i) a[i] = chain[i];
}

def sort_five(a, stats=None):
    if len(a) != 5:
        raise ValueError("exactly five items required")
    small1, big1, small2, big2 = a[:4]  # Constant-size scratch.
    if key_cmp(small1, big1, stats) > 0:
        small1, big1 = big1, small1
    if key_cmp(small2, big2, stats) > 0:
        small2, big2 = big2, small2
    if key_cmp(big1, big2, stats) > 0:
        small1, small2 = small2, small1
        big1, big2 = big2, big1

    bounded_insert(chain, length, 3, small2, stats)
    for i in range(5):
        a[i] = chain[i]

  2. 给出只需 7 次比较就能对 5 个元素排序的算法。

原书习题 6.35 · 印刷页 231 · PDF 第 248 页。

解答

6.38 · 把两个已按同一规则排序的文件合并为第三个

原题（中文翻译）

编写一个过程，读入两个已经按字母顺序排列的文件，将它们合并为第三个同样按字母顺序排列的文件。

原书习题 6.38 · 印刷页 231 · PDF 第 248 页。

解答

每份文件保存一行一项的键，输入已按同一规则有序。这里明确采用无符号字节词典序，适用于 ASCII 英文键或同规则的 UTF-8 文本；它不等同于地区字母序、大小写折叠或拼音序。C 的 memcmp 与 Python bytes 使用相同规则。相等时先取第一文件，文件内部原序也保留。

C（C11）
#include <stdio.h>
#include <string.h>

enum { LINE_CAP = 4096 };
typedef struct { unsigned char text[LINE_CAP]; size_t len; } Line;

/* 1 line, 0 EOF, -1 I/O/invalid input. Newline is not part of the key.
   Reject NUL and lines exceeding 4095 bytes; accept an unterminated last line. */
int read_line(FILE *f, Line *line) {
    line->len = 0;
    int c;
    while ((c = fgetc(f)) != EOF && c != '\n') {
        if (c == 0 || line->len == LINE_CAP - 1) return -1;
        line->text[line->len++] = (unsigned char)c;
    }
    if (ferror(f)) return -1;
    return c == EOF && line->len == 0 ? 0 : 1;
}

int line_cmp(const Line *x, const Line *y) {
    size_t common = x->len < y->len ? x->len : y->len;
    int c = memcmp(x->text, y->text, common);
    if (c != 0) return c;
    return (x->len > y->len) - (x->len < y->len);
}

int write_line(FILE *out, const Line *line) {
    if (fwrite(line->text, 1, line->len, out) != line->len) return -1;
    return fputc('\n', out) == EOF ? -1 : 0;
}

/* Caller owns three distinct streams, and verifies input files are sorted.
   No stream is closed here. An I/O error may leave partial output. */
int merge_files(FILE *first, FILE *second, FILE *out) {
    Line a, b;
    int ha = read_line(first, &a), hb = read_line(second, &b);
    while (ha > 0 && hb > 0) {
        if (line_cmp(&a, &b) <= 0) {
            if (write_line(out, &a) < 0) return -1;
            ha = read_line(first, &a);
        } else {
            if (write_line(out, &b) < 0) return -1;
            hb = read_line(second, &b);
        }
    }
    if (ha < 0 || hb < 0) return -1;
    while (ha > 0) {
        if (write_line(out, &a) < 0) return -1;
        ha = read_line(first, &a);
    }
    while (hb > 0) {
        if (write_line(out, &b) < 0) return -1;
        hb = read_line(second, &b);
    }
    if (ha < 0 || hb < 0 || fflush(out) != 0) return -1;
    return 0;
}

6.41 · Floyd 下滤：先到叶子，再往上找落位

原题（中文翻译）

考虑下滤 PercolateDown 的另一种策略。在节点 X 处有一个空穴。通常的最大堆下滤会比较 X 的两个孩子；如果较大的孩子大于待放入的元素，就把这个孩子移到 X，使空穴下移，直到可以安全地把新元素放入空穴。

替代策略是：不检查新元素能否放入，直接将孩子向上移动，让空穴尽可能下降到叶子；然后把新元素放在叶子处，这可能违反堆序，再按通常方式将它上滤以修复堆序。编写采用此思想的过程，并将运行时间与标准堆排序实现比较。

原书习题 6.41 · 印刷页 232 · PDF 第 249 页。

解答

6.42 · 只用两条磁带，给出完整的大文件排序算法

原题（中文翻译）

提出一个算法，仅用两条磁带对一个大文件排序。

原书习题 6.42 · 印刷页 232 · PDF 第 249 页。

解答

一个不需要第三条磁带的确定方法是逐次选择、反复顺序扫描。T1 保存原始 N 条记录，T2 从空输出开始；内存只保留上一条已输出的“键、原始顺序号”阈值及本轮最小候选。顺序号来自每次扫描时从 0 开始计数，无须为 T1 改写记录。

第一次扫描 T1，寻找按“键、顺序号”最小的记录，追加到 T2，并保存该二元阈值。回卷 T1；下一次只考虑严格大于阈值的记录，找其中最小者追加。重复直到扫描找不到候选即结束。记录比较在相同键时用原始顺序号消除平局，所以重复键不会漏掉，输出仍稳定。空文件第一次扫描就结束。

不变量是 T2 恰好保存整个输入全序中的最小若干条；每轮补入唯一下一条，最多 N 轮输出全部记录。T1 从不被覆盖，T2 只顺序追加，任一时刻最多两个磁带驱动参与。空间为常数条记录／机器字，比较与记录读访问总数为 Θ(N2)，输出 N 项；回卷另付线性带长成本，不改变二次数量级。

这个方案用反复扫描交换掉第三条磁带的空间，代价很明确。直接套用标准两输入、一输出的归并，会需要三条可同时访问的流；若选择在两磁带上来回移动输入位置，也必须计入回卷代价，不能把磁带下标当内存随机访问。题目中的两磁带限制由上述算法完整满足。

6.43 · 由 BuildHeap 的比较数推出堆的数量

原题（中文翻译）

  1. 由 BuildHeap 至多使用 2N 次比较这一事实，证明堆的数量至少为 N!/22N。
  2. 使用 Stirling 公式展开这个下界。

原书习题 6.43 · 印刷页 232 · PDF 第 249 页。

解答

a：固定完全二叉树形状，键为 1–N 的所有不同排列，令 H(N) 为合法最大堆数量。BuildHeap 至多 2N 次二分比较，因此比较结果路径（前缀码）至多 22N 种。给定最终堆和这条路径，每次选择与交换都已确定，逆向撤销即可唯一恢复输入；所以一个最终堆最多有 22N 个输入原像。

N!≤H(N)22N⟹H(N)≥N!22N

关键是“堆 + 路径”可以逆向确定输入，而不是误说每个决策树叶子只包含一个输入。最小堆把键的大小映射反转，同样数量成立。

b：把下界本身用 Stirling 展开：

N!4N=2πN(N4e)N(1+O(1/N))

故其指数规模为 (N/(4e))N，还带有 2πN 的因子。这里展开的是一个确定下界，不是声称堆数量等于此表达式；更精确的数量还取决于全部子树形状。
