全书地图程序说明下一章：算法分析

一、§1.1：正确答案只是起点

作者没有先罗列数据结构，而是给出一个人人似乎都会做的任务：从 N 个数中找第 k 大。把全部数按降序排序，取第 k 项，当然正确；只保留当前最大的 k 项，也看起来更节省。两种想法真正的区别，要到规模和参数一起变大时才能看清。

第一种若用冒泡排序，最坏要做与 N2 同阶的比较。第二种先把前 k 项排好，再逐项读入新数：新数不超过当前第 k 大时直接丢弃，否则插入降序表并淘汰末项。它的不变量是工作数组恰保存已读输入中最大的 k 项，重复值按出现次数计入排名。一次接纳可能移动整个工作数组，因此朴素实现最坏为 O(k2+(N−k)k)=O(Nk)，额外存储 O(k)。

这并不自动比全排序好：固定很小的 k 时，它接近线性；题目取 k=⌊N2⌋ 时，仍是二次级。书中以一百万个数、寻找中位附近的元素说明差距，所引“数天”与“约一秒”属于当时的算法和硬件背景。现代机器更快，但把输入扩大十倍，二次算法的核心工作仍约扩大一百倍。

“writing a working program is not good enough.”

译：仅仅写出能工作的程序还不够。

§1.1，印刷页 2。这里的“还不够”是增加资源要求，不是降低正确性的优先级。

第六章会引入更好的选择方法。现在应抓住的是分析习惯：先说清输入规模、排名约定、工作数组的含义，再判断有没有反复搬移或排序并不需要的信息。只找一个秩，不一定需要获得所有秩的完整排序。

二、同一个字谜，为什么可以把循环倒过来？

图 1.1 的网格如下。单词沿八个固定方向延伸，不能在途中转弯；正文坐标从 1 开始。下面用表格重绘，避免把 OCR 的 h、i 读成其他字符。

第一种方法以词表为外循环：对每个词，枚举起点与方向，再逐字符核对。第二种以网格为外循环：枚举起点、方向和长度，把得到的字符串拿去词表查找。前者重复搜索同一网格，后者反复问“这个候选字符串在字典里吗”。瓶颈因此从路径核对转移到了字典查询。

设网格有 R 行、C 列，词数 W，最长词长 L。按词搜索的直接上界是 O(WRCL)；八个方向只是常数。按网格生成候选，至多有 8RCL 个；若每个候选线性扫描词表、一次词比较最多检查 L 个字符，则直接上界为 O(RCWL2)，须另计输入读取。第二章习题 2.21 固定 L=10，这时长度因素才可当常数。

本章只是指出能改善，并没有在这里给出字典结构。后面有序数组的二分查询、散列表的成员查询，以及适合前缀的树结构，都能改变这项代价。不能只数外层有几个 for，就断言两种搜索同样快。

三、§1.2：把当前问题写成更小的问题

书中先对比直接公式与递归定义。温度换算是 C=5(F−32)9；递归例子则指定

F(0)=0,F(x)=2F(x−1)+x2(x≥1).

C 版数值范围为 0…61：第 61 项仍可由 uint64_t 表示，第 62 项超出范围，因此超界直接拒绝；Python 教学版采用同一范围。这里的递归深度与 n 同阶。
其中这个 F 是教学函数，不是本章习题中的 Fibonacci 序列。求 F(4) 时，当前层暂时不能完成乘加，必须先求 F(3)，再向下直到 F(0)。回程才依次得到 1、6、21、58。

待完成的一层返回后完成的运算结果
F(1)2·0+121
F(2)2·1+226
F(3)2·6+3221
F(4)2·21+4258

循环定义的问题不是“定义里出现了自己”，而是同一个实例是否直接或间接依赖自己。F(4) 依赖更小的 F(3) 没有问题；F(1) 依赖 F(1) 则无法推进。运行时保存返回位置和局部状态的机制，第三章会用调用栈正式解释。

C（C11）
#include <stdint.h>
#include <stdlib.h>
/* 精确 uint64_t 版本：0..61；超出本例的数值范围就拒绝。 */
static uint64_t recurrence(unsigned n) {
    if (n > 61) abort();
    if (n == 0) return 0;
    return 2 * recurrence(n - 1) + (uint64_t)n * n;
}
Python 3
def recurrence(n):
    # 与 C 版使用同一输入范围，便于逐值对照。
    if not 0 <= n <= 61:
        raise ValueError('n must be in 0..61')
    if n == 0:
        return 0
    return 2 * recurrence(n - 1) + n * n

这个程序每层只有一次递归，单位成本模型下时间 Θ(n+1)，未进行递归消除时的调用栈也为 O(n+1)。unsigned 限制了输入符号，但没有防止数值溢出；“数学值有定义”与“机器类型装得下”仍是两件事。简单循环足以实现本例，递归只用于讲清依赖关系。

图 1.2：一个小错误为什么会污染所有正输入？

原书的 Bad 在正输入时调用 Bad(N/3+1)。N=1 得到的下一参数仍为 1，N=2 也到 1；更大参数虽先变小，最终仍陷入 1 的自循环。因而除 0 外都不能返回。图旁的论点不是“加了一个 if 就能终止”，而是每条递归路径都必须到达基例。

字典查词的比喻补充了同一件事：解释 A 用到了 B，解释 B 又用到了 A，即使词典有限，也可能无限循环。有限状态集合不等于终止；还要有下降的度量，或者在图式依赖中检测正在访问的环。

四、打印整数：输出顺序就是递归结构

只有 PrintDigit、一次只能输出一个十进制数字时，打印 76234 可以拆成“先打印 7623，再打印 4”。较高位部分是 ⌊N10⌋，末位是 Nmod10。先调用递归，后输出末位，顺序才正确；交换两句会把数字倒着打印。

C（C11）
#include <stdio.h>
#include <assert.h>
#include <stdint.h>
static void PrintDigit(unsigned d) {
    assert(d < 10);
    putchar((int)('0' + d));
}
static void print_uint(uint64_t n) {
    if (n >= 10) print_uint(n / 10);
    PrintDigit((unsigned)(n % 10));
}
Python 3
import sys

def PrintDigit(d, output=None):
    if not 0 <= d < 10:
        raise ValueError('digit must be in 0..9')
    (sys.stdout if output is None else output).write(chr(ord('0') + d))

def print_uint(n, output=None):
    if not 0 <= n <= 2**64 - 1:
        raise ValueError('uint64 value required')
    if n >= 10:
        print_uint(n // 10, output)
    PrintDigit(n % 10, output)

0 是一位数，也要打印一次，不能用“只要 N 非零就递归”的逻辑漏掉它。若有 D 位，调用 D 次，输出 D 个字符；时间 Θ(D)，栈空间 O(D)，正整数时 D=⌊log10N⌋+1。这里假设机器整数除法、余数和单字符输出各按单位成本计。

定理 1.1 的完整归纳

对位数归纳。一位数直接交给 PrintDigit，正确。假设所有不超过 D 位的非负整数都能正确打印。一个 D+1 位的正整数的商 N10 恰有 D 位，递归按假设输出其高位部分；随后输出余数，它正是最后一位。拼接得到原整数，因此程序对任意有限位非负整数正确。终止性由位数严格下降单独保证，归纳假设并不是允许递归调用当前实例。

“Assume that all the recursive calls work.”

译：假定所有递归调用都能正确工作。

§1.2，印刷页 6。使用这个设计规则之前，先确认子问题确实更小；其数学依据是归纳。

五、四条规则是一条设计流程

先定基例，再选下降度量，随后组合子结果，最后检查有没有重复求解。 前两步决定能否结束，第三步决定返回结果是否正确，第四步决定能否承受规模增长。一个函数完全可能正确并终止，却因为重复子问题而极慢；第二章的朴素 Fibonacci 正是这个反例。

规则自己写代码时的问题本章对应处
基例不再调用别人时，我能直接给出什么？单数字与 F(0)
推进哪一个非负度量严格减小？位数；Bad 的反例
设计假设子结果正确，当前结果如何组合？高位输出后追加末位
复利是否对同一输入反复算了相同子结果？下一章的 Fibonacci 调用树

本章结尾再提醒“速度是相对的”：算法、输入、机器和测量边界必须一起说明。下一章把这句话转成单位成本模型与渐近界；第三章解释递归调用怎样在栈上保存，第四章则展示递归与树结构真正契合的场景。

1.1 · 第 k 大与规模计时

原题（中文翻译）

编写一个程序解决选择问题。令 k=N/2，用表格列出程序在不同 N 值下的运行时间。

原书上下文：本章的选择问题是：给定 N 个数，找出其中第 k 大的数。

原书习题 1.1 · 印刷页 7 · PDF 第 24 页。

解答

取偶数规模并令 k=N2；按出现次数排名，返回降序第 k 项。下面实现正文“维护 k 项”的策略，不修改输入；工作数组归函数所有，释放以后只返回整数结果。空输入、k=0、k>N 返回 false。Python 非法排名返回 None，移动元素使用显式循环，时间界与 C 相同。合法请求要求 a 指向 n 个有效整数，out 可写；工作数组分配失败或字节数溢出时用 abort 终止。

C（C11）
#include <stddef.h>
#include <stdbool.h>
#include <stdlib.h>
#include <stdint.h>
static bool select_kth(const int *a, size_t n, size_t k, int *out) {
    if (!k || k > n) return false;
    if (k > SIZE_MAX / sizeof(int)) abort();
    int *best = malloc(k * sizeof *best);
    if (!best) abort();
    size_t used = 0;
    for (size_t i = 0; i < n; ++i) {
        int x = a[i];
        if (used == k && x <= best[k - 1]) continue;
        size_t j = used < k ? used++ : k - 1;
        while (j > 0 && best[j - 1] < x) {
            best[j] = best[j - 1]; --j;
        }
        best[j] = x;
    }
    *out = best[k - 1]; free(best); return true;
}
Python 3
def select_kth(a, k):
    if not 1 <= k <= len(a):
        return None
    best = [0] * k
    used = 0
    for x in a:
        if used == k and x <= best[k - 1]:
            continue
        if used < k:
            j = used
            used += 1
        else:
            j = k - 1
        while j > 0 and best[j - 1] < x:
            best[j] = best[j - 1]
            j -= 1
        best[j] = x
    return best[k - 1]

初始化时逐项有序插入，处理未满数组时最多只写到 k−1。例 [7,2,7,4]、k=2 的答案是 7，而不是第二个不同值 4；相等的后来元素即使被丢弃，前面已有足够多份相等值，秩不变。工作区未满时必须接纳，不能提前拿未初始化的末项比较。

随机输入与递增输入分别计时：递增会让已满工作数组每次移动 k−1 项，构造出二次最坏情况。测试 k=1、k=N、重复键、全部相等，并与排序结果对照。表的含义必须同时包含规模、输入分布、重复次数和编译选项；不能把理论工作量当成实测秒数。

C（C11）
#include <stdio.h>
#include <time.h>
/* 与 selection-code 合并编译；固定种子 LCG 只用于可重复负载。 */
int main(void) {
    uint32_t state = 7;
    puts("N,distribution,cpu_seconds");
    for (size_t n = 250; n <= 4000; n *= 2) {
        int *a = malloc(n * sizeof *a);
        if (!a) abort();
        for (int mode = 0; mode < 2; ++mode) {
            for (size_t i = 0; i < n; ++i) {
                state = state * 1664525u + 1013904223u;
                a[i] = mode ? (int)i : (int)(state & 0x7fffffffu);
            }
            clock_t begin = clock();
            volatile int sink = 0;
            for (int repeat = 0; repeat < 20; ++repeat) {
                int value; select_kth(a, n, n / 2, &value); sink = value;
            }
            double seconds = (double)(clock() - begin) / CLOCKS_PER_SEC / 20;
            printf("%zu,%s,%.9f\n", n, mode ? "ascending" : "lcg", seconds);
            (void)sink;
        }
        free(a);
    }
}
Python 3
from time import process_time

# 与上面的 select_kth 放在同一 Python 文件中。
def benchmark_selection(repeats=20, maximum_n=4000):
    state, n = 7, 250
    print('N,distribution,cpu_seconds')
    while n <= maximum_n:
        for mode in range(2):
            a = [0] * n
            for i in range(n):
                state = (state * 1664525 + 1013904223) & 0xffffffff
                a[i] = i if mode else state & 0x7fffffff
            begin = process_time()
            for _ in range(repeats):
                value = select_kth(a, n // 2)
            seconds = (process_time() - begin) / repeats
            assert value is not None
            print(f'{n},{"ascending" if mode else "lcg"},{seconds:.9f}')
        n *= 2

if __name__ == '__main__':

两版采用固定种子的同一 LCG 负载。计时包含函数内工作区分配，不包含输入生成；多次测量共用同一数组，可能有缓存收益。若单次太短，可增加重复次数。表格用于研究输入增长趋势。

1.2 · 八方向字谜程序

原题（中文翻译）

编写一个程序解决字谜问题。

原书上下文：给定一个字母网格和单词表，在网格中寻找单词；单词可以沿水平、垂直或对角线的直线方向出现，方向可以正向或反向。

原书习题 1.2 · 印刷页 7 · PDF 第 24 页。

解答

采用按词枚举起点和方向的直观解法。两个版本展示相同的边界判断，C 用回调逐项输出，Python 用生成器逐项输出；坐标输出仍转为书中的一基坐标。输入要求矩形网格、非空单词；单字词只报告一次起点，不人为重复八份方向。

C（C11）
#include <stdbool.h>
#include <stddef.h>
#include <string.h>
/* 单词指针由调用者拥有；回调只在本次调用期间借用。坐标为一基。 */
typedef void (*WordMatch)(const char *, size_t, size_t,
                         size_t, size_t, void *);
static bool word_puzzle(const char *const *board, size_t rows,
                        const char *const *words, size_t word_count,
                        WordMatch emit, void *context) {
    size_t cols = rows ? strlen(board[0]) : 0;
    for (size_t r = 0; r < rows; ++r)
        if (strlen(board[r]) != cols) return false;
    for (size_t w = 0; w < word_count; ++w) {
        const char *word = words[w];
        size_t length = strlen(word);
        if (!length) return false;
        size_t steps = length - 1;
        for (size_t r = 0; r < rows; ++r)
            for (size_t c = 0; c < cols; ++c)
                for (int dr = -1; dr <= 1; ++dr)
                    for (int dc = -1; dc <= 1; ++dc) {
                        if (length == 1 ? (dr || dc) : (!dr && !dc)) continue;
                        if ((dr < 0 && steps > r) ||
                            (dr > 0 && steps > rows - 1 - r) ||
                            (dc < 0 && steps > c) ||
                            (dc > 0 && steps > cols - 1 - c)) continue;
                        size_t rr = r, cc = c, i = 0;
                        for (; i < length; ++i) {
                            if (board[rr][cc] != word[i]) break;
                            if (i + 1 < length) {
                                if (dr < 0) --rr; else if (dr > 0) ++rr;
                                if (dc < 0) --cc; else if (dc > 0) ++cc;
                            }
                        }
                        if (i == length) emit(word, r + 1, c + 1,
                                               rr + 1, cc + 1, context);
                    }
    }
    return true;
}
Python 3
def word_puzzle(board, words):
    rows = len(board)
    cols = len(board[0]) if rows else 0
    if any(len(row) != cols for row in board):
        raise ValueError('board must be rectangular')
    directions = [(dr, dc) for dr in (-1, 0, 1)
                  for dc in (-1, 0, 1) if dr or dc]
    for word in words:
        if not word:
            raise ValueError('empty word')
        dirs = [(0, 0)] if len(word) == 1 else directions
        for r in range(rows):
            for c in range(cols):
                for dr, dc in dirs:
                    end_r = r + (len(word) - 1) * dr
                    end_c = c + (len(word) - 1) * dc
                    if not (0 <= end_r < rows and 0 <= end_c < cols):
                        continue
                    if all(board[r + i * dr][c + i * dc] == ch
                           for i, ch in enumerate(word)):
                        yield word, (r + 1, c + 1), (end_r + 1, end_c + 1)

端点合法且路径方向固定时，所有中间点都在矩形内，故只需先检查端点，再逐字符核对。该程序不修改输入，输出每个匹配；若词表重复，按请求重复输出，去重应另定语义。测试上述网格四个词，还应测试逆向、越界、空网格和单字符。

上界 O(RC∑w|w|)⊆O(WRCL)；若不把输入和输出算入辅助空间，生成器状态为 O(1)。串比较及 all 的总工作按字符数计，不能把任意长单词的比较当一个单位。

1.3 · 仅用 PrintDigit，能否输出任意实数？

原题（中文翻译）

编写一个过程，仅使用 PrintDigit 进行输入／输出，输出任意实数；该实数也可能为负数。

原书习题 1.3 · 印刷页 7 · PDF 第 24 页。

解答

严格按正文的接口，通常意义的十进制实数输出无法实现。PrintDigit 只接受 0…9，每次只写一个数字字符；任意有限次调用的输出都属于数字字符组成的字符串。负号与小数点不在可输出字母表中，所以 −1、0.5 已构成反例。更进一步，任意实数可能需要无限展开，有限程序输入和有限输出也不能精确表示所有实数。

这不是递归技巧能补救的事。实用题意需要补上两项：允许输出负号与小数点；规定可表示的输入类型及输出精度、舍入方式。若把 PrintDigit 改成通用 PrintChar，已改变原接口，应明确说明。

保留数字原语时的一种可解版本

可以输出编码而不是通常的小数文字：把输入限定为符号 s、非负整数 m、非负小数位数 p，数值为 (−1)sm10p。先输出 s，再输出 p 个 1 和一个 0，再输出 m 的数字。接收方可先读符号，再数 1 到分隔 0，余下部分就是幅值。例 −6.25 编码为 1110625。

C（C11）
#include <stdbool.h>
#include <stdint.h>
/* 依赖正文的 PrintDigit 和 print_uint；负零可按接口保留。 */
static bool print_fixed_encoding(bool negative, uint64_t magnitude, int64_t p) {
    if (p < 0) return false;
    PrintDigit(negative ? 1u : 0u);
    for (int64_t i = 0; i < p; ++i) PrintDigit(1);
    PrintDigit(0);
    print_uint(magnitude);
    return true;
}
Python 3

def print_fixed_encoding(negative, magnitude, p, output=None):
    if (not isinstance(negative, bool) or type(p) is not int or
            not 0 <= p <= 2**63 - 1):
        raise ValueError('boolean sign and nonnegative int64 scale required')
    if type(magnitude) is not int or not 0 <= magnitude <= 2**64 - 1:
        raise ValueError('uint64 magnitude required')
    PrintDigit(1 if negative else 0, output)
    for _ in range(p):
        PrintDigit(1, output)
    PrintDigit(0, output)
    print_uint(magnitude, output)

幅值为 uint64 范围的整数，小数位数为非负 int64 范围的整数；C 的类型约束在调用前成立，负位数返回 false，Python 对应抛 ValueError。两版均在写出首个字符前完成参数检查，成功时保留负零的符号。

此对代码依赖正文完整定义的C 数字打印原语与Python 数字打印原语，按各自语言合并运行；两版幅值均限于 uint64_t 范围。此版本只用数字原语，但输出是协议编码；输入已经量化，并未宣称解决任意实数的精确十进制显示。时间与输出长度同阶，打印整数部分的栈空间与 m 的位数同阶。

1.4 · 递归展开 include 文件

原题（中文翻译）

C 允许使用如下形式的语句：

#include filename

这条语句读入 filename，并用文件内容替换这条 include 语句。include 语句可以嵌套，即被包含的文件本身也可以包含 include 语句；但显然，任何包含链都不能让一个文件包含它自己。编写一个程序，读入一个文件，输出按 include 语句展开后的文件内容。

原书习题 1.4 · 印刷页 7 · PDF 第 24 页。

解答

把“处理文件”看成递归任务：普通行原样写出，include 行换成递归处理被包含文件的结果。需要的环检测是当前递归路径上的文件集合，不是永久 visited：A 两次包含 B 是合法重复展开；A→B→A 才是环。路径要规范化，否则 ./A 与 sub/../A 可能漏检。

C（C11）
#define _XOPEN_SOURCE 700
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>
/* C11 语言；realpath 是 macOS/Linux 的 POSIX 路径规范化接口。 */
typedef struct ActiveFile {
    const char *path;
    const struct ActiveFile *parent;
} ActiveFile;
static void *include_allocate(size_t size) {
    void *p = malloc(size);
    if (!p) abort();
    return p;
}
/* 1=读到一行，0=EOF，-1=I/O 错误；保留原来的换行字节。 */
static int include_read_line(FILE *source, char **line,
                             size_t *capacity, size_t *length) {
    *length = 0;
    int ch;
    while ((ch = fgetc(source)) != EOF) {
        if (*length + 1 >= *capacity) {
            if (*capacity > SIZE_MAX / 2) abort();
            size_t next = *capacity ? 2 * *capacity : 128;
            char *p = realloc(*line, next);
            if (!p) abort();
            *line = p; *capacity = next;
        }
        (*line)[(*length)++] = (char)ch;
        if (ch == '\n') break;
    }
    if (ferror(source)) return -1;
    if (!*length) return 0;
    (*line)[*length] = '\0';
    return 1;
}
static char *include_name(char *line) {
    char *p = line;
    while (isspace((unsigned char)*p)) ++p;
    if (strncmp(p, "#include", 8) != 0 ||
        !isspace((unsigned char)p[8])) return NULL;
    p += 8;
    while (isspace((unsigned char)*p)) ++p;
    char *name, *end, *tail;
    if (*p == '"') {
        name = ++p;
        while (*p && *p != '"' && *p != '\r' && *p != '\n') ++p;
        if (*p != '"' || p == name) return NULL;
        end = p; tail = p + 1;
    } else {
        name = p;
        while (*p && !isspace((unsigned char)*p) && *p != '"') ++p;
        if (p == name || *p == '"') return NULL;
        end = p; tail = p;
    }
    while (isspace((unsigned char)*tail)) ++tail;
    if (*tail) return NULL;
    *end = '\0';
    return name;
}
static char *include_child_path(const char *parent, const char *child) {
    const char *slash = strrchr(parent, '/');
    size_t prefix = child[0] == '/' ? 0 : (size_t)(slash - parent) + 1;
    size_t suffix = strlen(child);
    if (suffix == SIZE_MAX || prefix > SIZE_MAX - suffix - 1) abort();
    char *path = include_allocate(prefix + suffix + 1);
    memcpy(path, parent, prefix);
    memcpy(path + prefix, child, suffix + 1);
    return path;
}
static bool include_visit(const char *filename, FILE *output,
                           const ActiveFile *active) {
    char *path = realpath(filename, NULL);
    if (!path) { perror(filename); return false; }
    for (const ActiveFile *p = active; p; p = p->parent)
        if (strcmp(p->path, path) == 0) {
            fprintf(stderr, "include cycle: %s\n", path);
            free(path); return false;
        }
    FILE *source = fopen(path, "rb");
    if (!source) { perror(path); free(path); return false; }
    ActiveFile here = {path, active};
    char *line = NULL;
    size_t capacity = 0, length = 0;
    int status;
    bool ok = true;
    while ((status = include_read_line(source, &line, &capacity, &length)) > 0) {
        char *child = include_name(line);
        if (child) {
            char *next = include_child_path(path, child);
            ok = include_visit(next, output, &here);
            free(next);
        } else {
            ok = fwrite(line, 1, length, output) == length;
        }
        if (!ok) break;
    }
    if (status < 0 || ferror(output)) ok = false;
    if (fclose(source) != 0) ok = false;
    free(line); free(path);
    return ok;
}
/* output 由调用者打开、关闭；失败时可能已经写出部分内容。 */
static bool expand_file(const char *filename, FILE *output) {
    return include_visit(filename, output, NULL);
}
Python 3
from pathlib import Path
import re
import io

# 教学语法：独占一行的 #include filename 或 #include "filename"。
# 不执行 C 的宏、条件编译、注释处理或系统头搜索。
include_line = re.compile(r'^\s*#include\s+(?:"([^"\n]+)"|([^\s"]+))\s*$')

def expand_file(filename):
    output = io.StringIO()
    active = set()
    def visit(path):
        path = Path(path).resolve()
        if path in active:
            raise ValueError(f'include cycle: {path}')
        active.add(path)
        try:
            with path.open(encoding='utf-8', newline='') as source:
                for line in source:
                    match = include_line.fullmatch(line)
                    if match:
                        child = match.group(1) or match.group(2)
                        visit(path.parent / child)
                    else:
                        output.write(line)
        finally:
            active.remove(path)
    visit(filename)
    return output.getvalue()

C 版用 realpath 规范化相对路径与符号链接。Python 使用 Path.resolve。两版都处理独占一行的 include，未加引号的路径不能含空白或引号；带空白的路径用双引号。C 版直接写入调用者提供的 FILE 并返回成功状态，Python 返回字符串；C 版所有内部缓冲与路径都自行释放，输出流由调用者管理。相对路径以包含者所在目录为基准，打开失败直接报告异常；try/finally 保证当前路径集合恢复。示例 A 含两行 include B、B 只有 int x;\n，结果必须出现两份该行。让 B 又 include A，应报环。

时间按所有展开时读取的字节数计，不能按去重后的源文件总量计：同一文件可能展开多次。输出缓冲与结果大小同阶，活动路径和同时打开的文件句柄与包含深度同阶；路径解析成本另计。大输出可直接流式写到临时文件，成功后再发布；深包含链需考虑递归深度和打开文件数限制。

1.5 · Fibonacci 求和、指数界与闭式

原题（中文翻译）

设 Fi 为 Fibonacci 数。证明下列结论：

  1. ∑i=1N−2Fi=FN−2。
  2. FN<ϕN，其中 ϕ=(1+5)/2。
  3. 给出 FN 的一个精确闭式表达式。

原书习题 1.5 · 印刷页 7 · PDF 第 24 页。

解答

先固定下标。本版 a 的题面是 ∑i=1N−2Fi=FN−2，对应本书后续 Fib 的 F0=F1=1，不是常见的 0、1 起点。用这个约定，数列为 1、1、2、3、5、8。若记标准序列 G0=0,G1=1，则 FN=GN+1；第三、四章中出现的标准 Fibonacci 下标不能直接搬来。

a· 望远镜求和，N≥2

由递推得 Fi=Fi+2−Fi+1。相加以后中间项抵消：

∑i=1N−2Fi=∑i=1N−2(Fi+2−Fi+1)=FN−F2=FN−2.

N=2 时左边为空和，右边也为 0；N=5 时 1+2+3=6=8−2，可核对下标。

b· 黄金比上界，N≥1

令 ϕ=1+52，满足 ϕ2=ϕ+1。基例 F1=1<ϕ、F2=2<ϕ2。假设前两项的严格界成立，则

FN=FN−1+FN−2<ϕN−1+ϕN−2=ϕN.

N=0 是等号，不属于这个严格不等式的范围。两基例强归纳即完成证明。

c· 求出常数，而不只写“指数增长”

设 ψ=1−52。递推的特征方程 r2=r+1 的两根是 ϕ、ψ；它们的幂均满足递推。选择线性组合，使第 0、1 项都等于 1：

FN=ϕN+1−ψN+15(N≥0).

直接代入两基例，再代入递推，就证明闭式与原序列处处相同。因为 |ψ|<1，还得到 FN=Θ(ϕN)；浮点闭式不是可靠的大整数生成程序，舍入误差和溢出需另行处理。
