12.1：边搜索边拆树，再把三部分接回去

第四章的伸展从根下降，再沿父指针或栈回升。本节把调整放在下降过程中：中间树保存尚未处理的子树，L 收集比目标小的部分，R 收集比目标大的部分。L 的右边界和 R 的左边界各用一个指针指向末端；不必为每个节点增加父指针。

同向走两步时，先作一次 zig-zig 旋转，再把旧部分挂入 L 或 R；转向时，原始版本一次接走两个边界节点，简化版本只接走一个，下一轮再判断。两种算法都保持中序顺序，但最终形状不必相同。因此比较它们要统计比较、旋转和连接，不能只数循环轮数。

图 12.4 故意查找不存在的 19。算法先分离 12 与 25 附近的边界，再在 15、20 之间转向，最终停在 18。失败查找也会调整：若只在找到键时伸展，重复失败请求就可能一直走同一条长链，访问引理的操作口径也随之改变。

插入先伸展目标，再用新根隔开小键和大键；重复键只调整位置。删除先把目标伸展到根；若存在左树，伸展这个左树中的最大键，它的右孩子必为空，再接上原来的右树。本页用同一接口选择两种伸展，并维护子树 size。size 的修复只沿本次 L、R 边界逆转、恢复指针，时间与本次路径长成正比，辅助指针数仍为常数。

void repair_spine(Tree *t, Node *first, Node *tail, unsigned dir) {
    if (first == t->nil) return;
    Node *end = tail->ch[dir], *prev = t->nil, *x = first;
    while (x != end) { Node *next = x->ch[dir]; x->ch[dir] = prev; prev = x; x = next; }
    x = end;
    while (prev != t->nil) { Node *next = prev->ch[dir]; prev->ch[dir] = x;
        pull(t, prev); x = prev; prev = next;
    }
}
Node *splay(Tree *t, Node *x, int64_t key, bool original) {
    if (x == t->nil) return x;
    Node header = {0}; header.ch[0] = header.ch[1] = t->nil;
    Node *l = &header, *r = &header;
    for (;;) {
        ++t->w.visits; int c = key_cmp(key, x->key, &t->w);
        if (!c) break;
        unsigned d = c > 0; Node *y = x->ch[d];
        if (y == t->nil) break;
        int cy = key_cmp(key, y->key, &t->w);
        if ((d && cy > 0) || (!d && cy < 0)) {
            x = rotate(t, x, 1-d);
            if (x->ch[d] == t->nil) break;
        }
        if (d) { l->ch[1] = x; l = x; x = x->ch[1]; }
        else { r->ch[0] = x; r = x; x = x->ch[0]; }
        ++t->w.links;
        if (original && ((d && cy < 0) || (!d && cy > 0))) {
            if (x->ch[1-d] == t->nil) break;
            if (d) { r->ch[0] = x; r = x; x = x->ch[0]; }
            else { l->ch[1] = x; l = x; x = x->ch[1]; }
            ++t->w.links;
        }
    }
    l->ch[1] = x->ch[0]; r->ch[0] = x->ch[1];
    repair_spine(t, header.ch[1], l, 1); repair_spine(t, header.ch[0], r, 0);
    x->ch[0] = header.ch[1]; x->ch[1] = header.ch[0]; pull(t, x);
    return x;
}

bool sp_kth(Tree *t, size_t k, int64_t *answer) {
    if (!k || k > t->n) return false;
    Node *x = t->root;
    while (x != t->nil) {
        size_t left = node_size(t, x->ch[0]);
        if (k == left + 1) { *answer = x->key; t->root = splay(t, t->root, x->key, false); return true; }

12.2：下降前拆开 4 节点，删除前补足黑高度

红黑树用颜色编码多路树的层次。根为黑，红节点的孩子为黑，每条从节点到空端点的路径含相同数目的黑节点；于是最长路径至多交替出现黑、红节点。红链接只把同一层的键放在一起，黑链接才进入下一层。

若等到插入红叶以后才修复，父亲和叔父可能同时为红，修复会一路向上。本书的做法是下降途中遇到两个红孩子就翻色：把孩子变黑、当前节点变红，提前拆开对应的 4 节点；若当前节点与父亲形成红红相邻，再按同向或转向旋转。最后把根置黑。

在图 12.9 中插入 45，搜索会到达 50；它的孩子 40、55 都为红，翻色使 50 变红，因父节点 60 也红，需要围绕 70 调整这条左左路径。随后 45 接在 40 的右侧。这说明颜色变换与旋转承担不同任务：前者分拆多路节点，后者恢复二叉表示的方向。

删除也在下降时准备路径。当前黑节点若没有红孩子，就从兄弟借红链接，或将父亲与两个黑孩子翻色，使当前一侧有可删除的红资源。到达目标后继续寻找可直接摘除的位置，把它的键复制到目标节点；摘除后将根置黑。本页给出一般红黑树的非递归自顶向下插入、删除，12.5 逐项解释删除分支。

bool rb_insert(Tree *t, int64_t key) {
    if (t->root == t->nil) { t->root = node_new(t, key); ++t->n; return true; }
    Node head = {0}; head.ch[0] = t->nil; head.ch[1] = t->root;
    Node *q = t->root, *p = t->nil, *g = t->nil, *great = &head;
    unsigned dir = 0, last = 0; bool added = false;
    for (;;) {
        ++t->w.visits;
        if (q == t->nil) { q = node_new(t, key); q->red = true; p->ch[dir] = q; added = true; }
        else if (is_red(t, q->ch[0]) && is_red(t, q->ch[1])) {
            q->red = true; q->ch[0]->red = q->ch[1]->red = false;
        }
        if (is_red(t, q) && is_red(t, p)) {
            unsigned d2 = great->ch[1] == g;
            great->ch[d2] = q == p->ch[last] ? rb_single(t, g, 1-last) : rb_double(t, g, 1-last);
        }

}

12.3：用间隙控制高度，把期望保证改成最坏保证

第十章的跳跃表随机决定塔高。本节改为确定性约束：高度 h 的相邻分隔键之间，有一至三个高度 h−1 的键。每层只需经过常数个分隔键即可下降，而且每升一层，键数至少缩减一半，搜索路径因而最坏为 O(logN)。

插入 27 之前，上层有三个高度 2 的分隔键 10、25、45，先提升中间的 25。下降到 25 与 45 之间又遇到三个高度 1 的键 30、35、40，提升 35，最后插入 27。调整发生在插入点到达以前，避免增加一个低层键后才发现形成大小 4 的间隙。

这也是一棵 2-3-4 树：同一间隙的一至三个分隔键构成多路节点，其下是二至四个子间隙。删除下降前若目标间隙只有一个键，就向相邻间隙借一个，或连同高一层的分隔键合并。删除高塔的键时还要搬移相邻的逻辑记录，不能只删最底层副本。

书中最简实现把各层写成 Right／Down 节点，并使用 Header、Tail、Bottom 哨兵；插入时还会移动节点中的键。本页采用 12.11 要求的数组式塔：稳定的 Tower 包装保存动态前向数组，另用 2-3-4 的 Gap 索引保存局部间隙，便于在分裂、借键、合并时取得相邻位置。该索引额外占 O(N) 空间；所有真实键仍只在最底层存一份记录，各层前向项的总量为 O(N)。

12.4：只允许向右的水平链接

AA 树把 BB 树的对称情况进一步收紧：水平链接只向右，且不能连续两次。叶子 level 为 1，空哨兵为 0；左孩子恰低一级，右孩子与当前节点同级或低一级，右孙子必须更低。level 大于 1 的节点必须有两个孩子。这就是只含 2 节点、3 节点的多路树的一种二叉表示。

作者将两个修复动作命名为 Skew and Split（纠斜与分裂，§12.4）。Skew 对同级左孩子做右旋，消除向左的水平链接；Split 对连续两个同级右链接做左旋，把中间键提一级。先 Skew 后 Split，顺序不能颠倒，因为前者可能制造后者要处理的连续水平链接。

局部形状调整层级含义
左孩子与根同级Skew：右旋，双方 level 保持把水平链接转向右
根、右孩子、右孙同级Split：左旋，新根 level 加 1将三键分裂并提升中间键
删除后某孩子低了两级先降当前 level，必要时降右孩子重新建立共同的多路层级

递归插入只是普通 BST 插入后依次 Skew、Split。删除则先删除叶位，再把当前 level 降到两个孩子较小 level 加一，并修复当前节点、右孩子、右孙的左水平链接，最后处理两处可能的连续右链接。书中使用静态 DeletePtr、LastPtr 追踪候选；本页以显式后继替换表达同一删除思想，多个树调用不会共享删除状态。

12.5：键决定中序，优先级决定根

treap 同时是搜索树和最小堆：按键保持 BST 顺序，按 priority 保持父节点不大于孩子。若两种顺序都严格确定，整棵树也唯一确定：区间内优先级最小的键必须为根，左右区间递归采用同样规则。节点的插入先后不再决定最终形状。

新键先作为叶子插入，再旋转到优先级合法；删除把较优孩子旋上来，令目标继续下降，直到只剩至多一个孩子即可摘除。优先级相互独立且连续随机时，所有优先级排列等可能，形状等价于随机插入 BST，因此任意固定输入顺序的搜索与更新都是 O(logN) 期望。最坏仍能形成链。

本页随机数是有限 32 位值，可能相同，故用“priority，再比较 key”形成严格全序；树中的键按集合处理。固定频次策略用负访问次数作为最小优先级：访问越多越靠近根；重采样策略只接受更小的新随机值。前者会记住长期历史，后者会积累多次抽样的优势，12.18 用固定热点与切换热点观察这种差别。

12.6：二维搜索不等于两棵一维树

原书的应用是广告邮寄名单：同时筛选年龄 34–49 岁和年收入 100,000–150,000 美元。只按年龄建立 BST，收入条件仍可能迫使扫描大量候选；k-d 树轮流用不同坐标切分空间，查询矩形与子区域不相交时，整棵子树都能剪去。

节点深度 d 比较第 d mod k 个坐标。范围搜索先检验当前点的所有坐标，再根据当前分割坐标决定是否进入左、右树。区间包含端点时，等于分割值的边界必须谨慎处理；本页比较“坐标、记录 ID”，用唯一 ID 打破坐标平局，查询剪枝仍在等号两侧保守访问，确保同坐标记录全部返回。

单次查询不能仅按树高计时：查询可能横跨许多分区，还必须输出 M 个匹配。完全平衡树的范围界为 O(M+kN1−1/k)；二维即 O(M+sqrtN)。随机树的部分匹配还取决于指定多少维，指数由 12.24 的方程确定。

本页插入、范围搜索与最小值查找均不用递归，动态栈只保存实际经过的路径或待访问节点。删除保留位置的分割维度，用右子树中该维最小点替换；若只有左树，则用左树该维最小点替换，并把剩余左树移到右侧，详见 12.30。同一个 point 的 ID 在整个树中必须唯一，点由值复制到节点，外部对象不会被释放。

12.7：删除最小根以后，合并次序成为核心

配对堆保留一棵堆序多叉树。合并只比较两个根，把大根整棵挂为小根的第一个孩子，插入就是与单节点合并。左孩子／右兄弟表示只用两个方向表达多叉结构；为了快速剪切指定节点，书中再加 Prev：第一个孩子的 Prev 是父节点，后续兄弟的 Prev 是左兄弟。

降低键后，即便无法直接知道父节点的键，也可以将非根节点剪下再与根合并。必须依次修复后继的 Prev、前驱的 child 或 next，并清除脱离节点的 next；否则一条残留兄弟链接就可能把其他子堆重复带走。根降低键只需修改键。

删除根留下若干兄弟子堆。第一趟从左到右两两配对，第二趟从右到左合并结果；有奇数个时，最后一个单独进入第二趟。实际工作与根的孩子数成正比，但双趟次序使势能变化能抵消长兄弟链，12.33 给出摊还对数证明。

12.1 · 自顶向下伸展的摊还界

原题（中文翻译）

证明自顶向下伸展操作的摊还代价为 O(logN)。

本版习题 12.1；印刷页 497／PDF 第 514 页。

解答

先固定成本口径。把每个真实节点权重取为 1，s(v) 是其子树节点数，r(v)=log₂s(v)，势能为所有节点秩的和。搜索、旋转、链接与最终拼接的实际工作和访问路径长度成正比；论文访问引理中的常数 3 对应其归一化的基本步骤，不能直接当作本实现的比较次数或指针写入次数。以下先展开标准双层版本的局部账目，再说明本章简化版本使用的结果。

  1. 只计算会改变的子树。将原搜索路径按同向两层、转向两层分组，末尾最多留一层。标准双层版本先处理当前根 t、孩子 y，再下降到孙子所在的剩余子树；把后续处理看作已完成，设它返回的根为 x。用 r、r′ 表示把 x 接回 t、y 之前和之后的秩。挂在路径两侧的子树集合不变，只有 x、y、t 三个秩进入局部势能差。重新接好后 x 接管原 t 的全部节点，因此 r′(x)=r(t)。
  2. 转向两层的两个小子树互不相交。例如先左后右，完成后 y 与 t 分别在 x 的左右。两次局部调整的归一化成本加势能差为 2+r′(y)+r′(t)−r(x)−r(y)。因为新 y、t 的子树不相交且都在新 x 内，用 r′(y)+r′(t)≤2r′(x)−2；再用旧 y 包含旧 x，得到 2+ΔΦ≤2(r′(x)−r(x))≤3(r′(x)−r(x))。这说明付出的两单位由秩增加支付。
  3. 同向两层要换一对不相交的子树。例如先左再左，原来的 t 被放到 y 的右侧，x 成为新根。旧 x 的整棵子树与新 t 的子树互不相交，都包含于新 x；故 r(x)+r′(t)≤2r′(x)−2。又有 r′(y)≤r′(x)、r(y)≥r(x)，代入同一局部成本式得到 2+ΔΦ≤2+r′(x)+r′(t)−2r(x)≤3(r′(x)−r(x))。不能继续套用转向情形的“新 y 与新 t 不相交”，因为这里 t 就在 y 的子树里。
  4. 最后一层与整次访问。只剩一层时，一次调整给出 1+ΔΦ≤1+r′(x)−r(x)。沿递归展开的各层求和，剩余子树根的秩一正一负抵消，只留下整树根与最初访问节点的秩差。这里“假想先完成后续子树再接回”只是计算最终同一棵标准双层树的方法；最后把左右链接到 x 的操作已包含在这些局部连接中，不能再遗漏一条长链的势能变化。于是标准版本满足 c^≤3(log2N−log2sbefore(x))+1。
  5. 本章程序采用的简化转向。程序在转向时只链接一层，再由下一轮决定继续链接或旋转，因此最终树形可能不同。对这份实现，使用 Sleator–Tarjan 原论文第 4 节印刷 670 页明确给出的“标准和简化两种自顶向下算法均满足访问引理”这一结果；上面逐项展开的是标准双层版本，不能把它冒充简化版得到同一树形的证明。该引理把链接的归一化工作和最终拼接一起计账，给出相同数量级。成功查找访问目标，失败查找伸展最后一个真实节点；空树另作常数时间处理。
  6. 从一次访问得到整个序列。取覆盖真实基本工作常数的 K，并相应使用 KΦ 计账，有 c+KΔΦ≤K(3log2N+1)。固定 N 个节点、从任意初始树开始，M 次访问的总成本为 ∑i=1Mci≤KM(3log2N+1)+K(Φ0−ΦM)=O(MlogN+NlogN)，因为 0≤Φ≤Nlog₂N。已有 size 字段只沿本次访问与拼接的边界链重算，节点数与路径工作同阶，吸收到 K 中。这里是序列的摊还界；某一次操作仍可能线性长。

原书习题 12.1：印刷 497 / PDF 514。补充依据：Sleator 与 Tarjan，Self-Adjusting Binary Search Trees（1985），Lemma 1 与 §4，尤其印刷 668—670 页的两种自顶向下程序与适用声明。底向上局部势能计算可回读第十一章访问引理及习题 11.8；两种算法的树形和成本口径分别解释。

12.2 · 每次访问至少两倍对数旋转的构造

原题（中文翻译）

证明存在访问序列，使自底向上伸展每次访问需要 2logN 次旋转。证明自顶向下伸展也有类似结果。

本版习题 12.2；印刷页 497／PDF 第 514 页。

解答

给出一族明确的树和访问序列，所有对数取底 2。“需要”按下界理解。先取有 2h 个叶位的完美二叉骨架，把每个叶位替换成长度 L=8h+5 的单向右链，再按整棵树的中序次序赋予互异键。节点总数为 N=2h(L+1)−1=2h(8h+6)−1。取 h≥8，依次访问每条链最深处的键，每条链只访问一次。

此前的访问路径不会进入一个尚未访问的叶位区间；伸展旋转只会改变这棵旁挂子树的接入位置，内部单向链保持完整。因此，当第一次访问这条链的末端时，仍必须穿过它的全部内部边。自底向上每次基本旋转使目标上升一层，仅这条链就至少需要 L−1 次。

自顶向下中，进入链时与骨架相接的一次转向至多接走前两个节点；剩余同向链每两步至少产生一次 zig-zig 基本旋转，故至少有 ⌊(L−3)/2⌋=4h+1 次。又因 8h+6≤2h，有 log2N<2h，于是两种算法在这 2h 次访问中的每一次都至少作 2log2N 次旋转。

这里的序列长为 Θ(N/logN)，长链的初始势能也已计入 12.1 的总界。它证明题目要求的存在性，并表明访问引理中的对数成本不能解释为“一条搜索路径只需一倍对数的旋转”。该构造不把有限访问块当作无限重复序列。

12.3 · 第 k 小：size 与跳跃表跨度

原题（中文翻译）

修改伸展树，使其支持查询第 k 小的元素。在确定性跳跃表中应怎样实现？

本版习题 12.3；印刷页 497／PDF 第 514 页。

解答

在伸展树节点记录 size＝左树大小＋右树大小＋1。当前左树大小为 l：k＝l＋1 时找到；k≤l 时进左树；否则进入右树并令 k←k−l−1。找到以后伸展该键到根。k 从 1 开始，空树或 k 不在 1…N 时返回失败；sp_kth 给出完整两版实现。每次旋转与边界拼接都更新 size，故查询仍为 O(logN) 摊还。

跳跃表可在每条前向边上加 span，表示跨过的底层键数，包括到达的真实键；指向空端点的 span 是右侧剩余键数。先校验 1≤k≤N，再从头和累计秩 0 开始：仅当前向目标真实存在且累计秩加 span 不超过 k 时沿边前进，否则下降一层，最后恰好到达累计秩 k 的键。

插入时记录各层前驱及其秩；若在秩 u 的键后新增秩 v 的塔，则将原边跨度 s 拆为 v−u 与 s−(v−u)+1，没有新增前向项的穿越边跨度加一。删除做逆操作：合并两段时取 s1+s2−1，其余穿越边减一。单独提升已有塔没有新增底层键，分裂边改用 v−u 与 s−(v−u)；单独降低塔的合并跨度为 s1+s2，其他穿越边不增减。

确定性间隙调整不能用底层线性扫描重算秩。给 Gap 索引 的每个子间隙加真实键计数，分裂、借键、合并时按至多四个孩子重算，并沿路径携带前缀秩；每层只更新常数项，搜索、排名和更新仍最坏 O(logN)，总跨度空间 O(N)。

12.5 · 红黑树删除：下降时借红链接

完整实现见 rb_delete。保存当前节点 q、父亲 p、祖父 g、临时根 head，并记录搜索中最后一个等于目标的节点 found。每次选择下降方向之前，若 q 和该方向孩子都黑，就准备下一层的红资源。

可用条件处理维持的性质
q 的反方向孩子为红先旋转该红孩子上来，重新接入父节点旋转后下降侧可继续处理

12.6 · 红黑树高度与不可降低的系数

原题（中文翻译）

证明红黑树的高度至多为 2logN，并且这个界不能被大幅降低。

本版习题 12.6；印刷页 497／PDF 第 514 页。

解答

高度按边数计，单节点高度 0，根为黑。若根的黑高度为 b，不含空哨兵，则其节点数至少 2b−1：两边黑高度相同，红节点只能增加节点。路径上不能连续红，因此高度至多 2b−1，立即得到常用的精确写法 h≤2log2(N+1)−1。

要写成题目的 2logN，可把最少节点数再收紧。选最长路径，路径外每棵兄弟子树至少有 2j−1 个节点，j 是该位置要求的黑高度。高度 2b−1 时最少使用 b 个黑、b 个红，交替结束于红；路径本身有 2b 个节点，两种颜色各贡献一遍短侧和，因此最小规模为 2b+2∑j=0b−1(2j−1)=2b+1−2。

高度 2b 时至少有 b＋1 个黑节点，至多 b 个红节点。为让路径外节点最少，应省去最上面的可选红节点，使黑节点的兄弟黑高度从 b 到 0、红节点的兄弟黑高度从 b−1 到 0；总数为 2b+1+∑j=0b(2j−1)+∑j=0b−1(2j−1)=3·2b−2。再增加黑节点只会增加这些下界。两个最小规模均不少于 2h/2，故 h≤2log2N；高度 0 的单节点独立满足。

取黑根 B_b：左边为黑高度 b−1 的全黑完美树，右边为一个红节点；该红节点左边也为同一高度的完美黑树，右边继续放 B_{b-1}，B_0 为空。每一条路径黑高度一致且红不相邻。其规模满足 nb=2b+nb−1=2b+1−2，最长高度为 2b−1。于是 h=2log2N−3+o(1)，主项系数 2 无法改成更小常数。

12.7 · AVL 可以着红黑色，逆命题不成立

原题（中文翻译）

证明每棵 AVL 树都能着色为红黑树。所有红黑树都是 AVL 树吗？

本版习题 12.7；印刷页 497／PDF 第 514 页。

解答

可以。将 AVL 高度改为节点数，空树 h＝0。归纳构造黑根形式 B(h)，黑高度为 ⌈h/2⌉；若 h 为奇数，还构造红根形式 R(h)，黑高度为 ⌊h/2⌋。同一个给定 AVL 形状只改变颜色。

当 h＝2m＋1 时，孩子高度只能是 2m 或 2m−1，它们的 B 形式黑高度均为 m。根着黑得到 B(h)；根着红、孩子仍为 B 得到 R(h)，没有红红相邻。当 h＝2m 时，孩子高度为 2m−1 或 2m−2；较高的奇数高度孩子用 R，较矮的偶数高度孩子用 B，二者黑高度均为 m−1，当前根着黑得到 B(h)。两个孩子同高时使用同一种形式。基例空树及叶子立即满足，最终根取 B，完成全树着色。

逆命题不成立。12.6 的 B3 有一条交替黑红的长路径，另一边是全黑短树，在根或其子节点处，两孩子高度差大于 1；它满足红黑的黑高度约束，却违反 AVL 的左右高度差约束。红黑树控制黑层数，允许某些红链接把实际路径拉长。

12.8 · 确定性跳跃表与 2-3-4 树

原题（中文翻译）

证明 1-2-3 确定性跳跃表可以表示为一棵 2-3-4 树，其中内部节点和叶子节点都存有元素。

本版习题 12.8；印刷页 497／PDF 第 514 页。

解答

从最高层向下，将两个高于本层的边界之间的一至三个本层分隔键组成一个多路节点。这些分隔键把下一层划分为二至四个子间隙，分别作为孩子；最底层没有下一层，因而是叶节点。由于所有塔都从底层连续向上存在，所有叶间隙的层数相同。

一个高塔的键作为其最高出现层的分隔键只存一次；下面的前向项是该键的索引投影，不再当成新的逻辑元素。因此内部节点与叶节点都能存键，没有把所有键强行放在叶子。反过来，把 2-3-4 树 level 为 h 的分隔键建成高度 h 的塔，每个多路节点的一至三个键恰形成允许的间隙。两个构造互为对应，分裂提升中间键、借键与合并也逐项相符。

12.9 · 重复插入仍可能调整塔高

原题（中文翻译）

若试图在确定性跳跃表中插入一个已经存在的元素，会发生什么？

本版习题 12.9；印刷页 497／PDF 第 514 页。

解答

集合的键数不变，已有键不会被重复添加；但下降途中可能已经拆开满间隙、提升分隔键，所以结构形状不必保持原样。原书按各层搬移键并在 Bottom 处识别终点，不能把末层“未加新键”理解为此前“未修改结构”。

本页数组式实现 在某层找到相等键时返回 false；之前的满间隙分裂同样允许发生。它们都保存中序键集合和 1-2-3 间隙约束。若应用要求重复插入连结构都保持不变，可以先执行一次查找，再决定插入，仍为 O(logN)，但会多走一遍路径。

12.10 · 真实键的层副本至多 2N

原题（中文翻译）

证明 1-2-3 确定性跳跃表至多使用 2N 个节点。

本版习题 12.10；印刷页 497／PDF 第 514 页。

解答

题干校注：扫描文本中的“ZN”是 2N。节点计数按真实元素的各层副本计，Header、Tail、Bottom 等辅助哨兵另外占 O(logN) 或固定字长空间。

令 m_j 为高度至少 j 的真实键数，m_1＝N。相邻两个高度至少 j＋1 的键之间，至少存在一个恰为高度 j 的键，两端同样满足边界间隙条件，故 mj+1≤⌊(mj−1)/2⌋≤mj/2。每个高度 h 的塔贡献 h 个层项，因此总真实层项数为

∑j≥1mj≤N+N/2+N/4+⋯≤2N

有限非空表实际上小于这个无穷和；N＝0 时真实层项为 0。数组容量按 2 的幂保留，会有未使用槽，Gap 索引也有额外节点，不能把它们一并宣称为“至多 2N”；12.11 的实现总空间仍是 O(N)。

12.11 · 数组式塔：每次操作最坏对数

原题（中文翻译）

在 C 中，可把每个抽象节点表示为动态分配的前向指针数组，取代前向指针的链表表示。说明如何在此方案下实现 1-2-3 确定性跳跃表，并维持每次操作的 O(logN) 时间界。

本版习题 12.11；印刷页 497／PDF 第 514 页。

解答

完整双语实现见 Tower／Gap／DSL。Tower 包装稳定，外来前向指针指向包装对象；只有包装内部的 fwd 数组重新分配。容量取不小于逻辑高度的最小 2 次幂，提高一级时必要才倍增；降低至容量四分之一时才缩小，以避免边界上反复复制。

一次搜索路径只有 H＝O(logN) 层，每层只分裂、借键或合并常数个塔。所有会复制长度 2^j 数组的事件都发生在高度约 2^j 的层，且一次路径中这一高度只有常数个候选。因此本次操作的复制总量为 O(1+2+4+⋯+H)=O(H)。这是单次路径的几何界，包含最坏 O(logN) 的一次复制，而不是仅说“动态数组平均 O(1)”后再忽略各层。

调整前向链接时从该间隙继承的高层左边界出发，至多经过四个分隔键取得本层前驱；整条路径只做 O(H) 次局部工作。删除高塔替换另外做常数次全表前驱查找，各为 O(H)。容量迟滞使每塔容量不超过四倍逻辑高度，加上 12.10 的和，总前向空间 O(N)，Gap 索引也为 O(N)。

C 的重新分配失败报告并终止，Python 分配失败由运行时异常表达；成功路径的算法相同。程序不保留关键字无穷大值，64 层头数组对应固定 64 位键／规模模型。几何容量方法及最坏界也可核对 Munro、Papadakis、Sedgewick 1992 年论文§3–4。

12.12 · 确定性跳跃表删除

原题（中文翻译）

编写 1-2-3 确定性跳跃表的删除过程。

本版习题 12.12；印刷页 497／PDF 第 514 页。

解答

实现见 DSL.delete／dsl_delete。下降前确保目标孩子至少有两个分隔键：相邻孩子有至少两个键时借一个，把父分隔键降入目标孩子、邻居边界键升入父；否则把两个只有一个键的孩子与父分隔键合成三个键的间隙，再下降。根允许临时少一个键，最后为空则收缩一层。

若目标是叶间隙的键，直接从底层及其所有塔层摘下。若目标在内部，选择已有至少两个键的相邻子树，取其中最右前驱或最左后继，继续安全下降到这个替换键；摘下它的原塔，再接入被删除键的高度，更新该分隔位置。若两侧都只有一个键，必须先把目标分隔键随两侧合并，随后从合并孩子继续删。

借键保持父子区间顺序，合并保持一至三个分隔键，根收缩保持所有叶同层；每次下降前目标间隙有足够键，摘除不会形成非根空间隙。失败查找也可能借键或合并，但集合不变。每层常数次局部操作加 12.11 的几何复制，最坏 O(logN)，空表与缺失键返回 false。

12.13 · AA 删除的正确性

原题（中文翻译）

证明 AA 树删除算法正确。

本版习题 12.13；印刷页 497／PDF 第 514 页。

解答

按递归返回的子树高度归纳。普通 BST 删除在叶位摘除一个键；内部替换取右子树最小键，保留中序顺序。未改变的一侧仍合法，改变的一侧 level 最多降低一级。若当前层级仍与孩子匹配，就没有新的低层缺口；否则把当前 level 设为 min(左 level，右 level)＋1，必要时把右孩子降到相同值。

删除后的局部现象为何只影响有限位置修复
左侧下降或右侧被降级原来合法的同层横链只有至多两个节点；降一级后，左同层边只可能出现在当前、右孩子、右孙依次对三处 Skew
Skew 将左水平链接转成右水平链接旋转不改中序与较低子树的 level，当前层可能形成长度三的横链Split 当前和右孩子
Split 提升一个中间键较低子树仍合法，影响只传给上一递归层上一层重复同一固定修复

每次 Skew 只交换同级根与左孩子，不改变任何到低一层子树的层数；它消除一条左水平边。全部 Skew 后，同层节点依中序向右排列；Split 将连续三节点的中键提一级，两侧降为它的低一层孩子。两处 Split 足以消除本次降级产生的连续横链。最终左孩子恰低一层，右孩子同层或低一层，右孙更低；level＞1 的节点仍有两个非空孩子。

因此 aa_fix 把一个“孩子已合法、当前缺至多一层”的子树变回完整 AA 子树，归纳到根即得正确性。空树、缺失键与单孩子根不需要特殊平衡状态；删除过程使用 O(logN) 递归深度，每层至多三次 Skew、两次 Split。

12.15 · 一次递归 Skew、一次递归 Split

原题（中文翻译）

将 Skew 与 Split 写成递归过程，使删除时只需分别调用它们一次。

本版习题 12.15；印刷页 497／PDF 第 514 页。

解答

用 aa_skew_level、aa_split_level、aa_fix_level、aa_delete_level_rec。降级以后保存当前 level；Skew 在这个原层级先修当前节点，再沿右链接递归，遇到空节点或其他 level 即停止；Split 同样先修当前节点，再沿右链接递归。Split 即使提升当前根，也必须继续检查它的右孩子是否仍处于原层级。

不能把递归作用扩成整个子树：较低层已合法，不需要再遍历。一次合法删除造成的同层链只有常数个节点，递归 Skew 等价于逐项覆盖原来的三处候选，递归 Split 覆盖原来的两处候选。调用顺序仍是先 Skew 后 Split；若先从链尾 Split 再回头，可能重复提升已有新层级的节点。

整棵删除仍为 O(logN)，该层额外递归深度为常数。两版检查驱动对这个完整删除入口也逐步检查 AA 层级与键集合，不只验证两个辅助函数能编译。

# A valid BB-tree with a canonical left red link; equivalent to a 2-3 tree.
def bb_rotate(t, x, d):

def bb_flip(t, x):

12.17 · treap 的显式栈插入是否值得

原题（中文翻译）

维护一个栈，以非递归方式实现 treap 的插入过程。这是否值得花费精力？

本版习题 12.17；印刷页 497／PDF 第 514 页。

解答

使用 tr_iter_insert。下降时记录“父节点及孩子方向”（C 保存指向子树根的槽位）；在空位接入新节点，再从栈顶向上检查这个子树根与孩子的优先级，违反堆序则旋转，旋转后的根写回保存槽。到根后，两种顺序都恢复；重复键返回 false，不新增节点。

C 路径数组从小容量开始按倍数增长，Python 记录相同路径；它们没有在每次插入前分配 N 个槽。栈空间与实际深度成正比，最坏 O(N)、随机优先级下期望 O(logN)，更新时间同样期望 O(logN)。递归版本在退栈时处理同一节点，因此键比较与旋转数相同。

12.14 的 N＝1024 随机批次中，两种 treap 都有 36177 次键比较与 2842 次旋转；C 递归与栈为 0.217、0.236 毫秒，Python 为 6.235、5.892 毫秒。显式栈能控制极长链的调用栈风险，但会增加路径存储与代码；本批数据没有跨语言一致的加速，因此是否采用应取决于递归深度要求和实际负载。

12.19 · 已排序键在线性时间建 treap

原题（中文翻译）

证明：即使优先级尚未排序，只要元素已经按键排序，就能在线性时间构造 treap。

本版习题 12.19；印刷页 497／PDF 第 514 页。

解答

使用 tr_build_sorted。按键从小到大处理新节点 x，维护当前 Cartesian 树最右路径的栈，栈的优先级严格递增。不断弹出优先级比 x 大的节点，记最后一个弹出的节点 last；令 x.left＝last。若栈非空，令栈顶.right＝x；否则 x 成为新根。然后压入 x。未弹出时 last 是空节点。

所有弹出节点的键小于 x，组成 x 的左子树；剩余栈顶的优先级小于 x，且键也小于 x，接到它的右侧恰好满足两种顺序。右路径之外的子树没有改变。归纳得到插入全部键后的正确 treap，而两种严格顺序保证该 treap 唯一。

每个节点入栈一次、出栈至多一次，每条边建立常数次，总时间 O(N)，额外栈最坏 O(N)。输入必须键严格递增；重复键先合并或拒绝。有限随机优先级平局用键补成全序，不要求事先对优先级排序。

class PlainTree(Tree):
    def __init__(self): self.nil = self.root = None; self.n = 0; self.w = Work()
def plain_level(x): return x.level if x is not None else 0

def plain_skew(t, x):
    if x is not None and x.ch[0] is not None and x.ch[0].level == x.level: x = t.rotate(x, 1)
    return x

def plain_split(t, x):
    if (x is not None and x.ch[1] is not None and x.ch[1].ch[1] is not None
            and x.ch[1].ch[1].level == x.level):
        x = t.rotate(x, 0); x.level += 1
    return x

def plain_aa_insert(t, x, key, changed):
    if x is None: changed[0] = True; t.n += 1; return t.new(key)
    c = t.w.cmp(key, x.key)
    if c: x.ch[c > 0] = plain_aa_insert(t, x.ch[c > 0], key, changed)
    return plain_split(t, plain_skew(t, x))

def plain_aa_fix(t, x):
    if x is None: return x
    level = min(plain_level(x.ch[0]), plain_level(x.ch[1]))+1
    if level < x.level:
        x.level = level
        if x.ch[1] is not None and x.ch[1].level > level: x.ch[1].level = level
    x = plain_skew(t, x); x.ch[1] = plain_skew(t, x.ch[1])
    if x.ch[1] is not None: x.ch[1].ch[1] = plain_skew(t, x.ch[1].ch[1])
    x = plain_split(t, x); x.ch[1] = plain_split(t, x.ch[1]); return x

def plain_aa_delete(t, x, key, changed):
    if x is None: return x
    c = t.w.cmp(key, x.key)
    if c: x.ch[c > 0] = plain_aa_delete(t, x.ch[c > 0], key, changed)
    elif x.ch[0] is None or x.ch[1] is None:
        changed[0] = True; t.n -= 1; return x.ch[x.ch[0] is None]
    else:
        y = x.ch[1]
        while y.ch[0] is not None: y = y.ch[0]
        x.key = y.key; x.ch[1] = plain_aa_delete(t, x.ch[1], y.key, changed)
    return plain_aa_fix(t, x)

12.21 · 按 NULL 数计权重的重建平衡

原题（中文翻译）

为每个节点存储其子树中 NULL 指针的数量，称为该节点的权重。采用如下策略：若左右子树的权重之比超出 2 的范围，就完全重建以此节点为根的子树。证明：

  1. 可以在 O(S) 时间重建一个节点的子树，其中 S 是该节点的权重。
  2. 每次插入的摊还代价为 O(logN)。
  3. k-d 树中的节点子树可在 O(SlogS) 时间重建，其中 S 是该节点的权重。
  4. 将该算法用于 k-d 树，每次插入的摊还代价为 O(log2N)。

本版习题 12.21；印刷页 498／PDF 第 515 页。

解答

(a) 权重与普通树重建

空子树权重为 1；真实节点的权重等于两孩子权重之和，所以有 n 个节点的子树权重为 n＋1。中序遍历得到有序节点数组，按中点选根并递归或任务栈安排两半，左右规模差至多一；遍历与重接各 O(S)。

(b) 为什么重建能由许多插入分摊

合法时较重孩子不超过父权重的 2/3，树高 O(logN)。刚重建的左右权重近乎 S/2；要再使一侧超过另一侧两倍，至少需要 Ω(S) 次插入落在这一子树中。每次经过该祖先存常数个信用，就足够支付下一次 O(S) 重建。

一次插入先收集路径并更新权重，若多处不平衡，重建最高的一处即可，较低违例由同次重建一并消除。一次插入经过 O(logN) 个祖先，存入 O(logN) 信用；每次重建消耗该子树从上次重建以来的信用，故总摊还 O(logN)。重建后也重置所有新子树的账目，信用重复使用不会发生。

(c) 多维重建

固定 k，先把节点按每个坐标各排序一次，O(kSlogS)。按当前分割维度选中位记录，用该记录的坐标及 ID 把其余 k 份有序数组稳定分成左右两份；当前层总 O(kS)。下一层换维度，平分规模的每一层总 O(kS)，共 O(logS) 层，得 O(kSlogS)，固定 k 即 O(SlogS)。不能在每个递归节点重新排序所有坐标，否则会多出一个对数因子。

(d) 多维摊还账

同样要 Ω(S) 次插入才再次失衡，现在每次经过权重 S 的祖先存 O(logS) 信用，以支付 O(SlogS) 重建。路径上有 O(logN) 个祖先，每个 O(logN) 信用，合为 O(log2N) 摊还。节点更新及选择最高违例的路径扫描不超出这个界。空间按固定 k 为 O(S)，重建后保留按深度循环的分割维度。

12.22 · 为什么普通单旋转破坏 2-d 树

原题（中文翻译）

假设对任意一棵 2-d 树调用 SingleRotateWithLeft。详细说明为什么所得结果不再是一棵可用的 2-d 树。

本版习题 12.22；印刷页 498／PDF 第 515 页。

解答

二维树左右关系使用当前深度的分割坐标；根与左孩子使用不同坐标。右旋后两者交换深度，把分割维度随深度重置，会把原本按 y 分类的子树当成按 x 分类，反过来也一样。保留节点原来的分割字段则又失去逐层交替的约定。

原节点／子树坐标原先位置
X(5,5)根，按 x 分割
Y(3,8)X 左孩子，按 y 分割
B(1,9)Y 右孩子，满足 x＜5 且 y＞8

对 X 右旋后，Y 成为根，X 成为 Y 的右孩子，B 成为 X 的左树。如果 Y 改按 x 分割，它的整个右树应满足 x≥3，但其中 B 的 x＝1，查询会被错误剪去。如果 Y 保留按 y 分割，其右侧 X 的 y＝5＜8，也已经违反自身分割约束。

因此问题同时涉及深度与维度的绑定、整棵旁挂子树的坐标归属、以及查询依赖的祖先空间区间。BST 旋转只保存一种中序顺序，不能保存交替坐标下的所有区域关系。正确修复要重划分记录并重建子树，而非给旋转后的两节点简单换一个 axis 字段。

12.23 · k-d 树的非递归插入与范围搜索

本版习题 12.23；印刷页 498／PDF 第 515 页。

完整程序见 kd_insert、kd_query／KDTree。插入保存当前子树槽位和下一分割维度，比较“该维坐标、唯一 ID”，直到空位分配节点；时间与实际树高成正比，辅助指针 O(1)。记录 ID 全局唯一是调用者前提，坐标可以重复，程序没有全局 ID 去重表。

固定 k，按坐标中位划分，分割边界没有大批重合坐标；有重复坐标时可对查询端点与 ID 作一致的符号平局划分。先数一个平行于某坐标轴的查询边界所穿过的分区：每 k 层里，另外 k−1 个坐标可以让边界进入两侧，本坐标的分割只进入一侧。故每完整周期最多进入 2k−1 个大小约 N/2k 的子树。

B(N)≤2k−1B(N/2k)+O(2k),B(N)=O(N1−1/k)

矩形有 2k 个边界面，将边界分区访问量相加为 O(kN1−1/k)。完全落在查询区域内的子树，其节点访问都能归入输出的 M 个记录；完全在外的子树剪去。合起来得到 O(M+kN1−1/k)，固定维度的坐标检验常数吸收入系数。二维一个边界每两层至多进入两个孙子，递推 T(N)=2T(N/4)+O(1)，所以为 O(M+N)。

一维应单独写 O(M＋logN)，因为递推的一分支边界搜索保留了树高项；所有点均命中时至少 O(M)。未经平衡的插入树，以及简单地把大量相等坐标都送一侧的树，都不能仅凭这个几何推导获得相同保证。

12.26 · 2-d 堆：两个坐标的极值

原题（中文翻译）

2-d 堆允许每个元素有两个独立关键字，可以对任一关键字执行 DeleteMin。它是一棵完全二叉树，满足：偶数深度节点 X 中的元素具有其子树最小的关键字 #1，奇数深度节点 X 中的元素具有其子树最小的关键字 #2。

  1. 为 (1,10)、(2,9)、(3,8)、(4,7)、(5,6) 画出一个可能的 2-d 堆。
  2. 如何找到关键字 #1 最小的元素？
  3. 如何找到关键字 #2 最小的元素？
  4. 给出插入新元素的算法。
  5. 给出对任一关键字执行 DeleteMin 的算法。
  6. 给出线性时间 FixHeap 的算法。

本版习题 12.26；印刷页 498／PDF 第 515 页。

解答

(a) 数组层序为 (1,10)、(4,7)、(5,6)、(2,9)、(3,8)。根在第一坐标最小；左孩子的第二坐标 7 小于其两孩子的 9、8；右孩子为叶。空树没有极值。

(b) 第一坐标的最小元素就是根。(c) 第二坐标最小元素在根及两个孩子中；孩子已经是自己整棵子树的第二坐标最小值，根本身也必须参与比较。例中为 (5,6)。

(d) 新元素先进入完全树的下一个数组槽。沿它的祖先从根向叶处理：若当前携带元素在该祖先的指定坐标更小，就与该祖先交换，旧祖先元素继续保留在新槽作为携带元素。每个祖先原来已是其子树的该维最小值，加入新点后只需比较这两个候选；先修高祖先保证低层携带值满足已经建立的上层约束。

(e) 找到所需极值位置，用最后元素补洞并缩短数组。先按相同根向叶次序修复洞的祖先，再向下修洞。当前深度使用第一坐标时，只需比较其孩子及孙子：孙子已是自己的第一坐标子树最小，孩子自身也可能更小。选这两层中该坐标最小点换上来；若跨过一层，沿中间路径再按根向叶方式修复被破坏的第二坐标。洞移到交换点，继续。另一坐标对称，时间 O(logN)。

(f) 从最后一个内部数组位置倒序调用下修过程，孩子子树先合法。高度 h 的节点下修 O(h)，该高度的节点至多 N/2^h，求和 O(N)。新元素插入前预留容量，避免动态扩容的一次 O(N) 拷贝破坏最坏对数界；容量满返回失败。下方代码同时给出一般 k 维版本，数组从 0 编号，记录平局按唯一 ID。

class Slots:
    # Capacity is reserved by the caller before operations, so insertion never copies N slots.
    def __init__(self, capacity): self.data, self.n = [None]*capacity, 0
    def __len__(self): return self.n
    def __bool__(self): return bool(self.n)
    def __iter__(self):
        for i in range(self.n): yield self.data[i]
    def __getitem__(self, i):
        if not 0 <= i < self.n: raise IndexError(i)
        return self.data[i]
    def __setitem__(self, i, value):
        if not 0 <= i < self.n: raise IndexError(i)
        self.data[i] = value
    def append(self, value):
        if self.n == len(self.data): return False
        self.data[self.n] = value; self.n += 1; return True
    def pop(self):
        self.n -= 1; value = self.data[self.n]; self.data[self.n] = None; return value
class KDHeap:
    def __init__(self, k, capacity=4096):
        assert 1 <= k <= KMAX
        self.k, self.a, self.comparisons = k, Slots(capacity), 0
    def axis(self, i): return ((i+1).bit_length()-1)%self.k
    def before(self, i, j, axis):
        self.comparisons += 1
        return (self.a[i].v[axis], self.a[i].id) < (self.a[j].v[axis], self.a[j].id)
    def ancestors(self, i, stop=None):
        path = []
        while i:
            i = (i-1)//2
            if i == stop: break
            path.append(i)
        return path
    def upward(self, i, stop=None):
        # Process root to leaf, keeping the carried item at the original hole.
        for p in reversed(self.ancestors(i, stop)):
            if self.before(i, p, self.axis(p)): self.a[i], self.a[p] = self.a[p], self.a[i]
    def frontier(self, i):
        # Every descendant within k levels, including the next same-axis layer.
        stack = [(i, 0)]
        while stack:
            x, distance = stack.pop(); yield x
            if distance == self.k: continue
            for j in (2*x+2, 2*x+1):
                if j < len(self.a): stack.append((j, distance+1))
    def down(self, i):
        while True:
            best, axis = i, self.axis(i)
            for j in self.frontier(i):
                if j != i and self.before(j, best, axis): best = j
            if best == i: return
            self.a[i], self.a[best] = self.a[best], self.a[i]
            self.upward(best, i)  # repair the intervening axes in top-down order
            i = best
    def insert(self, point):
        if not self.a.append(point): return False
        self.upward(len(self.a)-1); return True
    def min_index(self, axis):
        assert 0 <= axis < self.k
        if not self.a: return None
        best, stack = 0, [0]
        while stack:
            i = stack.pop()
            if i and self.before(i, best, axis): best = i
            if self.axis(i) == axis: continue
            for j in (2*i+2, 2*i+1):
                if j < len(self.a): stack.append(j)
        return best
    def delete_min(self, axis):
        i = self.min_index(axis)
        if i is None: return None
        answer = self.a[i]; last = self.a.pop()
        if i < len(self.a):
            self.a[i] = last; self.upward(i); self.down(i)
        return answer
    def fix_heap(self, points):
        if len(points) > len(self.a.data): self.a = Slots(len(points))
        self.a.n = len(points)
        for i, point in enumerate(points): self.a.data[i] = point
        for i in range(len(self.a)//2-1, -1, -1): self.down(i)

原题（中文翻译）

推广上一题，得到每个元素有 k 个独立关键字的 k-d 堆。应达到以下界：Insert 为 O(logN)，DeleteMin 为 O(2klogN)，FixHeap 为 O(kN)。

本版习题 12.27；印刷页 498／PDF 第 515 页。

解答

题干校注：原页 DeleteMin 中的 2k 是指数，不是 2k。根的深度为 0，本页数组使用从 0 开始的坐标编号。

使用 KDHeap，深度 d 的节点是整个子树第 d mod k 维的最小值。Insert 的祖先携带法逐个比较各祖先自己的坐标，与 k 无关地进行 O(logN) 次坐标比较。记录通过引用／固定大小值移动；容量预留成本放在初始化，满容量插入不修改堆。

FindMin(a) 检查根及到第一次遇到 a 维层为止的全部节点，遇到 a 维节点即停止进入其子树；共至多 1+2+⋯+2k−1<2k 个候选。删除后的每次下修检查当前节点以下至多 k 层的全部节点，到同维层时已代表更深子树；每次候选数 O(2k)，选择极值后补好至多 k−1 个中间祖先，再继续下降。总时间 O(2klogN)。

FixHeap 的线性系数需要更细地计数，不能给每个节点都乘 k。高度 h＜k 时，检查的只有整棵小子树，下修各次扫描几何缩小，总 O(2h)；高度 h≥k 时，成本不超过 O(2k(h−k＋1))，路径中间修复的 O(k) 被 O(2k) 吸收。于是

∑h<kN2hO(2h)+∑h≥kN2hO(2k(h−k+1))=O(kN)+O(N)=O(kN)

代码演示 k＝1…8；KMAX 是固定坐标数组容量，数学构造适用于任意 k。k 很大时 DeleteMin 的指数系数会迅速增加；维度固定时各操作仍分别为 O(logN)、O(logN)、O(N)。

12.29 · 只有第一维分支的 k-d 堆

原题（中文翻译）

抽象地推广 k-d 堆，让只有按关键字 1 分支的层有两个孩子，其他层都只有一个孩子。

  1. 还需要指针吗？
  2. 基本算法显然仍可使用。新的时间界是什么？

本版习题 12.29；印刷页 498／PDF 第 515 页。

解答

(a) 仍可用数组。把真正的二分节点抽成完全二叉骨架，骨架根编号 q＝1，单独放在数组 0。每个非根骨架节点 q≥2 与它前面的 k−1 个单链节点组成一块，共 k 个元素，依次按坐标 2、3、…、k、1 排列；块首索引为 1＋k(q−2)，块尾分支节点为 k(q−1)。按骨架编号顺序填块，末块允许仅填前缀。

因此数组索引 i 的分割坐标为 i mod k（从 0 计）：i mod k＝0 时，两个孩子为 2i＋1、2i＋k＋1；其他节点唯一孩子为 i＋1，只访问小于 N 的位置。块首的父亲可由 q 的骨架父编号 floor(q/2) 算出，其余节点父亲为 i−1。k＝1 时公式恢复普通零基完全二叉树。

(b) 完全骨架有 O(logN) 个分支层，每层间隔 k，实际高度为 O(klogN)。两个同维层之间最多只出现一次二分，候选区间是两条长度 O(k) 的链，FindMin 为 O(k)。直接沿用携带与下修算法，Insert 为 O(klogN)，每次下修扫描及修复 O(k)、下降路径 O(klogN)，DeleteMin 得到 O(k2logN) 的上界。

同样的直接 FixHeap 版本，高度小于 k 的尾链一次下修保守计 O(h2)；每个完整分支周期的节点数约减半。若骨架块高度为 j，每块 k 个元素，单元素下修保守计 O(k2(j＋1)2)，该高度块数 O((N/k)/2j)，求和为 O(k2N)。它将完全二叉版 DeleteMin 的指数系数换为多项式系数，同时增加实际高度。这些是直接复用本题基本算法的界；固定 k 时仍为对数插入／删除和线性建堆。

12.30 · k-d 搜索树的 DeleteMin

原题（中文翻译）

使用 k-d 树实现 DeleteMin。对于随机树，你预期它的平均运行时间是多少？

本版习题 12.30；印刷页 499／PDF 第 516 页。

解答

完整非递归实现见 kd_min_node、kd_delete_point、kd_delete_min。求第 a 维最小时：当前节点也参与比较；若当前按 a 维分割，只需进左树，其他维则要查两侧。找到极值点后，从根按坐标及 ID 到它的位置；若有右树，以右树中“当前位置分割维度”的最小点替换，并继续删替换点的原位置。若只有左树，取左树该维最小点，再把整棵剩余左树移为右树。最后在叶位摘除。

替换值不超过剩余右树的所有该维值，原左树仍小于旧分割值，因而也小于新的右侧极小值；只有左树时，选其极小值后，其他点均应归右，且移到同深度的右位置不改变 axis。这解释了为什么不能像普通 BST 那样直接用一个孩子提升到当前位置。坐标可重复，所有极值比较加入唯一 ID。

题目要求的是平均成本预期。对新近随机建立、独立连续坐标、固定 k＞1 的树，极值搜索要在 k−1 种分割层访问两侧，在本坐标层只访问一侧；用均衡规模估计，得 T(N)=2k−1T(N/2k)+O(1)，所以自然预期 O(N1−1/k)，二维为 O(√N)，而不是沿一条路径的 O(logN)。删除接续的极值替换通常发生在较小子树，不改变这个主量级预期。

这与 Bentley 1975 年原论文§5 的极值／根删除估计一致。该段是题目所问的模型估计：随机划分不能无条件当作每次精确二等分，持续删除也可能改变分布。对操作前已按中位数完全平衡的树，搜索以及下降替换各层的子树规模几何缩小，可用 12.25 的边界访问计数得到同阶最坏上界；若先按 12.21(c) 重建，则这次 O(NlogN) 预处理另外计入，不能算作免费。k＝1 单独为 O(logN)。空树返回失败，取得的是被删记录值。

12.31 · 带 DeleteMin 的双端队列

原题（中文翻译）

使用 k-d 堆实现双端队列（习题 3.26），并额外支持 DeleteMin。

本版习题 12.31；印刷页 499／PDF 第 516 页。

解答

使用 PriorityDeque 的三维堆。给每条记录分配队列顺序 t，存坐标 (t,−t,value)。尾端插入递增右端 t，前端插入递减左端 t；删前端取第 0 维最小，删后端取第 1 维最小，DeleteMin 取第 2 维最小。每个操作最坏 O(logN)，查询三个极值为 O(1)，初始化容量另计。

示例：尾入 8、前入 3、尾入 1，队列为 3、8、1；删前端得到 3，DeleteMin 得到 1，删后端得到 8。顺序标号只代表相对位置，不要求删除后连续。值平局由插入编号打破，DeleteMin 删除较早编号。

程序预留容量，满容量返回 false；空队列删除返回失败／None。顺序 t 限制在 −INT64_MAX…INT64_MAX，使 −t 可表示，编号也设 64 位上界；溢出或满容量在修改前拒绝。队列完全变空时可重置左右顺序；长期非空且持续单端插入的应用可更换更宽标号，或在标号耗尽时显式重编号并重建，将那次线性工作计入。

12.32 · 用 NullNode 表达配对堆

原题（中文翻译）

使用 NullNode 哨兵实现配对堆。

本版习题 12.32；印刷页 499／PDF 第 516 页。

解答

实现见 PairHeap。哨兵的 child、next、prev 都自指，空根、空孩子和兄弟链终点统一为 nil。pair_link 先处理任一输入为空，再比较真实根；不能给哨兵分配一个普通最小键并让它参加堆比较。

插入节点时三个指针均为 nil；剪切先修前驱与后继，再把本节点的 prev、next 重置为 nil 后合并；删除最小值把每个孩子拆成独立根，合并结束后新根的 prev、next 也为 nil。销毁只遍历真实节点，哨兵由调用者保存，不释放。

两个可常数时间合并的堆必须共享同一哨兵；否则合并后每个旧叶的空指针仍指向旧哨兵，遍历时会把它误认为真实节点。C 由调用者提供共用 Pair，Python 可显式传同一 nil。合并消费第二个堆，并要求记录 ID 在两个输入中互异、句柄归属合法。

12.33 · 标准双趟配对堆的摊还对数界

原题（中文翻译）

证明正文配对堆算法的每种操作摊还代价都是 O(logN)。

本版习题 12.33；印刷页 499／PDF 第 516 页。

解答

按左孩子／右兄弟二叉表示定义 s(x)：包括 x、其左孩子子树和右兄弟子树中的全部节点。它不是抽象多叉树里“x 的孩子后代数”。取 r(x)=log2s(x)，全体堆势能为 Φ=∑xr(x)≥0。这正是 Fredman 等 1986 年原论文 Theorem 1 的计账方式。

建立空堆、查询根不改势能。一次根链接至多改变两个根的二叉规模：原本较大规模的根至多翻倍，秩增至多 1；另一个根增至多 log N。插入是单节点链接；合并是两根链接。DecreaseKey 的剪切只减少旧祖先规模，再作一次根链接，因此实际常数工作加势能增量均为 O(logN)。

对 DeleteMin，设根有 d 个孩子、第一趟配对 q＝⌊d/2⌋ 次，以 x1,x2,… 标原兄弟链。一个非末尾配对只改变两个参与根的秩；对数凹性 logu+logv≤2log(u+v)−2 给出

ΔΦi≤2logs(x2i−1)−2logs(x2i+1)−2

最后一对没有尾部时，势能增量至多 2logs(x2q−1)。相加后，中间项望远镜消去，第一趟总增量至多 2logN−2(q−1)。第二趟从右向左合并，除最终根之外，每个二叉子树都能对应到一个合并前规模不小于它的子树，所以其势能增量至多 log(N−1)。摘除旧根再减 log N。

c^≤(2q+1)+2logN−2(q−1)−logN+log(N−1)≤2logN+3

这里基本成本按“摘根 1，加链接次数”计；第一趟链接数不少于第二趟，故 2q＋1 是实际链接上界。零或一个孩子直接处理，摊还常数；奇数孩子的末个未配对子树进入第二趟，同一界仍成立。程序拆链、保存孩子的线性工作与链接数同阶，用常数倍势能即可覆盖，动态数组没有隐藏额外渐近代价。

从空堆开始势能为 0，所有操作相加即得每种操作摊还 O(logN)。结论适用于本页标准双趟版；FIFO 变体改变第二趟，不能只凭相同链接总数套用这段证明。这里证明的是 O(logN) 的 DecreaseKey，上述推导没有给出常数摊还界。

12.34 · FIFO 合并兄弟子堆

原题（中文翻译）

CombineSiblings 的另一种方法是把所有兄弟子堆放入一个队列，反复 Dequeue 并合并队列前两个元素，把结果放到队尾。实现这种变体。

本版习题 12.34；印刷页 499／PDF 第 516 页。

解答

使用 pair_combine 的 mode＝1。拆开兄弟链并按原顺序写入数组队列；维护 front、end，两者之差是待合并树数。每轮取 a[front]、a[front＋1]，front 前进 2，合并结果写 a[end] 并令 end 前进 1。剩一个时返回，零个返回空哨兵。

初始 d 棵树，每轮减少一棵，共 d−1 次链接；新结果总共 d−1 个，故最多使用 2d−1 个数组槽，C 检查大小并分配 2d，Python 保存相同队列。实际时间 O(d)、临时空间 O(d)，不采用反复删除数组首元素导致的二次搬移。

例如根 6、3、4、5、9、7，前两轮分别产生 3、4，之后仍先处理等待的 9、7，得到 7，再处理 3、4；这种层次轮转不同于双趟的从右往左折叠。12.35 用同一接口比较三种次序，程序均核对排序输出及堆序。

12.35 · 单趟合并每次线性的操作序列

原题（中文翻译）

给出一个操作序列，证明上一题把队列换成栈是坏做法，会导致每次操作 Ω(N) 的代价。这就是从左到右的单趟合并。

本版习题 12.35；印刷页 499／PDF 第 516 页。

解答

先建立一个星形堆：根为 0，N 个叶子的键都大于 R，R 是接下来循环次数。第 i 轮先插入键 i，再删最小根 i−1，其中 1≤i≤R。插入把 i 放成旧根第一个孩子；删除后，兄弟从 i 开始，后面的 N 个背景叶都比它大。左到右单趟每次由 i 获胜，把败者作为自己的新孩子，最后又得到以 i 为根的星形堆。

归纳可见星形在每轮重现。该轮插入 1 次链接，删除 N 次链接，总为 N＋1；R 轮 2R 个操作累计 R(N+1) 次链接，平均 (N+1)/2=Ω(N)。初始建堆 O(N)，取 R 足够大即可摊薄，不是只举一个昂贵删除。记录键有限时预先选背景键 R＋1…R＋N 即可。

实验取 N＝128、512、2048，R＝128，背景键均大于 128；bad 驱动 比较双趟、FIFO 与单趟。初始星形在计时外，三次重新建立，计入后续插入、删除与临时数组，取 CPU 中位数。

12.36 · 省去 Prev 的配对堆与斜堆

原题（中文翻译）

不用 DecreaseKey 时，可以删去父指针。所得结构与斜堆相比有多强的竞争力？

本版习题 12.36；印刷页 499／PDF 第 516 页。

解答

配对堆的 Prev 既可能指父亲也可能指左兄弟，只为快速摘下任意句柄所必需；不提供 DecreaseKey 时，仅保留孩子与下一兄弟即可。下面与不递归的斜堆一起给出两指针实现；插入、合并与删除均以“键、编号”补全平局。两者管理自己的节点，删除释放根，位置句柄随删除失效。

class Compact:

    def __init__(self, key, ident): self.key, self.id, self.left, self.right = key, ident, None, None
class CompactHeap:
    def __init__(self, skew=False): self.root, self.n, self.skew, self.w = None, 0, skew, Work()
    def before(self, a, b):
        self.w.comparisons += 1
        return (a.key, a.id) < (b.key, b.id)
    def link(self, a, b):
        if a is None: return b
        if b is None: return a
        if self.before(b, a): a, b = b, a
        b.right, a.left = a.left, b; self.w.links += 1
        return a
    def skew_merge(self, a, b):
        first = tail = None
        while a is not None and b is not None:
            if self.before(b, a): a, b = b, a
            x, a = a, a.right; x.right, x.left = x.left, None
            if tail is not None: tail.left = x
            else: first = x
            tail = x; self.w.links += 1
        if tail is None: return a if a is not None else b
        tail.left = a if a is not None else b
        return first
    def insert(self, key, ident):
        x = Compact(key, ident)
        self.root = self.skew_merge(self.root, x) if self.skew else self.link(self.root, x)
        self.n += 1
    def combine(self, first):
        a = []
        while first is not None:
            nxt = first.right; first.right = None; a.append(first); first = nxt
        if not a: return None
        paired = [self.link(a[i], a[i+1]) for i in range(0, len(a)-1, 2)]
        if len(a)%2: paired.append(a[-1])
        answer = paired.pop()
        for x in reversed(paired): answer = self.link(x, answer)
        return answer
    def delete_min(self):
        if self.root is None: return None
        old = self.root
        self.root = self.skew_merge(old.left, old.right) if self.skew else self.combine(old.left)

共享定义、检查方法与实验驱动

本章树以键集合为接口，重复插入返回失败，但允许调整形状；k-d 记录与堆的编号要求在结构内唯一，合并后的编号也不能重复。C 的树与配对／斜堆拥有并释放节点；k-d 堆只保存调用者的 Point 值或引用。共享 Node 同时保留各练习所需字段，比较树的节点大小时不应把这份通用教学类型当成最小专用布局。普通坐标和键统一取有符号 64 位，Python 在同一输入域内运行；C 统计使用无符号机器整数，本页规模不溢出。分配失败报告并终止，Python 对应内存异常。

下列检查用集合、排序与线性扫描作参照，并逐步检查树序、红黑黑高度、AA level、treap 优先级、伸展 size、塔高度与前向边、k-d 堆全部祖先约束及配对堆 Prev。它们检查具体实现；一般复杂度由题内推导建立。代码组合顺序、入口与运行方法集中在 全局程序说明。
