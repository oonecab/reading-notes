一、§10.1：贪心必须有交换理由

第九章已经出现 Dijkstra、Prim 和 Kruskal。第十章把视角从“怎样把给定算法实现得高效”转向“怎样设计求解方法”。贪心每一阶段作一个当前看来最好的选择；做过之后不回头。它是否得到全局最优，要由问题结构决定。找零钱先取最大面额在某些币制成立，但面额 1、3、4 时，金额 6 用 4、1、1 就输给 3、3。

“we hope that the local optimum is equal to the global optimum”

我们希望局部最优等于全局最优。

§10.1，印刷页 349／PDF 366。这里的 hope 随后必须由证明兑现。

§10.1.1 假设所有作业时刻 0 可用、时长已知、不能抢占，目标是平均完成时间。四个时长 15、8、3、10 按给定顺序运行，完成时间为 15、23、26、36，平均 25；按 3、8、10、15 运行，完成时间为 3、11、21、36，平均 17.75。若排列为 t1,…,tN，完成时间总和是 Nt1+(N−1)t2+⋯+tN。较短作业放在较大的系数上，才能降低后续作业共同承担的等待。

相邻作业时长 a>b 却先执行 a，交换后两者的完成时间之和减少 a−b，其他作业完成时间不变。不断交换逆序对就得到 SPT，即最短处理时间优先。排序 O(NlogN)，输出 O(N)；若已有排序则无需重复排序。

三个相同处理器上的例子使用时长 3、5、6、10、11、14、15、18、20。把排序后的作业轮流交给处理器，三条序列为 (3,10,15)、(5,11,18)、(6,14,20)，完成时间总和 165，平均约 18.33；最后一台到 40 才结束。原书另一种最短作业分配保持同一平均值却把最后完成时间降到 38，最小化最后完成时间还能达到 34。这三个目标的差异解释了为什么不能把 SPT 的证明套到 makespan 上。多处理器的完整证明见 10.1，带收益与期限的单位作业见 10.2。

二、§10.1.2–10.1.3：同一种局部选择，得到两种保证

例：七种字符的 Huffman 编码

Huffman 从字符频率出发。书中 a、e、i、s、t、空格、换行的频率分别为 10、15、12、3、4、13、1，共 58 个字符。固定三位编码需 174 位；前缀树允许常见字符离根更近，而且不需要额外分隔码字。完整二叉树把最低频率的两个节点合并为一个节点，反复执行。合并权重依次为 4、8、18、25、33、58，其和 146 就是加权外部路径长度。

为什么能先合并最少的两个？任何最优满前缀树都有一对最深兄弟叶；把最低频率的两个符号交换到那里不会增加总位数。收缩这对叶后，两个频率相加，问题缩小一个符号；若缩小后的树还有更优解，展开它就能改进原树。交换与收缩一起构成归纳证明，见 10.5。左右枝和平频率可能产生不同码字，但位数相同。本页按“权重、创建编号”决定平局，叶按字节升序创建。

优先队列做两次删除最小值与一次插入，建立树 O(KlogK)；已有频率顺序时可以用两个队列做到 O(K)。本页另保存每个字节的码字，总代码长度为 O(K2) 的最坏上界；字节字母表 K≤256。文件是二进制流，包括空字节；频数与原长度使用无符号 64 位，溢出报错。空文件没有树，只有一种字节时可以使用长度 0 的码字，靠原长度恢复重复次数。

typedef struct { uint64_t weight; int left,right,symbol; } HNode;
typedef struct { HNode node[511]; int count,root; unsigned char code[256][256]; int len[256]; } Huffman;
int h_less(Huffman *h,int a,int b) {
    return h->node[a].weight<h->node[b].weight ||
        (h->node[a].weight==h->node[b].weight && a<b);
}
void h_push(Huffman *h,int *heap,int *n,int x) {
    int i=++*n;
    while(i>1 && h_less(h,x,heap[i/2])) { heap[i]=heap[i/2]; i/=2; }
    heap[i]=x;
}
int h_pop(Huffman *h,int *heap,int *n) {
    int ans=heap[1], x=heap[(*n)--], i=1;
    while(2*i<=*n) {
        int c=2*i;
        if(c<*n && h_less(h,heap[c+1],heap[c])) c++;
        if(!h_less(h,heap[c],x)) break;
        heap[i]=heap[c]; i=c;
    }
    if(*n) heap[i]=x;
    return ans;
}
void h_codes(Huffman *h,int u,unsigned char *path,int depth) {
    HNode *p=&h->node[u];
    if(p->symbol>=0) {
        h->len[p->symbol]=depth;
        memcpy(h->code[p->symbol],path,(size_t)depth); return;
    }
    path[depth]=0; h_codes(h,p->left,path,depth+1);
    path[depth]=1; h_codes(h,p->right,path,depth+1);
}
void h_build(Huffman *h,const uint64_t *freq) {
    memset(h,0,sizeof *h); h->root=-1;
    int heap[257], n=0;
    for(int s=0;s<256;s++) if(freq[s]) {
        int u=h->count++; h->node[u]=(HNode){freq[s],-1,-1,s}; h_push(h,heap,&n,u);
    }
    while(n>1) {
        int a=h_pop(h,heap,&n),b=h_pop(h,heap,&n),u=h->count++;
        h->node[u]=(HNode){add64(h->node[a].weight,h->node[b].weight),a,b,-1};
        h_push(h,heap,&n,u);
    }
    if(n) { unsigned char path[256]; h->root=heap[1]; h_codes(h,h->root,path,0); }
}

void h_compress(FILE *in,FILE *out) {
    uint64_t freq[256]={0}, size=0; int c;

    if(size) h_tree_write(out,h,h->root);

        bits=(bits<<1)|h->code[c][j];
        if(++used==8) { byte_write(out,(int)bits); used=0; bits=0; }
    }
    if(ferror(in)) fail("read error");
    if(used) byte_write(out,(int)(bits<<(8-used)));
    free(h);
}

    for(int i=0;i<4;i++) if(byte_read(in)!="WH10"[i]) fail("bad magic");
    uint64_t size=u64_read(in);
    Huffman *h=alloc(1,sizeof *h); unsigned char seen[256]={0};
    if(size) h->root=h_tree_read(in,h,seen,0);
    int bits=0, left=0;
    for(uint64_t i=0;i<size;i++) {
        int u=h->root;
        while(h->node[u].symbol<0) {
            if(!left) { bits=byte_read(in); left=8; }
            int bit=(bits>>(--left))&1;
            u=bit?h->node[u].right:h->node[u].left;
        }
        byte_write(out,h->node[u].symbol);
    }
    if(left && (bits&((1<<left)-1))) fail("nonzero padding");
    if(fgetc(in)!=EOF || ferror(in)) fail("trailing bytes or read error");
    free(h);
}

class Huffman:
    def __init__(self, freq=None):
        self.node = []
        self.root = -1
        self.code = [b'']*256
        if freq is None: return
        heap = [None]
        def less(a,b): return (self.node[a][0],a) < (self.node[b][0],b)
        def push(x):
            heap.append(x); i=len(heap)-1
            while i > 1 and less(x,heap[i//2]):
                heap[i]=heap[i//2]; i//=2
            heap[i]=x
        def pop():
            ans,x=heap[1],heap.pop(); i=1
            while 2*i < len(heap):
                c=2*i
                if c+1 < len(heap) and less(heap[c+1],heap[c]): c+=1
                if not less(heap[c],x): break
                heap[i]=heap[c]; i=c
            if len(heap)>1: heap[i]=x
            return ans
        for s,f in enumerate(freq):
            if f:
                self.node.append((f,-1,-1,s)); push(len(self.node)-1)
        while len(heap)>2:
            a,b=pop(),pop()
            self.node.append((add64(self.node[a][0],self.node[b][0]),a,b,-1))
            push(len(self.node)-1)
        if len(heap)==2:
            self.root=heap[1]
            def walk(u,path):
                _,a,b,s=self.node[u]
                if s>=0: self.code[s]=path
                else: walk(a,path+b'\0'); walk(b,path+b'\1')
            walk(self.root,b'')

例：同一序列的五种装箱结果

装箱则说明贪心有时只能近似。箱容量为 1，物品不可分，在线算法见到一件就必须决定放哪里，也不知道输入何时结束。对 0.2、0.5、0.4、0.7、0.1、0.3、0.8，最优需要 3 箱；Next Fit 只看当前箱，用 5 箱；First Fit 看最早放得下的箱，用 4 箱；Best Fit 选放入后余量最小的箱，也用 4 箱。先递减排序后的 FFD 与 BFD 在这个输入上都用 3 箱，但已是离线策略。

若最优需要 M 箱，Next Fit 的任意相邻两箱总负载大于 1，否则后箱第一件本来能放到前箱。两箱成对给出 NF≤2M−1（非空输入），足以得到书中 2M 上界；并存在接近两倍的序列。在线算法的 4/3 下界来自“先给许多略小于半箱的物品，可能立刻停止，也可能再给略大于半箱的物品”；更强的 3/2 构造完整见 10.8。

定理 10.3 与 10.5 · 装箱近似界

原书定理 10.3 给出 FF≤⌈17M/10⌉，定理 10.5 给出 FFD≤11M/9+4，是对容量 1、尺寸在 (0,1] 的物品序列成立的近似界。这里采用本版参考文献 [23] Johnson、Demers、Ullman、Garey、Graham（1974，Worst-case performance bounds for simple one-dimensional packing algorithms）已经证明的上界；常数界需要按尺寸分类计费，不能从“总量够放”直接推出。

证明：FFD 的较松上界

书中较容易证明的 FFD 界是 (4M+1)/3。假设第一件进第 M+1 箱的物品 x>1/3：此前每箱至多两件，且单件箱一定排在双件箱之前，否则较晚单件与 x 可塞入较早双件箱。前 j 个单件相互不能合箱，也不能容纳剩余大件；后面的 2(M−j)+1 件都大于 1/3，却只有 M−j 箱，矛盾。因此额外物品至多 1/3。若额外物品至少 M 件，把其中 M 件分别与前 M 箱配对，每一对负载都大于 1，总尺寸就大于 M，又矛盾。最多 M−1 件小物品，额外箱除最后一箱都可放至少三件，于是额外箱数至多 ⌈(M−1)/3⌉，得到所述界。

例：FFD 的下界构造

图 10.28 的下界构造为 6M 件 1/2+ε、6M 件 1/4+2ε、6M 件 1/4+ε、12M 件 1/4−2ε。FFD 先把每个大件与第二类的一件配对，第三类每三件一箱，最后一类每四件一箱，共 6M+2M+3M=11M 箱；最优用 6M 箱各放第一、第三、第四类一件，再用 3M 箱各放第二、第四类两件，共 9M 箱。这里 0<ε<1/24，三类合计恰为 1。原书前一句提及 next fit decreasing，但本定理陈述及该构造讨论的算法是 first fit decreasing。

程序把容量与尺寸按同一整数比例表示，避免小数舍入改变可行性。First Fit 的区间树存每段箱子的最大余量，从根优先走左边找到最早箱；Best Fit 的 AVL 树键为（余量、箱号），找最小的可用键。更新各需 O(logN)，两版递减排序都用稳定归并，平尺寸保持输入顺序。Next Fit 线性，其余包括排序在内 O(NlogN)，保存分配结果及索引的空间均 O(N)。

typedef struct Avl { int rem,id,height; struct Avl *left,*right; } Avl;
int ah(Avl *p) { return p?p->height:0; }
void afix(Avl *p) { int a=ah(p->left),b=ah(p->right); p->height=1+(a>b?a:b); }
Avl *aright(Avl *p) { Avl *q=p->left; p->left=q->right; q->right=p; afix(p); afix(q); return q; }
Avl *aleft(Avl *p) { Avl *q=p->right; p->right=q->left; q->left=p; afix(p); afix(q); return q; }
Avl *abalance(Avl *p) {
    if(!p) return p;
    afix(p);
    if(ah(p->left)-ah(p->right)>1) {
        if(ah(p->left->left)<ah(p->left->right)) p->left=aleft(p->left);
        return aright(p);
    }
    if(ah(p->right)-ah(p->left)>1) {
        if(ah(p->right->right)<ah(p->right->left)) p->right=aright(p->right);
        return aleft(p);
    }
    return p;
}
int akless(int rem,int id,Avl *p) { return rem<p->rem || (rem==p->rem && id<p->id); }
Avl *ainsert(Avl *p,int rem,int id) {
    if(!p) { p=alloc(1,sizeof *p); p->rem=rem; p->id=id; p->height=1; return p; }
    if(akless(rem,id,p)) p->left=ainsert(p->left,rem,id);
    else p->right=ainsert(p->right,rem,id);

}
Avl *aerase(Avl *p,int rem,int id) {
    if(!p) fail("AVL missing key");
    if(rem==p->rem && id==p->id) {
        if(!p->left || !p->right) { Avl *q=p->left?p->left:p->right; free(p); return q; }
        Avl *q=p->right; while(q->left) q=q->left;
        p->rem=q->rem; p->id=q->id; p->right=aerase(p->right,q->rem,q->id);
    } else if(akless(rem,id,p)) p->left=aerase(p->left,rem,id);
    else p->right=aerase(p->right,rem,id);
    return abalance(p);
}

}

四、§10.2.2–10.2.3：控制合并量，也控制留下来的量

最近点对直接枚举需要 Θ(N2)。先按 x 排序，再按排序位置分成两半，分别得到距离 δL,δR。令 δ=min(δL,δR)，跨界的改进点对只能在分割线两边各 δ 宽的条带内。若重扫条带所有点对，仍可能平方；必须利用两个半区内已经没有距离小于 δ 的点对。

对条带按 y 排序，只比较 y 差小于 δ 的后继。在宽 2δ、高 δ 的局部矩形内，把每个半区切成四个边长 δ/2 的小格，同一半区一个小格至多一个点，否则距离小于 δ。边界按半开格与同距离不更新处理，一个点只需看后面至多七个候选。递归结束时把两半的 y 顺序线性归并，因此每层 O(N)，总时间 O(NlogN)，辅助空间 O(N)。

排序划分按位置和稳定编号进行，使所有 x 相等也能平衡分开；分割 x 在递归前保存，因为递归会把数组改为 y 顺序。重复点直接得到距离 0。这里坐标限定为 ±10⁶ 内整数，返回平方距离，差值乘积与总和用 64 位精确表示；不依靠浮点阈值。

随机算法的期望通常针对固定输入、算法内部的随机选择，不是对随机输入取平均。快速选择改变枢轴，跳跃表改变层高；这类过程始终返回正确结果，代价是随机变量。概率素数判定则在有限轮内可能把合数报告为“尚未发现合数证据”，需要单独讨论错误率。伪随机生成器的固定种子让运行可复现，但并不把输出变成独立理想随机数。

线性同余生成器 Xi+1=AXimodM 的例子使用 A=48271、M=2³¹−1。种子必须在 1…M−1，0 会永远留在 0。直接乘法在旧的 32 位类型上可能溢出；有符号溢出在 C 中未定义，无符号回绕虽有定义，却改变模数。按 Schrage 的 Q=44488、R=3399 计算 A(XmodQ)−R⌊X/Q⌋，若非正再加 M，可避免溢出。本页共享实现采用固定宽度类型，区间随机数使用拒绝法消除取模偏差。

跳跃表把有序链表中的每个节点随机提升：首层总在，之后每次以概率 1/2 再升一层，故 Pr(H≥k)=2−(k−1)、期望层数为 2。查找从最高层向右走，不能超过目标时下降；插入先记录各层前驱，再一次接入节点；删除先找到前驱再释放节点。节点只分配自己的层数，本页最高 32 层、最多 10⁶ 个节点；理论期望论证中的独立公平选择，与固定伪随机实验的观测分开，见 10.37。

八、§10.5：探索之后，准确撤销

回溯先扩展一个部分解，发现不可能再成为完整解时撤销，再尝试下一条分支。收费公路重建输入的是所有两点距离，共 N(N−1)/2 个，重复距离必须保留重数。先把点 0 与最大距离 L 放在两端；当前最大剩余距离 d 必须来自尚未放置的最右点到 0，或最左点到 L，所以只需试 d 与 L−d。对候选 v 检查它到每个已放点的距离，必须从多重集中逐次扣除；任何一项缺失都恢复此前扣除的距离。

原书的多重集为 1、2、2、2、3、3、3、4、5、5、5、6、7、8、10。固定 0、10，放 8 后先试 7；之后的 6 需要已没有的距离 1，4 需要两个距离 4 也失败。撤销 7 改试 3，随后放 6、5，得到 (0,3,5,6,8,10)。先前通过的部分检查不能替代完整恢复。下面列举所有正规化解，保留镜像，重复完整点集只输出一次。距离索引用归并排序和二分查找，多重数独立保存。程序限制 N≤12、输出≤65536 个解；成功单分支成本 O(N2logN)，分支数可能指数增长。

10.1 · 多处理器最短作业优先的证明

原题（中文翻译）

证明：多处理器作业调度中，用来最小化平均完成时间的贪心算法是正确的。

本版习题 10.1；印刷页 417／PDF 第 434 页。

解答

假设 P 个相同处理器，作业均在时刻 0 可用，时长为正，非抢占；把作业按时长递增，按处理器循环顺序分配并连续运行。考虑任何一台处理器有 m 个作业，其完成时间总和把队列中的时长分别乘以 m、m−1、…、1。固定各处理器的作业数时，交换论证要求全体最短时长对应全体系数中的最大者。

各处理器的作业数还必须相差至多 1：若一台有 a 件、一台有 b 件且 a≥b+2，将计数改为 a−1、b+1，会把系数多重集中的 a 替换成较小的 b+1，其他系数保持；对正时长，重新按最优配对后总价严格下降。故最优计数一定均衡。

写 N=qP+r，0≤r<P，r 台各 q+1 件，其余各 q 件。循环分配的时长对应系数依次为：先 r 个 q+1，再 P 个 q，再 P 个 q−1，直到 1，恰为全体系数递减顺序；它同时满足最优计数与最优配对，故最小化完成时间总和，也最小化平均值。N<P 时每件直接占一台；零时长允许时严格下降改为不增加，结论仍成立。

10.2 · 单位作业、期限与收益

原题（中文翻译）

输入为 N 个作业 j1,…,jN，每个完成需一个时间单位。作业 ji 在期限 ti 前完成可挣 di 美元，超过期限则没有收益。

  1. 给出一个 O(N2) 的贪心算法解决此问题。
  2. 修改算法，得到 O(NlogN) 时间。提示：时间界完全来自按收益排序，其余部分可以借助不相交集在 o(NlogN) 内实现。

本版习题 10.2；印刷页 417／PDF 第 434 页。

解答

按收益递减、相同收益按输入编号排序；每次把作业放到不超过期限的最晚空槽，若没有空槽就跳过。期限可截断为 N，收益为零可以省略。最晚放置给更紧的后续期限留位置。选中集合的可行性等价于：对每个期限 d，期限≤d 的作业数至多 d。

这个可行集合满足交换性质：给可行集合 A、B 且 |A|<|B|，若 B 中而不在 A 的每个作业加入 A 都不可行，它们的期限各落在 A 的一个已饱和前缀内；取这些饱和期限的最大者 d，所有 B 中而不在 A 都在 d 内，而 A 在 d 内已有 d 件，A 中而不在 B 在 d 内的件数少于 B 中而不在 A，便使 B 在 d 内超过 d 件，矛盾。因此能交换加入一个作业；这是单位期限调度拟阵。按权重递减接受可行作业的交换证明给出最大收益，晚槽策略正好实现可行性检查。

(a) 从期限向左线性找槽，排序后最多 N 次各 O(N)，总 O(N2)。(b) 槽 0 是“没有空位”的哨兵；已占用槽与左邻槽合并，每个并查集代表保存本分量最左的空槽 avail。Find 配路径压缩，Union 配秩，不把代表编号强迫成槽号；每件 O(α(N)) 摊还，总 O(NlogN)+O(Nα(N))。下面给出同一函数的线性找槽与并查集两种模式，C 的 slots[1…N] 与 Python 的结果列表对应。

原题（中文翻译）

10.5 · 完整证明 Huffman 最优

原题（中文翻译）

完成证明：Huffman 算法产生最优前缀码。

本版习题 10.5；印刷页 417／PDF 第 434 页。

解答

先只考虑正频率符号。最优树可取为满二叉树：若内部节点只有一个孩子，删除这一层会降低其后所有叶深，故不可能严格最优。选最深叶 x；其兄弟也必须是叶，否则存在更深叶。令 a、b 为最低的两个频率，把它们分别交换到这对最深兄弟位置。

交换频率 fa≤fx、深度 da≤dx 时，代价变化为 (fa−fx)(dx−da)≤0；再交换 b 同理，故存在一棵最优树，使 a、b 是最深兄弟。把这对叶收缩为频率 fa+fb 的符号 c，原树代价等于缩小树代价加 fa+fb。

如果收缩树不是缩小问题的最优树，替换成更优树并展开 c，就会得到比原最优树更好的码，矛盾。由 N=1 的零长度码或 N=2 的一步合并作基例，对 N 归纳，最低频率合并加上缩小问题的最优解必为全局最优。零频率符号可从输入字母表删除；若要求保留，零权叶的交换使用非严格不等式，结论仍适用。

10.6 · 频率已排序时线性构建 Huffman

原题（中文翻译）

证明：若符号已按频率排序，Huffman 算法可以在线性时间内实现。

本版习题 10.6；印刷页 417／PDF 第 434 页。

解答

保存两个 FIFO 队列：Q1 是升序的原叶，Q2 是已建立的内部节点。每次在两队队首中取较小者，两次取最小后相加形成父节点，追加到 Q2 尾；平权统一选择创建编号小的。

Q2 保持升序。某次取出的最小两项为 a≤b，下次取出的两项都不小于 b；新插入的 a+b 也不小于 b。因此下一次合并的权重至少 a+b，后续父权单调。两个有序队列的队首包含全局最小项，所以每步与优先队列算法相同，最优性随之成立。N−1 次合并、每次常数个队首操作，树建立时间 O(N)、空间 O(N)。已有排序是前提；若还需频率排序，总时间仍 O(NlogN)。

10.8 · 在线装箱的 3/2 下界

原题（中文翻译）

证明：任何在线装箱算法都可被迫使用至少最优箱数的 3/2 倍。考虑依次到达的三组物品：N 件尺寸 1/6−2ε，N 件尺寸 1/3+ε，N 件尺寸 1/2+ε。

本版习题 10.8；印刷页 417／PDF 第 434 页。

解答

取 N 为 12 的倍数，0<ε<1/84；对手可在任何一组结束后停止。记 a=1/6−2ε、b=1/3+ε、c=1/2+ε。仅 A 组的最优是 N/6 箱，因为每箱至多六件；A+B 的最优是 N/2 箱，每箱各两件（2a+2b<1），且 b 每箱至多两件；A+B+C 的最优是 N 箱，各一件恰好装满，因为 a+b+c=1，而 c 每箱至多一件。

算法在 A 后开 n 箱，B 后开 m 箱。若 n≥N/4，立即停止就达到 3/2；若 m≥3N/4，在 B 后停止也达到。只需考虑 n<N/4、m<3N/4。令 U 为 B 后剩余空间小于 c 的箱数。

一个 A 阶段已经存在的箱，装 u 件 a、v 件 b。能继续装 c 时有 u/2+v≤2：v=0 时 u≤3，v=1 时 u≤1，v≥2 不可放 c；不能放 c 时，由容量可得 u/2+v≤3。一个 B 阶段新开的箱装 v 件 b，满足 v≤1+I(不能装 c)。汇总 N 件 a 与 N 件 b：

32N≤2n+(m−n)+U=n+m+U

所以 U≥3N/2−n−m>N/2。C 到来后，最多 m−U 个已有箱能各收一件，其他 C 必须新开箱，最终箱数至少 m+N−(m−U)=N+U>3N/2。三种停止方式必有一种达到所需比例。这是对任意确定性在线算法的自适应输入／停止构造；不直接等同于对随机算法及固定输入分布的同一错误或期望界。

10.9 · First Fit 与 Best Fit 的对数查找

原题（中文翻译）

解释如何在 O(NlogN) 时间内实现 First Fit 与 Best Fit。

本版习题 10.9；印刷页 417／PDF 第 434 页。

解答

First Fit 以箱号为叶下标，区间树保存该段最大余量；根余量不足就新开箱，否则优先选择最大余量足够的左子段，直到叶。得到的是最早可行箱，而不是最大余量箱。每次放入后从叶向根更新，O(logN)。

Best Fit 用 AVL 树存（余量、箱号），下界查询最小的余量≥物品尺寸，余量相同时选最早箱；放入前删除旧键、之后插入新键。平衡高度 O(logN)，每件常数次查询、删除与插入，总 O(NlogN)、空间 O(N)。对应两版全部定义见 装箱实现。直接扫描箱子的实现仍可能平方，单纯按余量排序不能实现 First Fit 的箱号优先。

10.13 · 不等比例子问题的线性界

原题（中文翻译）

证明定理 10.8。

原书上下文：T(N)=∑i=1rT(αiN)+O(N)，r 与各比例固定、αᵢ>0，且 ρ=∑iαi<1。

10.17 · 三元素分组选择能证明什么界

原题（中文翻译）

快速选择采用“三个一组的中位数，再取这些中位数的中位数”划分策略时，渐近运行时间是多少？

本版习题 10.17；印刷页 418／PDF 第 435 页。

解答

每组至少两个元素位于该组中位数的同一侧，因此枢轴两侧各能排除 N/3−O(1) 个元素。标准最坏情况递推是 T(N)≤T(N/3)+T(2N/3+O(1))+cN。忽略常数取整，用归纳假设 A xlog x，两个子式的和为 ANlogN+AN[(1/3)log(1/3)+(2/3)log(2/3)]；方括号为负，选 A 足够大即可吸收 cN，严格得到 O(NlogN) 上界。读取一般输入还需要 Ω(N)。

这里不能把递推不等式直接改成等式，从而声称已证明 Θ(NlogN)。求中位数组与保留分支的最坏输入受到同一组比较结果约束，未证明能同时实现两个上界。Chen、Dumitrescu《Selection Algorithms with Small Groups》（2019），§3 与 §8 明确区分这点。标准分析严格给出的结论是 Ω(N)≤T(N)≤O(NlogN)；紧确的下界不由这个递推不等式推出。

若要求确定的线性改进，连续做两轮三元素分组：N/3 个中位数再分组，得到 N/9 个“中位数的中位数”，递归只在它们上选择枢轴。至少 N/9 个第一轮中位数在每侧，每个保证两个原元素，即每侧可丢 2N/9−O(1) 个；递推 T(N)≤T(N/9)+T(7N/9+O(1))+O(N)，比例和 8/9<1，所以 Θ(N)。这个变体有完整线性证明，区别于题干的单轮三元素版本。

10.18 · 七元素分组的线性证明

10.20 · 复用五元素组的比较信息

原题（中文翻译）

本版习题 10.20；印刷页 418／PDF 第 435 页。

解答

先讨论互异元素，组内排序为 a≤b≤m≤d≤e。若 m<pivot，a、b、m 已确定在小侧，只需比较 d、e；若 m>pivot，m、d、e 已在大侧，只需比较 a、b。枢轴所属组直接按次序分类，不需再与枢轴比较。

令 g=⌊N/5⌋。若对其余组中位数各补一次比较，需要至多 (g−1)+2(g−1)=3g−3 次划分比较，加上不足五件的尾组；普通扫描接近 N−1 次。若递归选择中位数组时已经保存每个中位数相对枢轴的分类，便连 g−1 次也可省，最多 2g−2+O(1)。必须保存中位数的原组编号，不可在交换中位数组后误配。

重复值情况下已知的是≤或≥，三路划分要进一步区分等号；可以额外比较这些已知方向的元素，或采用稳定编号使键互异后对数值等值段计数。此题的比较节省结论针对复用偏序的设计；本页实际实验使用更直接的三路扫描，因此表中的比较数不声称已经采用这个优化。

10.21 · 抽样秩偏移、失败概率与样本量

原题（中文翻译）

完成 §10.2.3 末尾抽样算法的分析，并解释如何选择 δ 与 s。

本版习题 10.21；印刷页 418／PDF 第 435 页。

解答

题干校注：书中 δ 是样本里的秩偏移；全体输入中候选区间的规模应换算为 Nδ/s。下述期望比较数分析针对互异键、独立均匀无放回样本；有重复键的程序仍正确，但不借此宣称同一领先比较常数。

用一开始的 1 起始目标秩 K。抽 s 个样本，令 r1=⌊Ks/N⌋−δ、r2=⌈Ks/N⌉+δ，样本这两个秩为 l、u；越界秩用 −∞ 或 +∞。全体中目标之前的元素在样本里的数量为超几何变量，均值约 Ks/N。目标落在 [l,u] 之外要求该数量偏离均值至少 δ（取整只需固定常数校正）。无放回 Hoeffding 界给出

Pr(目标未被包住)≤2exp(−2δ2/s)

取 δ=⌈2slogN⌉，使失败概率至多 2N⁻⁴；失败时用完整线性选择，期望额外代价 O(N⁻3)。程序另外直接计数等于上界 u 的元素，目标在这个等值段时立即返回。

均匀无放回样本第 r 个元素在全体的期望秩为 r(N+1)/(s+1)。因此两个端点之间的期望元素数 O(Nδ/s)，在边界截断时仍同阶。先与 u 比较全部 N 件，再仅对小于 u 的元素比较 l，平均比较数至多 N+K+O(Nδ/s)，两个样本选择花 O(s)，候选线性选择花期望 O(Nδ/s)。对右侧目标镜像，有

E[C]≤N+min(K,N−K)+O(s+NlogNs)

令两项同阶：s=NlogN/s，得到 s3=N2logN，即 s=Θ(N2/3log1/3N)、δ=Θ(N1/3log2/3N)。于是余项为 O(N2ᐟ3log¹ᐟ3N)，比 N 小，选择中位数接近 1.5N 比较。端点求解必须用线性选择而非对样本完全排序，否则样本成本要多算一个 log s。

实现见 抽样选择：每个样本取自部分 Fisher–Yates 洗牌而非有放回随机下标，δ 超过样本边界使用哨兵；候选失败时有完整线性回退。固定伪随机种子的实验核对结果与成本，概率不等式依赖理想样本假设。

10.24 · 和式乘法与差式乘法

原题（中文翻译）

10.25 · 五个三分之一乘积与任意固定 ε

原题（中文翻译）

  1. 说明如何将两个数的乘法化为五个约为原规模三分之一的乘法问题。
  2. 推广，得到对任意固定 ε>0 的 O(N1+ε) 算法。
  3. (b) 的算法是否优于 O(NlogN)？

本版习题 10.25；印刷页 418／PDF 第 435 页。

(a) 分三段，写 X=x0+x1B+x2B2、Y 同理。把位权暂换成变量 t，乘积 Z(t) 是四次多项式。只求 t=0、1、−1、2 处的四个积和最高项 z4=x2y2（t=∞），每个子操作数约 N/3 位，固定小倍数仅增加常数位。

z0=p0,z4=p∞,o=(p1−p−1)/2=z1+z3
z2=(p1+p−1)/2−z0−z4,v=(p2−z0−4z2−16z4)/2=z1+4z3
z3=(v−o)/3,z1=o−z3,XY=∑i=04ziBi

10.26 · Strassen 为什么不能交换乘积顺序

原题（中文翻译）

本版习题 10.26；印刷页 418／PDF 第 435 页。

递归时每一个“元素”成为一个子矩阵。子矩阵加法仍可交换与结合，乘法通常不交换：AB 与 BA 可能不同。只有保持左矩阵子块在左、右矩阵子块在右，且仅使用分配律、结合律和加减恒等式，七积公式才能在下一层仍有效。

10.33 · 四边形不等式与 Knuth 的平方时间优化

原题（中文翻译）

设 C(i,i)=0，否则 C(i,j)=W(i,j)+mini<k≤j(C(i,k−1)+C(k,j))。W 满足四边形不等式：对 i≤i′≤j≤j′，

W(i,j)+W(i′,j′)≤W(i′,j)+W(i,j′)

并且单调：若 i≤i′ 且 j≤j′（相关区间有效），W(i′,j)≤W(i,j′)。

  1. 证明 C 也满足四边形不等式。
  2. 令 R(i,j) 是达到最小值的最大 k（平局取最大 k）。证明 R(i,j)≤R(i,j+1)≤R(i+1,j+1)。
  3. 证明 R 沿每行、每列都不下降。
  4. 由此证明 C 的全部条目可以在 O(N2) 时间计算。
  5. 哪些动态规划算法可以用这项技术做到 O(N2)？

本版习题 10.33；印刷页 419／PDF 第 436 页。

解答

(a) 先证明相接区间，再证明四边形

以下对外层跨度归纳，基例空区间成立。先证 C(a,c)+C(c,d)≤C(a,d)。取 C(a,d) 的最优根 k：若 k≤c，用同一 k 作 C(a,c) 的候选，由较短区间归纳 C(k,c)+C(c,d)≤C(k,d)，再用 W(a,c)≤W(a,d)，即可；若 k>c，用 k 作 C(c,d) 的候选，归纳 C(a,c)+C(c,k−1)≤C(a,k−1)，配 W(c,d)≤W(a,d)，同样得到。

现取 a≤b≤c≤d，b=c 已由上一段处理。令 k 是 C(a,d) 的最优根，l 是 C(b,c) 的最优根。若 k≤l，用 k 作 C(a,c) 候选、l 作 C(b,d) 候选；加上 W 的四边形不等式，以及较短区间的

C(k,c)+C(l,d)≤C(l,c)+C(k,d)

其他两项 C(a,k−1)、C(b,l−1) 保持，得到 C(a,c)+C(b,d)≤C(b,c)+C(a,d)。若 k>l，改用 l 作 C(a,c) 候选、k 作 C(b,d) 候选；这次较短区间不等式为

C(a,l−1)+C(b,k−1)≤C(b,l−1)+C(a,k−1)

配同一个 W 不等式，仍得到所需结果。子区间严格短于外跨度，归纳闭合。

(b) 平局取最右根才与证明一致

令 p=R(i,j)、q=R(i,j+1)，反设 p>q。两区间的最优性不等式相加，左半成本抵消，得到

C(p,j)+C(q,j+1)≤C(q,j)+C(p,j+1)

由 (a) 在 q≤p≤j≤j+1 上应用四边形不等式，反向不等式也成立，因此等号成立；p 也达到 (i,j+1) 的最小值且比 q 大，违背最大根选择。故 p≤q。

再令 p=R(i,j+1)、q=R(i+1,j+1)，反设 p>q。两最优性不等式相加，右半成本抵消，得到

C(i,p−1)+C(i+1,q−1)≤C(i,q−1)+C(i+1,p−1)

四边形不等式又给反向，故 p 也是右区间的更大最优根，矛盾。于是 R(i,j+1)≤R(i+1,j+1)，两端结论成立。

(c)–(e) 搜索范围与总工作量

第一条就是沿行单调，第二条把 j+1 改成 j 就是沿列单调。求 C(i,j) 时只试 R(i,j−1)≤k≤R(i+1,j)，并截到 i+1…j。长度 ℓ 固定时，令 Aᵢ=R(i,i+ℓ−1)，所有候选数之和至多 ∑i(Ai+1−Ai+1)，相邻项抵消，端点差与区间数均 O(N)。共有 N 个跨度，总 O(N2)，前提 W 可以 O(1) 取得；成本及根表空间 O(N2)。

成功／失败最优 BST 的 W 是非负区间和，四边形式两边实际相等，包含关系给出单调，所以适用。一般矩阵链的额外成本 dᵢ₋₁dₖdⱼ 依赖 k，不是这个固定 W；Floyd 也不是同一段区间根递推，不能直接套用。加速实现 将根的最大平局规则与上述范围一致保留。

10.37 · 跳跃表操作期望对数界的正式证明

原题（中文翻译）

本版习题 10.37；印刷页 419／PDF 第 436 页。

解答

固定 N 个互异有序键与一次查询，层高独立，Pr(H≥h)=2−(h−1)。最大层高 Hmax 满足 Pr(Hmax≥h)≤min(1,N2−(h−1))。对 h 求尾概率，前 ⌈log₂N⌉ 层加上几何尾部得到 E[Hmax]=O(log(N+1))。

反向看一次查找路径：在某层向左回走，遇到一个同时存在于上一层的节点便能向上。每个当前层节点独立以 1/2 升层，回走次数由成功率 1/2 的几何变量控制，包含成功位置的期望至多 2。每一层下降或反向上升另为常数工作，故每层期望常数，取固定 L=⌈log₂N⌉+1，低于 L 的层每层期望常数，共 O(logN)；更高层的水平移动最多为该层全部节点数，期望之和 Σh>L N·2⁻⁽ʰ⁻¹⁾=O(1)，高层下降次数的期望也由最大层高的几何尾得到 O(1)。这样得到完整对数界，不把随机 Hmax 与路径次数误作独立。

插入先做查找，新增 H 个指针的期望为 2；删除查找之后最多撤 H 个指针，期望同阶。若封顶在 L 层，顶层可能还要扫描期望 N/2L−1 个节点，因此统一界为 O(L+N2−L)；L=⌈log₂N⌉+O(1) 时仍对数。本页 L=32、N≤10⁶，使额外项小于常数；无限扩容却保持固定 L 不能继续声称渐近期望对数。固定伪随机实验也不能替代独立公平层高假设。

原题（中文翻译）

本版习题 10.40；印刷页 419／PDF 第 436 页。

解答

使用 完整多重集回溯程序。输入数量必须正好为 N(N−1)/2，距离为正，固定起点 0，终点为最大距离。每层仅试当前最大剩余距离 d 与 L−d，逐项扣除候选到已放点的全部距离，任何检查失败都恢复已经扣除的部分；成功递归返回后也恢复，以枚举其他解。

    }

原题（中文翻译）

解答

原书上下文：每场有唯一胜者，无平局；比赛结果构成 tournament，有向完全图每对点只有一个方向。

递归把选手分成两半，各得到相邻者获胜的路径。归并两条路径时，比较两个队首的比赛结果，把获胜者放入输出并从其路径弹出，继续；一条用完便追加另一条。

归并为何仍是一条胜者路径：刚弹出的左队首同时赢过当前右队首（本次比较）与其新的左队首（左路径原本相邻胜利）；下一次无论弹哪一边，都被刚输出者战胜。右侧弹出同理，只有一侧时由原路径成立。单点基例，加归并归纳便证明 (a)。每次归并至多 N−1 次比赛查询，T(N)=2T(N/2)+O(N)=O(NlogN)，额外 O(N) 缓冲及 O(logN) 栈。

它只是相邻胜利关系，不要求排前者战胜全部排后者；三人循环 A→B→C→A 仍有路径 A,B,C。比赛关系不满足传递性，所以不能把它当作普通排序比较器使用。

实现把已经合法的胜负矩阵作为只读、常数时间查询接口，路径构造本身 O(NlogN)。矩阵满足 win[i][i]=0，且每对不同选手恰有一方向为 1；读取并校验完整 N×N 输入另需 O(N2)，路径算法的 O(NlogN) 仅计算已经合法的矩阵查询与归并。N≤2048，空输入返回空路径，胜者由矩阵唯一决定。C 返回的路径由调用者 free；依赖共享定义。三人循环 0→1→2→0 的示例输出 0、1、2。

10.52 · 右对齐排版与线性打印机特例

原题（中文翻译）

右对齐段落包含词 w1,…,wN，长度 a1,…,aN，要分成宽度 L 的行。词之间理想空白宽 b（毫米），可伸缩但严格大于 0，使一行 wᵢ…wⱼ 恰为 L；每个空白 b′ 收 |b′−b| 丑度。最后一行只在 b′<b 时收费，因为它不必对齐；否则丑度为 0。对 j>i，某行所有空白取平均宽 b′ 后，费用为

∑k=ij−1|bk−b|=(j−i)|b′−b|

最后一行仅在 b′<b 时也使用上述收费，否则为 0。

  1. 给出动态规划，求整个段落丑度最小的排版。提示：按 i=N、N−1、…、1，计算后缀 wᵢ…wN 的最优排法。
  2. 以 N 为词数，给出时间与空间复杂度。
  3. 改用行式打印机，理想 b=1（一个空格），空白不能缩小，因为下一级为 0。给出线性时间生成最小丑度排版的算法。

本版习题 10.52；印刷页 422／PDF 第 439 页。

解答

(a) 前缀和 O(1) 求词长和 A(i,j)。j>i 且 A(i,j)<L 时可行，平均空白 b′=(L−A(i,j))/(j−i)>0，非末行费用 |L−A(i,j)−(j−i)b|，末行费用 max(0,(j−i)b−(L−A(i,j)))。任意不等空白的丑度至少为“空白数乘平均偏差”，由绝对值三角不等式得到；把空白均分能达到这个下界，所以只枚举平均宽不漏最优。单词非末行只能 aᵢ=L 才恰满行，费用 0；单词末行 aᵢ≤L，费用 0；其他候选为∞。把单词特例写清才能遵守“只有词间空白”的原模型。

F(N+1)=0,F(i)=mini≤j≤N{linecost(i,j)+F(j+1)}

(b) 每个 i 枚举后面的 j，保存最优断点；按后缀长度归纳，首行选 j 后剩余必用 F(j+1)，所以全体最优。时间 O(N2)，前缀、费用和断点 O(N) 空间，沿断点打印 O(N)；没有可行候选则报告不可排。

(c) aᵢ、L 为正整数、不缩空白。定义 Sj=∑k=1j(ak+1)，行 i…j 的理想宽度 Sj−Si−1−1；两指针 O(N) 求每个 i 的最大可行尾 rᵢ，满足 Sri−Si−1≤L+1。末行若 rᵢ=N 则费用 0。非末、至少两词的行有费用 L+1+Si−1−Sj，故

F(i)=L+1+Si−1+mini+1≤j≤min(ri,N−1){F(j+1)−Sj}

另比较 aᵢ=L 时的单词行 F(i+1)，以及能作为末行时的 0。从 i=N 递减，候选 j 的合法窗口向左移动：加入新 j=i+1（小于 N 且 F(j+1) 有限），用递减 j、递增键 F(j+1)−Sⱼ 的单调队列维护；加入时从队尾删除不更小的旧键，rᵢ 变小时从队首删除 j>rᵢ。队首就是当前最小候选，记录其 j 作断点。每个 j 仅入队、出队一次，连同求 r 与恢复，O(N) 时间、O(N) 空间。

删除旧键的理由是新 j 更小，在后续窗口中的寿命不短，且费用不大，因而旧候选永远不会再优于它。这个方法保留严格单词行规则；若简单“尽量塞满当前行”，宽 10、词长 1,4,1,8,2 会先塞前三词，让 8 独占非末行却不能拉到 10；可行排法是 (1,4)、(1,8)、(2)。因此原模型下不应跳过单词特例而直接宣布贪心成立。

10.56 · 精确子集和及伪多项式界

原题（中文翻译）

背包问题的一种形式：给整数集合 A={a1,…,aN} 与整数 K，是否存在 A 的一个子集，元素和恰为 K？

  1. 给出 O(NK) 算法。
  2. 为什么这不能说明 P=NP？

本版习题 10.56；印刷页 423／PDF 第 440 页。

解答

题干校注：按 0…K 建表要求 ai≥0、K≥0。原题只写“整数”；有负数时必须扩展状态范围，不能直接套用 NK 界。

(a) 非负版本 D(i,s)=前 i 件能否达到 s，D(i,s)=D(i−1,s)∨D(i−1,s−ai)，D(0,0)=真。滚动一行时 s 从 K 递减，避免一件被重复使用；首次可达时保存该件和前一个和，能恢复具体子集。0 不必加入已有状态，目标 0 以空集成功。subset_sum 实现这个非负约定，O(NK) 时间、O(K+N) 含答案空间。

(b) 二进制编码 K 只占 O(logK) 位，而 K 本身可指数大于输入位数。O(NK) 对数值多项式，对输入编码长度不一定多项式，是伪多项式算法；因此没有证明 P=NP。

10.59 · 闭合骑士巡游

原题（中文翻译）

在 B×B 棋盘，骑士从行 R、列 C 移到 1≤R′≤B、1≤C′≤B，允许 |R−R′|=2, |C−C′|=1，或 |R−R′|=1, |C−C′|=2。骑士巡游访问每格恰一次，并回到起点。

  1. B 为奇数时证明不存在这种巡游。
  2. 给出寻找骑士巡游的回溯算法。

本版习题 10.59；印刷页 424／PDF 第 441 页。

解答

(a) 棋盘黑白染色，骑士每步改变颜色。闭合巡游的边数等于格数 B²，闭合路径必须走偶数步；B 奇则 B² 奇，矛盾，也可由两色格数不相等得出。这里要求闭合，不能据此否认某些奇棋盘的开放巡游。

(b) 起点固定左上角，记录已访问格与路径，递归尝试八种位移中合法未访问格；走完 B² 格后还要与起点有骑士边。失败则恢复已访问标记和路径。按后续合法度数较小、再按格编号较小的顺序试，只影响效率，不漏掉分支。

可作确定剪枝：尚未走完时至少保留一个未访问的起点邻居，才能闭合；每个未访问格在“未访问格加当前端点与起点”中必须有至少两个可用相邻连接，否则无法在完整闭合路中成为内部格。这两个必要条件失败就回溯。knight_tour 完整实现，教学入口 B=1…6，奇 B 先排除。6×6 从左上角出发找到 36 格闭合巡游，两版同一搜索顺序共进入 48 个状态。

这是完整回溯配必要条件，最坏仍指数，上界可按 O(8B2·B2) 计（节点的可用度检查扫棋盘），路径与标记 O(B2)。启发式顺序不能当成存在性证明，最终每格一次与闭合边必须检查。

题干校注：图中比较行将局部 d_T 写成 D_T，大小写不一致；按同一个局部最小距离变量理解。算法中的抽象 Infinity 加有限边权仍为 Infinity，实际固定宽度实现应先检查不可达。

(a) 没有已访问标记或备忘表。有回路 S→V→S 且未先达到 T 时，就无限递归；负环还可能使有限最短值不存在。即便费用非负，也不能靠费用比较终止，因为比较发生在递归返回之后。(b) DAG 有拓扑序，每次递归沿边向严格更晚位置移动，路径长度至多 |V|−1；终点返回 0，无出边叶返回∞。以逆拓扑位置归纳，每个调用的所有子调用都终止，自己也终止。

(c) 无备忘会对不同路径共享的后缀重复求解。取 N 个顶点 1…N，每个 i 向所有 j>i 连边，S=1、T=N。每个中间点选择出现或不出现，S→T 有 2ᴺ⁻² 条路径；顶点 i 的调用数满足 Ci=1+∑j>iCj，C_N=1，所以 C₁=2ᴺ⁻¹。每次遍历的边对应一次子调用，总时间 Θ(2ᴺ)。

一般简单 DAG 的拓扑位置限定每条路径为中间顶点子集，递归展开也不超过这个完全有序 DAG，因此最坏 Θ(2ᴺ)，栈 O(N)（图存储另计）。允许平行边时需把重复分支按边数另算。若保存每个顶点到 T 的答案，或按逆拓扑序填表，就降到 O(V+E)，并允许负边；这正好连接回本章动态规划与第九章 DAG 最短路。
