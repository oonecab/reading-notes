2026-10-15 的详细过程修订先验收第 1 章样章：31 条编号定理／引理各有“完整证明 →”，与原来的例题入口并存。4 个原证明锚点保留，新增 27 个独立证明块；每条按条件、实际推导、边界和原书页码展开。56 个原书例子在原推导组内逐例列出过程；77 道习题逐题读回，其中 44 道补充本题计算、逐行代回或论证。例 1.24 只推导已给出的规则与概率聚合，原书模拟图的全部输入未提供，整图频率未复现。

公式讲解先说明所求事件及已知条件，再解释为什么这样分解、每个数从哪里来、每次运算对应什么条件，最后连接一般公式。例 1.4 按父代—子代—孙代的三条路径展开：先解释中间阶层为何需要分类，再解释条件比例为何相乘、互斥且穷尽为何相加，以及马尔可夫性和逐代同一转移表各自的作用。读者确认这一解释方式后，以它作为第一章逐项修订的标准。
