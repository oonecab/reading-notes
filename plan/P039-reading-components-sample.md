# P039：四类教学组件的统一样章计划

关联 [I039](../issues/I039-reading-components-sample.md)。

1. 从 56 个正式源页枚举明确结构，复用 I038 的标题节点与组件差异证据；普通正文中隐含的例题和证明单列为人工映射范围。
2. 用一个共享 CSS 提案制作随机过程第一章完整副本，并生成五书 12 组实际内容的前后对照。所有输出仅保存在 tmp。
3. 比较正文文本、MathML、SVG、代码、锚点及链接；只允许视觉群论样例增加一个明确记录的“证明”标签。用公式篡改样本验证检查器会拒绝内容变化。
4. 在桌面/窄屏实际打开样章，检查长证明、长公式、宽表格、C/Python 代码和原生展开；补充无 JS 路径及相关断点检查。
5. 提交具体可审阅样章与统一规则。后续全站改写等样章反馈后分批执行，本阶段不承诺全站已经采用。
