# 四类教学组件统一提案

日期：2026-10-20。状态：I039 历史样章；随后由 [I040](../issues/I040-unified-reading-components.md) 接入正式 RN-001 规则。本文保留提案时的范围与验收依据。关联 [I039](../issues/I039-reading-components-sample.md)。

I038 已确认五书采用相同纸色、绿色、正文和主要布局，但同类教学内容仍有不同的标签、边框及折叠方式。统一应让读者能稳定识别“这是陈述、这是论证、这是演算、这是题解”，同时保留学科和原书编号。

## 统一规则

| 类型 | 提案中的固定形式 | 保留的内容差别 |
|---|---|---|
| 定义、定理与原理 | 常显；浅绿色底和绿色左边线；统一标题、来源与内边距 | 原书称谓、编号、完整条件、原文/译义、校注 |
| 例题 | 常显；轻分隔线和统一例题标题；步骤使用同一间距 | 短定义例、数值演算、状态过程、图与程序的组织 |
| 证明 | 独立原生 `details`；默认展开；统一标题和浅色左边线 | 条件、引理、编号推导、边界、来源及返回链接 |
| 习题 | 原生 `details.exercise` 默认收起；展开后题干与解答分区；标签同字号/粗细 | 原题翻译、中文转述或原创自测的语义标记，原编号、小问与来源 |

沿用 17px 正文、1.9 行高和现有布局；组件标题 1.05rem、题干/解答及证明标签 .95rem。来源采用 .85rem 次级文字。长公式、宽表、源码继续使用原有局部横向滚动容器。证明仍默认可见，原生控件在没有 JavaScript 时可以操作。

## 范围与样章

完整样章采用随机过程第一章，含 38 个陈述区块、56 个例题、31 个证明和 77 道习题。五书另提供 12 组原有内容对照，涵盖长短证明、定义性短例、双语原理、宽表和 C/Python 代码。视觉群论 Theorem 5.1 后的三段原有论证增加一个“证明”标签并归入证明区，原段落与公式不改写。

命令：从仓库根目录运行 `python3 tools/project.py preview-components`。打开 `tmp/reading-components-preview/index.html`，完整章为同目录 `chapter01.html`。生成器从 Git 基线 `41a77dd3affc726bef81505ca5cde067d6f3944c` 读取提案前的正式页面，以便全站上线后仍能重现相同对照；不依赖旧 dist，也不覆盖正式源、检查镜像或发布目录。结果含本机文件链接，只用于本地审阅。

全量清单与源哈希写入 `report.json`，覆盖 56 页及全部 1,525 个习题/自测容器。显式组件数用于定位现有结构；它不能把 Weiss/CS:APP/视觉群论的普通正文自动认作完整例题或证明。正式迁移前需逐项确认这些边界，避免用标题关键词猜测论证范围。

| 书籍 | 正式页 | 习题/自测容器 | `source-statement` / `statement` | `example-worked` | `proof-item` / `proof` |
|---|---:|---:|---:|---:|---:|
| 随机过程 | 9 | 236 | 150 | 162 | 31 |
| Weiss | 13 | 362 | 0 | 0 | 0 |
| CS:APP | 14 | 455 | 114 | 0 | 0 |
| 视觉群论 | 12 | 302 | 62 | 0 | 0 |
| 测度概率 | 8 | 170 | 203 | 0 | 196 |

这张表统计指定类名，不是原书内容总量：0 表示没有该类名。随机过程其他证明仍可能位于 `source-review`，测度概率例题采用 `article`；Weiss 算法推演、CS:APP 状态说明和视觉群论正文论证均须从原书清单与现有锚点补充映射。不能因容器计数为 0 删除这些内容或宣称缺失。

实现只对已确定容器及标签作字节位置补丁，保留 MathML/SVG 原始串。提案 CSS 仅在 `.rn-components` 下生效；正式样式和构建尚未引入这份文件。

## 检查规则与扩展门槛

生成器验证原有文本、所有锚点和链接顺序，逐字比较全部 MathML、SVG、pre 和 code；视觉群论新增标签独立记录。公式被改为不同数值的负例必须被拒绝。此检查保护排版变换中的内容完整性，不能代替数学或来源正确性审阅。

浏览器验收核对桌面及 390px，补充 1024/1800px；检查标题计算样式、整体溢出、局部滚动、长证明、题解与代码，实际操作原生展开及深链接，并打开截图读回。截图数量、实际目视数量与未覆盖路径分别记录到 T039。

样章获反馈后，才把确认的规则写入 RN-001，并将正式组件适配、书级映射清单、受控修订链和回归门禁分批接入。样章本地通过不表示全站已统一，也不关闭 I038 的内容与代理验收问题。

2026-10-20 样章验收完成：52 个四档视口检查及 26 个无 JS 视图通过；实际打开 36 个独立阅读/对照位置的截图，修正长证明间距、来源行对齐和窄屏深链接遮挡。完整性、原生控件、长代码局部滚动及边界证据见 [T039](../test/T039-reading-components-sample.md)。
