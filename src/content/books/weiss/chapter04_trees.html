第四章：树

沿原书的思路追问：树怎样表示关系，遍历怎样表达计算依赖，查找怎样利用顺序；当树变深时，又该维护平衡、调整访问路径，还是改变每个节点的容量？

一、第三章留下的问题：找到位置仍然太慢

链表把局部插入与删除变成了少量链接修改，但这有一个前提：已经知道操作位置。若每次按值查找都要从头扫描，输入一大，O(N) 的定位就成了瓶颈。第四章开头正是从这个问题出发，提出多数查找操作平均只需 O(logN) 的结构。

不过作者没有直接开始写查找树。他先把“树”作为更一般的抽象介绍：目录有层次，表达式有嵌套，查找有逐步缩小的候选范围。三种问题都能用树表达，但它们需要的结构约束不同。一棵二叉树不会仅仅因为长得像树，就自动拥有对数时间的查找能力。

全章随后给出三个不同的保护策略：AVL 严格限制局部高度差；伸展树允许某次访问很慢，却通过调整控制连续操作的总成本；B 树扩大分支数，把注意力转向磁盘访问。这不是三种可以随意互换的“平衡技巧”，而是三种不同的代价管理方式。

二、§4.1：先把关系说清，再决定指针怎样放

2.1　深度向上看，高度向下看

树的定义本身是递归的：空集合可以是树；非空树有一个根，根连接零棵或多棵非空子树。非空树有 N 个节点、N−1 条父子边，因为除根外，每个节点恰好有一个父亲。从根到任意节点的路径唯一，这也是文件路径与递归下降能够工作的重要原因。

原书图 4.2 用字母树区分父亲、孩子、兄弟、叶子、祖先与后代。读图时必须按边数计路径长度，而不是数经过几个节点：根深度为 0，叶子高度为 0；节点深度是根到它的距离，高度是它到最深叶子的距离。整棵树的高度等于最深叶子的深度。

本章的约定：空树高度为 −1，单节点树高度为 0。因此 height(T) = 1 + max(height(T.left), height(T.right)) 对叶子也成立。它不是所有教材共同采用的约定，写代码与推导时要保持一致。

2.2　图 4.3–4.4：第一孩子／下一兄弟

一般树的孩子数量未知。若每个节点固定预留很多孩子指针，会浪费空间；若预留太少，又装不下。作者把第三章的链表思想搬过来：节点只存 FirstChild 与 NextSibling。第一个链接向下进入孩子表，第二个链接向右寻找同一父亲的其他孩子。

链接含义遍历动作
FirstChild当前节点的第一个孩子进入下一层
NextSibling当前节点的下一个兄弟保持层次，走向另一棵兄弟子树

图 4.4 中，E 的孩子链接指向 I，兄弟链接指向 F。这两个字段都能为空。虽然每个节点只有两个链接，却仍在表达一棵多叉树：兄弟不是孩子，不能把两个字段机械当成普通二叉树的左右孩子来解释深度。列出某个节点的全部孩子，需要从其 FirstChild 开始沿 NextSibling 扫描；访问整棵树时，再对每个孩子递归。

这种表示总空间为 O(N)，代价是无法像数组那样直接取得“第 k 个孩子”。它再次说明：减少存储与增强随机访问能力，是两种不同的目标。

三、§4.2：表达式树，把第三章的栈接到树上

二叉树的每个节点最多有两个孩子，且区分左、右位置。于是图 4.7 可以直接保存两个孩子指针。拥有 N 个节点的非空二叉树共有 2N 个孩子指针槽位，其中 N−1 个用于真实父子边，剩下 N+1 个为 NULL。这个计数将在后面的线索二叉树中再次出现。

图 4.6 则先打破一个误解：二叉树可以退化成高度 N−1 的链。原书对“一般随机二叉树”和“随机插入形成的查找树”讨论了不同的平均深度；这些平均结论依赖各自的随机模型，不能把任意二叉树都说成高度 O(logN)。

3.1　图 4.8：结构本身已经保存了运算优先级

表达式树的叶子是操作数，内部节点是运算符。图 4.8 表示 (a + b*c) + ((d*e + f)*g)：乘法为什么先算？因为乘法节点在加法节点的子树中，求加法时，必须先拿到子树的结果。这里的二叉形式来自例子中的运算符都是二元运算；一元负号可以只有一个孩子。

3.2　从后缀表达式构造树：栈里保存的是子树根

§4.2.2 使用 a b + c d e + * * 推演建树。第三章求后缀表达式时，栈里放计算结果；现在栈里放已经建好的子树指针。遇操作数，创建单节点树并压栈；遇二元运算符，弹出两棵树，创建运算符根，再把合成树压回去。

读入栈内容（右侧为栈顶）新树
a b +[a+b]+ 的左孩子 a，右孩子 b
c d e[a+b, c, d, e]三个单节点树
+[a+b, c, d+e]先弹出 e 为右孩子，再弹出 d 为左孩子
*[a+b, c*(d+e)]合并 c 与 d+e
*[(a+b)*(c*(d+e))]最后合并两棵子树

左右次序不是细枝末节。输入 a b -，第一次弹出 b，应该放在右边；第二次弹出 a，才放左边，否则得到 b−a。每个符号只处理一次，每次栈操作为 O(1)，在单个符号解析与分配成本按常数计时，建树为 O(N)，节点和最坏栈空间均为 O(N)。

实现时还要处理非法输入：运算符处栈不足两个元素，或者输入结束后栈中不恰好剩一棵树，都不能直接返回成功。节点由建树过程分配，成功后归返回树的所有者；失败时，应释放栈中全部独立子树。新运算符节点一旦接上两棵子树，便接管它们的所有权，不能再单独释放孩子。

四、§4.2.3：遍历顺序就是计算依赖顺序

4.1　前序、中序、后序：决定何时处理当前节点

作者不是只让我们记住三套顺序，而是用表达式解释它们的用途。中序是左、根、右，得到中缀形式；后序是左、右、根，得到后缀形式；前序是根、左、右，得到前缀形式。中序输出表达式时还需保留结构括号，否则 (a+b)*c 可能被打印成含义不同的 a+b·c。

遍历什么时候处理根适合的依赖
前序进入子树之前先打印父目录，再列子项
中序左子树之后、右子树之前表达式的中缀输出；查找树的有序输出
后序两棵子树完成以后求值、求高度、汇总大小、释放节点
层序先浅层后深层队列保存下一批待访问节点

图 4.10 求高度最能体现后序：先知道左右子树高度，才能计算根的高度。若每个节点只做常数工作，遍历时间为 O(N)，递归辅助空间为 O(h+1)；平衡树是 O(logN)，链形树则可达 O(N)。遍历每个节点一次，并不意味着递归栈只占常数空间。

层序使用第三章的队列：根入队；重复取队头、处理节点、把非空孩子依次入队。每个节点入队出队各一次，时间 O(N)，辅助空间由最大层宽决定，最坏 O(N)。

4.2　图 4.11–4.16：目录树为何分别需要前序和后序

目录例子以 /usr 为根，下面有 mark、alex、bill 等目录。路径保存的是从根沿父子边行走的选择，因此不同目录里的同名文件可以拥有不同完整路径。图 4.12 的 ListDir 先打印当前名字，再递归列孩子；这就是前序。深度只负责缩进，外部调用通过包装函数从深度 0 开始，不必了解这个内部状态。

图 4.14–4.16 统计磁盘块时，情况变了：目录自身也占块，必须加上所有后代文件的占用。先算每个孩子的总量，再加当前目录，得到 mark 为 30、alex 为 9、bill 为 32；加上 /usr 自身的 1，总共 72。它是后序汇总，而不是“只把叶子加起来”。

原书把目录遍历按每节点常数工作计为 O(N)。若真实输出每层缩进和完整路径，还要计入输出字符总量；极深的树可能输出远多于 N 个字符。真实文件系统还存在 .、..、链接等关系，书中也以脚注提醒它严格说并非一棵纯树；实际遍历应明确是否跟随链接及如何避免循环。

4.3　线索二叉树：把空链接变成中序导航

本改编版在 §4.2.3 专门加入线索二叉树（图 4.17–4.19）。前面算出的 N+1 个 NULL 孩子指针，现在可以部分改为中序前驱或后继链接：左孩子为空，左指针可指向前驱；右孩子为空，右指针可指向后继。LeftThread、RightThread 标记分别说明链接是线索还是真孩子。

哨兵 header 的左链接指向实际根，右链接指回自身；中序第一个节点没有前驱、最后一个没有后继，它们的端点线索接到 header。求后继时分两种情况：右链接是线索，就直接跟随；是真右孩子，就进入右子树，再沿真实左孩子找到最左节点。遍历从首节点开始，不断求后继，回到 header 时结束。

C（C11）
/* 与题 4.45 的 ThreadNode 定义及 header 约定一起编译。 */
static ThreadNode *thread_successor_demo(ThreadNode *p) {
    ThreadNode *next = p->right;
    if (!p->rt)
        while (!next->lt) next = next->left;
    return next;
}
Python 3
# 使用题 4.45 的 ThreadNode；p 必须是数据节点。
def thread_successor_demo(p):
    nxt = p.right
    if not p.rt:
        while not nxt.lt:
            nxt = nxt.left
    return nxt

单次求后继最坏仍可沿较长路径下降，但完整中序遍历可在 O(N) 时间、O(1) 额外遍历空间内完成，因为真实树边和线索只被有限次数经过。收益是省去显式栈或递归栈；代价是每次结构修改还要维护线索和标记。普通释放或遍历函数不能无视标记地递归 Left、Right，否则会把线索当孩子，进入环或重复释放。header 本身也需要单独管理生命期。

五、§4.3：有序约束让查找只走一条路

5.1　图 4.20 的错误树：只比较父子还不够

二叉查找树要求每个节点 X 的整个左子树都小于 X，整个右子树都大于 X。图 4.20 右边的树，在根 6 的左子树里藏了 7；即使 7 大于它的直接父节点 4，仍然不合法。检查 BST 要传播上下界，不能只检查相邻两层。

书中首先假设关键字互异。重复关键字可以用计数字段表示；若同一键对应多个完整记录，则可以另存一个记录集合。简单地把相等值不断插到某一侧，可能制造额外深度；比较规则与重复语义应在接口中统一规定。

5.2　Find、FindMin、FindMax：先检查空树

Find 比较目标与当前键：小则去左，大则去右，相等便返回节点，遇 NULL 表示不存在。每次只走一棵子树，所花时间与走过的路径长度有关。FindMin 一直走左，FindMax 一直走右，空树均返回 NULL。

“It is important that similar-looking operations do similar things.”

译：看起来相似的操作，应当做相似的事情。

§4.3.3，印刷页 99

这句话解释了为什么 FindMin 和 FindMax 返回位置而不是直接返回元素：它们与 Find 保持接口一致。返回的是借用指针，不意味着把节点所有权交给调用者。另一个细节是：T = T->Right 只改变局部指针副本；T->Right = ... 则修改共享节点的链接，两者影响完全不同。

5.3　图 4.26–4.27：Insert 返回新的子树根

插入沿查找路径下降，直到适合位置的空链接，再创建叶子。原书在根 6、左孩子 2、右孩子 8 的树里插入 5：依次比较 6、2、4，最后接到 4 的右边。返回子树根很关键：空树首次插入会改变根，后面的旋转与删除也可能改变根。

C（C11）
/* 使用后面的 Node 和 bst_insert；返回值接回根入口。 */
static Node *insert_five(Node *root) {
    return bst_insert(root, 5);
}
/* bst_insert 内递归调用也写作 t->left = bst_insert(t->left, key)。 */
Python 3
# 使用后面的 Node 和 bst_insert。
def insert_five(root):
    return bst_insert(root, 5)
# 调用者仍须执行 root = insert_five(root)。

函数返回新根只更新函数值，调用者不接回，就可能丢掉新树。图 4.27 的 return 与递归结果赋值，不是为了满足语法，而是实现“修改后仍可从原来的入口到达整棵子树”的契约。

5.4　删除：先保顺序，再保可达性，最后释放

图 4.28–4.30 把删除分成三种。叶子可由 NULL 取代；只有一个孩子，直接用孩子替换本节点；两个孩子时，选右子树最小键作为中序后继，把其键放到当前位置，再从右子树删除后继节点。后继没有左孩子，因此第二次删除落入前两种简单情况。

删除对象返回给父亲的子树根内存处理
叶子NULL保存原节点后释放
只有一个孩子唯一孩子先保存孩子，释放原节点
有两个孩子通常仍为原节点替换键，递归删除并释放后继节点

以图 4.29 为例，要删 2；其左边是 1，右子树根 5 的左边有 3，3 的右边又有 4。把 3 复制到原来 2 的位置后，删除原来的 3，让 4 接到 5 的左边。所有左侧键仍小于新键 3，右侧键都大于 3。

书中为清晰起见，用 FindMin 找后继，再递归 Delete 走一次相同方向。两遍扫描增加常数，但没有改变 O(h+1) 的阶；可以用专门的 DeleteMin 合并扫描。如果节点保存的是带堆内存的记录，而不只是整数，不能不加考虑地浅复制全部字段：需要另行定义记录迁移、销毁和共享规则。

本版图 4.30 的印刷错误：印刷页 103 的 “Go right” 分支写成了 T->Right = Delete(X, T->Left)。已核对 PDF 页面图像，正确的递归对象应是 T->Right。直接照抄会破坏链接。下面的教学代码使用正确分支。

5.5　一份能看清生命期的教学实现

以下代码独立编写，采用整数键、相等插入不变、删除不存在的键不变；后一个约定不同于书中报错的 Delete。分配失败采用 abort()，以集中观察结构操作。它没有封装为完整库；递归版本在链形树上可能栈溢出。节点由插入分配，由删除或清空释放，查找返回的指针只是借用。

C（C11）
#include <stdlib.h>

typedef struct Node {
    int key;
    struct Node *left, *right;
} Node;

static Node *bst_find(Node *t, int key) {
    while (t != NULL && t->key != key)
        t = key < t->key ? t->left : t->right;
    return t;
}

static Node *bst_min(Node *t) {
    if (t != NULL)
        while (t->left != NULL) t = t->left;
    return t;
}

static Node *bst_insert(Node *t, int key) {
    if (t == NULL) {
        t = malloc(sizeof *t);
        if (t == NULL) abort();
        *t = (Node){.key = key, .left = NULL, .right = NULL};
    } else if (key < t->key) {
        t->left = bst_insert(t->left, key);
    } else if (key > t->key) {
        t->right = bst_insert(t->right, key);
    }
    return t;
}

static Node *bst_delete(Node *t, int key) {
    if (t == NULL) return NULL;
    if (key < t->key) {
        t->left = bst_delete(t->left, key);
    } else if (key > t->key) {
        t->right = bst_delete(t->right, key);
    } else if (t->left != NULL && t->right != NULL) {
        Node *successor = bst_min(t->right);
        t->key = successor->key;
        t->right = bst_delete(t->right, successor->key);
    } else {
        Node *child = t->left != NULL ? t->left : t->right;
        free(t);
        return child;
    }
    return t;
}

static Node *bst_clear(Node *t) {
    if (t != NULL) {
        bst_clear(t->left);
        bst_clear(t->right);
        free(t);
    }
    return NULL;
}
/* 调用：root = bst_insert(root, x);
         root = bst_delete(root, x);
         root = bst_clear(root); */

    if t is None:
        return Node(key)
    if key < t.key:
        t.left = bst_insert(t.left, key)
    elif key > t.key:
        t.right = bst_insert(t.right, key)
    return t

def bst_delete(t, key):
    if t is None:
        return None
    if key < t.key:
        t.left = bst_delete(t.left, key)
    elif key > t.key:
        t.right = bst_delete(t.right, key)
    elif t.left is not None and t.right is not None:
        t.key = bst_min(t.right).key
        t.right = bst_delete(t.right, t.key)
    else:
        return t.left if t.left is not None else t.right
    return t

def bst_clear(t):
    # Python 回收对象；先解除树持有的孩子引用。外部借用仍可能存活。
    if t is not None:
        bst_clear(t.left)
        bst_clear(t.right)
        t.left = t.right = None
    return None

释放之后，旧 Position 不再有效。双孩子删除还存在更微妙的情况：原节点地址保留，键却改变；后继节点被释放。若业务把“地址”当成永不改变的记录身份，这套按键复制的删除策略就不能直接使用。清空采用后序，先释放孩子，再释放根，最后把调用者 root 设成 NULL。

懒惰删除则把节点标为无效，不马上释放；重复键计数也可减一来表示逻辑删除。这样可减少结构修改和重新分配，但查找、极值与遍历都必须识别无效状态，且成本由实际保留的节点数决定。已删除节点持续积累时，需要回收或重建，不能把它们当成“没有代价的空位”。

六、§4.3.6：平均 O(logN)，究竟平均了什么？

查找、插入、删除的直接保证是 O(h+1)，而非无条件的 O(logN)。作者用内部路径长度 D(N)——全部节点深度之和——推导平均结论。若根的左子树有 i 个节点，右子树有 N−i−1 个，则把两棵子树接到根下，会使其中每个节点深度增加 1：

D(T)=D(Tleft)+D(Tright)+N−1

随机插入模型下，令 EN 为期望内部路径长度。根的秩均匀，两侧期望求和对称，于是

E0=E1=0,EN=2N∑j=0N−1Ej+N−1.

与前一规模的递推相减，再除以相邻规模，可求得 EN=2(N+1)HN−4N，其中 HN=∑j=1N1j。因此 EN=O(NlogN)，平均节点深度为 EN/N=O(logN)（N≥1）。

这里应把“随机”说具体：N 个互异键以各插入排列等可能的方式建树，根的秩均匀，于是左子树规模 0 到 N−1 等可能。不同树形本身并不等概率。例如三个键时，以最小键为根的某些链形只有一个排列产生，以中间键为根的平衡形可以由两个排列产生。原书关于“all trees equally likely”的概括，阅读时宜以随后的插入序列与根秩推导为准确依据。

这证明的是随机插入条件下的平均访问深度，不能把“节点平均深度”和“整棵树的最大深度”当成同一量。若输入已经排好序，N 次插入会形成链，每一步越来越深，总成本达到 Θ(N2)。

图 4.31–4.32 及邻近说明进一步提醒：交错插入、删除会改变分布。总从右子树取后继的删除带有方向偏置；原书讨论长期更新下的失衡现象，并没有给任意插删序列颁发平均对数时间保证。这里最重要的不是记住一次实验的数字，而是明白“平均”需要能够被维护的概率前提。

因此，下节的 AVL 才有必要：不是再证明随机输入表现好，而是改变结构约束，使有序输入这样的简单坏例子也不会把树拖成长链。

七、§4.4：AVL 把平衡变成每个节点的不变量

7.1　只要求根平衡，为什么不够？

图 4.33 两边可以同样高，却各自都很深，说明只平衡根无济于事。若要求所有节点左右高度完全相同，又太严格，几乎只允许完美二叉树。AVL 放宽为：每个节点的左右子树高度差至多 1。这是逐节点的约束，不是整棵树“看起来比较匀”。

图 4.35 讨论高度为 h 的 AVL 至少有多少节点。为了节点尽可能少，两棵子树高度应为 h−1 与 h−2，因此 S(h)=S(h−1)+S(h−2)+1，且 S(−1)=0、S(0)=1。其增长类似 Fibonacci 数，反过来得到 h=O(log N)。例如高度 9 至少需要 143 个节点。这个递推比背诵高度上界的系数更能解释平衡条件为什么有效。

7.2　插入只影响访问路径

插入发生在一个空孩子位置。只有这个位置的祖先高度可能改变，因此沿递归返回路径更新高度，找第一个（最深的）失衡节点 α。左右高度差从合法的 1 变到 2，失衡落在四种方向组合之一。

从 α 下降的两步位置修复
LL左孩子的左侧，外侧在 α 处右旋
RR右孩子的右侧，外侧在 α 处左旋
LR左孩子的右侧，内侧先左旋左孩子，再右旋 α
RL右孩子的左侧，内侧先右旋右孩子，再左旋 α

注意书中的 SingleRotateWithLeft 名称是“与左孩子旋转”，对应通常说的右旋。不能单凭 Left 字样判断旋转方向。

7.3　图 4.36：单旋真正移动的是哪几条链接？

以 LL 为例，旧根 k2 的左孩子为 k1。原有键序是 X < k1 < Y < k2 < Z。让 k1 升为根，k2 成为它的右孩子，Y 转为 k2 的左子树。X、Y、Z 的内部结构完全保留。

例：AVL 插入与旋转

图 4.37 的具体例子是给原来的 AVL 插入 6，使 8 的左侧过深，再让 7 升到 8 的位置。单旋只需要常数次链接修改，但必须把新根接回原父节点：原书随后插入 3、2、1、4、5、6、7 的推演中，旋转使 4 取代 3 时，2 的右孩子也必须从 3 改为 4，否则新树会变得不可达。

7.4　图 4.39–4.41：内侧失衡为什么要双旋？

LR 情况下，深的是左孩子的右子树。直接右旋把外层换了，却没把这棵内侧子树拉上来。最小例子是依次插入 3、1、2：3 左边是 1，1 右边是 2；只右旋会得到根 1、右孩子 3、3 左边 2，仍然失衡。先在 1 处左旋，再在 3 处右旋，得到根 2、左孩子 1、右孩子 3。

图 4.40 把它推广到四棵子树 A、B、C、D：中间键 k2 升为根，k1、k3 分居两边，B、C 分别转接到两侧的内侧孩子位置。它不是丢掉中间子树再重建，而是通过键的区间约束确定每条链接的新位置。书中继续插入 16、15、14 等值的长例子，是为了展示子树非空时也必须保留这套区间关系。

7.5　高度更新是旋转的一部分

图 4.43 的 Height 读取节点中保存的高度，空节点返回 −1，时间 O(1)；它不同于图 4.10 那个递归计算整棵树高度的函数。若在 AVL 的每一层都重新遍历子树来算高度，就会破坏预期的插入效率。

下面是独立编写的旋转教学代码。前提是根及被提升的孩子非空，而且原有高度字段正确；双旋还要求内侧孙子存在。它不分配、不释放节点，只修改链接与高度；调用者必须接回返回值。AVL 插入的比较与递归外壳见图 4.44，这里只展示维护约束的核心。

C（C11）
#include <stddef.h>
typedef struct Avl {
    int key, height;
    struct Avl *left, *right;
} Avl;

static int avl_height(const Avl *t) {
    return t != NULL ? t->height : -1;
}

static void avl_update(Avl *t) {
    int l = avl_height(t->left), r = avl_height(t->right);
    t->height = 1 + (l > r ? l : r);
}

static Avl *rotate_right(Avl *root) {
    Avl *up = root->left;
    root->left = up->right;  /* 保存并转接中间子树 */
    up->right = root;
    avl_update(root);        /* 先更新下降的旧根 */
    avl_update(up);          /* 再更新依赖旧根的新根 */
    return up;
}

static Avl *rotate_left(Avl *root) {
    Avl *up = root->right;
    root->right = up->left;
    up->left = root;
    avl_update(root);
    avl_update(up);
    return up;
}

static Avl *rotate_left_right(Avl *root) {
    root->left = rotate_left(root->left);
    return rotate_right(root);
}

static Avl *rotate_right_left(Avl *root) {
    root->right = rotate_right(root->right);
    return rotate_left(root);
}

插入后在最深失衡点做一次修复（一次单旋或一次双旋），该子树高度恢复到插入前的高度，因此不会再引起更高祖先失衡。整条查找与高度更新路径仍为 O(logN)。不要把“只需一个修复点”误读为“只能执行一次基本旋转”，也不要推广到物理删除：删除可能让高度持续下降，需要在多个祖先处修复。书中只概述 AVL 删除，建议删除较少时考虑懒惰删除，没有给出完整物理删除实现。

高度或平衡因子都可记录约束。书中讨论用少量位保存 −1、0、1，却也提醒机器对齐和代码复杂度可能抵消空间收益。维护信息越紧凑，不代表实现一定更好；可读性也是成本。

八、§4.5：伸展树关心的是下一次访问

8.1　允许一次很慢，但不能一直很慢

普通 BST 遇到深节点，如果结构不变，重复访问它仍然每次都慢。伸展树的想法是：访问以后把节点送到根，并调整沿途结构。它不保存 AVL 的高度或平衡信息，也不要求每次更新后形状均匀；被访问过的热点键靠近根，符合许多程序的局部性。

“There are no bad input sequences.”

译：不存在使整段操作序列失去总成本保证的坏输入序列。

§4.5，印刷页 119；译文根据附近的总时间界补足含义。

这不是说每次都快。单次操作最坏可达 O(N)，但从空树出发，M 次标准操作总时间有 O(MlogN) 的界，N 可理解为过程中的最大规模，空树边界可写作 O(Mlog(N+1))。因此每次摊还 O(logN)。摊还界约束最坏操作序列，不依赖“输入随机”；单次响应时限严格的场景，却不能用它代替 AVL 的单次最坏界。

8.2　§4.5.1 的失败尝试：只把访问节点逐级提上来

一个很自然的做法是每次把 X 与父亲做单旋，直到 X 为根。它确实让下一次访问 X 便宜，但可能把路径中的另一个节点推得同样深。书中用插入 1、2、…、N 后形成的左链说明：按升序访问所有键，逐级上提策略花费约 (N−1)+(N−2)+…+1，得到 Θ(N2)，还可能回到相同坏形状。改善一个节点，不等于改善整个操作序列。

8.3　图 4.49–4.50：把父亲与祖父一起考虑

伸展每次看 X、父亲 P 与祖父 G 的相对方向。P 已为根时，最后做一次 zig；方向不同为 zig−zag，采用与 AVL 双旋相同的局部结构变换；方向相同为 zig−zig，先旋转 P 与 G，再旋转 X 与 P。最后一条正是与朴素上提策略的关键差别。

情形左侧示例的操作顺序区别
zigX 是根的左孩子：在根处右旋只有父亲，没有祖父
zig−zag（LR）先左旋 P，再右旋 G把中间键 X 提到上方
zig−zig（LL）先右旋 G，再右旋新的子树根 P先提升父亲，再提升 X

在图 4.50 的完整 LL 例子里，原有区间为 A < X < B < P < C < G < D。调整后 X 左边仍为 A，右边为 P；P 左边为 B，右边为 G；G 左右为 C、D。顺序保持，沿访问路径的大部分深节点获得了更好的位置。它不等于把所有节点深度严格减半，也不建立 AVL 式局部高度约束。

图 4.51–4.60 从纯左链开始依次访问，展示昂贵访问如何改善后续路径。原书还说明顺序访问所有键是更强的特殊结果，可做到总计 O(N)，不能仅凭小图把它当成摊还定理的证明。一般证明留在第 11 章，本节主要建立直觉。

8.4　删除变成两棵树的拼接

先访问并伸展待删键，使其到根；保存左右子树并释放根。如果左树为空，直接返回右树。否则，在左树中找最大键并把它伸展到左树根；最大键不可能有右孩子，故可把原右树直接接到这个空右链接。顺序保证是左树中所有键小于原根、原右树中所有键大于原根，因此拼接不违反 BST 约束。

空树、键不存在与左树为空都要独立处理。未命中查找在常见实现中也会伸展最后访问节点；本章没有给出完整接口代码，这一行为必须由实际实现约定。若保持父指针或显式祖先栈，每次旋转还需维护它们；“无需平衡字段”并不等于“无需其他状态”。此外，查找本身会修改根和链接，不能当成结构上的只读操作。

8.5　可复用的底向上伸展实现

使用正文 Node 定义；查找未命中时伸展最后访问的节点，插入相等键不变，删除不存在键不变。返回值总是新的根入口。显式祖先数组使链形树访问不依赖递归调用栈；C 分配失败中止，销毁使用正文 bst_clear（深链宜另用显式后序栈）。每个单旋使 splay_rotations 加一，双旋加二。

#include <stdint.h>
#include <stddef.h>
/* 与正文 Node 定义一起编译。返回新根，查找也会修改结构。 */
static unsigned long long splay_rotations;
static Node *sright(Node *g) {
    ++splay_rotations;
    Node *p=g->left; g->left=p->right; p->right=g; return p;
}
static Node *sleft(Node *g) {
    ++splay_rotations;
    Node *p=g->right; g->right=p->left; p->left=g; return p;
}
static Node *splay_access(Node *root,int key) {
    if (!root) return NULL;
    size_t n=0,cap=16;
    Node **path=malloc(cap*sizeof *path);
    if (!path) abort();
    Node *x=root;
    while (x->key!=key) {
        Node *next=key<x->key ? x->left : x->right;
        if (!next) break; /* 未命中时访问最后一个非空节点。 */
        if (n==cap) {
            if (cap>SIZE_MAX/2/sizeof *path) abort();
            cap*=2; Node **p=realloc(path,cap*sizeof *path);
            if (!p) abort();
            path=p;
        }
        path[n++]=x; x=next;
    }
    while (n) {
        Node *p=path[--n];
        if (!n) x=p->left==x ? sright(p) : sleft(p);
        else {
            Node *g=path[--n];
            if (g->left==p && p->left==x) x=sright(sright(g));
            else if (g->right==p && p->right==x) x=sleft(sleft(g));
            else if (g->left==p) { g->left=sleft(p); x=sright(g); }
            else { g->right=sright(p); x=sleft(g); }
            if (n) {
                Node *a=path[n-1];
                if (a->left==g) a->left=x; else a->right=x;
            }
        }
    }
    free(path); return x;
}
static Node *splay_insert(Node *root,int key) {
    root=splay_access(root,key);
    if (root && root->key==key) return root;
    Node *t=malloc(sizeof *t);
    if (!t) abort();
    *t=(Node){.key=key};
    if (root && key<root->key) {
        t->left=root->left; t->right=root; root->left=NULL;
    } else if (root) {
        t->right=root->right; t->left=root; root->right=NULL;
    }
    return t;
}
static Node *splay_delete(Node *root,int key) {
    root=splay_access(root,key);
    if (!root || root->key!=key) return root;
    Node *l=root->left,*r=root->right; free(root);
    if (!l) return r;
    /* key 比 l 中的所有键都大，未命中访问恰伸展其最大键。 */
    l=splay_access(l,key); l->right=r; return l;
}

九、§4.6：当读取一个节点需要访问磁盘

9.1　本书采用的 B 树约定

前面的查找树都为二叉，而 B 树允许一个节点连接多棵子树。书中明确提醒 B 树有不同定义，因此必须先按本版规则读图：阶 M 是最大孩子数；非根内部节点的孩子数在 ⌈M2⌉ 与 M 之间，根要么是叶子，要么至少有两个孩子；所有叶子同深。示例暂时还让非根叶子保存 ⌈M2⌉ 到 M 个实际键。

“All data are stored at the leaves.”

译：所有数据都存储在叶子中。

§4.6，印刷页 128

内部节点存孩子指针与分隔键：k1 是第二棵孩子子树的最小键，k2 是第三棵的最小键，依此类推。分隔键是路由信息，不是被搬走后只剩内部节点保存的唯一记录。该定义属于数据在叶子中的 B 树变体；它具有常见 B+ 树的这种组织特点，但本章并未规定叶子之间的顺序链，不能额外假设沿叶子链扫描。

图 4.61 的根分隔值为 21、48、72。查找 59 时，因 48≤59<72，进入第三棵子树；其分隔键是 59，再进入相应叶子。这也说明相等时走向右侧对应孩子。M 个孩子只需要 M−1 个有效分隔键，不能把“阶 M”误读为“内部节点恰有 M 个键”。

9.3　删除与重新分配：下溢也可能向上传播

删掉叶子的键后，若叶子仍满足最小容量，结构不用变化，但涉及子树最小键时必须更新相应分隔信息。若三阶树的叶子从 2 个键变成 1 个，就看相邻兄弟：兄弟有 3 个，借一个使两边都剩 2 个；兄弟只有 2 个，就合并成一个含 3 键的叶子。合并让父节点少一个孩子，也可能使父节点下溢，因此修复可以沿访问路径继续向上传播。根若只剩一个孩子，可以撤掉根，树高减少 1；删除全部键还要按实现约定回到空树或空根叶子。

书中还举插入 70 的重新分配例子：在 [58,59,61] 溢出前，把 58 移给相邻 [41,52]，新叶子变为 [59,61,70]，同步调整分隔值。这样用更复杂的更新过程换较高利用率，未必每次溢出都立刻分裂。

9.4　为什么磁盘上反而愿意让 M 很大？

若只数内存计算，每个节点内用二分查找分支要 O(logM)，修复数组可能要 O(M)；树高为 O(log⌈M/2⌉N)，查找总比较量仍为 O(logN)，插删的朴素最坏 CPU 界为 O(Mlog⌈M/2⌉N)。把 M 视为固定常数时是对数时间，但比较不同阶数时不能隐藏这部分成本。

磁盘模型的重点却是页读取次数。若每个节点恰好装进一页，一条查找路径只需按树高读取页面；较大 M 能显著减少层数。内部页按孩子指针与分隔信息定容量，叶子按记录大小定容量，两者在真实实现中可以不同。书中举 M 通常为 32–256、根及首层可常驻内存的历史性例子，目的在说明页大小与记录大小决定选择，而不是给现代系统规定固定参数。

同一个结构有两种账本：CPU 比较／移动成本与页面 IO 成本。B 树用较多的页内工作换较少的页面访问；AVL 则主要保护内存中的查找路径长度。把二者都只写成 O(logN)，会隐藏最重要的设计区别。

4.7 · 叶子深度的 Kraft 不等式

原题（中文翻译）

假设二叉树有叶子 l1,l2,…,lM，其深度分别为 d1,d2,…,dM。证明 ∑i=1M2−di≤1，并确定等号何时成立。

原书习题 4.7 · 印刷页 134 · PDF 第 151 页。

解答

根获得质量 1，每向一个左／右孩子传质量减半，深度 d 叶子获得 2−d。两孩子节点不损失总量，一个孩子节点会损失一半，质量不可能增加，故所有叶子的质量和 ≤1。

等号当且仅当每个内部节点都恰有两个孩子，即没有单孩子节点。单节点树也满足等号；叶子不必同深，满二叉树不必是完美二叉树。

不借助概率语言的归纳证明

定义 W(T)=∑ℓ 是叶子2−d(ℓ)。单叶树 W=1；只有一个孩子时 W 为孩子的 W 除以 2，严格小于 1；有两个孩子时 W 为两孩子 W 的平均，至多 1，且等号恰在两孩子都取等号时出现。按节点数归纳，同时得到不等式与等号条件。不能仅检查根是否有两个孩子，必须每个内部节点都如此。

C（C11）
#include <stdbool.h>
#include <stdio.h>
static Node *bst_max(Node *t) {
    if (t) while (t->right) t = t->right;
    return t;
}
static bool bst_retrieve(const Node *p, int *out) {
    if (!p) return false;
    *out = p->key; return true; /* out 必须非空 */
}
static void bst_print(const Node *t) {
    if (t) {
        bst_print(t->left); printf("%d\n", t->key); bst_print(t->right);
    }
}

4.11 · 游标 BST

原题（中文翻译）

采用与游标链表类似的策略，可以用游标实现二叉查找树。编写这种游标实现下的基本二叉查找树操作。

原书习题 4.11 · 印刷页 135 · PDF 第 152 页。

解答

节点数组每槽保存 key、leftIndex、rightIndex；0 为无节点。建立独立 freelist，分配弹空闲槽，释放归还槽。Find 以索引下降；Insert 返回新根索引；Delete 仍分三种，用右子树最小索引的键替换，再归还被删槽；Clear 后序归还全部槽。节点访问 pool[t] 替代 t->。

操作复杂度同指针版，分配／归还槽 O(1)，总容量固定；空间 O(C)。下标被归还并复用后，旧游标可能指向不同节点，不能继续当作原记录的位置。

固定容量游标版

C（C11）
#include <stdbool.h>
#include <stdlib.h>
#define CAP 4096
typedef struct { int key, left, right, next; } Slot;
static Slot pool[CAP + 1];
static int free_head;
static void cursor_init(void) {
    for (int i = 1; i <= CAP; ++i) pool[i].next = i == CAP ? 0 : i + 1;
    free_head = 1;
}
static int take(int key) {
    int t = free_head;
    if (!t) abort();  /* 容量不足；库接口可改为返回错误 */
    free_head = pool[t].next;
    pool[t] = (Slot){key, 0, 0, 0};
    return t;
}
static void give(int t) { pool[t].next = free_head; free_head = t; }
static int cursor_find(int t, int key) {
    while (t && pool[t].key != key)
        t = key < pool[t].key ? pool[t].left : pool[t].right;
    return t;
}
static int cursor_insert(int t, int key) {
    if (!t) return take(key);
    if (key < pool[t].key) pool[t].left = cursor_insert(pool[t].left, key);
    else if (key > pool[t].key) pool[t].right = cursor_insert(pool[t].right, key);
    return t;
}
static int cursor_delete(int t, int key) {
    if (!t) return 0;
    if (key < pool[t].key) pool[t].left = cursor_delete(pool[t].left, key);
    else if (key > pool[t].key) pool[t].right = cursor_delete(pool[t].right, key);
    else if (pool[t].left && pool[t].right) {
        int s = pool[t].right;
        while (pool[s].left) s = pool[s].left;
        pool[t].key = pool[s].key;
        pool[t].right = cursor_delete(pool[t].right, pool[s].key);
    } else {
        int child = pool[t].left ? pool[t].left : pool[t].right;
        give(t); return child;
    }
    return t;
}
static int cursor_clear(int t) {
    if (t) {
        cursor_clear(pool[t].left); cursor_clear(pool[t].right); give(t);
    }
    return 0;
}
static int cursor_min(int t) {
    if (t) while (pool[t].left) t = pool[t].left;
    return t;
}
static int cursor_max(int t) {
    if (t) while (pool[t].right) t = pool[t].right;
    return t;
}
static bool cursor_retrieve(int t, int *out) {
    if (!t || !out) return false;
    *out = pool[t].key; return true;
}
#include <stdio.h>
static void cursor_print(int t) {
    if (t) {
        cursor_print(pool[t].left); printf("%d\n", pool[t].key);
        cursor_print(pool[t].right);
    }
}

            raise ValueError("capacity must be positive")
        self.pool = [[0, 0, 0, i + 1] for i in range(capacity + 1)]
        self.pool[capacity][3] = 0
        self.free_head, self.root = 1, 0
    def take(self, key):
        t = self.free_head
        if not t:
            raise OverflowError("cursor pool is full")
        self.free_head = self.pool[t][3]
        self.pool[t] = [key, 0, 0, 0]
        return t
    def give(self, t):
        self.pool[t][3], self.free_head = self.free_head, t
    def find(self, key):
        t = self.root
        while t and self.pool[t][0] != key:
            t = self.pool[t][1 if key < self.pool[t][0] else 2]
        return t
    def minimum(self):
        t = self.root
        if t:
            while self.pool[t][1]:
                t = self.pool[t][1]
        return t
    def maximum(self):
        t = self.root
        if t:
            while self.pool[t][2]:
                t = self.pool[t][2]
        return t
    def retrieve(self, t):
        return (True, self.pool[t][0]) if t else (False, None)
    def insert(self, key):
        def descend(t):
            if not t:
                return self.take(key)
            side = 1 if key < self.pool[t][0] else 2
            if key != self.pool[t][0]:
                self.pool[t][side] = descend(self.pool[t][side])
            return t
        self.root = descend(self.root)
    def remove(self, key):
        def descend(t, key):
            if not t:
                return 0
            if key != self.pool[t][0]:
                side = 1 if key < self.pool[t][0] else 2
                self.pool[t][side] = descend(self.pool[t][side], key)
            elif self.pool[t][1] and self.pool[t][2]:
                s = self.pool[t][2]
                while self.pool[s][1]:
                    s = self.pool[s][1]
                self.pool[t][0] = self.pool[s][0]
                self.pool[t][2] = descend(self.pool[t][2], self.pool[s][0])
            else:
                child = self.pool[t][1] or self.pool[t][2]
                self.give(t)
                return child
            return t
        self.root = descend(self.root, key)
    def values(self):
        def walk(t):
            if t:
                yield from walk(self.pool[t][1])
                yield self.pool[t][0]
                yield from walk(self.pool[t][2])
        return list(walk(self.root))
    def clear(self):
        def release(t):
            if t:
                release(self.pool[t][1]); release(self.pool[t][2]); self.give(t)
        release(self.root)
        self.root = 0

调用模式为 cursor_init(); int root=0;，随后每次 root=cursor_insert(root,k) 或 root=cursor_delete(root,k)。slot 0 从不分配；give 只写空闲链字段，不影响尚存活的父入口。清空后要接回 0，再次初始化只能在没有存活树时进行。查找返回的游标仅在对应节点被删除前有效。

4.12 · 随机插删实验中的拒绝采样

原题（中文翻译）

假设要通过实验验证随机插入／删除对可能造成的问题。下面的策略并非完全随机，但足够接近：从 1 至 M=αN 中随机选择 N 个元素插入，建立查找树；然后执行 N2 对“先插入、再删除”操作。假设 RandomInteger(A,B) 返回闭区间 [A,B] 内的均匀随机整数。

  1. 说明如何生成一个介于 1 与 M 之间、且尚未在树中的随机整数，以便随机插入。用 N,α 表示其运行时间。
  2. 说明如何生成一个介于 1 与 M 之间、且已经在树中的随机整数，以便随机删除。其运行时间是多少？
  3. α 选什么值较好？为什么？

原书习题 4.12 · 印刷页 135–136 · PDF 第 152–153 页。

解答

令键空间大小 M=αN，当前有 N 个互异键。

a 均匀抽 [1,M]，Find 不存在才接受，成功率 (α−1)/α，期望尝试次数 αα−1。b 删除键通过反复抽到已存在键，成功率 1α，期望尝试 α 次。每次检查期望 O(logN) 仅在当前树的访问成本具备该条件时成立；一般应写为尝试次数乘实际 Find 成本。

c α 不能太接近 1，也不能太大。一对采样的期望次数为 αα−1+α，在 α=2 时最小，所以 M≈2N 是自然选择。实验固定种子、记录树大小与内部路径长度，N2 对更新不等于随机树形始终均匀。

期望次数与最佳 α 的计算

独立重试成功概率 q 时，尝试数 X 满足 Pr(X≥r)=(1−q)r−1，故

𝔼[X]=∑r=1∞(1−q)r−1=1q.

令 u=α−1>0，一对采样成本为 α+αα−1=u+2+1u≥4，等号当且仅当 u=1，即 α=2。这不需要微积分。若先插后删且插入后有 N+1 个键，删除成功率应改为 (N+1)/M；原式按采样时大小 N 计算，程序须明确操作顺序。

4.13 · 三种双孩子删除策略的实验

原题（中文翻译）

编写程序，实测删除一个有两个孩子的节点时，以下策略的表现：

  1. 用左子树 TL 中的最大节点 X 替代被删除节点，再递归删除 X。
  2. 交替使用 TL 中的最大节点和 TR 中的最小节点替代，再递归删除相应节点。
  3. 随机选择 TL 中的最大节点或 TR 中的最小节点替代，再递归删除相应节点。

哪一种策略看起来最能保持平衡？哪一种处理完整操作序列所需的 CPU 时间最少？

原书习题 4.13 · 印刷页 136 · PDF 第 153 页。

解答

a 始终取左子树最大；b 前驱与后继交替；c 每次用独立随机位选择前驱或后继。只有双孩子删除需要选择；三种均 O(h+1)。用同一初始排列与相同插删键序列，每种重复多个种子，比较平均深度、最大深度、总比较数与 CPU 时间。

# 64 位 xorshift*；与 C 驱动生成完全相同的键序列。
class RNG:
    MASK = (1 << 64) - 1
    def __init__(self, seed):
        if not seed:
            raise ValueError("seed must be nonzero")
        self.state = seed & self.MASK
    def next(self):
        x = self.state
        x ^= x >> 12; x ^= (x << 25) & self.MASK; x ^= x >> 27
        self.state = x
        return x * 2685821657736338717 & self.MASK
    def below(self, width):
        threshold = (1 << 64) % width
        while True:
            x = self.next()
            if x >= threshold:
                return x % width
    def key(self, width):
        return 1 + self.below(width)

def node_shape(t):
    if t is None:
        return 0, 0, -1
    an, ad, ah = node_shape(t.left)
    bn, bd, bh = node_shape(t.right)
    return an + bn + 1, ad + bd + an + bn, 1 + max(ah, bh)

def node_values(t):
    if t is not None:
        yield from node_values(t.left)
        yield t.key
        yield from node_values(t.right)

def strategy_delete(t, key, mode, state, rng):
    if t is None:
        return None
    if key < t.key:
        t.left = strategy_delete(t.left, key, mode, state, rng)
    elif key > t.key:
        t.right = strategy_delete(t.right, key, mode, state, rng)
    elif t.left is not None and t.right is not None:
        pred = True if mode == 0 else state[0] if mode == 1 else rng.below(2) == 0
        if mode == 1:
            state[0] = not state[0]
        s = t.left if pred else t.right
        if pred:
            while s.right is not None:
                s = s.right
        else:
            while s.left is not None:
                s = s.left
        t.key = s.key

            t.left = strategy_delete(t.left, s.key, mode, state, rng)
        else:
            t.right = strategy_delete(t.right, s.key, mode, state, rng)

    return t

4.14 · 随机 BST 的期望最大深度

原题（中文翻译）

证明：随机二叉查找树的深度，即最深节点的深度，其平均值为 O(logN)。

原书习题 4.14 · 印刷页 136 · PDF 第 153 页。

解答

证明路线：给各键独立连续随机优先级，越小者越早插入，这与均匀随机排列等价。键 j 左侧的祖先是向左扫描时的优先级记录最小值，右侧同理。忽略 j 的优先级门槛，只会增加记录数，于是其深度由两侧记录数之和 R 支配。

随机排列的记录指示相互独立，第 m 个位置成为记录的概率为 1m。两侧记录也来自互不相交的随机优先级，故 𝔼[eλR]≤exp((eλ−1)(2lnN+2))。取 λ=1，用 Markov 不等式并对 N 个节点作并合界：Pr(H≥t)≤Nexp((e−1)(2lnN+2)−t)。

当 t≥8 ln N+常数时，尾概率以 t 指数衰减；将 P(H≥t) 对整数 t 求和，得到 𝔼[H]=O(log N)。这证明最大深度，而不是仅凭平均节点深度代替最大值。记录独立性可由随机排列的相对秩均匀且独立证明。

补足记录变量独立性与尾和

长度 m 的随机优先级序列中，第 r 项在前 r 项的相对秩均匀分布于 1…r；整个相对秩向量与排列一一对应，共有 ∏r=1mr=m! 种等可能取值。因此这些秩独立，记录指示 Ir=𝟏{rankr=1} 也是独立 Bernoulli 变量。于是

𝔼[eλ∑Ir]=∏r=1m(1+eλ−1r)≤exp((eλ−1)Hm),Hm≤1+lnm.

对于节点 j，左侧键 i 成为祖先，当且仅当 i 的优先级是区间 [i,j] 的最小值；去掉端点 j 后，它必是从 j−1 向左扫描时的一次新纪录。右侧同理。左右两组独立，不声称不同节点的深度相互独立；并合界不需要后一个独立性。

取 t0=⌈8lnN+2(e−1)⌉。N≥2 时，前面的尾界给 Pr(H≥t0+s)≤e−s，所以

𝔼[H]=∑t≥1Pr(H≥t)≤t0+∑s≥1e−s=O(logN).

N=0、1 分别单独处理。二叉树容量界还给 H≥⌈log2(N+1)⌉−1，因而随机排列模型下最大深度的期望实际上为对数阶。这里的概率来自插入次序均匀，而不是“所有树形均匀”。

4.15 · AVL 的最小节点数与高度 15

原题（中文翻译）

  1. 给出高度为 H 的 AVL 树最少节点数的精确表达式。
  2. 高度为 15 的 AVL 树最少有多少个节点？

原书习题 4.15 · 印刷页 136 · PDF 第 153 页。

a 令 S(−1)=0、S(0)=1，S(h)=1+S(h−1)+S(h−2)。按 F0=0、F1=1 的 Fibonacci 定义，S(h)=Fh+3−1，代入基例后归纳即可。

b S(15)=F18−1=2584−1=2583。空树高度为 −1，不能把高度 15 当成 15 层而错移下标。

最小性和闭式的完整归纳

高度 h≥1 的 AVL 至少有一个孩子高 h−1，另一个孩子高不小于 h−2，否则根失衡。因此节点数至少 1+S(h−1)+S(h−2)。反过来把这两棵最小树接到新根，根平衡、其余节点仍平衡，确实达到该数；这一步证明下界可达到。

基例：S(−1)=0=F2−1，S(0)=1=F3−1。假设前两项成立，则

S(h)=1+(Fh+2−1)+(Fh+1−1)=Fh+3−1.

解答

先证明一个更强的不变量

记 T(n) 为按标准 AVL 插入升序键 1…n 的结果。除 n=1、2 单独列出外，设 r≥1 是使 3·2r−1≤n<3·2r 成立的唯一整数。证明：T(n) 的根为 2r，左子树是含 2r−1 个节点的完美树，右子树是键整体平移后的 T(n−2r)，而高度为 ⌊log2n⌋。n=1、2 时根均为 1，左空、右为 T(n−1)，高度分别 0、1，也满足对应的 r=0 形式。

强归纳：普通增长与临界旋转

每个新键都比当前键大，只插入右子树；对子树应用归纳假设即可知道右侧修复后的形状。固定根指数 r 时，左高为 r−1。只要右侧节点数小于 2r+1，归纳给右高至多 r，根不会失衡，左树不变。其右侧节点数至少 2r−1，因此根高由 n 是否达到 2r+1 决定，恰为上述取整对数。

临界时新总数为 n=3·2r，右侧节点数刚变成 2r+1，右高 r+1，旧根必须左单旋。归纳给这棵右树的局部根键为 2r，平移后为 2r+1；它的左树是有 2r−1 个节点的完美树。旋转后，旧根的左右两侧恰是这样的两棵完美树，所以新左树是有 2r+1−1 个节点的完美树。新右树有 2r 个节点，仍是平移的 T；这正是根指数 r+1 的不变量。基例、非临界增长和临界旋转穷尽所有情况，强归纳完成。

代入题目的节点数

k≥2 时 n=2k−1 落在 r=k−1 的区间，根为 2k−1，左右都含 2k−1−1 个节点；左边由不变量完美，右边对 k 归纳也完美，因此全树完美、高度 k−1。k=1 是单节点基例。这个证明使用了插入动态与旋转时机，并非从节点总数反推树形；中间前缀不必完美。

4.19 · 非递归 AVL 插入

原题（中文翻译）

编写一个非递归函数，实现 AVL 树插入。

原书习题 4.19 · 印刷页 136 · PDF 第 153 页。

解答

沿 BST 查找路径保存祖先指针与每次方向，遇空位置插叶子；从路径尾向前弹出，更新 height、检查平衡因子，必要时按 LLRR/LR/RL 修复，并把新子树根写回父孩子或全树 root。修复后高度不再向上增长，可停止继续找失衡，但已保存的元信息必须一致。

时间 O(logN)，祖先栈 O(logN)。可额外保存父指针减少路径栈，但旋转维护父链接仍有成本。重复键不插入，分配失败在接入前处理；非递归不等于自动拥有 O(1) 额外空间。

不调用递归的具体流程

使用下面 4.20 的 ANode 和 rebalance，保存的是“指向子树根的指针”，所以根旋转与孩子旋转使用同一入口。路径数组长度不依赖预设高度。

C（C11）
#include <stdint.h>
static ANode *avl_insert_iter(ANode *root, int key) {
    size_t n = 0, cap = 16;
    ANode ***path = malloc(cap * sizeof *path);
    if (!path) abort();
    ANode **link = &root;
    while (*link) {
        if (key == (*link)->key) { free(path); return root; }
        if (n == cap) {
            if (cap > SIZE_MAX / 2 / sizeof *path) abort();
            cap *= 2;
            ANode ***grown = realloc(path, cap * sizeof *path);
            if (!grown) abort();
            path = grown;
        }
        path[n++] = link;
        link = key < (*link)->key ? &(*link)->left : &(*link)->right;
    }
    ANode *leaf = malloc(sizeof *leaf);
    if (!leaf) abort();
    *leaf = (ANode){.key=key, .height=0};
    *link = leaf;
    while (n) { link = path[--n]; *link = rebalance(*link); }
    free(path); return root;
}

4.20 · AVL 的物理删除

原题（中文翻译）

如何在 AVL 树中实现实际删除，而非懒惰删除？

原书习题 4.20 · 印刷页 136 · PDF 第 153 页。

解答

先执行 BST 删除；双孩子时换后继并从后继实际删除位置开始回溯。每个祖先更新高度，若平衡因子 b=h(left)−h(right)=2，检查左孩子因子：≥0 右单旋，<0 LR 双旋；b=−2 时右孩子因子≤0 左单旋，否则 RL。

删除时孩子因子可能为 0，不可使用“新插入键与孩子键比较”的判据。若修复后高度继续下降，继续向父亲处理；直到高度未变或到根。最坏 O(logN) 个修复点，整体 O(logN)。必须更新所有旋转后的 height 与父入口，且只释放真正被摘下的节点。

static ANode *rebalance(ANode *t) {
    if (!t) return NULL;
    update(t);
    int b = ah(t->left) - ah(t->right);
    if (b > 1) {
        if (ah(t->left->left) < ah(t->left->right))
            t->left = aleft(t->left);
        return aright(t);
    }
    if (b < -1) {
        if (ah(t->right->right) < ah(t->right->left))
            t->right = aright(t->right);
        return aleft(t);
    }
    return t;

        t->key = s->key;
        t->right = avl_delete(t->right, s->key);
    } else {

        free(t); return child;
    }

4.22 · 直接做双旋，避免调用两次单旋

原题（中文翻译）

编写直接执行双旋转的函数，避免通过两次单旋转实现双旋转所带来的低效。

原书习题 4.22 · 印刷页 136 · PDF 第 153 页。

解答

LR：旧根 g、左孩子 p、p 的右孩子 x；保存 x 的两棵子树。先令 p.right=x.left; g.left=x.right，再令 x.left=p; x.right=g。按 p、g、x 的次序重算高度并返回 x。RL 镜像：g.right=x.left; p.left=x.right; x.left=g; x.right=p，这里 p 为旧根右孩子。

仍是 O(1)，减少函数调用与中间高度计算；所有中间子树必须先转接，不能丢链接。

enum { N=1024 };

    int p=L[g]; L[g]=R[p]; R[p]=g; return p;
}

    int p=R[g]; R[g]=L[p]; L[p]=g; return p;
}
static int access(int root,int key) {
    int path[N], n=0, x=root;
    while (x && x!=key) {
        path[n++]=x; x=key<x ? L[x] : R[x];
    }
    assert(x); /* 本题访问 1..N 的已存在键。 */
    while (n) {
        int p=path[--n];
        if (!n) x=L[p]==x ? right(p) : left(p);
        else {

            else if (R[g]==p && R[p]==x) x=left(left(g));
            else if (L[g]==p) { L[g]=left(p); x=right(g); }
            else { R[g]=right(p); x=left(g); }
            if (n) {

                if (L[a]==g) L[a]=x; else R[a]=x;

    }

4.26 · 顺序访问后的链形与总成本

原题（中文翻译）

  1. 证明：按键的顺序访问伸展树的全部节点之后，所得树是一条由左孩子组成的链。
  2. 证明：无论初始树的形状如何，按键的顺序访问伸展树的全部节点，其总访问时间都是 O(N)。

原书习题 4.26 · 印刷页 137 · PDF 第 154 页。

解答

a 访问 1 后它为根且无左树。归纳：访问 k 后，左侧是 k−1…1 的左链；下一键 k+1 在右子树的最左路径上，将它伸展时，已访问的左链整体保留并最终接到 k+1 的左边。访问完 N，得到 N→N−1→…→1 的纯左链。

b：把访问路径映射到旋转费用

设键互异，按秩改记为 1,2,…,N，依次成功查找并执行本章 底向上 zig／zig−zig／zig−zag 伸展；期间不插入或删除。空树的结论直接成立。为统一第一次访问，仅在分析中加一个更小的哨兵 0 作根，原树作其右树。第一次伸展只多一次涉及哨兵的旋转，去掉哨兵后与原操作得到同一棵树，之后它留在已访问左链中。记 Tt 为已访问 1,…,t 后的树，其根为 t。

下一目标 t+1 在根右树的最左路径上；称这条路径为访问脊，记节点数 st，从下至上标为 y1=t+1,y2,…,yst。底向上双旋依次处理 (y1,y2,y3),(y1,y4,y5),…。st 为奇数时最后另做一次 zig，为偶数时最后做一次 zig−zag；因此本次实际单旋数恰为 rt+1=st。每个已配对的 (y2i,y2i+1) 对应一个 zig−zig 的两次旋转。访问脊和成对链接的这种分解见 Elmasry，2001，§2；计费时必须把双旋算作两次单旋。

明确的信用定义与中间双旋

以下使用可逐步检查的局部势差引理，而不把顺序访问定理本身当作前提。对真实节点记录颜色 ct(x)：当前根为 3；全树从根沿右链接的脊上其他节点为 2；访问脊上其余节点为 1；其他节点初始为 0，之后保留上一时刻颜色。按该优先次序赋色。令 gt(x) 数从 x 沿右链接的脊上颜色为 1 的节点，ht(x) 数其左孩子的右脊上颜色为 1 的节点（无左孩子则为 0），并令 vt(x)=gt(x)−ht(x)。引用的基本不变量是：颜色 1 的节点满足 vt(x)≥0。下面只对两个节点前后均为颜色 1 的中间对使用局部关系 ht(w)=gt(z)、ht+1(w)=ht(w)−1、vt+1(w)=vt(w)+1。这些是 Kakimura／Terai，2026-09-17 预印本的引理 4、6 及推论 5、7，适用的操作正是上述连续底向上伸展。

给每个节点如下非负信用（势能），哨兵不计入总和：

α(v)={5,v=0,max(3−v,0),v≥1,β(h)={1,0≤h≤1,2h−2,h≥2.
ϕt(x)={11/2,ct(x)=0,ht(x)2/2+α(vt(x)),ct(x)=1,β(ht(x)),ct(x)=2,0,ct(x)=3,Φt=∑x=1Nϕt(x).

上述信用是原文定义 8 的具体势函数。把配对中上节点位于全树右脊的称为顶部对；其余配对中下节点直接为目标父亲的称为底部对；剩下的是中间对，集合记为 Mt。各对节点互不重叠。对中间对 (z,w)，记 v=vt(z),u=vt(w)。局部关系还给出 ht+1(z)=ht(z)+1、vt+1(z)=v+u，所以这一对的信用下降为：

Δϕ(z,w)=ht(z)2+ht(w)2−(ht(z)+1)2−(ht(w)−1)22+α(v)+α(u)−α(v+u)−α(u+1)=v−1+Δα.

由 u,v≥0 与 α 的定义直接验算：v=0,1,2 时 Δα 分别至少为 3、2、1；v≥3 时，α(v)=α(v+u)=0，且 α(u)≥α(u+1)，故 Δα≥0。所有情况都得到 Δϕ(z,w)≥2，恰好支付这一中间对的两次单旋；这是原文引理 10 的计费映射。节点再次进入访问脊时仍按当前信用计算，并未假设它只参与一次旋转。

边界信用、望远镜求和与总访问时间

中间对以外的真实节点构成 Ot。这里引用原文已经证明的边界势差引理 11（其 §3.4 的引理 16／17 展开奇偶边界）：对于同一赋色、同一势函数和同一次 t+1 伸展，有

∑x∈Ot(ϕt(x)−ϕt+1(x))≥rt+1−2|Mt|={1,st=1,3,st=3,5,st≥5 and st odd,2,st=2,4,st≥4 and st even.

右端逐项对应未由中间对支付的旋转：奇数脊至多“底部两次＋顶部两次＋最后 zig 一次”，偶数脊至多“底部两次＋最后 zig−zag 两次”；长度 1、2、3 的短脊分别直接付 1、2、3 次。这个引理把顶部、底部、目标和新入脊节点的信用变化一起计算，因此不会漏掉重新入脊的成本，也不把可能的局部信用增加误当作免费。原文 §3.4 给出该边界引理的完整分类证明。

中间各对与 Ot 是节点集的不交分割；相加得到 rt+1≤Φt−Φt+1。初始时颜色 1 的节点只有初始访问脊上的节点，h0(x)≤1；颜色 2 的节点也满足 h0(x)≤1。从显式信用定义可得每个真实节点初始最多 11/2 信用，故 Φ0≤11N/2。所有时刻 Φt≥0，因此

R=∑t=0N−1rt+1≤∑t=0N−1(Φt−Φt+1)=Φ0−ΦN≤11N/2=O(N).

这先证明加哨兵版本的单旋总数为线性；原树少一次旋转，界同样成立。再补上题目要求的访问时间：一次成功访问的原目标深度为 d，搜索经过 d+1 个节点；将目标移到根的底向上伸展恰做 d 次单旋。一次节点比较和一次局部旋转都只需常数时间，故全部查找、记录路径与旋转合计 O(N+R)=O(N)。访问 N 个节点本身又需 Ω(N) 时间，所以总成本为 Θ(N)，且初始树形任意。

顺序访问定理原始出处仍是本书参考文献 [32]：Tarjan，Sequential access in splay trees takes linear time，Combinatorica 5(4)，1985，367–378。本解答采用上面标明的后续势差引理，明确给出信用定义、每类旋转的支付者、初始总信用及从旋转数到访问时间的映射；常数仅服务于线性上界。

4.27 · 伸展、AVL、普通 BST 的性能实验

原题（中文翻译）

编写一个程序，对伸展树执行随机操作，统计整个序列中的总旋转次数。它的运行时间与 AVL 树、不平衡二叉查找树相比如何？

原书习题 4.27 · 印刷页 137 · PDF 第 154 页。

解答

旋转函数每调用一次计数器加 1，双旋记 2。固定初始键集、随机种子和操作序列，在三种树上执行相同成功／失败查找、插入、删除；记录总旋转、比较、耗时、最大深度。分别测均匀访问、少量热点、有序插入，不将键生成、打印与节点分配差异混入纯查找计时。

理论预测：普通 BST 随机插入可较快但有退化；AVL 单次高度有界；伸展热点访问可能更省比较，却有旋转开销。题目要求的实际胜负必须测量，下方实现已按同一输入完成小规模对照；较大规模与多次中位数协议仍是可继续验证的范围。

一套具体、可重复的实验协议

控制项建议设置
规模与种子N=1000、5000、10000；种子 1…10。
输入生成先生成并保存操作数组，再分别重放。键是否存在由独立集合决定，不依赖某棵树的形状；生成与打印不计入树操作时间。
访问负载均匀成功查找；90% 请求集中在 10 个热点键；有序插入。失败查找另测并说明伸展到最后访问节点的规则。
测量预热一轮，正式重复至少五轮，报告时间中位数及范围；同时报告键比较数、基本旋转数与最终高度。
公平性每组从同一初始状态重新开始。树节点尽量使用相同的分配策略；若分配也计时，明确这是一项端到端指标。

对热点序列，伸展树第一轮的代价与适应后的代价可能不同，不应混成一个数字。查找中恰遇根不旋转；zig 计一次，zig−zig／zig−zag 计两次。检查计数器再关掉计数单测纯耗时，避免计数开销改变结论。上述是扩展实验协议；本次已运行下方固定规模驱动，结果只覆盖说明中的负载与参数。

4.28 · 数节点、叶子与满节点

原题（中文翻译）

编写高效函数，只接收二叉树 T 的根指针，分别计算：

  1. T 的节点数。
  2. T 的叶子数。
  3. T 的满节点数。

这些过程的运行时间是多少？

原书习题 4.28 · 印刷页 137 · PDF 第 154 页。

解答

一次后序同时返回三个计数。空树返回 (0,0,0)；节点数=左右节点数+1；叶子数=左右叶子数+当前是否两孩子皆空；满节点数=左右满节点数+当前是否两孩子皆非空。

三种计数合并遍历 Θ(N)，辅助栈 O(h+1)。整数加法与孩子判断按常数计；叶子与满节点可用 4.6 的等式交叉检查。

空树返回全零；单节点返回 (1,1,0)；只有一条孩子链时叶子数 1、满节点数 0；根带两个叶子时返回 (3,2,1)。代码使用 size_t，树规模必须使计数相加不溢出。anode 与 afree 同时供后面的构造题使用。

本题及 4.29–4.31、4.33–4.35 共用 4.20 的 ANode；本题提供 anode 构造与 afree 销毁。正文 Avl 是旋转示意使用的独立类型，不与 ANode 混传。C 构造器接管左右子树，失败中止；Python 以对象引用保存孩子。返回树由调用者持有，销毁后应清空根入口。

4.29 · 生成键 1…N 的随机 BST

原题（中文翻译）

编写函数，生成一棵有 N 个节点、键为互不相同的 1 至 N 的随机二叉查找树。过程的运行时间是多少？

原书习题 4.29 · 印刷页 137 · PDF 第 154 页。

解答

简法：Fisher–Yates 均匀打乱 1…N，再逐个插入，期望 O(NlogN)、最坏 O(N2)。更高效：递归对区间 [lo,hi] 均匀选根 k，独立生成 [lo,k−1] 与 [k+1,hi]；各根秩等可能，分布与随机插入相同，且每个节点只创建一次，时间 Θ(N)，输出空间 Θ(N)。

递归栈期望 O(logN)，最坏 O(N)。这是随机插入诱导分布，不是所有二叉树形等概率。

线性构造及分布证明

C（C11）
/* pick(lo,hi) 必须均匀返回闭区间内整数，且各次选择独立。 */
static ANode *random_bst(int lo, int hi, int (*pick)(int, int)) {
    if (lo > hi) return NULL;
    int k = pick(lo, hi);
    ANode *left = k == lo ? NULL : random_bst(lo, k - 1, pick);
    ANode *right = k == hi ? NULL : random_bst(k + 1, hi, pick);
    return anode(k, left, right);
}
Python 3
# 使用题 4.28 的 anode。随机源为显式参数，便于复现和替换。
def random_bst(lo, hi, pick):

        return None
    key = pick(lo, hi)
    if not lo <= key <= hi:
        raise ValueError("pick returned an out-of-range key")

均匀随机排列的第一个键在 N 个键中均匀。条件于首键 k，左侧键的相对插入顺序、右侧键的相对插入顺序均匀且独立；二者的交错不影响各自子树。按区间长度归纳，程序与逐项随机插入的分布相同。

从递推 T(n)=T(k−1)+T(n−k)+c 不能直接按平均平分得到最坏界；更直接的证明是每个键只创建一次，空区间也至多出现 n+1 次。若 pick 按常数期望成本实现，整个构造期望线性；若把均匀抽样视为单位成本，结构性操作次数对每一树形都线性。rand()%width 通常有模偏差，不应当作严格均匀采样。

4.30 · 生成高度 H 的最小 AVL

原题（中文翻译）

原书习题 4.30 · 印刷页 137 · PDF 第 154 页。

解答

Build(-1) 返回空；Build(h) 建根，左右分别 Build(h-1)、Build(h-2)，H=0 仅叶子。可固定较高子树在左，镜像也是合法答案。建立后做中序递增编号以赋 BST 键，或预先算子树规模直接分配键。

构造同时完成中序赋键

4.31 · 生成完美 BST

原题（中文翻译）

原书习题 4.31 · 印刷页 137 · PDF 第 154 页。

解答

区间 [1,2H+1−1] 取中点为根，左右递归建半区间，空区间结束。根为 2H，每层满，树高 H。时间 Θ(2H+1−1)=Θ(N)，输出空间 Θ(N)，调用栈 O(H+1)。大 H 时先检查节点数与整数位宽，不能移位溢出后再申请。

4.32 · 只输出区间 [k1,k2]

原题（中文翻译）

编写函数，输入二叉查找树 T 及满足 k1≤k2 的两个键，输出树中所有满足 k1≤Key(X)≤k2 的元素 X。除了键能够按一致的规则比较大小之外，不得对键类型作其他假设。程序的平均运行时间应为 O(K+logN)，其中 K 为输出键数。给出算法运行时间的界。

原书习题 4.32 · 印刷页 138 · PDF 第 155 页。

解答

C（C11）
#include <stddef.h>
/* 键和节点均由调用者拥有；遍历借用它们，不分配、不修改。 */
typedef struct GNode {
    const void *key;
    struct GNode *left, *right;
} GNode;
typedef int (*KeyCompare)(const void *, const void *);
typedef void (*KeyVisit)(const void *, void *);
static void range_query(const GNode *t, const void *lo, const void *hi,
                        KeyCompare cmp, KeyVisit visit, void *ctx) {
    if (!t || cmp(lo, hi) > 0) return;
    int lower = cmp(lo, t->key), upper = cmp(t->key, hi);
    if (lower < 0) range_query(t->left, lo, hi, cmp, visit, ctx);
    if (lower <= 0 && upper <= 0) visit(t->key, ctx);
    if (upper < 0) range_query(t->right, lo, hi, cmp, visit, ctx);
}
Python 3
# 只使用一致的比较，不依赖整数加减；同样适用于字符串键。
def range_query(t, lo, hi):
    if t is None or hi < lo:
        return
    if lo < t.key:
        yield from range_query(t.left, lo, hi)
    if not t.key < lo and not hi < t.key:
        yield t.key
    if t.key < hi:
        yield from range_query(t.right, lo, hi)

输出有序。只会访问输出区间内的节点与两条边界路径，时间 O(K+h+1)，随机 BST 期望 O(K+logN)，平衡树最坏相同。没有输出时仍须计边界查找，不是 O(K)；辅助栈 O(h+1)。

C 的 GNode 与键均为借用；cmp 必须提供一致的全序，visit 负责打印或收集，ctx 是调用者状态。Python 返回生成器，可用 print 或 list 消费。字符串键 a、c、e 的树查 [b,e] 输出 c、e；这两个实现只比较，不依赖键的算术。

原题（中文翻译）

  2. 可以用节点深度的负值作为 y 坐标。编写过程，为每个节点计算 y 坐标。

  4. 证明这种画法的连线不会交叉，并且对于任意节点 X，其左子树全部位于 X 左边，右子树全部位于 X 右边。

原书习题 4.33 · 印刷页 138 · PDF 第 155 页。

解答

a 中序遍历共享计数器，每访问节点设 x=counter++。b 前序传 depth，设 y=−depth，孩子传 depth+1。c 横跨度 N−1，纵跨度 h；若目标实际高／宽=23 且 h>0、N>1，取单位比例 sysx=2(N−1)3h，单节点另设尺寸。

中序坐标与深度的具体实现

两个版本使用 4.20 的 ANode 定义；只改坐标字段，不改链接。空树不分配坐标，根深度为 0。

C（C11）
/* 使用题 4.20 的 ANode，其中 x、y、circle 是附加字段。 */
static void tree_layout(ANode *t, int depth, size_t *next) {
    if (!t) return;
    tree_layout(t->left, depth + 1, next);
    t->x = (*next)++; t->circle = t->x + 1; t->y = -depth;
    tree_layout(t->right, depth + 1, next);
}
/* 包装：size_t next=0; tree_layout(root, 0, &next); */
Python 3
# 使用题 4.20 的 ANode。返回节点总数与按边计的高度。
def tree_layout(root):
    next_x, height = 0, -1
    def visit(t, depth):
        nonlocal next_x, height
        if t is None:
            return
        visit(t.left, depth + 1)
        t.x, t.circle, t.y = next_x, next_x + 1, -depth
        next_x += 1
        height = max(height, depth)
        visit(t.right, depth + 1)
    visit(root, 0)
    return next_x, height

4.35 · 线性层序遍历

原题（中文翻译）

编写过程，按层序列出二叉树节点：先根，再深度 1 的节点，再深度 2 的节点，依此类推。必须在线性时间内完成，并证明该时间界。

原书习题 4.35 · 印刷页 138 · PDF 第 155 页。

解答

非空根入队；队列未空时取队头输出，非空左孩子、右孩子依次入队。每个节点恰入队和出队各一次，每条边考察一次，故 Θ(N)。队列空间为 O(w)，w 为最大层宽，最坏 O(N)。使用 O(1) 入出队实现，不能每次出队搬移整个数组。

线性队列的参考实现

C（C11）
#include <stdio.h>
/* 队列包装节点只借用树节点；出队立刻释放，树本身保持不变。 */
typedef struct QLink {
    const ANode *node;
    struct QLink *next;
} QLink;
static void level_order(const ANode *root) {
    QLink *head=NULL, *tail=NULL;
    if (!root) return;
    head=tail=malloc(sizeof *head);
    if (!head) abort();
    *head=(QLink){root,NULL};
    while (head) {
        QLink *old=head;
        const ANode *t=old->node;
        head=old->next; if (!head) tail=NULL;
        free(old); printf("%d\n", t->key);
        const ANode *children[2]={t->left,t->right};
        for (int i=0;i<2;++i) if (children[i]) {
            QLink *q=malloc(sizeof *q);
            if (!q) abort();
            *q=(QLink){children[i],NULL};
            if (tail) tail->next=q; else head=q;
            tail=q;
        }
    }
}

4.37 · B 树插入、删除与先借再裂

原题（中文翻译）

  1. 编写 B 树插入过程。
  2. 编写 B 树删除过程。删除一个键后，是否必须更新内部节点的信息？
  3. 修改插入过程：向已经有 M 项的节点插入时，在分裂前先寻找一个孩子数少于 M 的兄弟。

原书习题 4.37 · 印刷页 138–139 · PDF 第 155–156 页。

解答

a 插入沿分隔路由到叶子，有序插键；若超过容量，把 M+1 项分成 ⌊M+12⌋、⌈M+12⌉ 两叶，父节点接入新孩子并重算分隔。父超过 M 孩子同样拆分、向上传播；根拆分另建两孩子根。

b 删除定位键并移除；低于占用下限时向同父相邻兄弟借键／孩子，不能借则合并；更新父孩子数组并继续修复。即使未下溢，删掉某子树最小键也可能改变祖先分隔，因此需要沿相关路径更新。根只剩一孩子时收缩。

c 溢出前，先查看左右相邻同父兄弟是否未满；若有，把两节点键或孩子顺序合并后按容量重新分配，再更新父分隔；都满才分裂。只检查相邻兄弟即可保持键区间连续。节点内移动 O(M)，沿高度路径，CPU 最坏 O(Mh)，页 IO 与 h 同阶（需计兄弟页）。本题给出实现算法，完整页缓存、持久化与错误恢复不属于此教学版本。

#include <stddef.h>

/* 数据仅存在叶子；内部 minimum 缓存路由用的子树最小键。 */
typedef struct BPage {
    bool leaf;
    size_t n;
    int minimum;
    int *keys;
    struct BPage **child;
} BPage;
typedef struct { size_t M,m; bool redistribute; BPage *root; } BTree;
static BPage *bpage(const BTree *b,bool leaf) {
    BPage *p=calloc(1,sizeof *p);
    if (!p) abort();
    p->leaf=leaf;
    if (leaf) {
        p->keys=malloc((b->M+1)*sizeof *p->keys);
        if (!p->keys) abort();
    } else {
        p->child=malloc((b->M+1)*sizeof *p->child);
        if (!p->child) abort();
    }
    return p;
}
static void brefresh(BPage *p) {
    if (p->n) p->minimum=p->leaf ? p->keys[0] : p->child[0]->minimum;
}
static void binit(BTree *b,size_t order,bool redistribute) {
    assert(order>=3 && order<SIZE_MAX/sizeof(BPage *)-1);
    *b=(BTree){order,(order+1)/2,redistribute,NULL};
    b->root=bpage(b,true);
}
static size_t broute(const BPage *p,int key) {
    size_t lo=1,hi=p->n;
    while (lo<hi) {
        size_t mid=lo+(hi-lo)/2;
        if (key<p->child[mid]->minimum) hi=mid; else lo=mid+1;
    }
    return lo-1;
}
static size_t bposition(const BPage *p,int key) {
    size_t lo=0,hi=p->n;
    while (lo<hi) {
        size_t mid=lo+(hi-lo)/2;
        if (p->keys[mid]<key) lo=mid+1; else hi=mid;
    }
    return lo;
}
static bool bcontains(const BTree *b,int key) {
    const BPage *p=b->root;
    while (!p->leaf) p=p->child[broute(p,key)];
    size_t i=bposition(p,key);
    return i<p->n && p->keys[i]==key;
}
static BPage *bsplit(const BTree *b,BPage *p) {
    size_t mid=p->n/2;
    BPage *r=bpage(b,p->leaf); r->n=p->n-mid;
    for (size_t j=0;j<r->n;++j) {
        if (p->leaf) r->keys[j]=p->keys[mid+j];
        else r->child[j]=p->child[mid+j];
    }
    p->n=mid; brefresh(p); brefresh(r); return r;
}
/* 移动边界项时，叶子移动键，内部移动整个孩子的所有权。 */
static void bmove_first(BPage *left,BPage *right) {
    if (left->leaf) left->keys[left->n++]=right->keys[0];
    else left->child[left->n++]=right->child[0];
    for (size_t j=1;j<right->n;++j) {
        if (right->leaf) right->keys[j-1]=right->keys[j];
        else right->child[j-1]=right->child[j];
    }
    --right->n; brefresh(left); brefresh(right);
}
static void bmove_last(BPage *left,BPage *right) {
    for (size_t j=right->n;j>0;--j) {
        if (right->leaf) right->keys[j]=right->keys[j-1];
        else right->child[j]=right->child[j-1];
    }
    --left->n;
    if (right->leaf) right->keys[0]=left->keys[left->n];
    else right->child[0]=left->child[left->n];
    ++right->n; brefresh(left); brefresh(right);
}
static void boverflow(const BTree *b,BPage *parent,size_t i) {
    BPage *p=parent->child[i];
    if (b->redistribute) {
        if (i>0 && parent->child[i-1]->n<b->M) {
            bmove_first(parent->child[i-1],p); return;
        }
        if (i+1<parent->n && parent->child[i+1]->n<b->M) {
            bmove_last(p,parent->child[i+1]); return;
        }
    }
    BPage *r=bsplit(b,p);
    for (size_t j=parent->n;j>i+1;--j) parent->child[j]=parent->child[j-1];
    parent->child[i+1]=r; ++parent->n;
}
static void binsert_down(const BTree *b,BPage *p,int key) {
    if (p->leaf) {
        size_t i=bposition(p,key);
        if (i<p->n && p->keys[i]==key) return;
        for (size_t j=p->n;j>i;--j) p->keys[j]=p->keys[j-1];
        p->keys[i]=key; ++p->n;
    } else {
        size_t i=broute(p,key); binsert_down(b,p->child[i],key);
        if (p->child[i]->n>b->M) boverflow(b,p,i);
    }
    brefresh(p);
}
static void binsert(BTree *b,int key) {
    binsert_down(b,b->root,key);
    if (b->root->n>b->M) {
        BPage *r=bsplit(b,b->root), *p=bpage(b,false);
        p->n=2; p->child[0]=b->root; p->child[1]=r; brefresh(p); b->root=p;
    }
}
static void bcontainer_free(BPage *p) { free(p->keys); free(p->child); free(p); }
static void bmerge(BPage *parent,size_t left_index) {
    BPage *a=parent->child[left_index],*r=parent->child[left_index+1];
    for (size_t j=0;j<r->n;++j) {
        if (a->leaf) a->keys[a->n+j]=r->keys[j];
        else a->child[a->n+j]=r->child[j];
    }
    a->n+=r->n; brefresh(a);
    /* 孩子已交给 a；这里只释放 r 的容器，不能递归释放。 */
    bcontainer_free(r);
    for (size_t j=left_index+2;j<parent->n;++j) parent->child[j-1]=parent->child[j];
    --parent->n;
}
static void bunderflow(const BTree *b,BPage *parent,size_t i) {
    BPage *p=parent->child[i];
    if (i>0 && parent->child[i-1]->n>b->m) bmove_last(parent->child[i-1],p);
    else if (i+1<parent->n && parent->child[i+1]->n>b->m) bmove_first(p,parent->child[i+1]);
    else bmerge(parent,i>0 ? i-1 : i);
}
static void bremove_down(const BTree *b,BPage *p,int key) {
    if (p->leaf) {
        size_t i=bposition(p,key);
        if (i<p->n && p->keys[i]==key) {
            for (size_t j=i+1;j<p->n;++j) p->keys[j-1]=p->keys[j];
            --p->n;
        }
    } else {
        size_t i=broute(p,key); bremove_down(b,p->child[i],key);
        if (p->child[i]->n<b->m) bunderflow(b,p,i);
    }
    brefresh(p);
}
static void bremove(BTree *b,int key) {
    bremove_down(b,b->root,key);
    if (!b->root->leaf && b->root->n==1) {
        BPage *old=b->root; b->root=old->child[0]; bcontainer_free(old);
    }
}
static void bdestroy_page(BPage *p) {
    if (!p->leaf) for (size_t i=0;i<p->n;++i) bdestroy_page(p->child[i]);
    bcontainer_free(p);
}
static void bclear(BTree *b) {
    bdestroy_page(b->root); b->root=bpage(b,true);
}
static void bdestroy(BTree *b) { bdestroy_page(b->root); b->root=NULL; }

from bisect import bisect_left, bisect_right

class Page:
    def __init__(self, leaf, items=()):
        self.leaf = leaf
        self.items = list(items)
        self.refresh()
    def refresh(self):
        self.minimum = (None if not self.items else
                        self.items[0] if self.leaf else self.items[0].minimum)
    def route(self, key):
        return bisect_right([c.minimum for c in self.items[1:]], key)

class BTree:
    def __init__(self, order=3, redistribute=False):
        assert order >= 3
        self.M, self.m = order, (order + 1) // 2
        self.redistribute = redistribute
        self.root = Page(True)
    def split(self, t):
        middle = len(t.items) // 2
        right = Page(t.leaf, t.items[middle:])
        del t.items[middle:]
        t.refresh()
        return right
    def overflow(self, parent, i):
        t = parent.items[i]
        if self.redistribute:
            if i > 0 and len(parent.items[i - 1].items) < self.M:
                left = parent.items[i - 1]
                left.items.append(t.items.pop(0))
                left.refresh(); t.refresh(); return
            if i + 1 < len(parent.items) and len(parent.items[i + 1].items) < self.M:
                right = parent.items[i + 1]
                right.items.insert(0, t.items.pop())
                right.refresh(); t.refresh(); return
        parent.items.insert(i + 1, self.split(t))
    def insert(self, key):
        def descend(t):
            if t.leaf:
                i = bisect_left(t.items, key)
                if i == len(t.items) or t.items[i] != key:
                    t.items.insert(i, key)
            else:
                i = t.route(key)
                descend(t.items[i])
                if len(t.items[i].items) > self.M:
                    self.overflow(t, i)
            t.refresh()
        descend(self.root)
        if len(self.root.items) > self.M:
            right = self.split(self.root)
            self.root = Page(False, [self.root, right])
    def underflow(self, parent, i):
        t = parent.items[i]
        if i > 0 and len(parent.items[i - 1].items) > self.m:
            left = parent.items[i - 1]
            t.items.insert(0, left.items.pop())
            left.refresh(); t.refresh()
        elif i + 1 < len(parent.items) and len(parent.items[i + 1].items) > self.m:
            right = parent.items[i + 1]
            t.items.append(right.items.pop(0))
            right.refresh(); t.refresh()
        elif i > 0:
            left = parent.items[i - 1]
            left.items.extend(t.items)
            left.refresh(); del parent.items[i]
        else:
            right = parent.items[i + 1]
            t.items.extend(right.items)
            t.refresh(); del parent.items[i + 1]
    def remove(self, key):
        def descend(t):
            if t.leaf:
                i = bisect_left(t.items, key)
                if i < len(t.items) and t.items[i] == key:
                    del t.items[i]
            else:
                i = t.route(key)
                descend(t.items[i])
                if len(t.items[i].items) < self.m:
                    self.underflow(t, i)
            t.refresh()
        descend(self.root)
        if not self.root.leaf and len(self.root.items) == 1:
            self.root = self.root.items[0]
    def values(self):
        def walk(t):
            if t.leaf:
                yield from t.items
            else:
                for child in t.items:
                    yield from walk(child)
        return list(walk(self.root))

下溢前兄弟至少 m 项，受损节点为 m−1 项，所以合并后最多 2m−1≤M；溢出只有 M+1 项，均分后两份都至少 m 项。兄弟与 t 同层，因此移键或移孩子都保持所有叶子同深。父亲 refresh 总在孩子修复之后，保证最小键变动即使没有下溢也向上传播。

这里叶子与内部节点容量都取 M，是本章示例的简化。每层构造分隔列表、数组移动均按 M 计，整个更新为 O(M(h+1))；根扩裂或缩根单独处理。生产实现可把分隔数组显式缓存，但仍须维护其与孩子最小键的一致性。

C 以 binit 初始化，binsert/bremove 更新，bcontains 查找；bclear 释放数据并恢复空根叶子，bdestroy 释放整棵树后不可继续操作，除非重新初始化。页容器及数组归树拥有；分裂和合并转移孩子所有权，合并时仅释放被撤掉的容器。Python 对应 BTree.insert/remove/values，释放由运行时处理。

4.38 · B* 树的二转三分裂

原题（中文翻译）

阶为 M 的 B* 树是一种 B 树，其中每个内部节点有 2M/3 至 M 个孩子。描述一种 B* 树插入方法。

原书习题 4.38 · 印刷页 139 · PDF 第 156 页。

解答

节点满时先向未满兄弟重新分配。若相邻兄弟也满，把两满节点与新增孩子合计 2M+1 个孩子均分到三个节点，父亲由两个孩子入口改为三个；父溢出同样递归处理。这比一个满节点直接一分二，提高占用下限，根通常需要例外规则。

整数条件：若 M=3q，三份可为 2q、2q、2q+1，均不少于 2M3。题干未给舍入约定；M=3q+2 时，⌈2M3⌉=2q+2，而 2M+1=6q+5 不够给三份各 2q+2。因此不能对任意 M 生搬严格 ceil 下限；实现应选兼容的阶（如 M 为 3 的倍数），或明确采用允许的取整占用规则，再单独处理根分裂。证明占用率必须与整数容量一致。

/* 有序一般树；root 的 sibling 不属于本次单根遍历。 */
typedef struct GTree {
    const char *name;
    struct GTree *first_child, *next_sibling;
} GTree;
typedef void (*GVisit)(const GTree *, size_t, void *);
static void child_sibling_visit(const GTree *root, size_t depth,
                                GVisit visit, void *ctx) {
    if (!root) return;
    visit(root,depth,ctx);
    for (const GTree *c=root->first_child;c;c=c->next_sibling)
        child_sibling_visit(c,depth+1,visit,ctx);
}

class GTree:

        self.first_child, self.next_sibling = first_child, next_sibling

def child_sibling_visit(root, visit, depth=0):
    if root is None:
        return
    visit(root, depth)
    c = root.first_child
    while c is not None:
        child_sibling_visit(c, visit, depth + 1)
        c = c.next_sibling

static size_t sign_hash(size_t a,size_t b,int key) {
    uint64_t x=(uint64_t)a*UINT64_C(0x9e3779b97f4a7c15)^(uint64_t)b;
    x^=(uint64_t)(uint32_t)key*UINT64_C(0x517cc1b727220a95);
    x^=x>>30; x*=UINT64_C(0xbf58476d1ce4e5b9);
    x^=x>>27; x*=UINT64_C(0x94d049bb133111eb); x^=x>>31;
    return (size_t)x;
}
static void sign_grow(SignTable *tab) {
    size_t cap=tab->cap ? tab->cap*2 : 16;

4.43 · 两棵同键 BST 的旋转转换

原题（中文翻译）

  1. 证明：通过 AVL 单旋转，可以把任意二叉查找树 T1 转换成另一棵具有相同键的查找树 T2。
  2. 给出平均使用 O(NlogN) 次旋转的转换算法。
  3. 证明：最坏情况下，只用 O(N) 次旋转就能完成转换。

原书习题 4.43 · 印刷页 139 · PDF 第 156 页。

解答

a 把每棵树转成统一的升序右链，再把第二棵树转链操作反向重放到第一条链上。单旋保持中序序列，因此同键树得到同一右链，反向步骤即可恢复目标树。

b、c 有更强的线性界：从右脊上的当前节点开始，若有左孩子就在此右旋，否则沿右孩子前进。每次旋转使一个原本不在全树右脊的节点进入右脊，已在脊上的节点不离开，故每树至多 N−1 次右旋。两阶段合计至多 2N−2 次旋转，最坏 O(N)，自然也满足平均 O(NlogN)。

记录目标树转链时的旋转位置（可按键标识），逆序做相反旋转；节点地址可能不同，不能直接照搬另一棵树的指针。这里“AVL 单旋”指同一局部操作，不要求所有中间树都满足 AVL 平衡。

转右链并逆序恢复目标的具体实现

原题（中文翻译）

假设增加操作 FindKth(T,i)，返回树 T 中第 i 小的键，且所有键互不相同。说明如何修改二叉查找树，使此操作的平均时间为 O(logN)，同时不损害其他操作的时间界。

原书习题 4.44 · 印刷页 140 · PDF 第 157 页。

解答

节点记录 size=1+size(left)+size(right)，空树 size=0。FindKth 时令 r=size(left)+1：k=r 返回根；k<r 向左；否则向右找第 k−r 个。k 从 1 开始，先检查 1≤k≤size(root)。

一次只走一条路径，O(h+1)，随机 BST 期望 O(logN)，平衡树最坏对数。插删沿原路径维护 size，旋转先更新下降旧根再更新上升新根，均不改变各操作时间阶数。

4.45 · 线索树遍历、插入与删除

原题（中文翻译）

编写线索二叉树的中序遍历、插入与删除过程。使用线索树有什么优点？

原书习题 4.45 · 印刷页 140 · PDF 第 157 页。

解答

中序遍历从 header.Left 所指根的最左真实孩子开始，按正文后继函数前进，到 header 停止；非空树 O(N) 时间、O(1) 遍历空间，空树直接结束。

插入先按键序查找，只沿真实孩子走；在 p 的空左位置插 x 时：x.Left=p.Left、x.Right=p，x 的两标记均为线索；p.Left=x、p.LeftThread=false。右侧镜像。若原前驱／后继的相应线索指向 p，需改成 x；首次插入更新 header.Left，最小最大端点仍接 header。

删除双孩子时先用后继键替换，再摘后继，使实际删除节点 q 至多一真孩子。保存 q 的前驱 pred、后继 succ、父亲与方向；若 pred 的右线索指 q，改为 succ；若 succ 的左线索指 q，改为 pred。q 有真孩子时以孩子替换父入口；无真孩子且为左孩子时父 Left 改为 pred 并置线索标记，右侧则改为 succ。删除根须更新 header.Left，最后一个节点删掉后回到空树约定，再释放 q。

查找及局部前驱／后继定位 O(h+1)，不平衡时可 O(N)。优势是连续遍历不需栈；更新要维护更多不变量，不能对线索盲目递归或释放。以上给出局部维护算法，具体哨兵的空树标记需与实现一致。

双线索 BST 的完整结构操作

下面明确约定：header.left 是根入口；空树时它指向 header 且 lt=true。最小键的左线索、最大键的右线索都指向 header；header.right 固定指向自己。header 由调用者拥有，所有数据节点由树拥有。这里只存整数键，重复插入不变。Python 中线索形成环，clear 显式断开节点引用并恢复 header；节点对象的内存交给运行时回收。

        h.left, h.lt = x, False
    elif key < p.key:
        x.left, x.right = p.left, p
        pred = x.left
        if pred is not h and pred.rt and pred.right is p:
            pred.right = x
        p.left, p.lt = x, False
    else:
        x.left, x.right = p, p.right
        succ = x.right
        if succ is not h and succ.lt and succ.left is p:
            succ.left = x
        p.right, p.rt = x, False

def thread_delete(h, key):
    parent, q = h, h.left
    while q is not h and q.key != key:
        parent = q
        if key < q.key:
            if q.lt:
                return False
            q = q.left
        else:
            if q.rt:
                return False
            q = q.right
    if q is h:
        return False
    if not q.lt and not q.rt:
        s, parent = q.right, q
        while not s.lt:
            parent, s = s, s.left
        q.key, q = s.key, s
    pred, succ = thread_prev(q), thread_next(q)
    child = q.left if not q.lt else q.right if not q.rt else None
    if pred is not h and pred.rt and pred.right is q:
        pred.right = succ
    if succ is not h and succ.lt and succ.left is q:
        succ.left = pred
    if parent is h:
        h.left, h.lt = child if child is not None else h, child is None
    elif not parent.lt and parent.left is q:
        parent.left, parent.lt = child if child is not None else pred, child is None
    else:
        parent.right, parent.rt = child if child is not None else succ, child is None
    q.left = q.right = None
    return True

def thread_values(h):
    p = thread_first(h)
    while p is not h:
        yield p.key
        p = thread_next(p)

def thread_clear(h):
    p = thread_first(h)
    while p is not h:
        nxt = thread_next(p)
        p.left = p.right = None
        p = nxt
    thread_init(h)

遍历调用 for(p=thread_first(&h);p!=&h;p=thread_next(p))；不对 header 调用数据节点的前驱／后继函数。删除双孩子节点只换整数键，物理摘除的是后继，先记录其邻居再修线索。测试应同时检查中序递增、逆序递减、每个标为线索的链接确实等于相邻节点，以及空树 header 恢复；仅看键集不足以发现坏线索。

原题（中文翻译）

二叉查找树通常假定每条记录只按一个键查找。如果希望同时能按 Key1 或 Key2 查找：

  1. 一种方法是建立两棵独立的二叉查找树。需要多少额外指针？
  2. 另一种方法是 2−d 树。它类似二叉查找树，但偶数层按 Key1 分支，奇数层按 Key2 分支。图 4.67 以二战后美国总统的名与姓为键，按任职先后插入 Truman、Eisenhower、Kennedy、Johnson、Nixon、Ford、Carter、Reagan、Bush、Clinton。编写 2−d 树插入过程。

解答

a 若每条记录同时参与两棵 BST，可保存 Left1、Right1、Left2、Right2，合计 4N 个孩子指针，相比单索引额外 2N，另需两根入口。若用两个独立包装节点，还要计包装节点到记录的指针及分配开销，不能把这个数混进题目的纯孩子指针计数。

b 2−d 插入在深度 d 用维度 dmod2 比较，对应键小则向左，否则向右；相等时固定路由规则或统一重复记录策略。c 范围查询先检查两个维度都在矩形内再输出，按当前分割维度剪枝：区间有可能进入哪一侧就访问哪一侧，边界相等依插入约定处理；不能因一个维度满足就停止检查另一个。

d k 维轮换用 dmodk，或按实现的维度选择策略。固定维度 k 时，插入 O(h+1)，任意不平衡输入最坏 O(N)，矩形查询也可能访问全部节点；平衡 k−d 树的更好范围界需要额外几何和平衡假设，本题不能直接继承一维 BST 的 O(K+logN)。

参数化维度的插入和闭区间查询

C 的 KDTree 在初始化时固定维度 k，复制输入整数坐标并拥有节点；kd_clear 释放全部节点和坐标。Python KDTree 检查各点及边界的维数，支持同维度可比较的键。完全重复点作为同一记录，单个坐标相等时固定进入右树；数据若附记录，应另行定义同点记录集合。

static KDNode *kd_insert_down(KDNode *t,const int *p,size_t k,size_t axis) {
    if (!t) {
        t=calloc(1,sizeof *t); if (!t) abort();
        t->point=malloc(k*sizeof *t->point); if (!t->point) abort();
        for (size_t i=0;i<k;++i) t->point[i]=p[i];
        return t;
    }
    size_t i=0; while (i<k && p[i]==t->point[i]) ++i;
    if (i==k) return t; /* 完全重复点不重复分配。 */
    size_t next=(axis+1)%k;
    if (p[axis]<t->point[axis]) t->left=kd_insert_down(t->left,p,k,next);
    else t->right=kd_insert_down(t->right,p,k,next);
    return t;
}
static void kd_insert(KDTree *t,const int *point) {
    /* point 至少含 k 项；C 接口由调用者保证长度。 */
    t->root=kd_insert_down(t->root,point,t->k,0);
}
static void kd_range_down(const KDNode *t,const int *low,const int *high,
                          size_t k,size_t axis,KDVisit visit,void *ctx) {
    if (!t) return;
    size_t i=0;
    while (i<k && low[i]<=t->point[i] && t->point[i]<=high[i]) ++i;
    if (i==k) visit(t->point,k,ctx);
    size_t next=(axis+1)%k;
    if (low[axis]<t->point[axis]) kd_range_down(t->left,low,high,k,next,visit,ctx);
    if (high[axis]>=t->point[axis]) kd_range_down(t->right,low,high,k,next,visit,ctx);
}
static void kd_range(const KDTree *t,const int *low,const int *high,KDVisit visit,void *ctx) {
    for (size_t i=0;i<t->k;++i) if (low[i]>high[i]) return;
    kd_range_down(t->root,low,high,t->k,0,visit,ctx);
}
static void kd_free_node(KDNode *t) {
    if (t) { kd_free_node(t->left); kd_free_node(t->right); free(t->point); free(t); }
}

class KDNode:
    def __init__(self, point):
        self.point = tuple(point)
        self.left = self.right = None

class KDTree:
    def __init__(self, k=2):
        if not isinstance(k, int) or k < 1:
            raise ValueError("k must be a positive integer")
        self.k, self.root = k, None
    def insert(self, point):
        point = tuple(point)
        if len(point) != self.k:
            raise ValueError("point dimension differs from k")
        def descend(t, axis):
            if t is None:
                return KDNode(point)
            if point == t.point:
                return t
            if point[axis] < t.point[axis]:
                t.left = descend(t.left, (axis + 1) % self.k)
            else:
                t.right = descend(t.right, (axis + 1) % self.k)
            return t
        self.root = descend(self.root, 0)
    def range(self, low, high):
        low, high = tuple(low), tuple(high)
        if len(low) != self.k or len(high) != self.k:
            raise ValueError("bound dimension differs from k")
        if any(high[i] < low[i] for i in range(self.k)):
            return iter(())
        def walk(t, axis):
            if t is None:
                return
            if all(low[i] <= t.point[i] <= high[i] for i in range(self.k)):
                yield t.point
            nxt = (axis + 1) % self.k
            if low[axis] < t.point[axis]:
                yield from walk(t.left, nxt)
            if high[axis] >= t.point[axis]:
                yield from walk(t.right, nxt)
        return walk(self.root, 0)
    def clear(self):
        self.root = None

左侧严格小于切分值，右侧大于等于，因此查询左侧用严格 <，右侧用 ≥，与插入约定一致。测试 (2,1)、(2,3)、(1,2)、(4,4)，闭矩形 [2,2]×[0,3] 必须找到两个 x=2 的点。单维满足并不充分，输出前 all 检查两维。

实现已把维度设为参数；k 维的轮换规则是把常数 2 改成 k，并验证点与区间维度一致、每个下界不大于上界。几何剪枝会加速许多实例，但这份未经平衡的实现不具有最坏对数查询保证。

若维度 k 也作为输入参数，完整重复点比较与新点复制都要检查或复制 k 个坐标，插入最坏时间为 O(k(h+1))。一次范围查询若实际访问 V 个节点，每个节点需检查全部维度，加上边界维数与有效性检查，共为 O(k(V+1))；k 固定时才可把这个因子作为常数。C 回调与 Python 生成器借用已有点，若另行复制或输出 K 个完整点，还需计 O(kK) 的坐标处理及实际输出成本。最坏 V=N，因此参数化维度时不能继续写成与 k 无关的线性查询界。
