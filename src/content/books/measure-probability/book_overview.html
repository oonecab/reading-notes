从“能描述什么”走到“能测量什么”，再建立概率的极限语言

原书目录 PDF 11—12；正文六章印刷 1—216

伴读总览序言与前言 →

这本书在搭一座什么桥

初等概率里，我们常直接使用“事件的概率”“随机变量的期望”和“随机变量趋于某个极限”。一旦样本空间无限，三个问题就必须分开回答：哪些集合允许谈概率，哪些函数允许谈期望，哪一种“趋于”足以支持后续运算。本书用测度论把这些对象放进同一套严谨语言。

先选空间 X 和允许讨论的集合系 F，得到可测空间；再给集合赋予大小 μ，得到测度空间；再用简单函数把集合上的大小推广成函数的积分。概率空间是 P(X)=1 的测度空间，数学期望是这种空间上的积分。后半本书继续处理带正负号的测度、多坐标空间及独立随机变量序列。

前两章是这条路线的地基。第一章解决“能不能描述”，第二章解决“怎样测量、怎样理解极限”。第二章末的分布函数、分位数与 Skorokhod 表示已经把抽象工具接回概率论，因此阅读时不宜把它们拆成互不相干的定义表。

阅读注解
理解与条件

先问对象，再问运算

F 的成员是集合，μ 的输入是集合，可测函数的输入是点。把这三层混在一起，就容易误把 f(A) 当作 f−1(A)，或在没有测度时使用“几乎处处”。

带着哪些基础开始

需要熟悉集合、数列极限、实数完备性与基本微积分，也要能读懂“对每个”“存在”“充分大以后”这些量词。作者明确说明，实变函数不是先修前提；有相关基础会帮助比较 Lebesgue 测度，但本书自身建立需要的概念。

第一次读可以沿五个问题检查理解：为什么只要求可数运算？为什么用原像定义可测？为什么有限可加不够？为什么扩张的存在与唯一要分别证明？为什么不同收敛方式不能随意替换？第一章的生成定理与第二章的连续性是反复回读的位置。

用小模型看清抽象结构

四组程序都提供 C11 与 Python 3 源文件。有限集合模型把“能区分哪些点”变成可枚举的原子，再观察哪些集合可以被测量；同一程序还可以求覆盖外测度并验证分割条件。简单函数程序用整数运算实现向下取整；积分程序在同一个四点空间中计算正负积分、条件均值、Jordan 与 Lebesgue 分解，以约分整数对保留精确值。
