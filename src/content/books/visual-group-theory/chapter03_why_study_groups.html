3.1 对称群：把“看起来一样”写成操作规则

本章把“同一套组合规律”放进分子、晶体、装饰图案和舞蹈。共同问题是：一个对象有哪些保持结构的动作，这些动作怎样合成？模型必须先确定哪些部件算相同、哪些颜色或原子种类必须保留、是否只允许刚体转动。

Definition 3.1

原文节选（仅步骤 2 的结尾句；三步流程见下文）

This collection of actions forms a group.

中文陈述：测量对称性的办法：① 给对象中彼此同类、可能互换的部分加上可区别标签；② 收集所有重新排列标签、却使对象最终仍占据原来空间的手持刚体操作；③ 可选地探索这些操作，画出完整 Cayley 图。标签帮助观察移动，不能反过来要求每个标签原位不动。

来源：印刷 26 / PDF 41

3.1.1 分子的形状

原书把硼酸画成平面的三臂“螺旋桨”。绕中心转 120°，三个同类臂循环换位，而原子种类及位置关系恢复；转 240°、不转也是允许动作。将薄片左右翻面却使弯臂方向相反，无法重合，因此只有 e,r,r2e,r,r²，r3=er³=e。

这里讨论原书理想刚体模型可用手转动实现的置换。三维镜面反演、原子热运动、不同构象都不是此处加入的动作。平面图案在三维中翻面，可以实现它在平面上的镜像；非平面分子则不能把任意镜像都当作刚体转动。这个界限尤其决定习题 3.6 为什么得到四个而非八个动作。

来源：印刷 27—29 / PDF 42—44

3.1.2 晶体

体心立方的示意单元包含八个顶角及中心点。把它在三个方向无限重复，得到理想周期点阵。设立方边长为 aa，角点位于 aℤ3aℤ³，体心点位于 a(ℤ3+(1/2,1/2,1/2))a(ℤ³+(1/2,1/2,1/2))；平移 (a,0,0)(a,0,0) 将两类点分别送到同类点，逆平移 (−a,0,0)(−a,0,0) 撤销它。

TuTv=Tu+v，Tu−1=T−u；u,v是保持点阵的平移向量。TᵤTᵥ=Tᵤ₊ᵥ，Tᵤ⁻¹=T₋ᵤ；u,v 是保持点阵的平移向量。

整数倍平移已经给出无限多个不同动作。图里的有限几个立方体只是窗口；真正有限晶体的边界通常不会被非零平移保留。单个立方单元的转动群、无限点阵的完整对称群和这里选取的平移子群是三个不同层次。线条在此帮助显示空间连接，不据此解释所有材料的化学键。

来源：印刷 29—31 / PDF 44—46

3.1.3 艺术与建筑

把叶片向左右无限重复，允许整个图案平移。原书的主例是左右对称叶片交替向上、向下排列。为了看见左右翻转的区别，每片叶的两半都应标记；只给整片叶一个编号，会漏掉一个固定叶片却交换两半的动作。

将相邻叶的横向距离设为 1，令 h(x,y)=(−x,y)h(x,y)=(−x,y)，g(x,y)=(x+1,−y)g(x,y)=(x+1,−y)。hh 是左右翻转，gg 是向右移动一格再上下翻面。先 gg 再 gg 得 (x+2,y)(x+2,y)，所以 g2g² 是非零平移，gg 不是二阶动作。先 hh、gg、hh 逐步给出 (−x,y)→(−x+1,−y)→(x−1,−y)(−x,y)→(−x+1,−y)→(x−1,−y)，恰为 g−1g⁻¹。

h2=e，hgh=g−1；每个动作可写成gk或gkh，k∈ℤ。h²=e，hgh=g⁻¹；每个动作可写成 gᵏ 或 gᵏh，k∈ℤ。

用 hg=g−1hhg=g⁻¹h，把字词里所有 hh 移到右边，再消去成对的 hhh h，得到上述两类。不同 kk 的横向位移不同；带 hh 的动作还反转 xx 方向，所以表示不重复。这证明群是无限的，也证明没有漏掉由两生成元构成的动作。要证明它们覆盖整个图案的对称，观察任一叶片的像：它只能去另一叶片，且左右朝向只有保留或反转两种；两种信息已确定一个 gkgᵏ 或 gkhgᵏh。

原书说有七种饰带对称类型，同时在脚注提醒：其中若干类型作为抽象群同构。图案在平面上如何反射、滑移，与抽象乘法规则是两个比较层次。壁纸的 17 类和三维晶体的 230 类是本章介绍的分类结论，此处未给其分类证明；本节只完整推导一个具体无限群。

来源：印刷 31—34 / PDF 46—49

手持刚体模型允许三维转动；对薄片，翻面可能实现平面镜像。带颜色、原子种类或正反面差异的对象，还必须保存这些信息。改变对象或允许动作，得到的群也可能改变。

3.2 动作群：离开刚体，仍保留合成

3.2.1 舞蹈

图中的四个位置按左上、右上、右下、左下编号 1、2、3、4。把舞步的细节暂时压缩为“每个人最终落在哪个位置”。两个不同舞步只要对全部位置产生相同置换，在这个模型里就代表同一元素；舞蹈动作本身的轨迹并没有被声称相同。

动作位置置换重复至还原
r：Circle right(1 4 3 2)4 次
LL：Ladies’ chain(1 3)2 次
S：Swing on side(1 2)(3 4)2 次
G：Gents allemande(2 4)2 次
T：Right and left through(1 3)(2 4)2 次
C：California twirl(1 4)(2 3)2 次

以 rr 和 LL 生成，得到正方形的八个对称置换 D4D₄。这里并未允许任意四人交换：任意置换有 24 种，而指定舞步只生成 8 种。合成规则固定为先左后右，例如 LS：1 经 LL 到 3，再经 SS 到 4，其他三点也与 rr 一致，所以 LS=rLS=r。

3.2.2 多项式的根

原书把多项式求根作为群论的历史入口。要精确理解，群的元素不是“根这个数”本身，而是保持相关代数关系的根的置换。比如 x2−2x²−2 的两个根 ±2±√2 可以互换；在 ℚ(2)ℚ(√2) 中，a+b2↦a−b2a+b√2↦a−b√2（a,b∈ℚa,b∈ℚ）保持加法和乘法，且做两次还原。

(a+b2)(c+d2)=(ac+2bd)+(ad+bc)2。(a+b√2)(c+d√2)=(ac+2bd)+(ad+bc)√2。

把 2√2 的符号改成负号，上式两边的常数项不变，2√2 系数一起变号，因此乘法关系被保留。并不是随便换一组根就自动得到允许的变换；需要明确固定哪些系数、保留哪些运算。一般五次方程不存在统一的根式公式，仍允许特殊五次方程有根式解，也允许数值近似。这一完整论证留到第 10 章，本章只建立问题与群之间的接口。

来源：印刷 36 / PDF 51

阅读注解
理解与边界

位置编号与舞者身份分开

舞步规定的是旧位置到新位置的映射，舞者沿映射移动。合成时先把每个原位置追踪到中间位置，再执行下一步；不能仅凭某位舞者的终点判断整个置换相同。

3.3 群为什么会反复出现

对象可以变，操作之间的关系却可能相同。矩形翻转与双开关都满足两个互相交换的二阶生成元；正方形与四人舞步都含四阶循环及反向它的翻转。识别这种对应后，在一个模型里得到的乘法规律就能迁到另一个模型。

原书还提到异构体计数、物理、拓扑、纠错码、音乐等应用。它们不是靠一句“有对称性”就自动解决问题：先选状态和允许变换，证明它们保留研究对象，再研究轨道、稳定子或表示等结构。本章的贡献是让这些建模步骤可操作，而不是提前给出所有应用领域的完整理论。

来源：印刷 36—37 / PDF 51—52

阅读注解
理解与边界

模型相同需要保存合成

两个例子动作数相同，只给出同构的必要线索。还须找出一一对应，使先做 aa 再做 bb 的对应动作，等于先后执行 aa、bb 各自的对应动作。这是应用之间能共享推理的原因。

3.4 全部习题：把模型、计数和图连起来

3.4.1 基础

习题 3.1 · 六种舞步要重复几次

题目（中文转述）：

看图 3.15 的六种舞步（本页位置图与名称）：哪些连做两次还原？哪些要三次？哪些要四次？是否有需要超过四次的？

来源：印刷 37 / PDF 52

解答与推导

LL、SS、GG、TT、C 都是一个或两个互不相交的交换，重复两次每个人回原位。rr 是长度 4 的循环，前三次都让位置 1 去往不同位置，第四次才回到 1。没有恰为三阶的动作，也没有超过四次才还原的动作。注意“最少次数”与“某次也还原”不同：二阶动作做四次当然也还原。

习题 3.2 · 翻转与滑移反射

题目（中文转述）：

图 3.11 的水平翻转连续做两次有什么效果？同图的滑移反射有何不同？

来源：印刷 37 / PDF 52

解答与推导

h2(x,y)=(x,y)h²(x,y)=(x,y)，所以还原；g2(x,y)=(x+2,y)g²(x,y)=(x+2,y)，上下翻转被消去，横向位移却相加。对于无限图案，平移后外观重合，但带标签的部分整体移动了，故 g2≠eg²≠e。

习题 3.3 · 改用逆时针生成 C3C₃

题目（中文转述）：

硼酸模型顺时针三分之一转生成图 3.6。若改成逆时针生成，图、群的大小和结构怎样变化？

来源：印刷 37 / PDF 52

解答与推导

逆时针动作为 r−1=r2r⁻¹=r²。保持节点标号不变时，三循环每条箭头反向；若按新生成元重新命名，可交换 rr 与 r2r²。仍只有 ee、rr、r2r²，阶数 3，所有合成关系在重命名后保持。

习题 3.4 · 体心立方单元的三个操作

题目（中文转述）：

对图 3.7 的立方体（八角加中心点），给出三种把部件重新排列、但仍占据原空间的手持操作。

来源：印刷 37 / PDF 52

解答与推导

将中心设为原点，可取绕 xx、yy、zz 轴各转 90°：Rx(x,y,z)=(x,−z,y)Rx(x,y,z)=(x,−z,y)，Ry(x,y,z)=(z,y,−x)Ry(x,y,z)=(z,y,−x)，Rz(x,y,z)=(−y,x,z)Rz(x,y,z)=(−y,x,z)。顶角坐标都是 (±a/2,±a/2,±a/2)(±a/2,±a/2,±a/2)，三种变换仍把它们送到这种坐标，中心 (0,0,0) 固定；因此每个动作符合要求。

3.4.2 分子的对称

习题 3.5 · 乙烯模型

题目（中文转述）：

按定义 3.1 的全部步骤（包括画图）研究平面乙烯 C2H4C₂H₄：两个碳在水平方向，四个氢分别在左碳左上、左下和右碳右上、右下。原子种类必须保留。所得群以前在哪里出现过，叫什么？

来源：印刷 38 / PDF 53

解答与推导

给四个氢按矩形四角编号。允许不动、左右翻面、上下翻面、绕垂直纸面的轴转 180°。前三个非恒等动作分别互换对应角，群为 V4V₄，与第 2 章矩形和双开关相同。90° 转动会把碳轴从水平变为竖直，不重合，故不能加入。

习题 3.6·SF53.6 · SF₅Cl 的轴向限制

题目（中文转述）：

重复上述三步，研究 SF5SF₅Cl 模型：SS 在中心，Cl 在竖轴上端，一个 FF 在下端，另外四个 FF 位于水平正方形的四角。画图，并在 Group Explorer 找到群名。

来源：印刷 38 / PDF 53

解答与推导

唯一的 Cl 必须固定，故允许的三维刚体转动必须保持这条有向竖轴。四个赤道 FF 只允许以 90° 为单位循环换位；上下翻面会交换 Cl 与轴向 FF，不合法。因此只有 e,r,r2,r3e,r,r²,r³，得到 C4C₄（软件库记作 ℤ4ℤ₄）。

从顶端沿轴看，给四个赤道 FF 顺次标 1—4，转动分别产生四个循环排列，图每边为 90°。这是原书附录图 A.1 的内容；软件核对见实查说明。若改研究允许三维镜像的化学点群，动作集合会改变，不能套用这里的四个计数。

习题 3.7 · 苯的理想平面模型

题目（中文转述）：

重复习题 3.6 的要求，研究平面苯 C6H6C₆H₆：六个 C 位于正六边形顶点，各自外侧有一个同类 HH，中心固定，图没有额外区分某些边。

来源：印刷 38 / PDF 53

解答与推导

标记六个碳，旋转 60° 得 rr，沿一条对称轴把薄片翻面得 ff。六个 rkrᵏ 保持环绕次序，六个 rkfrᵏf 反转次序，共 12 个。固定一个碳的像有六种、其邻碳的方向有两种，所以这份清单穷尽所有刚体对称。群为 D6D₆。

软件库的 D6D₆ 有 12 个元素，Cayley 图由两层六循环及翻转边相连。这里按原图的理想几何模型计数，不把人为交替标色的边添加为题目条件。

习题 3.8 · 重叠式二茂铁

题目（中文转述）：

研究重叠式二茂铁 Fe(C5H5)2Fe(C₅H₅)₂：两个平行、上下对齐的正五边形环夹着中心 Fe，各环对应位置的 C、HH 同类。按定义 3.1 标号、找全部刚体动作、画图，并识别群。附录提示它与正五边形具有相同对称。

来源：印刷 38—39 / PDF 53—54

解答与推导

给上环五角标 1—5，下环对应角标 1′—5′。绕中心竖轴转 72° 是 rr；绕穿过中心、平行环面的合适对称轴转 180° 是 ff，它交换上下环并反转角顺序。rkrᵏ 保持上下，rkfrᵏf 交换上下，各五个，得到 D5D₅。

必须同时标两环，才能看见“翻过来”的动作；若只看轴向投影，会把交换上下环的操作漏掉。所列十个变换保持所有同类原子的位置集合；任意允许转动先决定是否交换两环，再决定一个角的五种像，至多十种，因此完整。

习题 3.9 · 群越大是否越对称

题目（中文转述）：

前面的分子例子有大小不同的对称群。群的大小与对象展现多少对称有何关系？

来源：印刷 39 / PDF 54

解答与推导

在固定同类部件、同一允许操作标准下，有限群越大，保持对象的不同动作就越多。这是可计数的“对称多少”。但它不是审美尺度；也不能跨模型只比数字，例如允许镜像与只允许刚体旋转会改变大小。无限群的基数相同也可能有很不同的结构，所以不能仅凭“都无限”排序。

习题 3.10 · 选一个日常对象

题目（中文转述）：

找一个熟悉且有对称性的物体，按定义 3.1 完成标号、动作枚举和 Cayley 图。

来源：印刷 39 / PDF 54

解答与推导

选无图案、两面相同的等边三角形杯垫，三个角标 AA、BB、C。120° 转动 rr 与沿角 AA 的对称轴翻面 ff 生成全部动作，分别 e,r,r2,fe,r,r²,f,rfr f,r2fr²f；图见三角形六节点图。如果真实杯垫一面印字，则翻面可能不再保留对象，故例子明确采用理想无图案模型。

3.4.3 重复图案

习题 3.11 · 六种无限饰带及原图校注

题目（中文转述）：

原书称饰带共有七种对称类型，正文展示其中一种；以下六图据称为其余六种。对每图应用定义 3.1，包含作图；重复图案沿水平方向无限延伸。

  1. 对图 (a) 完成标号、生成元和无限图。
  2. 对图 (b) 完成相同步骤。
  3. 对图 (c) 完成相同步骤。
  4. 对图 (d) 完成相同步骤；原书提示可参考附录四节点重复块。
  5. 对图 (e) 完成相同步骤。
  6. 对图 (f) 完成相同步骤。

解答与推导

把每个基本叶片按整数位置 kk 编号，再把一片中能互换的半片或四分之一片加上局部标记。下面 tt 总指最短纯平移，hh 指一个反转 xx 方向的二阶动作；具体是镜像还是半转会逐项说明。无限图仅画 k=−1,0,1k=−1,0,1 的窗口，两端继续，绝不能把窗口首尾相接。

(a) 不对称叶片都以同一方向挂在同侧，只能按一个叶距平移。群为 {tk:k∈ℤ}{tᵏ:k∈ℤ}；没有任何非零位移可还原，故是无限循环群。

(b) 上下交替的非对称叶片由“移一个叶距，再上下反射”gg 对应。g2=tg²=t 是两个叶距的纯平移；单独左右镜像或半转会改变叶尖偏向。因此仍是无限循环群 {gk}{gᵏ}，但奇数幂带反射，几何类型与 (a) 不同。

(c) 叶片左右对称，但都挂在同侧。令 hh 为穿过一片叶中心的竖直镜像，tt 为一个周期平移；h2=eh²=e，hth=t−1hth=t⁻¹，所有动作是 tktᵏ、tkhtᵏh。上下镜像会把叶片送到空白一侧，故排除。

(d) 每片叶的左右、上下两半均对称。除 tt 和竖直镜像 hh 外，还有水平镜像 vv；v2=ev²=e，vv 与 tt、hh 都交换。所有动作唯一写为 tkhtᵏhεεvvδδ（k∈ℤk∈ℤ，ε,δ∈{0,1}ε,δ∈{0,1}）。上下四行对应 e,h,ve,h,v,hvh v；每个 kk 的竖直四点块是 V4V₄，左右无穷延伸，与附录提示一致。

(e) 一列的上下叶不是镜像，而是绕交点转 180° 后重合。取 hh 为这个半转，h(x,y)=(−x,−y)h(x,y)=(−x,−y)，有 hth=t−1hth=t⁻¹；仍是 tktᵏ、tkhtᵏh 的两层图。它与 (c) 的抽象群同构，但 (c) 的 hh 固定整条镜轴，本题的 hh 只固定一个中心，几何动作不同。

(f) 按提供 PDF 的实际图形，纯平移需跨两列；上下两叶关于水平红线镜像，相邻两列又关于中间竖线镜像。取这两个镜像为 vv、hh，取两列宽为 tt，关系及四层图与 (d) 一样。镜轴选在相邻列中点，不是穿过叶片；叶尖及叶脉也随镜像对应。

理解与边界

无限饰带不能接成一圈

图只展示无限图案的一段窗口。把最左端与最右端相连会人为加入周期关系，把无限平移变成有限阶动作。用横坐标位移区分各次平移，才能看出为什么它们始终不同。

程序：用坐标检查无限饰带的关系

程序精确维护三元组 (sx, sy, dx)，表示坐标变换 (x,y)↦(sx·x+dx,sy·y)(x,y)↦(sx·x+dx,sy·y)。初始 (1, 1, 0) 是恒等。追加 h 会取反 sx 与 dx；追加 g 会取反 sy 并将 dx 加 1；追加 G（即 g−1g^{−1}）会取反 sy 并将 dx 减 1。这里没有浮点近似，所有分支直接来自本章写出的坐标公式。

默认依次输出 ee、hh、gg、GG、ggg g、hghh g h、hghgh g h g、ghghg h g h；hghh g h 与 GG 的三元组均为 (1,−1,−1)，hghgh g h g 与 ghghg h g h 均为 (1,1,0)。ggg g 的 (1,1,2) 明确显示位移没有消失。还可输入任意由 hh、gg、GG 构成的字词，按时间从左至右执行。

两版都限制至多 10000 个字符，以使 C 的 dx 在 −10000…10000 内，不依赖大整数。合法字词处理 O(m)O(m) 时间、O(1)O(1) 状态空间，输入本身占 O(m)O(m)；非法字符、过长输入或多参数返回 2。程序验证选定字词，不枚举整个无限群；所有整数 kk 的规范形仍由正文推导。

"""Exact affine actions on a frieze. h is a flip, g/G are inverse glides."""
import sys


def evaluate(word):
    if len(word) > 10000 or any(letter not in "hgG" for letter in word):
        raise ValueError("word must contain at most 10000 letters from h,g,G")
    sx, sy, dx = 1, 1, 0
    for letter in word:
        if letter == "h":
            sx, dx = -sx, -dx
        else:
            sy = -sy
            dx += 1 if letter == "g" else -1
    return sx, sy, dx


def main(args):
    if len(args) > 1:
        raise ValueError("usage: frieze.py [word]")
    words = args if args else ["", "h", "g", "G", "gg", "hgh", "hghg", "ghgh"]
    results = [evaluate(word) for word in words]
    print("word sx sy dx")
    for word, (sx, sy, dx) in zip(words, results):
        print(word or "e", sx, sy, dx)


if __name__ == "__main__":
    try:
        main(sys.argv[1:])
    except ValueError as error:
        print(error, file=sys.stderr)
        sys.exit(2)
C11 完整程序
/* Exact (x,y) -> (sx*x+dx, sy*y). At most 10000 actions avoids overflow. */
#include <stdio.h>
#include <string.h>

static int valid(const char *word) {
    if (strlen(word) > 10000) return 0;
    for (const char *p = word; *p; ++p) if (*p != 'h' && *p != 'g' && *p != 'G') return 0;
    return 1;
}

static void show(const char *word) {
    int sx = 1, sy = 1, dx = 0;
    for (const char *p = word; *p; ++p) {
        if (*p == 'h') { sx = -sx; dx = -dx; }
        else { sy = -sy; dx += *p == 'g' ? 1 : -1; }
    }
    printf("%s %d %d %d\n", *word ? word : "e", sx, sy, dx);
}

int main(int argc, char **argv) {
    if (argc > 2 || (argc == 2 && !valid(argv[1]))) {
        fputs("usage: frieze [word of at most 10000 letters from h,g,G]\n", stderr);
        return 2;
    }
    puts("word sx sy dx");
    if (argc == 2) show(argv[1]);
    else {
        const char *words[] = {"", "h", "g", "G", "gg", "hgh", "hghg", "ghgh"};
        for (size_t i = 0; i < sizeof words / sizeof words[0]; ++i) show(words[i]);
    }
    return 0;
}

反射会改变后续位移的方向

字词 hghh g h 按先左后右执行。第一个 hh 反转横坐标，中间 gg 平移一格，最后 hh 又反向，因此总位移为负一格，并保留一次纵向翻转；它与 gg 的逆动作相同。
