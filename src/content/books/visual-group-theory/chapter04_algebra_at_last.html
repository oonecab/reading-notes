4.1 动作到哪里去了：把节点也读成动作

Cayley 图只有生成元拥有单步箭头，但所有群元素都已经在节点上。固定一个起点，某节点便对应从起点到它的动作效果。例如矩形图的四个配置可改名为 e、R、B、RB；节点改写成动词后，图就成了动作的计算器。

Definition 4.1

原文节选（仅步骤 (i) 的开头；三步流程见下文）

Choose any node

中文陈述：动作图的构造：① 任选一个节点作起点；② 用一条从起点到该节点的路径重标其他节点；③ 去掉边上的文字，用颜色、实虚线等方式区分生成元。所得图称为动作图。起点对应空路径，也就是恒等动作。

来源：印刷 43 / PDF 58

同一个节点可以有多个路径名字，如 RB 和 BR；采用哪个短名字只是书写选择。但这依赖于图确为 Cayley 图：在起点相同的路径效果必须在所有节点一致。若只有某个特殊状态结果相同，就贸然认定两个动作相同，乘法表可能出现歧义，见习题 4.16。

理解与边界

起点与路径字词

选起点把状态节点解释为动作效果，起点本身代表空路径。到同一节点的字词可能不同；比较的是作用效果。这里从 Cayley 图出发，一般含固定点的状态作用图不能直接照搬这种一一对应。

4.2 合成：沿图计算长字词

本书写 AB 表示先 A 后 B，对应通常函数记法 B∘A。乘法符号表达“组合”，不承诺像实数一样可交换。计算 x·y 时，先站在节点 x，再按表示 y 的路径前进。

在 V₄ 中 R²=B²=e，RB=BR。原书的 R³BR²B³ 可先删去相邻的 R²：R³BR²B³=R³B⁴，再用 B⁴=e、R³=R，得到 R。另一条路线利用 RB=BR 交换中间的 R、B，合为 R⁵B⁴=R；后一条路线明确使用交换性，不能移植到任意群。

R³BR²B³ = R³B(R²)B³ = R³B⁴ = R；在 V₄ 中也等于 R⁵B⁴。R³BR²B³ = R³B(R²)B³ = R³B⁴ = R；在 V₄ 中也等于 R⁵B⁴。

括号和次序是两件事。把 RBR 分成 (RB)R 或 R(BR)，仍按 R、B、R 执行；把它写成 RR B 却改变了先后，只有证明相应动作可交换才允许。

来源：印刷 44—45 / PDF 59—60

阅读注解
理解与边界

括号不交换动作

结合律只改变相邻动作先合成哪一段，不改变执行顺序。先 a 后 b 后 c，既可先合成 ab，也可先合成 bc；把 ab 换成 ba 是交换律，需要另证。

4.4 经典定义：从图中经验到精确条件

现在把“动作”改称元素，把“先后执行”称为二元运算。元素可以是数字、置换或别的对象；群的内容在于规定了什么运算，而不在符号长什么样。

4.4.1 结合律

若动作 A、B、C 作为函数作用于任意状态 s，无论把前两步看成一个动作，还是把后两步合在一起，最终都是 C(B(A(s)))。这解释动作复合为什么结合。

(ab)c=a(bc)；括号改变分组，不改变 a、b、c 的顺序。(ab)c=a(bc)；括号改变分组，不改变 a、b、c 的顺序。

普通减法不结合：4−(2−5)=7，而 (4−2)−5=−3。并且若“whole numbers”严格指非负整数，减法还不封闭；把定义域放宽为整数，以上结合律反例仍成立。

来源：印刷 48—50 / PDF 63—65

4.4.2 逆元

恒等元 e 满足 eg=ge=g。逆元 g⁻¹ 满足 gg⁻¹=g⁻¹g=e，必须是同一个元素从两边撤销。上标 −1 表示逆元，不一定是数值倒数；在加法群里它就是相反数，在转动群里就是反向转动。

V₄ 的每个元素都自逆；三角形群中 r 与 r² 互逆，而反射 f 自逆。在运算表里，找到 g 行中出现 e 的列 b，还要核查 b 行 g 列也是 e。只有已知它是群时，唯一性和单侧逆推出双侧逆等结论才可放心使用。

来源：印刷 50—51 / PDF 65—66

4.4.3 合在一起

Definition 4.2

原文节选（仅条件 2 的开头；完整群公理见下文）

That operation is associative

中文陈述：群是非空集合 G 配二元运算 *:G×G→GG×G→G，并满足：① 任意有序对都有唯一、仍在 G 内的运算结果；② 任意 a,b,c∈G 有 (a*b)*c=a*(b*c)(a*b)*c=a*(b*c)；③ 存在 e∈G，对所有 g∈G 有 e*g=g*e=ge*g=g*e=g；④ 对每个 g∈G，存在 g−1∈Gg⁻¹∈G，满足 g*g−1=g−1*g=eg*g⁻¹=g⁻¹*g=e。

来源：印刷 51 / PDF 66

“存在 e”在“对所有 g”之前，要求同一个 e 服务所有元素；逆元则允许随 g 改变。二元运算已经包含处处定义、唯一性和封闭性，因此不能把空格、多值格或群外符号混进表。结合律与每格看起来整齐无关，必须证明或逐三元组核查。

第 1 章的完整可逆动作系统在复合下满足这些公理。反方向上，对抽象群可令每个 g 作用为“右乘 g”的置换 Rg:x↦xg；因 g 有逆，它确为双射，而且 e 在作用下去到 g，故不同 g 对应不同置换。这给出为什么抽象元素也能解释成动作的入口；完整置换群视角在下一章展开。

4.4.4 两种观点接起来

动作观点擅长解释为什么可逆、路径怎样走；代数观点擅长把条件写成可迁移的等式。接下来所有运算题都先固定表和次序，再使用逆元消去。解方程的关键不在多写一个逆号，而在把逆元乘到正确的一侧。

来源：印刷 52 / PDF 67

阅读注解
理解与边界

逆元公式为什么要反序

要撤销先 a 后 b 的动作，应先撤销 b，再撤销 a。代数上用结合律把 (ab)(b⁻¹a⁻¹) 化为 a(bb⁻¹)a⁻¹=e；中间只消去了相邻的一对逆元，没有交换 a 与 b。

习题 4.1 · 双开关字词

题目（中文转述）：

L 翻左开关，R 翻右开关，N 为不动。判断下列等式，并回答最小正幂问题。

  1. 判断 LRRRR=RRL、L=RR、LR=RLRLRL、R⁸=R¹⁰⁰。
  2. 判断 (LNR)²=LNR、NN=N、RL=N、R⁴=N、(LNR)³=R³L³、LRLR=N。
  3. R 的最小正幂几次等于 N？
  4. L 的最小正幂几次等于 N？
  5. RL 的最小正幂几次等于 N？
  6. LR 的最小正幂几次等于 N？

来源：印刷 52 / PDF 67

解答与推导

L2=R2=NL²=R²=N，LR=RLLR=RL；字词由两种字母各出现几次的奇偶性决定。

(a) 四个等式依题序为真、假、真、真：两边分别化为 L/L、L/N、LR/LR、N/N。

(b) 六个等式依题序为假、真、假、真、真、真：对应 N/LR、N/N、LR/N、N/N、LR/LR、N/N。

(c) R：最小正幂为 2。

(d) L：最小正幂为 2。

(e) RL：最小正幂为 2。

(f) LR：最小正幂为 2。

四问共用的理由是：L、R、LR=RLLR=RL 各是非恒等动作，一次不还原；两次时每个开关都被翻偶数次，故还原。

习题 4.3 · 交换与结合分别判断

题目（中文转述）：

对以下集合及运算，分别判断是否交换、是否结合。

  1. 全体 whole numbers 上的加法。
  2. 全体 whole numbers 上的减法。
  3. 正实数上的乘法。
  4. 正实数上的除法。
  5. 正整数上的乘幂 aᵇ。

来源：印刷 52—53 / PDF 67—68

解答与推导

(a) 加法交换且结合。(b) 减法不交换：3−1≠1−3；不结合：4−(2−5)=7≠−3=(4−2)−5。若 whole numbers 取非负整数，减法不是该集合上的二元运算，因为 1−3 不在集合；原书后面的整数加法表含负数，本题需把这一术语边界说明。

(c) 正实数乘法交换且结合。(d) 除法不交换，2÷4≠4÷2；也不结合，(8÷4)÷2=1，而 8÷(4÷2)=4。(e) 乘幂不交换，2³=8≠9=3²；不结合，(2³)²=64，而 23²=512。所有反例的输入都在相应允许集合中。

题目（中文转述）：

原题给出下列 C₅、八元素四元数群 Q₄ 的 Cayley 图。以下“红/蓝”沿原书名称，本页重绘分别用绿实线/棕虚线。

  1. C₅ 的红箭头表示右乘什么？
  2. 在 C₅ 中 a³·a 是什么？
  3. a³·a·a 是什么？
  4. Q₄ 以 1 为恒等；红、蓝箭头各表示什么？
  5. 求 i²、j·i。
  6. 求 i·j·j。

来源：印刷 53 / PDF 68

解答与推导

(a) 从 e 沿红边到 a，故是右乘 a。(b) a⁴。(c) a⁵=e。(d) 从 1 看，红边去 i、蓝边去 j，所以分别右乘 i、j。(e) i²=−1；从 j 走红边到 k，所以 ji=k。(f) j²=−1，故 ijj=i(−1)=−i。

习题 4.15 · 每行每列为何不能重复

来源：印刷 57 / PDF 72

习题 4.26 · 逐元素找逆

题目（中文转述）：

使用习题 4.6 的完整表求下列每个元素的逆。原题在 (c) 改用 a₁,a₂,… 的名字，本页明确采用 a₁=a、a₂=a²，b、c、d 同理。

  1. C₅：e、a、a²、a³、a⁴。
  2. Q₄：1、i、j、k、−1、−i、−j、−k。
  3. A₄：e、x、y、z、a₁、a₂、b₁、b₂、c₁、c₂、d₁、d₂。
  4. 一般怎样从乘法表找逆元？

来源：印刷 60 / PDF 75

解答与推导

(a) e⁻¹=e，a⁻¹=a⁴，(a²)⁻¹=a³，(a³)⁻¹=a²，(a⁴)⁻¹=a；指数两两相加为 0 mod 5。

(c) e、x、y、z 自逆；a₁↔a₂、b₁↔b₂、c₁↔c₂、d₁↔d₂ 分别互逆，十二个元素全部在这份清单中。(d) 找 g 行中恒等元所在列，列标题即候选逆元，再核查相反次序也得到恒等元。已知群时它唯一；任意非结合表可能有多个候选，如 4.10。

习题 4.27 · 在 C₅ 中解方程

题目（中文转述）：

仿照原题示范 a²x=a ⇒ x=(a²)⁻¹a=a⁴，在 C₅ 中解：

  1. a³x=a²。
  2. a⁴a²x=a。
  3. ax(a³)⁻¹=e。

解答与推导

(a) 左乘 a²=(a³)⁻¹，得 x=a²a²=a⁴；代回 a³a⁴=a⁷=a²。(b) a⁴a²=a⁶=a，所以 ax=a，左乘 a⁻¹ 得 x=e；代回 a⁶=a。(c) 左乘 a⁻¹、右乘 a³，得 x=a⁻¹a³=a²；代回 a·a²·a²=a⁵=e。每次只消去相邻的逆元对。

习题 4.28 · 隔着未知量能否消去

题目（中文转述）：

  1. 在 C₅ 的 a²x(a²)⁻¹=a 中能直接约掉两侧的 a² 吗？所得结果代回是否成立？
  2. 在 Q₄ 的 ixi⁻¹=j 中，能同样约去 i 与 i⁻¹ 吗？
  3. 解释两问答案为何不同，联系交换性。

来源：印刷 61 / PDF 76

解答与推导

(a) 可以，但依据是 C₅ 交换：a²x(a²)⁻¹=x·a²(a²)⁻¹=x，因此 x=a，代回成立。(b) 一般不能跨过 x 消去。左乘 i⁻¹、右乘 i，得 x=i⁻¹ji=(−i)ji=k i=−j（依本书表）。代回 i(−j)i⁻¹=k(−i)=j；若错取 x=j，左边变成 −j。

(c) 结合律只移动括号，不把 i 搬过 j。C₅ 中可交换，所以共轭 a²x(a²)⁻¹ 不改变 x；Q₄ 中 i 与 j 不交换，这个共轭会把 j 变成 −j。

习题 4.29 · A₄ 中左右消去

习题 4.30 · 三种群中的方程

题目（中文转述）：

分别解 t，保留乘法次序。A₄ 的 b₂=b²；S₃ 用 r³=f2=ef²=e、fr=r−1ffr=r⁻¹f，与图 4.7 相同。

  1. 在 Q₄ 中 ji·t·k⁻¹=kj。
  2. 在 A₄ 中 t(b₂)²=xyz。
  3. 在 S₃ 中 rtf=e。

来源：印刷 61 / PDF 76

解答与推导

习题 4.31 · 逆元为何唯一

题目（中文转述）：

设 G 是恒等元为 e 的群，a,b,c∈G。

  1. ab=e 表示 a、b 是什么关系？
  2. 若 ab=e 且 ac=e，用代数证明 b=c。
  3. 一个群元素可以有两个不同逆元吗？

来源：印刷 61 / PDF 76

解答与推导

(a) 左乘已存在的 a⁻¹，得 b=a⁻¹，因而也有 ba=e。(b) ab=ac，两边左乘 a⁻¹，并用结合律：(a⁻¹a)b=(a⁻¹a)c，即 b=c。(c) 不可以；任何两个逆元都满足 (b) 的前提。这里用的是群公理提供的逆元与结合律，不能把结论直接套到 4.10 的非结合表。

习题 4.32 · 整数及其倍数

题目（中文转述）：

ℤ 包含全部正负整数和零。用定义 4.2 回答：

  1. ℤ 对普通加法是群吗？
  2. ℤ 对普通乘法是群吗？
  3. 偶整数对普通加法是群吗？
  4. nℤ={nk:k∈ℤ} 对哪些整数 n 在加法下成群？

来源：印刷 62 / PDF 77

解答与推导

(a) 是：整数加法封闭、结合，恒等元 0，每个 m 的逆为 −m。(b) 否：恒等元为 1，但 0 无乘法逆，2 的倒数 1/2 也不在 ℤ；只有 ±1 在整数内有乘法逆。

(c) 是：2a+2b=2(a+b)，0=2·0，−2a=2(−a)，结合律继承自整数。(d) 对每个整数 n 都成立，包括 n=0：na+nb=n(a+b)，负元为 n(−a)，0 始终属于集合。n=0 时只有 {0}，是平凡群；负 n 给出与 |n| 相同的集合。

习题 4.33 · 有理数：先检查集合，再检查运算

题目（中文转述）：

ℚ={a/b:a,b∈ℤ,b≠0}；ℚ⁺ 为正有理数，ℚ* 为非零有理数。用群公理回答：

  1. ℚ 对加法是群吗？
  2. ℚ 对乘法是群吗？
  3. ℚ⁺ 对加法是群吗？
  4. ℚ⁺ 对乘法是群吗？
  5. ℚ* 对加法是群吗？
  6. ℚ* 对乘法是群吗？
  7. 为什么这些例子难以用乘法表和 Cayley 图展示？提示：原因不只是无限，整数平移也无限。

来源：印刷 62 / PDF 77

解答与推导

(a) 是。a/b+c/d=(ad+bc)/(bd) 仍是有理数，结合律继承自数的加法，恒等元 0，逆元 −a/b。(b) 否，0 没有乘法逆。(c) 否，正数相加仍为正且结合，但 0 不属于 ℚ⁺，也不存在加法逆。

(d) 是，正数乘积仍正，1 为恒等元，a/b 的逆 b/a 仍为正有理数。(e) 否，1+(−1)=0 不在 ℚ*，连封闭性都失败，且缺少加法恒等元。(f) 是，非零有理数相乘仍非零，逆元 b/a 也非零，1 在集合内。

(g) 关键是有限生成集不足。加法 ℚ 中，若只选有限个分数，令其分母公倍数为 D，则任意整数组合都落在 (1/D)ℤ，无法产生 1/(2D)。乘法 ℚ⁺ 或 ℚ* 中，有限个生成元的分子分母只涉及有限多个素数，任意乘积与逆仍只涉及这些素数，不能产生另一个素数。因此 Cayley 图需要无限多种生成边，难以用整数线上“一条重复边”的有限窗口说明全部。表仍可由分数公式定义，也可截取窗口；困难是信息与布局，不是这些可数集合完全不能枚举。

程序：从整张运算表检查群公理

程序输入 n 和 n×n 个整数，用 0,…,n−1 代表元素。默认无参数检查 V₄ 的异或表；加 --stdin 从标准输入读整张表，第一项 n，随后逐行 n² 项。它先检查封闭，避免用群外值作数组下标；再比较每个 (a,b,c) 的 T[T[a][b]][c] 与 T[a][T[b][c]]；随后寻找同一个双侧恒等元，最后逐个元素寻找同一个双侧逆元。

输出第一处结合律反例及左右值，便于回到表里重算。即使结合律失败，仍继续报告恒等元和逆元情况，因为习题 4.10 正是“有逆元却不结合”。若没有恒等元，逆元条件标为 UNDEFINED，不凭元素名字猜 e。

教学上限为 n=16；每个输入整数最多四位，可带负号。负数或 n 以外的表值是封闭性失败，程序返回 1；缺项、多项、非整数、超范围 n 是输入错误，返回 2。全公理通过返回 0。C 用固定 16×16 数组，先做边界检查；Python 接受相同 ASCII 文本输入，分隔符限空格、制表、换行、回车、纵向制表和换页这六种空白。时间 O(n³)，表的空间 O(n²)，这只是有限表的完全检验，不是对任意群定理的证明。

"""Check all group axioms for a finite operation table (1..16 elements)."""
import re
import sys


def check(table):
    n = len(table)
    if not 1 <= n <= 16 or any(len(row) != n for row in table):
        raise ValueError("expected a square table of size 1..16")
    if any(type(x) is not int for row in table for x in row):
        raise ValueError("table entries must be integers")
    for i in range(n):
        for j in range(n):
            if not 0 <= table[i][j] < n:
                return [f"CLOSURE FAIL {i} {j} {table[i][j]}", "GROUP NO"], False
    lines = ["CLOSURE OK"]
    witness = next(((a, b, c, table[table[a][b]][c], table[a][table[b][c]])
                    for a in range(n) for b in range(n) for c in range(n)
                    if table[table[a][b]][c] != table[a][table[b][c]]), None)
    lines.append("ASSOCIATIVE OK" if witness is None else
                 "ASSOCIATIVE FAIL " + " ".join(map(str, witness)))
    identity = next((e for e in range(n)
                     if all(table[e][a] == a and table[a][e] == a for a in range(n))), None)
    lines.append("IDENTITY NONE" if identity is None else f"IDENTITY {identity}")
    missing = None
    if identity is None:
        lines.append("INVERSES UNDEFINED")
    else:
        missing = next((a for a in range(n)
                        if not any(table[a][b] == identity and table[b][a] == identity
                                   for b in range(n))), None)
        lines.append("INVERSES OK" if missing is None else f"INVERSES FAIL {missing}")
    group = witness is None and identity is not None and missing is None
    lines.append("GROUP YES" if group else "GROUP NO")
    return lines, group


def read_table(text):
    if not text.isascii():
        raise ValueError("input must be ASCII text")
    tokens = re.split(r"[ \t\n\r\v\f]+", text.strip(" \t\n\r\v\f"))
    if not tokens or any(re.fullmatch(r"-?[0-9]{1,4}", t) is None for t in tokens):
        raise ValueError("expected integer tokens with at most four digits")
    numbers = list(map(int, tokens))
    n = numbers[0]
    if not 1 <= n <= 16 or len(numbers) != 1 + n * n:
        raise ValueError("expected n in 1..16 followed by exactly n*n entries")
    return [numbers[1 + i*n:1 + (i+1)*n] for i in range(n)]


def main(args):
    if args not in ([], ["--stdin"]):
        raise ValueError("usage: tables.py [--stdin]")
    table = read_table(sys.stdin.read()) if args else [[i ^ j for j in range(4)] for i in range(4)]
    lines, group = check(table)
    print("\n".join(lines))
    return 0 if group else 1


if __name__ == "__main__":
    try:
        sys.exit(main(sys.argv[1:]))
    except ValueError as error:
        print(error, file=sys.stderr)
        sys.exit(2)

/* Check all triples, a two-sided identity, and two-sided inverses. */
#include <ctype.h>
#include <stdio.h>
#include <string.h>

enum { MAX_N = 16 };

/* Bounded token parsing: optional minus and 1..4 ASCII digits. */
static int number(int *value) {
    int ch;
    do { ch = getchar(); } while (ch != EOF && isspace((unsigned char)ch));
    if (ch == EOF) return 0;
    int sign = 1, digits = 0, total = 0, valid = 1;
    if (ch == '-') { sign = -1; ch = getchar(); }
    while (ch != EOF && !isspace((unsigned char)ch)) {
        if (ch < '0' || ch > '9' || digits == 4) valid = 0;
        if (valid) total = 10 * total + (ch - '0');
        if (digits < 5) ++digits;
        ch = getchar();
    }
    if (!valid || digits == 0) return -1;
    *value = sign * total;
    return 1;
}

int main(int argc, char **argv) {
    int n = 4, table[MAX_N][MAX_N] = {{0}};
    if (argc == 2 && strcmp(argv[1], "--stdin") == 0) {
        if (number(&n) != 1 || n < 1 || n > MAX_N) goto bad_input;
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < n; ++j)
                if (number(&table[i][j]) != 1) goto bad_input;
        int extra;
        if (number(&extra) != 0 || ferror(stdin)) goto bad_input;
    } else if (argc == 1) {
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < n; ++j) table[i][j] = i ^ j;
    } else goto bad_input;

    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            if (table[i][j] < 0 || table[i][j] >= n) {
                printf("CLOSURE FAIL %d %d %d\nGROUP NO\n", i, j, table[i][j]);
                return 1;
            }
    puts("CLOSURE OK");
    int associative = 1;
    for (int a = 0; a < n && associative; ++a)
        for (int b = 0; b < n && associative; ++b)
            for (int c = 0; c < n; ++c) {
                int left = table[table[a][b]][c], right = table[a][table[b][c]];
                if (left != right) {
                    printf("ASSOCIATIVE FAIL %d %d %d %d %d\n", a, b, c, left, right);
                    associative = 0;
                    break;
                }
            }
    if (associative) puts("ASSOCIATIVE OK");
    int identity = -1;
    for (int e = 0; e < n && identity < 0; ++e) {
        int valid = 1;
        for (int a = 0; a < n; ++a)
            if (table[e][a] != a || table[a][e] != a) valid = 0;
        if (valid) identity = e;
    }
    int missing = -1;
    if (identity < 0) puts("IDENTITY NONE\nINVERSES UNDEFINED");
    else {
        printf("IDENTITY %d\n", identity);
        for (int a = 0; a < n && missing < 0; ++a) {
            int found = 0;
            for (int b = 0; b < n; ++b)
                if (table[a][b] == identity && table[b][a] == identity) found = 1;
            if (!found) missing = a;
        }
        if (missing < 0) puts("INVERSES OK");
        else printf("INVERSES FAIL %d\n", missing);
    }
    int group = associative && identity >= 0 && missing < 0;
    puts(group ? "GROUP YES" : "GROUP NO");
    return group ? 0 : 1;
