10.1 大问题：根式的表达能力

本书最后的问题是：能否只用有限次加、减、乘、除与开根号，写出每个有理系数多项式的全部根？“不能根式求解”不等于没有根，也不妨碍数值逼近。我们将用 x⁵+10x⁴−2 走完从系数到不可解性的论证。

理解与边界

先确定“可解”的含义

本章省略的限定始终是“用根式”。代数基本定理保证非恒定复系数多项式有复根；Galois 理论讨论的是这些根能否用指定运算表达。

10.2 运算能把我们带到哪些数

有理数的小数展开有限或最终循环；无理数不最终循环。√2 是实代数数，i 是非实代数数，π、e 是超越数。一个数是否代数，必须相对于系数域说：本章默认“代数”指在 Q 上代数，而不是允许任意复系数后用 x−z=0 把所有数都算进去。

若 a 已经代数，则添加 α 满足 αⁿ=a 后仍是有限扩张：先有 Q(a)/Q 有限，再有 Q(a,α)/Q(a) 次数至多 n，塔式乘法给总次数有限。因此有限次四则与根式只能达到代数数。反方向是否成立正是难点；x⁵+10x⁴−2 的根将给出反例。可达数的集合对四则运算封闭：两个有限根式表达式可放进一条共同的有限根式塔。

原书 Key Point 10.5 还将此思路与尺规作图相连。尺规步骤只引入一次或二次方程，所以可作数落在逐次二次扩张中，总次数为 2 的幂；∛2 次数为 3，故不能用尺规倍立方。三等分 60° 要作 cos20°，它满足 8x³−6x−1=0 且在 Q 上无有理根，次数 3，故一般角三等分也不可能；化圆为方所需 √π 甚至不是代数数。这里用到 π 超越这个外部经典事实，书中也未证明；三个例子展示运算限制的意义，不承担后面五次不可解证明。

10.4 不可约多项式与 Eisenstein 判别

“不可约”相对于基域 F：次数至少 1 的 f∈F[x]，不能写成两个正次数多项式的乘积。非零常数是单位，不计为有意义的因子。对次数大于 1 的不可约多项式，没有 F 中的根；反过来，“无 F 中的根”仅对二次与三次等价于不可约，四次可以分成两个无根的二次式。

例如 x²−x−6=(x−3)(x+2)，根在 Q 中。12x³−44x²+35x+17 可分为 (3x+1)(4x²−16x+17)；后一因子判别式 −16，不可约于 Q，但在 C 上等于 4(x−2−i/2)(x−2+i/2)。原书印刷 232 页的复线性分解漏写前面的 4，乘回最高次项即可发现。

10.5 计算 Galois 群

固定基域 Q。记 Q(r) 为包含 Q 与 r 的最小域；记 L=Q(r₁,…,rₙ) 为包含某多项式全部根的分裂域。后者的 Q 自同构才组成该多项式的 Galois 群。只添一个根的域可能并非分裂域，不能直接把两种对象混写。

10.5.1 小扩张 Q(√2)：从计算到基底

令 u=√2。所有元素恰写成 a+bu，a,b∈Q：和与积仍是这种形式，因为 u²=2；非零元素的逆为 (a−bu)/(a²−2b²)。分母不为零，否则 b≠0 会使 (a/b)²=2，或 b=0 时连 a 也为 0。这个集合是包含 Q,u 的域，所以就是 Q(u)。表达唯一，因为 (a−c)+(b−d)u=0 且 u 无理迫使系数均为零。

原书的例子 (√2+3/2)³=99/8+(35/4)√2，来自四项展开：2√2+9+(27/4)√2+27/8。另一个例子 √2/(16+√2)=(8√2−1)/127，来自分子分母同乘 16−√2。次数 [Q(u):Q]=2 的含义是 Q 向量空间的基底长度，不是任意书写形式的“项数”。

10.5.3 从根的置换到整个域的自同构

根置换只有保持全部代数关系，才能延伸成域自同构。若同一个域元素有两种根的表达，必须证明代换后仍相等，否则就没有良定义的函数。最小多项式与商环提供这个保证，而不是只检查某几条看起来对称的方程。

任何域自同构都保 0、1、整数与有理数：σ(0)=σ(0)+σ(0) ⇒ σ(0)=0；双射给 σ(1)≠0，而 σ(1)²=σ(1) ⇒ σ(1)=1。随后保加法、负数与非零逆元，得到 σ(m/n)=m/n。复共轭是 C 的一个自同构，固定全部 R；Q(2)Q(√2) 的另一个自同构仅固定 Q，且不连续，所以不能把它当成整个实轴的镜面反射。

10.5.5 立方根、单根域与六次分裂域

令 t=∛2，s=√−3=i√3，ζ=(−1+s)/2。ζ³=1、ζ≠1，x3−2x³−2 的根为 r₁=t、r₂=tζ、r₃=tζ²。E=Q(t) 的次数为 3，元素是 a+bt+ct²；它全在 R 中，故不含另外两个非实根。它的 Q 自同构只有恒等，因为 t 的其他候选像不在 E。

把 s 加入 E，得到 L=Q(t,s)。s 非实而 E⊂R，所以 s 在 E 上仍有最小多项式 x²+3，第二步次数为 2；因此 [L:Q]=2·3=6。六项基底是 1,t,t²,s,ts,t²s。由 ζ=r₂/r₁、s=2ζ+1，任意两个不同根就能生成 L；第三根可由 r₁+r₂+r₃=0 找出。

有限扩张的“正规”意为：基域上任何不可约多项式只要在扩域中有一个根，就在那里完全分裂。特征零还保证可分（无重根）；有限正规可分扩张称 Galois 扩张。有限分裂域满足这些条件，单根域 E=Q(t) 则不正规。

原文摘录：

这证明的是“根位于某条根式塔内”，不要求原分裂域本身恰由原来选定的那条根式塔构造。添单位根、取正规闭包的两步使群论条件适用。单根非正规域的自同构群可能平凡，不能据此断言其元素全可用根式写出。

习题 10.22 · 消根号之后还要证明不可约

解答与推导

(a) x²−15；若有有理根，其平方为 15，素数 3 的指数奇偶矛盾；或用 Eisenstein p=3。

(b) 设 r=⁵√(1+√2)，则 (r⁵−1)²=2，得到 r¹⁰−2r⁵−1=0。还必须证明次数确为 10，详证在下文；仅消去根号不能证明不可约。

(b) 的不可约性补证。 令 K=Q(2)Q(√2)、u=1+√2。先证 u 不是 K 中元素的五次方。若 v⁵=u，则 v 是首一整数系数多项式 x¹⁰−2x⁵−1 的根，这就是“代数整数”的定义。写 v=a+b√2，a,b∈Q；它不可能有理，否则 v⁵ 有理而 u 无理。其二次最小多项式为 x²−2ax+(a²−2b²)，是上述首一整数多项式的首一有理因子。由 Gauss 引理，这个因子的系数均为整数，故迹 2a 与范数 a²−2b² 必为整数。于是 判别式 8b² 为整数迫使有理 b 的分母至多 2，再写 a=m/2、b=n/2，m²−2n²≡0 mod4 迫使 m,n 都偶。

范数给 N(v)⁵=N(u)=−1，所以 N(v)=−1；K 是实域，v 为 u 的唯一实五次根，1<v<1+√2。其共轭为 −1/v，于是整数 b=(v+1/v)/(2√2)。函数 x+1/x 在 x>1 严格增，而 (1+√2)+1/(1+√2)=2√2，所以 0<b<1，矛盾。

最后若 x⁵−u 在 K 上有真首一因子，设次数 d∈{1,2,3,4}。其根是 r 乘五次单位根，根的乘积 c∈K 满足 c⁵=uᵈ。因为 gcd(d,5)=1，取整数 A,B 使 dA+5B=1，就有 (cᴬuᴮ)⁵=u，违背前段。因此 x⁵−u 在 K 上不可约，扩张次数为 5。又 √2=r⁵−1∈Q(r)，塔式定理给 [Q(r):Q]=5·2=10；所以刚得到的十次多项式才确为最小多项式。

程序：六维基底中的精确自同构

galois 程序精确计算 L=Q(t,s)，其中 t³=2、s²=−3。输入六个整数 a,b,c,d,e,f，表示 a+bt+ct²+ds+ets+ft²s；它打印全部六个自同构的像、迹（六个像之和），以及 z 与复共轭 z 的乘积。所有系数是约分后的有理数，没有用浮点根近似代替代数关系。

数组下标 i+3j 对应 tⁱsʲ（0≤i<3，0≤j<2）。两个基底元相乘先把指数相加：t 指数达到 3 就减 3 并乘 2，s 指数达到 2 就减 2 并乘 −3。例如 (t²s)(ts)=t³s²=−6，所以相应项进入常数坐标；不能只把指数取模而漏掉系数。

构造 ζ=(−1+s)/2 后，对每个 k=0,1,2 和 ε=±1，逐项代 t↦tζᵏ、s↦εs。像数组记录同一基底的系数，因此可以直接比较相等；两个映射的根像下标由 j↦k+εj mod3 给出。默认输入六个 1，复共轭只翻后三个坐标，迹为 6；乘积落回 Q(t)，后三个系数应为零。这些都是独立于打印顺序的数学不变量。

Python 使用标准库 Fraction；C11 使用 int64_t 分子分母并在每次运算后以 gcd 约分，分母保持正。输入限制为六个十进制整数、每项 −100…100，或者无参使用默认值；不接受部分向量、超界或小数。算法只进行固定的六维乘法、最多二次幂和一次输入乘积；在该范围内分母整除 4，自同构系数不超过数千，乘积系数不超过数百万，64 位中间乘加有充足余量。范围扩大或加入任意多次乘法时必须另做溢出设计。

六维朴素乘法检查 36 对坐标，推广到 d 维是 O(d²) 次有理运算；六个自同构各代换有限个基底项。它是本章具体分裂域的精确模型，不能自动判定任意多项式的 Galois 群。独立检查使用根置换、符号关系与单独的有理矩阵参考，另外核验有限域和习题多项式恒等式。

"""Exact arithmetic in Q(t,s), t^3=2 and s^2=-3; basis 1,t,t^2,s,ts,t^2s."""
from fractions import Fraction
import re
import sys


def basis(i):
    return tuple(Fraction(int(j == i)) for j in range(6))


def add(a, b):
    return tuple(x + y for x, y in zip(a, b))


def scale(a, c):
    return tuple(x * c for x in a)


def mul(a, b):
    out = [Fraction(0) for _ in range(6)]
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            tpower = i % 3 + j % 3
            spower = i // 3 + j // 3
            factor = 1
            if tpower >= 3:
                tpower -= 3
                factor *= 2
            if spower >= 2:
                spower -= 2
                factor *= -3
            out[tpower + 3 * spower] += x * y * factor
    return tuple(out)


def automorphism(a, k, sign):
    if len(a) != 6 or k not in (0, 1, 2) or sign not in (-1, 1):
        raise ValueError("invalid field vector or automorphism")
    one, t, s = basis(0), basis(1), basis(3)
    zeta = scale(add(scale(one, -1), s), Fraction(1, 2))
    zpower = one
    for _ in range(k):
        zpower = mul(zpower, zeta)
    timage = mul(t, zpower)
    simage = scale(s, sign)
    powers = [one, timage, mul(timage, timage)]
    images = powers + [mul(x, simage) for x in powers]
    out = (Fraction(0),) * 6
    for coefficient, image in zip(a, images):
        out = add(out, scale(image, coefficient))
    return out


def format_vector(a):
    return "[" + ",".join(map(str, a)) + "]"


def output(a):
    lines = ["basis=1,t,t^2,s,ts,t^2s; t^3=2; s^2=-3", "input=" + format_vector(a)]
    trace = (Fraction(0),) * 6
    for k in range(3):
        for sign in (1, -1):
            value = automorphism(a, k, sign)
            trace = add(trace, value)
            perm = ",".join(str((k + sign * j) % 3 + 1) for j in range(3))
            lines.append(f"sigma({k},{sign}) roots={perm} value=" + format_vector(value))
    lines.append("trace=" + format_vector(trace))
    lines.append("z*conjugate(z)=" + format_vector(mul(a, automorphism(a, 0, -1))))
    return "\n".join(lines) + "\n"


def main(args):
    if not args:
        a = (Fraction(1),) * 6
    elif len(args) == 6 and all(re.fullmatch(r"-?[0-9]{1,3}", s) for s in args):
        a = tuple(Fraction(int(s)) for s in args)
    else:
        print("usage: galois [a b c d e f], six integers -100..100", file=sys.stderr)
        return 2
    if any(abs(x) > 100 for x in a):
        print("coefficients must be in -100..100", file=sys.stderr)
        return 2
    print(output(a), end="")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))

/* Exact six-dimensional example, with a deliberately bounded integer CLI. */
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <string.h>

typedef struct { int64_t n, d; } Rational;
typedef struct { Rational c[6]; } Element;

static int64_t gcd(int64_t a, int64_t b) {
    if (a < 0) a = -a;
    while (b) { int64_t r = a % b; a = b; b = r; }
    return a;
}

static Rational rat(int64_t n, int64_t d) {
    /* All callers construct nonzero positive denominators in this example. */
    int64_t g = gcd(n, d);
    Rational r = {n / g, d / g};
    return r;
}

static Rational radd(Rational a, Rational b) {
    return rat(a.n * b.d + b.n * a.d, a.d * b.d);
}

static Rational rmul(Rational a, Rational b) {
    return rat(a.n * b.n, a.d * b.d);
}

static Element zero(void) {
    Element a;
    for (int i = 0; i < 6; ++i) a.c[i] = rat(0, 1);
    return a;
}

static Element basis(int i) {
    Element a = zero(); a.c[i] = rat(1, 1); return a;
}

static Element add(Element a, Element b) {
    for (int i = 0; i < 6; ++i) a.c[i] = radd(a.c[i], b.c[i]);
    return a;
}

static Element scale(Element a, Rational c) {
    for (int i = 0; i < 6; ++i) a.c[i] = rmul(a.c[i], c);
    return a;
}

static Element mul(Element a, Element b) {
    Element out = zero();
    for (int i = 0; i < 6; ++i) for (int j = 0; j < 6; ++j) {
        int tp = i % 3 + j % 3, sp = i / 3 + j / 3, factor = 1;
        if (tp >= 3) { tp -= 3; factor *= 2; }
        if (sp >= 2) { sp -= 2; factor *= -3; }
        int at = tp + 3 * sp;
        out.c[at] = radd(out.c[at], rmul(rmul(a.c[i], b.c[j]), rat(factor, 1)));
    }
    return out;
}

static Element automorphism(Element a, int k, int sign) {
    Element one = basis(0), t = basis(1), s = basis(3);
    Element zeta = scale(add(scale(one, rat(-1, 1)), s), rat(1, 2));
    Element zp = one;
    for (int i = 0; i < k; ++i) zp = mul(zp, zeta);
    Element ti = mul(t, zp), si = scale(s, rat(sign, 1));
    Element images[6]; images[0] = one; images[1] = ti; images[2] = mul(ti, ti);
    for (int i = 0; i < 3; ++i) images[i + 3] = mul(images[i], si);
    Element out = zero();
    for (int i = 0; i < 6; ++i) out = add(out, scale(images[i], a.c[i]));
    return out;
}

static void show(Element a) {
    putchar('[');
    for (int i = 0; i < 6; ++i) {
        printf("%s%" PRId64, i ? "," : "", a.c[i].n);
        if (a.c[i].d != 1) printf("/%" PRId64, a.c[i].d);
    }
    putchar(']');
}

static int parse(const char *s, int *value) {
    size_t len = strlen(s), at = s[0] == '-' ? 1U : 0U;
    if (len <= at || len - at > 3) return 0;
    int v = 0;
    for (size_t i = at; i < len; ++i) {
        if (s[i] < '0' || s[i] > '9') return 0;
        v = v * 10 + s[i] - '0';
    }
    if (v > 100) return 0;
    *value = at ? -v : v;
    return 1;
}

int main(int argc, char **argv) {
    Element a = zero();
    if (argc != 1 && argc != 7) {
        fputs("usage: galois [a b c d e f], six integers -100..100\n", stderr);
        return 2;
    }
    for (int i = 0; i < 6; ++i) {
        int value = 1;
        if (argc == 7 && !parse(argv[i + 1], &value)) {
            fputs("coefficients must be integers in -100..100\n", stderr);
            return 2;
        }
        a.c[i] = rat(value, 1);
    }
    puts("basis=1,t,t^2,s,ts,t^2s; t^3=2; s^2=-3");
    printf("input="); show(a); putchar('\n');
    Element trace = zero();
    for (int k = 0; k < 3; ++k) for (int sign = 1; sign >= -1; sign -= 2) {
        Element value = automorphism(a, k, sign);
        trace = add(trace, value);
        printf("sigma(%d,%d) roots=", k, sign);
        for (int j = 0; j < 3; ++j) printf("%s%d", j ? "," : "", (k + sign * j + 3) % 3 + 1);
        printf(" value="); show(value); putchar('\n');
    }
    printf("trace="); show(trace); putchar('\n');
    printf("z*conjugate(z)="); show(mul(a, automorphism(a, 0, -1))); putchar('\n');
    return 0;
}
