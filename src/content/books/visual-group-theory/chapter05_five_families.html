5.1 循环群：重复一个动作会得到什么

本章的五类是循环群、阿贝尔群、二面体群、对称群、交错群。它们不是互不相交的五个盒子：循环群一定阿贝尔，S₃ 与 D₃ 又是同一个抽象群。本章先建立可计算的例子，再用 Cayley 定理说明任何群都能忠实地表现为置换。

5.1.1 只会旋转的物体

有 n 片同向弯曲叶片的理想风车，每转 360°/n 回到同类位置，记这一步为 r。允许的动作是 e,r,…,rⁿ⁻¹；rn=erⁿ=e。叶片的弯曲方向排除了反射。两个动作 rⁱ、rʲ 合起来就是 rⁱ⁺ʲ，指数相差 n 的动作相同。这给出 n 阶循环群 Cₙ；n 是动作总数，不是生成元个数。

5.1.3 元素的 orbit

本书把不断重复 g 得到的 ⟨g⟩ 称为 orbit；这里它就是 g 生成的循环子群。若 g 的最小正整数幂 gᵈ=e，则 ⟨g⟩={e,g,…,gᵈ⁻¹}，d 叫元素的阶。注意 |G| 是整个群的阶，|g| 是一个元素的阶。对有限群，重复必然发生；gⁱ=gʲ（i<j）两边消去 gⁱ，得到 gʲ⁻ⁱ=e。

5.1.4 引入循环图

循环图把最大循环子群画成无向环，各环中的同一元素只画一次；二阶循环以一条边表示。它强调幂与阶，不指定一套生成元。它一般不能独自恢复任意两个元素的乘积；画得像一个多边形也不能忽略边是否带方向、颜色和生成元含义。

5.2 阿贝尔群：先后顺序能否交换

5.2.1 两条路径为什么必须到同一点

若任意 a,b∈G 都有 ab=ba，群就是阿贝尔群。图上从任意起点 x 先走 a 再走 b，与先走 b 再走 a，终点分别是 xab、xba。相等的不是两段曲线的形状，而是最终节点。只需验证生成元两两交换：在任意两个生成元字词间，反复交换相邻字母便可把整块字词换位；逆元也继承交换关系。

“只需检查生成元”不等于“找到一对交换的元素即可”。每个群都有 e 与其他元素交换；非交换群也可能有很大的交换子群。

5.2.2 表的对称与直积预告

5.2.3 循环之间怎样相交

C₂×C₂×C₂ 的七个非单位元都有阶 2，所以循环图是从 e 发出的七条边。C₂×C₄ 有两个四阶循环，共享 e 与 (0,2)，另有两个二阶循环。一般在 Cₚ×Cₚ（p 为素数）中，每个非零元素的阶都是 p：p 次相加为零，而更小的正整数倍不会使非零坐标归零。

非平凡循环数 = (p²−1)/(p−1) = p+1。非平凡循环数 = (p²−1)/(p−1) = p+1。

分子数出所有非零元素；一个循环贡献 p−1 个；若两个循环共享非零元素，这个元素已生成各自的整个循环，所以它们其实相同。由此可除而且不会重复计数。完整证明和循环图见习题 5.28、8.23。

5.3 二面体群：翻面会倒转旋转方向

5.3.1 正多边形的全部动作

对正 n 边形，r 旋转一格，f 沿某条对称轴翻面。一个刚体对称先决定顶点 0 去哪里（n 种），再决定环绕方向（2 种），所以 n≥3 时共有 2n 个动作。保持方向的是 rⁱ，反转方向的是 rⁱf。本书写 Dₙ 表示这个 2n 阶群；有的教材会把同一个群记作 D₂ₙ。这里也按原书把 D₁=C₂、D₂=V₄ 纳入代数定义。

5.3.2 图中的两圈与关系式

所有字词仍按时间从左到右执行。先翻面、转一格、再翻回去，整体相当于反向转一格，所以 frf=r−1frf=r⁻¹。右乘 r 时，rⁱ 变成 rⁱ⁺¹，rⁱf 则变成 rⁱ⁻¹f；两层循环方向相反。右乘 f 只在对应两层间切换。

rⁿ=e，f²=e，fr=r⁻¹f。rⁿ=e，f²=e，fr=r⁻¹f。

5.3.3 从关系式推到乘法表

将一个动作编码为 (i,j)=rifjrⁱfʲ，0≤i<n，j∈{0,1}。乘 (k,l) 时，关键是把中间的 fʲ 移过 rᵏ。j=0 无需改变；j=1 时 frᵏ=r⁻ᵏf，所以第二段的旋转指数要变号。

(rⁱfʲ)(rᵏfˡ)=rⁱ⁺⁽⁻¹⁾ʲᵏ fʲ⁺ˡ；(i,j)(k,l)=(i+(−1)ʲk mod n, j+l mod 2)。(rⁱfʲ)(rᵏfˡ)=r^(i+(−1)^j k) f^(j+l)；(i,j)(k,l)=(i+(−1)^j k mod n, j+l mod 2)。

这同时解释了旋转×旋转、旋转×反射、反射×旋转、反射×反射四种互不遗漏的情况。例如在 D₅，(r²f)(r⁴f)=r²⁻⁴=r³。原书表 5.18 用 f rⁱ 给反射命名；rⁱf=f r⁻ⁱ，换名会改变条纹的视觉方向，不能据此把运算顺序翻转。

5.3.4 乘积结构的预告

Dₙ 有一圈旋转与一圈反射，却通常不是 Cₙ×C₂。直积要求第二坐标不影响第一坐标的运算；上式中的 (−1)ʲ 恰好记录了这种影响。第 7—8 章会把它写成 Cₙ⋊C₂，称为半直积。n≥3 时 rf≠fr，所以 Dₙ 非交换；n=1、2 是例外。

5.3.5 二面体群的循环图

旋转构成一个 n 循环；每个 rⁱf 的平方是 rⁱf rⁱf=rⁱr⁻ⁱ=e，因此 n 个反射各给一条二阶边，皆从 e 发出。循环图能把这 n 个反射的阶一眼看清，但看不出不同反射相乘到底是哪一个旋转；这要回到 Cayley 图或乘法表。

5.4.4 任何群都能变成置换群

Theorem 5.1

Every group is isomorphic to a collection of permutations.

中文陈述：每个群都同构于某个集合上的置换群；有限 n 阶群可以嵌入 Sₙ。

来源：印刷 85 / PDF 100

证明与说明

给每个 g∈G 分配置换 Rg:x↦xg，也就是乘法表的第 g 列。它确为双射，逆置换是 Rg⁻¹。为了证明这张对应表忠实表达整个运算，需验证两个不同问题。第一，保乘法：先 Rg 后 Rh 把任意 x 送到 (xg)h=x(gh)，即 RgRh=Rgh；这里用了结合律。第二，单射：如果 Rg=Rh，就让它们作用于 e，得到 g=h。

G → Sym(G)，g ↦ Rg；Rgh(x)=x(gh)=(xg)h。G → Sym(G)，g ↦ R_g；R_(gh)(x)=x(gh)=(xg)h。

因此所有 Rg 组成的置换群与 G 同构。仅检查 e 的像能辨认元素，但保乘法还需对任意 x 使用结合律；这补出了原书图示证明中容易略过的一步。无限群也适用，只是置换作用的集合 G 可能无限，不能写成某个有限 Sₙ。

5.4.5 如何使用这五类群

判断同构时先看阶，再看是否交换、元素阶和循环如何相交；这些量必须在同构下保持。寻找反例时，Cₙ 提供单循环，V₄ 提供非循环的交换群，D₃ 提供最小非交换群，Q₄ 提供阶为 8 却不属于本章五类的例子。后续的子群、商群和同态都将在这份例子库上展开。

(b) 对 n≥2，按不同的无序二元集合计数是 3nφ(n)/2；D₃ 是 9 对。第一类是一条生成整个旋转群的 rᵏ（φ(n) 种）与任意反射（n 种），共 nφ(n)。第二类为两反射 rⁱf、rʲf，乘积 rⁱ⁻ʲ，需 gcd(i−j,n)=1；先选有序对有 nφ(n) 种，再除以 2，共 nφ(n)/2。两个旋转无法生成反射。若“对”保留先后顺序，答案是 3nφ(n)，D₃ 为 18。D₁ 单独处理：允许 e 作成员时唯一无序二元集为 {e,f}。

(c) (rf)(r⁻¹f)=r²，所以生成旋转部分 ⟨r²⟩，再加一个反射。n 为奇数时 gcd(2,n)=1，得到整个 Dₙ；n 为偶数时只得到指数 2 的 Dₙ/₂（下标 n/2），不是整个群。

图上的节点是群元素，箭头是右乘生成元。比较两种路径，要从同一起点按同一时间顺序走；题面的生成关系则应保留逆号和字母顺序。

程序：把置换的每一步算出来

程序输入两个一行置换，输出 p、q、p 后接 q、反序组合、p 的逆以及 p 的平方。默认 p=[2,3,4,1]，q=[2,1,3,4]。对 1，p 后 q 给 1→2→1；对 2，给 2→3→3；继续逐点得到 [1,3,4,2]=(234)。反序是 [3,2,4,1]=(134)，直接展示非交换性。

数组元素是目的地，内部减 1 以匹配从零开始的下标。compose 使用 q[p[x]]，inverse 把每条 source→destination 反写。cycles 从未访问点出发直到返回，visited 保证每个点恰访问一次；order 取各循环长度的最小公倍数。sign 用逆序对数的奇偶独立计算，便于与循环分解交叉核对。

解析首先验证 1≤n≤8、每个 1…n 恰出现一次，随后循环遍历才安全。C 使用固定八元素数组，Python 使用 tuple；两者都拒绝重复、越界、空字段和不同次数的输入。循环分解和求逆各用 O(n) 时间，逆序对计数用 O(n²)，存储为 O(n)。这里枚举的是有限置换，Cayley 定理的一般结论由正文证明。

#!/usr/bin/env python3
"""Chapter 5: permutations of 1..n, with p*q meaning p THEN q."""
import math
import sys


def parse(text):
    fields = text.split(',')
    if not 1 <= len(fields) <= 8 or any(not x.isascii() or not x.isdecimal() for x in fields):
        raise ValueError('use 1..8 comma-separated positive integers')
    p = tuple(int(x) - 1 for x in fields)
    if sorted(p) != list(range(len(p))):
        raise ValueError('each value 1..n must occur exactly once')
    return p


def compose(p, q):
    """Array entries are destinations; visit p[x], then q[p[x]]."""
    return tuple(q[x] for x in p)


def inverse(p):
    q = [0] * len(p)
    for source, destination in enumerate(p):
        q[destination] = source
    return tuple(q)


def cycles(p):
    seen = set()
    result = []
    for start in range(len(p)):
        if start in seen:
            continue
        cycle = []
        x = start
        while x not in seen:
            seen.add(x)
            cycle.append(x)
            x = p[x]
        result.append(cycle)
    return result


def describe(label, p):
    parts = cycles(p)
    text = ''.join('(' + ' '.join(str(x + 1) for x in part) + ')'
                   for part in parts if len(part) > 1) or '()'
    order = math.lcm(*(len(part) for part in parts))
    inversions = sum(p[i] > p[j] for i in range(len(p)) for j in range(i + 1, len(p)))
    print(label, ','.join(str(x + 1) for x in p), text,
          'order=' + str(order), 'sign=' + str(-1 if inversions % 2 else 1))


def main(args):
    if not args:
        args = ['2,3,4,1', '2,1,3,4']
    if len(args) != 2:
        raise ValueError('usage: permutations.py p q; e.g. 2,3,4,1 2,1,3,4')
    p, q = map(parse, args)
    if len(p) != len(q):
        raise ValueError('p and q must have the same degree')
    for label, permutation in [('p', p), ('q', q), ('p*q', compose(p, q)),
                               ('q*p', compose(q, p)), ('p^-1', inverse(p)),
                               ('p^2', compose(p, p))]:
        describe(label, permutation)


if __name__ == '__main__':
    try:
        main(sys.argv[1:])
    except ValueError as error:
        print('error:', error, file=sys.stderr)
        sys.exit(2)

/* Chapter 5. p*q applies p first and q second. C11; no dependencies. */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>
#define MAX_N 8

typedef struct { int n; int to[MAX_N]; } Perm;

static int parse(const char *text, Perm *p) {
    const char *s = text;
    p->n = 0;
    while (*s) {
        if (p->n == MAX_N || !isdigit((unsigned char)*s)) return 0;
        int value = 0;
        while (isdigit((unsigned char)*s)) {
            value = value * 10 + (*s++ - '0');
            if (value > MAX_N) return 0;
        }
        if (value < 1) return 0;
        p->to[p->n++] = value - 1;
        if (!*s) break;
        if (*s++ != ',' || !*s) return 0;
    }
    if (p->n == 0) return 0;
    int seen[MAX_N] = {0};
    for (int i = 0; i < p->n; ++i) {
        int v = p->to[i];
        if (v >= p->n || seen[v]) return 0;
        seen[v] = 1;
    }
    return 1;
}

static Perm compose(Perm p, Perm q) {
    Perm r = p;
    for (int i = 0; i < p.n; ++i) r.to[i] = q.to[p.to[i]];
    return r;
}
static Perm inverse(Perm p) {
    Perm q = p;
    for (int i = 0; i < p.n; ++i) q.to[p.to[i]] = i;
    return q;
}
static int gcd(int a, int b) {
    while (b) { int r = a % b; a = b; b = r; }
    return a;
}
static void describe(const char *label, Perm p) {
    printf("%s ", label);
    for (int i = 0; i < p.n; ++i) printf("%s%d", i ? "," : "", p.to[i] + 1);
    printf(" ");
    int seen[MAX_N] = {0}, order = 1, printed = 0, inversions = 0;
    for (int i = 0; i < p.n; ++i) {
        if (seen[i]) continue;
        int part[MAX_N], size = 0, x = i;
        while (!seen[x]) { seen[x] = 1; part[size++] = x; x = p.to[x]; }
        order = order / gcd(order, size) * size;
        if (size > 1) {
            printf("(");
            for (int j = 0; j < size; ++j) printf("%s%d", j ? " " : "", part[j] + 1);
            printf(")");
            printed = 1;
        }
    }
    if (!printed) printf("()");
    for (int i = 0; i < p.n; ++i)
        for (int j = i + 1; j < p.n; ++j) inversions += p.to[i] > p.to[j];
    printf(" order=%d sign=%d\n", order, inversions % 2 ? -1 : 1);
}
int main(int argc, char **argv) {
    Perm p, q;
    const char *a = "2,3,4,1", *b = "2,1,3,4";
    if (argc == 3) { a = argv[1]; b = argv[2]; }
    else if (argc != 1) { fprintf(stderr, "error: expected two permutations\n"); return 2; }
    if (!parse(a, &p) || !parse(b, &q) || p.n != q.n) {
        fprintf(stderr, "error: permutations must contain 1..n exactly once; 1 <= n <= 8\n");
        return 2;
    }
    describe("p", p); describe("q", q);
    describe("p*q", compose(p,q)); describe("q*p", compose(q,p));
    describe("p^-1", inverse(p)); describe("p^2", compose(p,p));
    return 0;
}
