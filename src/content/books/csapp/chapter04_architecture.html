来源：印刷 391—408 页 / PDF 392—409 页

第 3 章把指令集当作软件可以调用的接口，本章转到接口的实现一侧。同一段机器码必须得到同一组可见结果，内部可以串行，也可以让不同指令的阶段重叠。Y86-64 去掉复杂寻址和大多数运算，留下足以暴露数据依赖、控制依赖和异常的结构。它是独立的教学 ISA，普通 x86 汇编器不能直接汇编这里的程序。

原书论述 · ISA 约束程序可见的状态

We will see in our processor implementations that we do not need to represent and organize this state in exactly the manner implied by the ISA, as long as we can make sure that machine-level programs appear to have access to the programmer-visible state.

中文陈述。处理器内部可以用不同方式表示和组织状态，条件是机器程序观察到的状态与 ISA 规定一致。因而比较两种实现时，应从相同初态执行同一程序，核对寄存器、内存、控制流及异常语义。

下面先列出 Y86-64 的可见状态，再把每条指令写成状态转移；SEQ+ 的 PC 重定时则展示内部状态位置如何改变而保持同一地址序列。

原书 §4.1.1，印刷 391 页 / PDF 392 页。

4.1.1 · 程序看得到的状态Programmer-Visible State

把状态记为寄存器文件 R、字节内存 M、PC、三个条件位 ZF/SF/OF 和运行状态 Stat。每个程序寄存器恰好 64 位；%rsp 除了也是普通可读写寄存器，还被栈指令隐式使用。PC 指向正在解释的指令起始字节。内存地址同样按 64 位处理，但模拟器只实现一个有限地址区间，越界必须成为异常。

4.1.5 · 从数组求和读懂汇编程序Y86-64 Programs

图 4.6 的参数 %rdi=start、%rsi=count，返回值放 %rax。Y86 的 addq 不能直接以立即数或内存为源，因此把 8、1 放进 %r8/%r9，先 load 元素再累加；每轮最后的 subq 同时产生循环测试所需的条件码。进入循环之前的 andq 负责 count=0 的情况。以下保留原算法，要求 count≥0 且数组区间有效；位级模型的加法按模 2⁶⁴ 进行。

sum:
    irmovq $8,%r8
    irmovq $1,%r9
    xorq %rax,%rax
    andq %rsi,%rsi
    jmp test
loop:
    mrmovq (%rdi),%r10
    addq %r10,%rax
    addq %r8,%rdi
    subq %r9,%rsi
test:
    jne loop
    ret

以数组 [3,−2,7] 为例，初始 start=0x100、count=3：每轮先读当前元素，再把指针加 8、计数减 1。三次循环的 (sum,start,count) 分别为 (3,0x108,2)、(1,0x110,1)、(8,0x118,0)；最后一次减法使 ZF=1，jne 不跳。把 subq 换到 addq 指针之前会让 jne 读取“指针加法”的条件码，循环不再按 count 终止。

完整程序还需要 .pos 放置代码／栈，.align 对齐数据，.quad 写入八字节常量；这些是汇编器指令，不在 CPU 中执行。yas 把源码生成 .yo，yis 按 ISA 解释它。图 4.7—4.8 实際写入的是四个 48 位字样，和为 0x0000abcdabcdabcd；正文把数值多重复一组 abcd 的描述与其代码、输出不一致，应以列出的字节与实际求和为准。

4.1.6 · 栈指针同时是源和目的时Some Y86-64 Instruction Details

设旧 %rsp=S。pushq %rsp 将 S 写到 M8[S−8]，然后令 %rsp=S−8。若先更新栈指针再读取它，会错误地压入 S−8。popq %rsp 的两个逻辑写回都指向 %rsp：增量结果 S+8 和内存读值 M8[S]；内存值最终胜出，所以它等价于 mrmovq 0(%rsp),%rsp 的寄存器与内存效果。这个特殊情况决定了双写端口和转发源的优先级。

模型理解

状态与实现可以不同

ISA 规定能观察到的寄存器、PC 和内存结果；流水寄存器、预测地址与转发线路属于实现。验证时比较前者。

边界

Y86 的 64 位运算可以绕回；相同表达式若直接写成有溢出的 C 有符号运算，便不再是合法的复现。教学模型统一用 uint64_t。

4.2 · 让控制表达式变成有时序的电路Logic Design and the Hardware Control Language HCL

来源：印刷 408—420 页 / PDF 409—421 页

硬件描述先要回答两件事：输入给定后组合电路产生什么函数；哪些值必须跨越时钟周期保存。HCL 把前者写成可读的表达式，时钟寄存器与内存元件承担后者。两者组合才形成持续执行程序的机器。

4.2.1 · 门的输入输出都是位Logic Gates

aba∧ba∨ba⊕b
00000
01011
10011
11110

AND、OR、NOT 随输入电压改变而持续传播，HCL 的 &&、||、! 在这里只处理 0/1。它们不是一次函数调用，也没有 C 的短路副作用规则。

4.2.2 · 组合电路必须是有确定输出的无环网络Combinational Circuits and HCL Boolean Expressions

每条输入线由唯一信号源驱动；不把两个门的输出短接；纯组合网络不形成反馈环。相等检测可用“同时为 1 或同时为 0”构成：

bool eq = (a && b) || (!a && !b);
bool out = (s && a) || (!s && b);

第二式是二选一：s=1 只让 a 的支路通过，s=0 只让 b 的支路通过。把 s=1、a=0、b=1 代入可得 out=0，说明多路选择器选择的是指定输入，而不是对两个输入求 OR。

4.2.3 · 字级逻辑与优先选择Word-Level Combinational Circuits and HCL Integer Expressions

64 位相等检测可先并行比较每对位，再把 64 个相等结果相与。字级 MUX 相当于 64 份位 MUX 共用同一控制信号。HCL 的 case 是有优先级的组合选择：第一条成立的条件决定输出；综合成电路时，后面的选择条件会隐含“前面的条件都不成立”。

word Out4 = [
    !s1 && !s0 : A;
    !s1        : B;
    !s0        : C;
    1          : D;
];

当 s1s0=01 时，第一项假、第二项真，输出 B；当 11 时前三项都假，输出 D。不要把这段代码读成四次写入同一存储位置。ALU 另有两个字输入 A、B 和功能号：0 计算 B+A，1 计算 B−A，2 计算 B&A，3 计算 B^A。输入顺序直接对应 subq 的目的减源。

4.2.4 · 集合测试把指令分类变成电路Set Membership

bool need_regids = icode in { IRRMOVQ, IIRMOVQ, IRMMOVQ,
                             IMRMOVQ, IOPQ, IPUSHQ, IPOPQ };

这是若干相等比较的 OR。每个集合成员都应能从指令格式表解释：jmp 与 call 没有寄存器字节，所以不能加入；pushq 只有一个显式寄存器，也需要完整的寄存器字节。集合分类错误会使常量字段整体错位。

4.2.5 · 边沿保存值，周期内传播值Memory and Clocking

设寄存器当前输出 x=7，输入经组合逻辑算成 y=12。时钟边沿之前，输出仍是 7；上升沿采样后才变为 12。寄存器文件的读取按组合逻辑建模，读地址改变后经过延迟得到旧存值；写入只在边沿发生。同一周期读写同一个程序寄存器时，读值在写入边沿才发生变化。PIPE 因此需要 W→D 转发，不能假设“本周期写回了”就已能在本周期译码读到。

数据内存同样用组合读、边沿写来描述；地址错误信号由边界检查组合得到。真实缓存、虚拟地址转换和主存延迟更复杂，这个接口只假设访问结果能在一个阶段的时限内返回。指令与数据端口可以同时读取同一地址空间，但本章不允许程序改写自身指令。

4.3 · 用一条组合通路完成整条指令Sequential Y86-64 Implementations

来源：印刷 420—448 页 / PDF 421—449 页

SEQ 每周期完成一条指令。所谓取指、译码、执行、访存、写回、PC 更新，是一条组合路径上的逻辑分工；它们没有被六个时钟隔开。先把每条指令塞进同一张状态表，再把每一列的共同选择规律提炼为 HCL，可以避免为每条指令另造一台机器。

4.3.2 · 数据通路把同一结果送到多个用途SEQ Hardware Structure

同一 ALU 在 OPq 中运算，在访存中求地址，在 call/pushq 中把栈顶减 8。两个写端口的必要性来自 popq：valE 写 %rsp，valM 写 rA；两者同名时 M 端口优先。普通不写寄存器的指令把目的编号置 RNONE，省去为每个寄存器单独生成写使能。

4.3.3 · 为什么可以同时写回SEQ Timing

原书原则 · 无须回读新状态（No reading back）

The processor never needs to read back the state updated by an instruction in order to complete the processing of this instruction.

中文陈述。在这里设计的指令与 SEQ 数据通路中，完成本条指令不需要先写入某个状态，再从该状态读回新值。操作数来自周期开始时的状态，中间结果沿组合通路传递，状态写入可以在时钟边沿共同完成。

pushq 先由旧栈顶计算 valE=S−8，再把同一个信号同时送到内存地址端和 %rsp 写端口。因此它不必等 %rsp 更新后再读一次；下面的时序表把“组合信号已经算好”与“寄存器状态已经写入”分开。

T=N+4+L+2B+3R,CPI=1+4+L+2B+3RN

对长程序忽略 4N，便得到 CPI≈1+LN+2BN+3RN。若同时发生的控制事件共享了清空位置，应从实际气泡流计数，不能重复收费。

读代码 · 从旧状态计算，再提交一条指令

先看 C 的 Machine 或 Python 的 Machine：4096 字节内存、15 个 64 位寄存器、PC、CC 和 Stat 组成可见机器状态；steps、loads、misses、rets 与 previous_load 是执行统计。程序从地址 0 解释镜像，零填充余下内存。C 的 uint64_t 自然按模 264 运算，Python 的 alu 则用 MASK 保留同样的位型。

推荐沿 main → step → report 读 C 版本，再对照 Python 的 step 与 run。遇到 ALU 或条件判断时，回到 alu 和 condition；它们把第 4.1 节的状态规则集中成小函数。

step 的前半段：取得所有输入，准备候选结果

取指先检查 PC，再拆出 op/fn，并由指令类别决定寄存器字节 nr、八字节常量 nc 和总长度。member(op,bits) 用位掩码表达“op 是否属于某组指令”：bits 的第 op 位为 1 就表示属于该组。寄存器字段合法后，sa/sb 选择旧寄存器，va/vb 保存读得的值；de/dm 保存两个写端口的候选目的。常量 c 与这些输入产生 ALU 结果 ve、新条件码 cc 和条件 taken，此时还没有改动架构状态。

例如图 4.17 的 subq %rdx,%rbx 使 va=9、vb=21，alu 计算目的减源，得到 ve=12 和 CC=000。访存类指令用同一 ALU 求地址；word / put_word 负责小端八字节拼装与拆分，地址有效性由调用路径先检查。

step 的后半段：检查地址，再按优先级提交

数据地址检查成功后才读取 vm、选择 nextpc，并进入写入部分。内存写、de 写、dm 写、CC 写与 PC 更新位于这一段；当 popq %rsp 的 de 和 dm 同为 %rsp 时，dm 的内存结果后写，从而覆盖栈顶增量。条件移动不成立时先把 de 设为 NONE，后面的统一写回逻辑自然不会修改目标寄存器。

非法编码或寄存器字段把状态设为 INS；取指或数据访问越界设为 ADR，随后立即返回。发生这些错误时，寄存器、内存、CC 和 PC 保持本指令开始前的值。halt 则设置 HLT 并保留 halt 的 PC；它计入已执行指令数。文件错误、超长镜像和一百万条执行上限由入口处理为退出码 2；HLT、ADR、INS 都作为模拟结果由 report 输出，读结果时要同时看 status。

输出与控制函数：分别检查状态和选择规则

report 输出终态、事件次数和全部寄存器，并对完整 4 KiB 内存计算 FNV-64 摘要。默认镜像可沿 逐指令状态表核对，摘要用于跨语言一致性比较。control / forward / check_logic 是另一组纯函数：控制选择检查 D 的 stall/bubble 互斥，转发按最近的有效生产者优先。它们检查布尔控制和选择优先级；ISA 主循环仍然一次完整执行一条指令。

/* Bounded little-endian Y86-64 ISA model, not a PIPE circuit simulator. */
#include <stdbool.h>
#include <stdint.h>
#include <inttypes.h>
#include <stdio.h>
#include <string.h>

enum { SIZE = 4096, NONE = 15, RSP = 4 };
typedef struct { bool z, s, o; } CC;
typedef struct {
    unsigned char mem[SIZE]; uint64_t reg[15], pc;
    CC cc; const char *stat; unsigned steps, loads, misses, rets, previous_load;
} Machine;
typedef struct { bool f, ds, db, eb, mb, ws; } Control;
static bool member(unsigned x, unsigned bits) { return (bits & (1u << x)) != 0; }
static bool condition(unsigned f, CC c) {
    const bool values[] = {true, (c.s != c.o) || c.z, c.s != c.o, c.z,
                           !c.z, c.s == c.o, (c.s == c.o) && !c.z};
    return values[f];
}
static uint64_t alu(unsigned fn, uint64_t a, uint64_t b, CC *cc) {
    const uint64_t r = fn == 0 ? b + a : fn == 1 ? b - a : fn == 2 ? b & a : b ^ a;
    const bool sa = (a >> 63) != 0, sb = (b >> 63) != 0, sr = (r >> 63) != 0;
    *cc = (CC){r == 0, sr, fn == 0 ? sa == sb && sr != sb : fn == 1 && sa != sb && sr != sb};
    return r;
}
static uint64_t word(const Machine *m, uint64_t a) {
    uint64_t v = 0;
    for (unsigned i = 0; i < 8; ++i) v |= (uint64_t)m->mem[a + i] << (8 * i);
    return v;
}
static void put_word(Machine *m, uint64_t a, uint64_t v) {
    for (unsigned i = 0; i < 8; ++i) m->mem[a + i] = (unsigned char)(v >> (8 * i));
}
static Control control(bool l, bool b, bool r, bool m, bool w) {
    return (Control){l || r, l, b || (r && !l), l || b, m || w, w};
}
static uint64_t forward(unsigned src, uint64_t raw, const unsigned dst[5], const uint64_t val[5]) {
    for (unsigned i = 0; i < 5; ++i) if (src != NONE && src == dst[i]) return val[i];
    return raw;
}
static unsigned check_logic(void) {
    unsigned checks = 0;
    for (unsigned bits = 0; bits < 32; ++bits) {
        const bool l = (bits & 1) != 0, b = (bits & 2) != 0, r = (bits & 4) != 0;
        const bool m = (bits & 8) != 0, w = (bits & 16) != 0;
        if (l && b) continue;
        const Control c = control(l, b, r, m, w);
        if ((c.ds && c.db) || (l && !(c.f && c.ds && c.eb)) || c.mb != (m || w) || c.ws != w) return 0;
        ++checks;
    }
    const unsigned d1[5] = {15,4,4,15,15}, d2[5] = {2,15,2,15,15};
    const uint64_t v1[5] = {0,5,264,0,0}, v2[5] = {3,0,10,0,0};
    return forward(4,0,d1,v1) == 5 && forward(2,0,d2,v2) == 3 ? checks : 0;
}
static void step(Machine *m) {
    const uint64_t p = m->pc;
    if (p >= SIZE) { m->stat = "ADR"; return; }
    const unsigned op = m->mem[p] >> 4, fn = m->mem[p] & 15;
    if (op > 12 || fn > (op == 2 || op == 7 ? 6u : op == 6 ? 3u : 0u)) { m->stat = "INS"; return; }
    const bool nr = member(op, 0x1c7c), nc = member(op, 0x11b8);
    const unsigned len = 1 + (unsigned)nr + 8 * (unsigned)nc;
    if (p > SIZE - len) { m->stat = "ADR"; return; }
    const unsigned a = nr ? m->mem[p + 1] >> 4 : NONE, b = nr ? m->mem[p + 1] & 15 : NONE;
    const bool good = member(op, 0x74) ? a < NONE && b < NONE :
                      member(op, 0x1008) ? a == NONE && b < NONE :
                      member(op, 0xc00) ? a < NONE && b == NONE : true;
    if (!good) { m->stat = "INS"; return; }
    const uint64_t c = nc ? word(m, p + 1 + (unsigned)nr) : 0;
    const unsigned sa = member(op,0x454) ? a : member(op,0xa00) ? RSP : NONE;
    const unsigned sb = member(op,0x1070) ? b : member(op,0xf00) ? RSP : NONE;
    const uint64_t va = sa == NONE ? 0 : m->reg[sa], vb = sb == NONE ? 0 : m->reg[sb];
    unsigned de = member(op,0x104c) ? b : member(op,0xf00) ? RSP : NONE;
    const unsigned dm = member(op,0x820) ? a : NONE;
    const uint64_t aa = member(op,0x44) ? va : member(op,0x1038) ? c :
                        member(op,0x500) ? UINT64_MAX - 7 : member(op,0xa00) ? 8 : 0;
    CC newcc;
    const uint64_t ve = alu(op == 6 ? fn : 0, aa, vb, &newcc);
    const bool taken = op == 2 || op == 7 ? condition(fn,m->cc) : true;
    if (op == 2 && !taken) de = NONE;
    const bool read = member(op,0xa20), write = member(op,0x510);
    const uint64_t addr = member(op,0xa00) ? va : ve;
    if ((read || write) && addr > SIZE - 8) { m->stat = "ADR"; return; }
    const uint64_t vm = read ? word(m,addr) : 0;
    const uint64_t nextpc = op == 8 || (op == 7 && taken) ? c : op == 9 ? vm : p + len;
    if (m->previous_load != NONE && (m->previous_load == sa || m->previous_load == sb)) ++m->loads;
    m->previous_load = dm;
    ++m->steps;
    if (op == 7 && !taken) ++m->misses;
    if (op == 9) ++m->rets;
    if (op == 0) { m->stat = "HLT"; return; }
    if (write) put_word(m,addr,op == 8 ? p + len : va);
    if (de != NONE) m->reg[de] = ve;
    if (dm != NONE) m->reg[dm] = vm; /* M write wins for popq %rsp. */
    if (op == 6 || op == 12) m->cc = newcc;
    m->pc = nextpc;
}
static void report(const Machine *m) {
    static const char *const names[] = {"rax","rcx","rdx","rbx","rsp","rbp","rsi","rdi",
                                       "r8","r9","r10","r11","r12","r13","r14"};
    printf("steps=%u status=%s pc=0x%03" PRIx64 " cc=%d%d%d\n",m->steps,m->stat,m->pc,m->cc.z,m->cc.s,m->cc.o);
    printf("load-use=%u mispredict=%u ret=%u\n",m->loads,m->misses,m->rets);
    for (unsigned i = 0; i < 15; ++i) printf("%s=0x%016" PRIx64 "\n",names[i],m->reg[i]);
    uint64_t digest = UINT64_C(14695981039346656037);
    for (unsigned i = 0; i < SIZE; ++i) digest = (digest ^ m->mem[i]) * UINT64_C(1099511628211);
    printf("memory-fnv64=%016" PRIx64 "\n",digest);
}

MASK = (1 << 64) - 1
SIZE, NONE, RSP = 4096, 15, 4
NAMES = ('rax', 'rcx', 'rdx', 'rbx', 'rsp', 'rbp', 'rsi', 'rdi',
         'r8', 'r9', 'r10', 'r11', 'r12', 'r13', 'r14')

def cond(fn, z, s, o):
    return (True, (s != o) or z, s != o, z, not z,
            s == o, (s == o) and not z)[fn]


def alu(fn, a, b):
    r = ((b + a) if fn == 0 else (b - a) if fn == 1 else
         (b & a) if fn == 2 else (b ^ a)) & MASK
    sa, sb, sr = a >> 63, b >> 63, r >> 63
    overflow = (sa == sb and sr != sb) if fn == 0 else (
        (sa != sb and sr != sb) if fn == 1 else False)
    return r, (r == 0, bool(sr), overflow)


def control(load_use, mispredict, returning, memory_bad, writeback_bad):
    return (load_use or returning, load_use,
            mispredict or (returning and not load_use),
            load_use or mispredict, memory_bad or writeback_bad, writeback_bad)


def forward(src, raw, sources):
    # sources are ordered: e_valE, m_valM, M_valE, W_valM, W_valE.
    for dst, value in sources:
        if src != NONE and src == dst:
            return value
    return raw


def check_logic():
    checks = 0
    for l in (False, True):
        for b in (False, True):
            if l and b:  # E cannot be both a load and a branch.
                continue
            for r in (False, True):
                for m in (False, True):
                    for w in (False, True):
                        f, ds, db, eb, mb, ws = control(l, b, r, m, w)
                        if ds and db or (l and not (f and ds and eb)):
                            raise RuntimeError('pipeline control conflict')
                        if mb != (m or w) or ws != w:
                            raise RuntimeError('exception ordering')
                        checks += 1
    if forward(4, 0, [(15, 0), (4, 5), (4, 264), (15, 0), (15, 0)]) != 5:
        raise RuntimeError('pop forwarding priority')
    if forward(2, 0, [(2, 3), (15, 0), (2, 10), (15, 0), (15, 0)]) != 3:
        raise RuntimeError('latest producer priority')
    return checks


class Machine:
    def __init__(self, image):
        if len(image) > SIZE:
            raise ValueError('image exceeds 4096 bytes')
        self.mem = bytearray(SIZE)
        self.mem[:len(image)] = image
        self.reg = [0] * 15
        self.pc, self.cc, self.stat = 0, (True, False, False), 'AOK'
        self.steps = self.loads = self.misses = self.rets = 0
        self.previous_load = NONE
        self.trace = []

    def word(self, addr):
        if addr > SIZE - 8:
            raise IndexError('word address')
        return int.from_bytes(self.mem[addr:addr + 8], 'little')

    def step(self):
        p = self.pc
        if p >= SIZE:
            self.stat = 'ADR'
            return
        op, fn = self.mem[p] >> 4, self.mem[p] & 15
        if op > 12 or fn > (6 if op in (2, 7) else 3 if op == 6 else 0):
            self.stat = 'INS'
            return
        nr, nc = op in (2, 3, 4, 5, 6, 10, 11, 12), op in (3, 4, 5, 7, 8, 12)
        length = 1 + nr + 8 * nc
        if p > SIZE - length:
            self.stat = 'ADR'
            return
        a, b = (self.mem[p + 1] >> 4, self.mem[p + 1] & 15) if nr else (NONE, NONE)
        good = (a < NONE and b < NONE) if op in (2, 4, 5, 6) else (
            a == NONE and b < NONE) if op in (3, 12) else (
            a < NONE and b == NONE) if op in (10, 11) else True
        if not good:
            self.stat = 'INS'
            return
        c = self.word(p + 1 + nr) if nc else 0
        sa = a if op in (2, 4, 6, 10) else RSP if op in (9, 11) else NONE
        sb = b if op in (4, 5, 6, 12) else RSP if op in (8, 9, 10, 11) else NONE
        va, vb = (self.reg[sa] if sa != NONE else 0), (self.reg[sb] if sb != NONE else 0)
        de = b if op in (2, 3, 6, 12) else RSP if op in (8, 9, 10, 11) else NONE
        dm = a if op in (5, 11) else NONE
        aa = va if op in (2, 6) else c if op in (3, 4, 5, 12) else (
            MASK - 7 if op in (8, 10) else 8 if op in (9, 11) else 0)
        ve, cc = alu(fn if op == 6 else 0, aa, vb)
        taken = cond(fn, *self.cc) if op in (2, 7) else True
        if op == 2 and not taken:
            de = NONE
        read, write = op in (5, 9, 11), op in (4, 8, 10)
        addr = va if op in (9, 11) else ve
        if (read or write) and addr > SIZE - 8:
            self.stat = 'ADR'
            return  # Failed memory operation has no architectural writes.
        vm = self.word(addr) if read else 0
        nextpc = c if op == 8 or op == 7 and taken else vm if op == 9 else p + length
        if self.previous_load != NONE and self.previous_load in (sa, sb):
            self.loads += 1
        self.previous_load = dm
        self.steps += 1
        self.misses += op == 7 and not taken
        self.rets += op == 9
        self.trace.append((p, op, fn, taken, sa, sb, dm))
        if op == 0:
            self.stat = 'HLT'
            return
        if write:
            data = p + length if op == 8 else va
            self.mem[addr:addr + 8] = data.to_bytes(8, 'little')
        if de != NONE:
            self.reg[de] = ve
        if dm != NONE:
            self.reg[dm] = vm  # M write wins for popq %rsp.
        if op in (6, 12):
            self.cc = cc
        self.pc = nextpc

    def run(self):
        while self.stat == 'AOK' and self.steps < 1000000:
            self.step()
        if self.stat == 'AOK':
            raise RuntimeError('instruction limit exceeded')

    def report(self):
        print(f'steps={self.steps} status={self.stat} pc=0x{self.pc:03x} cc=' +
              ''.join(str(int(x)) for x in self.cc))
        print(f'load-use={self.loads} mispredict={self.misses} ret={self.rets}')
        for i, name in enumerate(NAMES):
            print(f'{name}=0x{self.reg[i]:016x}')
        digest = 14695981039346656037
        for value in self.mem:
            digest = ((digest ^ value) * 1099511628211) & MASK
        print(f'memory-fnv64={digest:016x}')


def main():
    try:
        if len(sys.argv) > 2:
            raise ValueError('usage: ch04_machine.py [image.bin]')
        image = open(sys.argv[1], 'rb').read(SIZE + 1) if len(sys.argv) == 2 else DEMO
        print(f'control-cases={check_logic()} forwarding-cases=2')
        machine = Machine(image)
        machine.run()
        machine.report()
        return 0
    except (OSError, ValueError, RuntimeError) as error:
        print(str(error), file=sys.stderr)
        return 2

/* Pointer bubblesort and the switch table's mathematical reference. */
#include <inttypes.h>
#include <stdint.h>

static void bubble_p(int64_t *data, size_t count) {
    if (count < 2) return; /* Avoid forming a pointer before the array. */
    for (int64_t *last = data + count - 1; last > data; --last) {
        for (int64_t *p = data; p < last; ++p) {
            if (p[1] < p[0]) {
                const int64_t t = p[1];
                p[1] = p[0];
                p[0] = t;
            }
        }
    }
}

补充实验 · 理想流水线时间模型

两份程序使用 300、200、400 ns 的三级组合延迟，每个输出寄存器的开销为 20 ns。串行实现由全部组合逻辑连接到一个输出寄存器，一项用时 300+200+400+20=920 ns；流水实现每级带一个寄存器，时钟周期取 400+20=420 ns。设任务彼此独立、每项都经过三级且没有停顿：

Tserial(n)=920n ns,Tpipe(n)=420(n+2) ns

第一项需要三级，后面每项只再增加一拍，所以流水总周期为 n+2；C 直接代入公式，Python 枚举三级占用来核对这一周期数。一次任务时流水用 1260 ns，四次任务时用 2520 ns，已经小于串行的 3680 ns。最后一行另给四条有效指令、一周期停顿的五级模型，共 4+5−1+1=9 周期。

n=1 seq-ns=920 pipe-cycles=3 pipe-ns=1260
n=4 seq-ns=3680 pipe-cycles=6 pipe-ns=2520
n=10 seq-ns=9200 pipe-cycles=12 pipe-ns=5040
five-stage=4 instructions,1 stall,9 cycles

这些是理想模型结果。若要修改完整 Y86-64 控制逻辑，应使用原书配套模拟器，并以 ISA 状态对照验证；本例只核对上述代数和调度时间。

自测 4-1 · 最慢阶段

问题

阶段延迟为 100、100、500 ns，寄存器开销 20 ns。能否以 240 ns 作为流水时钟？

解答

不能。500 ns 阶段无法在 240 ns 周期中形成稳定结果，统一时钟至少为 520 ns。平均数不代表关键路径；即使其他级空闲，最慢一级仍限制连续产出。

自测 4-2 · load-use

问题

为什么仅有转发还不能让紧邻 load 的数据使用者完全不停顿？

解答

load 的正确值到 M 阶段才形成，而消费者原计划更早进入 E；转发解决“值没写回”，不能让尚未产生的值提前出现。延迟消费者一周期之后，时间关系才成立。

自测 4-3 · 错误路径

问题

为什么分支预测错误要注入气泡，不能只把 PC 改回来？

解答

错误路径指令已经进入流水寄存器，只改 PC 会让它们继续前进并可能写寄存器或内存。需要清除相应年轻指令的效应，保留较老的有效指令，再从正确位置取指。

原题（中文翻译）

4.4 · 真正可执行的递归乘积

原题（中文翻译）

来源：印刷 406 页 / PDF 407 页

根据以下 C 程序编写递归函数 rproduct 的 Y86-64 代码。采用 x86-64 相同的参数传递和寄存器保存约定。提示：可先编译 C，再把所得指令翻译为 Y86-64。

long rproduct(long *start, long count) {
    if (count <= 1)
        return 1;
    return *start * rproduct(start+1, count-1);
}
题干校注：书末解答混用了 count<=0、xorq 清零却注释为1以及基础ISA不存在的 imulq；此处保留原题条件并给基础指令实现。

解答

按题面，count=1 返回 1，所以 count>1 时只乘前 count−1 项。例如 [2,3,5]、count=3 的结果是 2×3×1=6。下面严格保留这个条件，先用 count−1 与零比较。%rbx 跨递归保存当前元素，作为被调用者保存寄存器必须入栈和恢复。

rproduct:
    irmovq $1,%rax
    rrmovq %rsi,%rdx
    subq %rax,%rdx
    jle rp_done
    pushq %rbx
    mrmovq 0(%rdi),%rbx
    irmovq $8,%r10
    addq %r10,%rdi
    irmovq $1,%r10
    subq %r10,%rsi
    call rproduct
    rrmovq %rax,%rsi
    rrmovq %rbx,%rdi
    call mul64
    popq %rbx
rp_done:
    ret
# %rdi * %rsi mod 2^64 -> %rax; 64 bit positions.
mul64:
    xorq %rax,%rax
    irmovq $1,%rcx
mul_loop:
    rrmovq %rsi,%rdx
    andq %rcx,%rdx
    je mul_skip
    addq %rdi,%rax
mul_skip:
    addq %rdi,%rdi
    addq %rcx,%rcx
    jne mul_loop
    ret

基础 Y86-64 没有 imulq，mul64 用逐位乘法：第 j 轮，%rcx=2ʲ、%rdi=原乘数×2ʲ；若另一乘数的该位为 1 就累加。%rcx 连续加倍 64 次后回到零，循环恰好停止。算术全部按模 2⁶⁴；在所有中间乘积可由 C 的 long 表示时，与题面 C 的结果相同。若需要通常定义的“乘 count 项”，应明确把基例改为 count≤0；同一输入才得 30。

修改图 4.6 的 sum，实现 absSum，计算数组各元素绝对值之和；要求在内循环中使用条件跳转指令。

4.6 · 以条件移动求绝对值和
