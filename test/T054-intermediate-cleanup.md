## 前置条件与边界

使用实时精确清单和 SHA-256，保留原 Git 状态、正式资料与证据文件。只选择 Git 忽略的普通单链接文件，拒绝路径越界、符号链接、共享硬链接、活动占用和构建锁。公式、精度、币种及时区计算均不适用；异常、重复和恢复边界以下列场景核对。

## 场景

- CL054-01：目标须来自已完成生成流程；失败/运行中的检查、最新检查和被正式资料直接引用的文件保留。
- CL054-02：压缩恢复包的成员集合、路径、长度与 SHA-256 必须逐文件匹配清单，校验完成前不移除原件。
- CL054-03：移除前再次核对目标元数据、字节、Git 和活动占用；移除后目标残留数为零，保留文件无缺失或非预期变更。
- CL054-04：恢复器按原路径恢复并拒绝覆盖已有路径；实际抽样恢复站点文件、测试包和编译产物并检查字节与模式。
- CL054-05：`python3 tools/project.py check --quick`、`pnpm check:parity` 如实保存退出码和日志；未执行内容重审或生产操作。
