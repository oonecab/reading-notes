# T039：四类教学组件样章验证

关联 [I039](../issues/I039-reading-components-sample.md)。本记录仅针对本地提案，不代表正式发布。

证据目录：`tmp/reading-components-preview/`。复现命令：`python3 tools/project.py preview-components`。

## 内容与结构

生成器从 56 个受控源页生成清单，枚举 1,525 个习题/自测容器。第一章副本转换 38 个陈述、56 个例题、31 个证明和 77 道习题；逐字保护 5,159 个 MathML、1 个 SVG、2 个 pre 和 2 个 code，保留 262 个锚点、523 个链接及原有文本。12 组五书片段同样通过保护检查，视觉群论仅有一个明确记录的新增“证明”标签。

`report.json` 保存每页输入哈希、样章数量与保护对象哈希。改动公式数值的负例被拒绝。链接在内容比较后重定位到本机原文件；12 组片段所用本机文件目标均存在。本检查不重新判断数学与来源正确性。

最终 CSS SHA-256：`964e2b4a349347ea0c2239d4c713b8af55ad6ee4e037a53f001285874b981ae5`。

## 浏览器与实际阅读

Ego TaskSpace 17，桌面 Chromium；本轮结束时保留样章入口供用户审阅。浏览器报告均绑定上面的最终 CSS 哈希。

- `browser-matrix.json`：12 个片段与 1 个完整章 × 1800/1440/1024/390px，共 52 视图。展开全部正文 details 后 0 整页横向溢出、0 未被局部滚动容器承接的宽内容。所有证明初始展开，所有习题初始收起。题干、解答与证明标签统一为 15.2px、650 字重、绿色及 26.6px 行高。
- `nojs-matrix.json`：13 页 × 1440/390px，共 26 视图，0 整页横向溢出。完整章的增强脚本 class 为空，确认脚本被禁用。
- `nojs-interactions.json`：在同一个禁用脚本的浏览器调用中，390px 实际用键盘展开习题、关闭及重新展开证明；原题、答案、证明正文均可读。
- `proof-navigation.json`：390px 通过原生 summary 收起证明，再点击原陈述的完整证明链接；证明重新展开，顶部位于 90.2px，避开约 53px 高的固定目录栏。四档最终锚点位置另记在 `browser-matrix.json.navigation`。
- `preview-ui.json`：入口和前后对照页在桌面/窄屏无整体溢出；Weiss C/Python 代码保持局部横滚。390px 的首个代码框宽 291px、内容宽 567px，实际滚动至 160px，整页宽度仍为 375px（另有系统滚动条）。

实际打开 36 个独立位置的截图：12 个片段 × 桌面/窄屏（24），完整章证明 × 4 档（4），无 JS 习题/证明（2），样章入口/对照页 × 桌面/窄屏（4），C/Python 代码细读 × 桌面/窄屏（2）。最终修改影响的证明、来源对齐及锚点位置重新打开复核。完整章页头另有自动截图，未计入 36 个目视位置。

目视发现并修正三项样章问题：随机过程长证明段落偏紧；视觉群论习题的独立来源行未继承题干内边距；窄屏新组件的 24px 锚点留白被固定目录遮挡，现针对完整页改为 90px。浏览器跨调用会恢复部分 CDP 设置，因此最终无 JS 操作在同一调用内重新设置禁用脚本和 390px，并读回宽度与增强 class；不采用早期命名为 390px、实际恢复了默认视口的截图作为窄屏证据。
