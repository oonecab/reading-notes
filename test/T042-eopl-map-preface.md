# T042：EOPL 地图与序言验证设计

关联 [I042](../issues/I042-eopl-map-preface.md) / [P042](../plan/P042-eopl-map-preface.md)。规则权威为 RN-001 v1.2 与本批正式正文。

## 场景

- 来源：核对 433 页 PDF 的 SHA-256、第三版版权信息、九章与两篇附录的起止页；前置罗马页码与正文阿拉伯页码分段登记。原书编号清单从 PDF 提取建立，原书疑点单独记录。
- 内容：区分 Foreword 与 Preface，覆盖 Goal、六项方法、第三版变化、Organization、Usage 与完整习题 0.1；地图区分原书章节范围与已写页面。
- 示例：以封闭的小型 AST 解释器核对词法作用域下闭包使用创建环境、遮蔽与错误分支；手算预期独立于解释器，动态作用域变体必须使区分用例得到不同结果。明确 Python 宿主模型与原书 Scheme 解释器的边界。
- 静态：两页入口与相互导航、目录锚点、源码阅读副本、来源/引用/习题 0.1 的绑定、图可访问名称及表头语义。缺失已登记锚点、页序错位、示例漂移应失败。
- 阅读：最终两页分别在 1800、1440、1024、390px 观察正文、图与代码；操作目录、跨页、深链、习题原生展开和程序下载；在无 JS 状态检查正文及习题可读。
- 集成：准备批通过既有受控资源展开器生成独立 HTML，核对内容字节和本地入口；旧书公共回归从根入口执行。正式 catalog 和历史基线在代表章接入时登记；未注册本书的公共发布构建不计作本书验收。

本批没有币种、时间边界或数值近似规则。示例整数采用 Python 整数，只用于有限教学输入。未知变量、非法 AST、非数值运算与非过程调用属于失败用例。
